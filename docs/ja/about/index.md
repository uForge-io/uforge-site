# μForge.ioについて { #about-forgeio }

新しいMCUを評価する際、エンジニアがデータシートやWiki、フォーラムを個別に調べて全体像をつなぎ合わせる必要はありません。**μForge.ioは、そうした手間を減らすためのサイトです。**

私たちは、SiFliのSF32シリーズに関する情報を、製品開発の流れに沿って一貫したドキュメントとしてまとめています。SF32は、ウェアラブル端末やスマートディスプレイなど、バッテリー駆動のコネクテッド製品向けの超低消費電力MCUです。Bluetooth接続とグラフィックス処理に対応し、AIoT用途も視野に入れています。チップやモジュールの選定、開発ボード、SDKの使い方、ハードウェア設計ガイド、量産チェックリストを集約し、部品の選定、動作検証、設計への組み込み、出荷という実際の開発手順に沿って整理しています。技術情報は、参照できる資料がある場合にSiFliの公式資料と照合し、追加確認が必要なページにはその旨を示しています。

SF32を選んだ理由は二つあります。一つ目は、複数のコア構成があり、グラフィックスアクセラレーションやハードウェア解凍を備えていることです。具体的な組み合わせはファミリーによって異なります。二つ目は、SDK、ハードウェア設計ガイド、ソースコードがオープンである一方、エコシステムの知名度はESP32やSTM32ほど高くないことです。この「開発資源の公開」と「エコシステムの認知度」の隔たりを埋めることが、当サイトの目的です。

目標はシンプルです。エンジニアがハードウェアとファームウェアに関する判断を、より速く、確かな根拠をもって行えるようにすることです。基本事項を何度も調べ直す手間を減らし、その分を製品開発に充てられるようにします。

## 名称について { #the-name }

μForge.io と uForge.io は同一のプロジェクトで、相互に置き換えて使われます。「μ」（ギリシャ文字のミュー、micro＝マイクロ）はギリシャ文字を入力しにくい場面で ASCII の「u」（you＝あなた、とも読む）と書かれ、μForge = uForge、μForge.io = uForge.io（ドメインは uForge.io）です。
