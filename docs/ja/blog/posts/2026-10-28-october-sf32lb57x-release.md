# 10月：SF32LB57xのご紹介 [2026-10-28] { #october-sf32lb57x-2026-10-28 }

今月、μForge.ioにSF32LB57xファミリーを追加しました。SF32LB52xとSF32LB56xの強化版であり、CPU演算性能とグラフィックス機能が大きく向上しながら、非常に競争力のあるコスト構造を維持しています。

### より高いCPU演算性能 { #more-cpu-power }

SF32LB52xとSF32LB56xは、いずれも240 MHzのCortex-M33アプリケーションコア1つと低消費電力コアを組み合わせています。SF32LB57xは、240 MHzのCortex-M33 STAR-MC1高性能コア2つに加え、専用Bluetoothコントローラーとして動作する24 MHzの低消費電力コアを搭載します。2つの高性能コアの合計性能は1968 CoreMark / 740 DMIPSで、SF32LB56xのアプリケーションコア（984 CoreMark / 370 DMIPS）の約2倍です。この余裕により、UI描画、アプリケーション処理、オーディオやマルチメディア処理を1つのコアで奪い合うことなく別々のコアで実行でき、Bluetoothやセンサーのタスクはそのまま低消費電力側で処理できます。

### より強力なグラフィックス機能 { #more-graphics-capability }

グラフィックスはePicasso 3.0とeZip 3.0ハードウェア展開に進化しました（SF32LB52xはePicasso 2.0 Lite、SF32LB56xはePicasso 2.0）。ePicasso 3.0はリアルタイムの回転、拡大縮小、投影、ミラー、アルファブレンドを高速化し、eZip 3.0はeZip、JPEG、MJPEGのアセットをCPUに重いデコード処理を課さずに展開します。コア以外にも、DCMIカメラ入力、一部の型番で最大48 MBのパッケージ内PSRAMと32 MBのパッケージ内NORフラッシュ、2系統のオーディオADC、2系統のCANインターフェース、そしてタイミングに敏感な周辺処理をオフロードする並列タスクマシンPTMを備えています。

### 競争力のあるコスト構造 { #competitive-cost-structure }

性能の向上は、SF32LB57xを別のコスト帯に押し上げるものではありません。私たちは、この演算性能とグラフィックス機能に対して非常に競争力のあるコスト構造を維持していると考えています。コンパクトなQFN68（7 × 7 mm）、QFN80（8 × 8 mm）、BGA112（5.4 × 4.4 mm）のパッケージも、基板サイズと複雑さの抑制に役立ちます。より豊かなスマートウォッチUI、カメラ付きハンドヘルド、ディスプレイ中心の小型端末など、SF32LB52xやSF32LB56xでは足りなくなった製品に、フラッグシップ級のプラットフォームへ移行せずに応える自然な選択肢です。

### ドキュメントと始め方 { #documentation-and-where-to-start }

[SF32LB57xチップページ](../../sf32-products/chips/SF32LB57x.md)で詳しい概要を確認でき、型番は[製品セレクター](../../sf32-products/product-selector.md)に登録されています。[ハードウェア設計ガイド](../../hardware/chip-guides/SF32LB57x_hardware_design_guide.md)は、他のファミリーと同様に回路図、PCBレイアウト、チェックリスト、レビューの構成です。回路図を流用する前に、発注可能な正確な型番を選んでください。パッケージと電源構成によって、使用可能なGPIO数などが決まるためです。最終的な数値はSiFliのデータシートで確認してください。
