# ファームウェアのトピック { #firmware-topics }

これらはプラットフォームを問わず共通するトピックです。サンプルを製品化する際に必要となる、ブート構成、パーティション、OTA、USB、電源管理、ログ、クラッシュ解析を扱います。

ファームウェアの構成、更新動作、低消費電力方針を変更する前に、各ページを確認してください。設定に誤りがあってもビルドが成功する場合がありますが、製品の復旧、デバッグ、出荷が難しくなるおそれがあります。

## 実務上の原則 { #practical-rule }

起動、OTA、ファイルシステム、ストレージの動作を変更する前に、パーティションテーブルを確認し、復旧手段を検証してください。アプリケーションの不具合は不便ですが、起動／更新用のパーティション構成を誤ると、ボードの復旧が困難になる場合があります。

## 製品出荷準備チェックリスト { #product-readiness-checklist }

- [ ] 通常のOTA経路に頼らずデバイス全体を書き込める、検証済みのコマンドを用意している。
- [ ] パーティション配置が製品リポジトリーに記録されている。
- [ ] OTA/DFUの失敗時の動作を試験済みである。
- [ ] USBを使う場合、USBディスクリプターとVID/PIDの管理元が記録されている。
- [ ] 実機で低消費電力モードを測定している。
- [ ] リリース版のバイナリを使ってクラッシュログをデコードできる。
- [ ] 工場での書き込み手順と開発時の書き込み手順を分けている。
