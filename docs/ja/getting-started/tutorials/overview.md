# チュートリアルの概要 { #tutorials-overview }

このシリーズでは、初回のファームウェア書き込みに成功した後、実践的なSF32開発スキルを段階的に身につけます。まず個々のペリフェラルの動作を確認し、次にサブシステムを組み合わせ、最後に製品化に必要な検証結果をそろえます。SiFli-SDKのサンプルを出発点としますが、ハードウェアの確認、動作する基準構成の維持、結果の測定は、どのSF32ソフトウェア環境でも役立つ基本です。

チュートリアルは[はじめに](../index.md)の第二段階です。まずは、そこに記載された初回起動の成功条件を満たしてください。チップ、モジュール、開発ボードを選定中の場合は、このシリーズを始める前に[SF32ファミリー](../../sf32-products/family/SF32_family.md)を確認してください。

## 必要なもの { #what-you-need }

動作するUSBデータ接続とシリアルコンソールを備えたSF32開発ボードを使用してください。たとえば、`sf32lb52-lcd_n16r8`はSF32LB52-DevKit-LCD_N16R8のSiFli-SDK上のボード名です。本シリーズでは、すべての演習を1枚のボードで実行できるとは限りません。各サンプルの対応プラットフォームを確認し、関連する回路図とボードファイルでピン、ペリフェラル、ディスプレイ、オーディオ、ストレージの詳細を確認してください。SF32LB52xのSDKボード識別子は、公式の[対応ボード一覧](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/supported_boards/index.html)を参照してください。

<div align="center"><em>表: チュートリアルの前提条件</em></div>

<div align="center" markdown>

| 項目 | 開始前の確認項目 |
|:-----|:------------------------|
| ツールチェーン | SiFli-SDKでお使いのボード向けの動作確認済みサンプルをビルドできる。 |
| 書き込み手順 | セットアップを変更せずに、ボードへ繰り返し書き込みできる。 |
| シリアルコンソール | ブートログを確認でき、FinSHの`msh>`プロンプトにアクセスできる。 |
| ボード情報 | ピンやペリフェラルを割り当てる前に、ボードの回路図またはサポートファイルを入手している。 |
| 測定ツール | 必要に応じてマルチメーターやロジックアナライザーを使い、低消費電力の検証では適切な電流測定環境を用意する。 |

</div>

## おすすめの学習順序 { #recommended-learning-path }

<div align="center"><em>表: チュートリアルロードマップ</em></div>

<div align="center" markdown>

| 学習目標 | 開始条件 | 学ぶ内容 | 次に進む条件 |
|:------|:-----------|:------------------|:--------------|
| [ペリフェラル入門](beginner.md) | `hello_world`をビルドして書き込み、シリアル出力を確認できている。 | GPIO、FinSH、ADC、PWM、RTC、小規模なボードレベルのプロジェクト。 | 入力、出力、基本的なペリフェラルの動作を自分で確認できたら次に進みます。 |
| [複数サブシステムの連携](intermediate.md) | 個々のペリフェラルが安定して動作している。 | I2Cセンサー、LVGL、BLE、オーディオ、ストレージ、複数機能の併用テスト。 | 実機で二つのサブシステムを同時に動かしても安定することを確認できたら次に進みます。 |
| [製品検証](advanced.md) | ミドルウェアを統合でき、一般的な問題を診断できる。 | 消費電力の実測、OTAからの復旧、カスタムディスプレイ、クラッシュ解析、複数接続BLE、再利用可能なドライバー。 | 実装時の継続的な参考資料として、開発・学習に関する記事を活用してください。 |

</div>

この順序には理由があります。ボード、書き込み手順、シリアルコンソール、簡単なGPIOテストが正常に動作することを確認するまでは、ディスプレイ、BLEサービス、カスタムドライバーから始めないでください。後のチュートリアルで問題が起きたら、成功条件をまだ再現できる最後の段階まで戻ってください。

## 各チュートリアルの使い方 { #how-to-use-each-tutorial }

各演習では、関連するSDKサンプル、目標、成功基準、失敗時に確認すべき点を明示しています。空のプロジェクトではなく、指定されたサンプルから始め、一度に一つの動作だけを変更し、機能を組み合わせる前に動作確認済みのビルドを保持してください。再利用を想定している構成については、ボードリビジョン、SDKバージョン、ボード名、観測した結果を記録してください。

チュートリアルはリファレンス資料を補完するものであり、代替ではありません。

- プラットフォームの作業手順、ツール、ファームウェアのトピック、SDKサンプルの一覧は[開発](../../develop/index.md)を参照してください。
- グラフィックス処理フロー、Bluetoothの挙動、電力設計など、アーキテクチャやサブシステムの判断には[学習](../../learn/graphics/overview.md)を参照してください。
- デバイス選定、ボード情報、ハードウェア設計指針、量産チェックには[SF32ファミリー](../../sf32-products/family/SF32_family.md)を使用してください。
