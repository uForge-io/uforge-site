# SF32LB52xハードウェア設計ガイド { #sf32lb52x-hardware-design-guide }

## 1. はじめに { #1-introduction }

本書は、超低消費電力AIoTマイクロコントローラーSF32LB52xファミリーを採用する製品向けに、設計上の推奨事項と出典に基づく参考情報をまとめたハードウェア設計ガイドです。バッテリー駆動のウェアラブル機器や小型組み込みシステムを開発するハードウェアエンジニア、PCB設計者、製品開発者を対象としています。

電源設計、クロック回路、RFレイアウト、ディスプレイ／ストレージインターフェース、オーディオ回路、PCBレイアウト、製造上の考慮事項まで、ハードウェア開発プロセス全体を扱います。本書の指針は、開発リスクの低減、システムの信頼性向上、製品開発期間の短縮に役立ちます。

本書は、組み込みハードウェア設計と回路図作成の基礎知識を前提としています。詳細な電気仕様、周辺機能の動作、ソフトウェア開発については、SF32LB52xのデータシート、リファレンスマニュアル、SDKドキュメントを参照してください。これらの公式資料が最終的な根拠となります。

SiFliの元のハードウェアアプリケーションノート2件（バッテリー駆動のSF32LB520/3/5/7向けと、外部レギュレーターで給電する52B/D/E/G/J向け）を、1つの設計ワークフローに統合しています。元資料の表現に揺れがある場合は、正確な発注型番、電源ドメインの明確な動作説明、リリースレビュー時の分かりやすさを優先します。

## 3. デバイス概要 { #3-device-overview }

SF32LB52xファミリーは、デュアルコアSTAR-MC1プロセッサー、Bluetooth接続、グラフィックスアクセラレーター、オーディオ機能、ディスプレイインターフェース、ストレージコントローラー、電源管理を小型のQFN68パッケージに統合しています。BOMコスト、バッテリー駆動時間、PCB面積のすべてが重要となる製品に適しています。

### 3.1. 特長 { #31-features }

本ファミリーには次の機能が統合されています。

- Arm Cortex-M33互換で、FPUとMPUを備えたデュアルコアArm China STAR-MC1プロセッサー
- デュアルモードBluetooth 5.3無線機能
- ePicasso 2.0 2D/2.5Dグラフィックスアクセラレーター
- SPI、QSPI、8080、JDI、8ビットEPDインターフェースに対応するディスプレイコントローラー
- USB 2.0 Full-Speedデバイス
- 対応バリアントで利用できるSDIO/eMMCストレージインターフェース
- アナログ／デジタルオーディオインターフェース
- PMU、DC/DCコンバーター、LDOレギュレーターを内蔵
- 最大44/45本のGPIOを備えるQFN68パッケージ

### 3.2. バリアント { #32-variants }

SF32LB52xファミリーは、電源アーキテクチャに応じて、バッテリー駆動デバイスと外部レギュレーター給電デバイスの2つの設計グループに分かれます。

=== "SF32LB520/3/5/7 (バッテリー駆動)"

    このグループは、チップ内に**充電管理モジュールとPMU**を搭載しています。単セルのリチウムイオンバッテリーに直接接続できるほか、外付け充電方式にも対応します。

    |:---|:---|:---|:---|
    | SF32LB520U36 | 1 MB QSPI-NOR Flash | リチウムイオンバッテリー、3.2～4.7 V、充電式 | デフォルトでは同一パッケージ内のFlashから起動。`VDD18_VOUT`には外部3.3 V電源が必要 |
    | SF32LB523UB6 | 4 MB OPI-PSRAM | リチウムイオンバッテリー、3.2～4.7 V、充電式 | 外部ストレージから起動する必要あり |

    | SF32LB52BU56 | 4 MB QSPI-NOR Flash | 2.97～3.63 V、充電不可 | `VDD_SIP`には外部3.3 V電源が必要 |

    | SF32LB52JUD6 | 16 MB OPI-PSRAM | 2.97～3.63 V、充電不可 | `VDD_SIP`は内蔵LDOから給電可能 |

### 3.4. 用途 { #34-applications }

長いバッテリー駆動時間と小型フォームファクターが重視される、携帯型の組み込みシステムに適しています。用途の例を以下に示します。

- エントリーモデルのスマートウォッチ、フィットネスバンド
- Bluetoothモジュール、ワイヤレスアダプター
- Bluetoothオーディオアクセサリー
- スマートセンサー、ウェアラブル機器
- 電子棚札、スマートバッジ
- 電子書籍リーダー
- 携帯型ラベルプリンター
- 電動自転車／電動スクーターのディスプレイ
- ネットワーク接続型のヒューマンマシンインターフェース (HMI) 機器
- 携帯型の産業機器、医療機器
- その他のバッテリー駆動AIoTデバイス

### 4.2. ハードウェア設計フロー { #42-hardware-design-flow }

通常、ハードウェア設計の決定事項が固まる順に本書を読み進めてください。以下のフローでは、回路図やPCBの詳細設計に入る前に、初期のアーキテクチャ選択を明確にします。

<div align="center"><em>表 4.2-1: ハードウェア設計フロー</em></div>

<div align="center" markdown>

| 手順 | 設計上の決定事項 | 主な参照セクション |
|:---|:---|:---|
| 1 | 正確な発注型番と電源バリアントを選択する | デバイス概要、バリアント選択 |
| 2 | パッケージ、GPIO数、専用機能ピンを確認する | パッケージ、回路図設計指針 |
| 3 | 最小システムを確定する: 電源ツリー、ブートストレージ、ブートストラップピン、デバッグアクセス、クロック、ウェイクアップ方針 | 最小システム設計、ストレージ、デバッグ、クロック生成 |
| 4 | RFトポロジー、ディスプレイ、オーディオ、センサー、その他の製品インターフェースを選定する | クロック生成、RF、ユーザーインターフェース、ストレージと接続性 |
| 5 | PCB積層、ファンアウト、インピーダンス、ノイズに敏感な信号の配線を確認する | PCBレイアウト指針 |
| 6 | 元資料の回路図、PCBレイアウト、機構図、電源図と照合する | 付録A～E |
| 7 | 立ち上げ、デバッグ、キャリブレーション、量産テスト用のアクセスを確保する | デバッグ、製造、設計レビュー用チェックリスト |

</div>

**設計判断フロー**

- USB経由で充電できる単セルバッテリー動作が必要ですか？`SF32LB520/3/5/7`から検討してください。
- 外部安定化電源またはeMMCブートが必要ですか？`52B/D/E/G/J`から検討してください。
- 8ビットパラレルEPDが必要ですか？SiFliが対象設計でバッテリー駆動経路を使えると確認しない限り、外部レギュレーター給電の設計経路を選んでください。
- 待機電流をできるだけ小さくする必要がありますか？PCB配置の前に、ストレージ電源のスイッチング、センサーのロードスイッチ、ディスプレイ電源の分離を決めてください。

### 4.3. 本書の使い方 { #43-how-to-use-this-guide }

回路図設計を始める前に、正確な発注型番を確認してください。SF32LB52xファミリーは、バッテリー駆動の`SF32LB520/3/5/7`グループと、外部レギュレーター給電の`52B/D/E/G/J`グループに分かれます。第 3.2 節でグループを選び、第 5.1 節と第 5.2 節で最小システムと電源システムを確認してください。第 5.6.1 節と第 5.7.1 節でブートストレージとデバッグアクセスを確認し、第 5 節と第 6 節で回路図およびPCBの指針をレビューします。付録A～Eは元資料の参考図との照合に使い、第 7 節をリリース前のチェックリストとして利用してください。

既存のSF32LB52x回路図を流用する場合は、まず電源ピン、SIPメモリー電源、ブートストレージ電源レール、DBG_UART/SWDピン、水晶振動子の負荷、RF整合回路のフットプリント、量産テストポイントを確認してください。これらは、立ち上げ時に見落とされやすいリスクの主な要因です。

### 4.4. レビュー証跡一式 { #44-review-evidence-pack }

ハードウェアをリリースする前に、回路図PDF、PCB積層情報、インピーダンスレポート、部品AVL照合結果、DRCレポート、RF、水晶振動子、USB、SDIO/eMMC、オーディオ、電源、ブートストレージのレイアウトを示すスクリーンショットを収集してください。後のファームウェア、RF、量産上の問題をレビュー済みのハードウェア基準構成に遡って確認できるよう、基板リビジョンと一緒に証跡を保管します。


## 5. チェックリストの使い方 { #using-the-checklists }

本書には2段階のチェックリストがあります。第 5.1.1.5 節、第 5.5.3 節、第 7 節に埋め込まれた簡易チェックリストは、リスクの高い項目を素早くセルフチェックするためのものです。[回路図チェックリスト](SF32LB52x_schematic_checklist.md)（第 5.8 節）と[PCBレイアウトチェックリスト](SF32LB52x_pcb_layout_checklist.md)（第 6.15 節）には、ハードウェア設計ガイドとともに[SiFliのWiki][SiFli チップハードウェア設計ガイド一覧 (Wiki)]で公開された [*SF32LB52回路図・PCBチェックリスト*][SiFli SF32LB52 回路図・PCB チェックリスト (XLSX)]（V1.0、2026-01-21）の全項目を掲載しています。対象は、バッテリー駆動のSF32LB520/3/5/7と外部電源駆動の52B/D/E/G/Jの両バリアントです。

両チェックリストの各項目には、適用されるSF32LB52xバリアントと、「必須（Required：リリース前に合格が必要）」または「任意（Optional：該当機能を使用する場合に推奨）」の区分が記載されています。特に絞り込みがない場合、「全バリアント（All variants）」はSF32LB520/3/5/7と52B/D/E/G/Jの両方を指します。色付き文字および<span class="flag-red flag-yellow">黄色の背景</span>は、元のスプレッドシートで強調されていた箇所です。強調理由は元資料に記載されていないため、同じ表の他の項目に代わるものではなく、追加のレビュー注意表示として扱ってください。チェックリストはスプレッドシートのレイアウトを維持していますが、元の記述が不完全、一貫しない、または短すぎる場合は、設計ガイド、データシート、リファレンスマニュアル、SiFliの型番ガイドと併せて確認してください。

[回路図チェックリスト](SF32LB52x_schematic_checklist.md)はPCBレイアウトを始める前の回路図レビュー時に、[PCBレイアウトチェックリスト](SF32LB52x_pcb_layout_checklist.md)はGerberリリース前のレイアウトレビュー時に使用してください。通常、それぞれ設計エンジニアが確認した後、設計凍結または製造リリースの前に独立したレビュアーがもう一度確認します。

チェックリストは読むだけでなく、承認記録として使うと効果的です。

1. まず対象シリコンの正確なバリアントを確認してください。特に520/3/5/7と52B/D/E/G/Jのどちらでも設計できる場合は注意が必要です。
2. 表を読むだけでなく、レビュー時に各項目を合格 / 不合格 / 該当なし (pass / fail / not applicable) で記録してください。
3. ブートメディア、ディスプレイの種類、電源スイッチの動作に関する項目は、実際の回路図と設計ガイドの該当するサブシステムの節を照合してください。
4. 元資料の表現が曖昧な場合は、リリース前に正確な型番と設計上の前提をレビュー記録に残してください。
