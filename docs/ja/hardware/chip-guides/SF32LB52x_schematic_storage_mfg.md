# SF32LB52xハードウェア設計ガイド — ストレージと製造 { #sf32lb52x-hardware-design-guide-storage-manufacturing }

!!! note "SF32LB52xハードウェア設計ガイドの一部"
    このページでは、回路図設計ガイドの「5.6ストレージと接続機能」および「5.7製造」を説明します。前のページは[RFとユーザーインターフェース](SF32LB52x_schematic_rf_interfaces.md)です。項目ごとの確認には[回路図チェックリスト](SF32LB52x_schematic_checklist.md)を使用してください。

### 5.6. ストレージと接続機能 { #56-storage-and-connectivity }

#### 5.6.1. ストレージ { #561-storage }

**要点**

- 外部SPI NOR、SPI NAND、SD NANDから起動できます。対応する外部レギュレーター給電版では、eMMCも使用できます。
- ブートストラップピン`PA13`と`PA17`でブートメディアを選択します。
- アプリケーションノートと回路図設計ガイドでは、ブートストレージの電源切り替えに`PA21`を指定しています。一方、公式チェックリストではバッテリー駆動版の外付けFlashに`PA11`を指定しています。具体的な設計で使用する制御ピンをSiFliに確認してください。別途、MPI接続の32 MB以上のNOR Flashは、リセットまたはHibernate移行後にROMが認識できるよう、`PA21`による電源再投入が必要です。また、Hibernate中は`VDD_SIP`をオフにし、パッケージ内蔵メモリーのI/Oを経由するリーク電流を防いでください。

**設計目標**

ファームウェア容量、更新方式、低消費電力状態に適合し、リセット後やHibernateからの復帰後にROMから確実に起動できるブートメディアとストレージ電源構成を選定します。

##### 5.6.1.1. ストレージインターフェース { #5611-storage-interface-description }

本チップは、外部SPI NOR Flash、SPI NAND Flash、SD NAND Flashに対応します。**eMMCに対応するのは、外部レギュレーター給電版の52B/D/E/G/Jのみです。**

|:---|:---|:---|
| CS# | PA12 | チップセレクト、アクティブLow |
| SO | PA13 | データI/O 1 |
| WP# | PA14 | データI/O 2 / 書き込み保護 |
| SI | PA15 | データI/O 0 |
| SCLK | PA16 | シリアルクロック |
| Hold# | PA17 | データI/O 3 / ホールド |

</div>

<div align="center"><em>表5.6-2: SD NAND FlashおよびeMMCの信号接続</em></div>

<div align="center" markdown>

|:---|:---|:---|
| SD2_CMD | PA15 | コマンド |
| SD2_D1 | PA17 | データ1 |
| SD2_D0 | PA16 | データ0 |
| SD2_CLK | PA14 | クロック |
| SD2_D2 | PA12 | データ2 |
| SD2_D3 | PA13 | データ3 |

</div>

!!! note "eMMCの電源ドメイン（外部レギュレーター給電版のみ）"
    eMMCにはVCCとVCCQの2つの電源ドメインがあります。選択肢1: 両方を同時に切り替えます。シャットダウン電流を抑えられますが、eMMCのスリープ復帰が遅くなり、CPUの平均消費電力は増加します。選択肢2: VCCのみを切り替え、VCCQは常時オンにします。選択肢1よりシャットダウン電流は増えますが、eMMCのスリープ復帰が速くなり、CPUの平均消費電力は低下します。

!!! important "ストレージインターフェースのプルアップ"
    外部レギュレーター給電版のアプリケーションノートでは、NOR Flashに外付けプルアップは不要、SPI NANDではPA17（Hold#）、SD NANDではPA13（D3）とPA15（CMD）、eMMCではPA17（D1）、PA13（D3）、PA15（CMD）にプルアップが必要とされています。推奨抵抗値は7.5 kΩです。バッテリー駆動版のアプリケーションノートにはPA13/PA17のブート設定用フットプリントだけが記載され、PA15/CMDのプルアップが必要かどうかは示されていません。SiFliへの確認なしに、外部レギュレーター給電版のPA15要件をバッテリー駆動版へ転用しないでください。対象バリアントとブートメディアに必要なプルアップをSiFliに確認してください。

##### 5.6.1.2. ブート設定 { #5612-boot-configuration }

=== "SF32LB520/3/5/7（バッテリー駆動版）"

    本チップは、同一パッケージ内に搭載されたSPI NOR Flash、外部SPI NOR Flash、外部SPI NAND Flash、外部SD NAND Flashから起動できます（**eMMC起動には対応しません**）。

    - SF32LB520Ux6はFlashを同一パッケージ内に搭載しており、デフォルトでそこから起動します。
    - SF32LB523/5/7Ux6はPSRAMを同一パッケージ内に搭載しているため、外部ストレージから起動する必要があります。

    ![図5.6-1: ブートストラップピンの推奨回路（バッテリー駆動版）](../../sf32-products/chips/assets/52xA/SF32LB52x-A-Bootstrap.png){ width="100%" loading="lazy" }

    <div align="center"><em>表5.6-3: ブート設定（バッテリー駆動版）</em></div>

    <div align="center" markdown>

    | Bootstrap[1] (PA13) | Bootstrap[0] (PA17) | ブートメディア |
    |:---|:---|:---|
    | L | L | SPI NOR Flash |
    | L | H | SPI NAND Flash |
    | H | X | SD NAND Flash |

=== "52B/D/E/G/J（外部レギュレーター給電版）"

    本チップは、同一パッケージ内に搭載されたSPI NOR Flash、外部SPI NOR Flash、外部SPI NAND Flash、外部SD NAND Flash、または外部**eMMC**から起動できます。

    - Flashを同一パッケージ内に搭載したモデル（SF32LB52BU36）は、デフォルトでそこから起動します。
    - PSRAMを同一パッケージ内に搭載したモデル（SF32LB52DUB6/EUB6/GUC6/JUD6）は、外部ストレージから起動する必要があります。

    ![図5.6-2: ブートストラップピンの推奨回路（外部レギュレーター給電版）](../../sf32-products/chips/assets/52xB/sf32lb52X-B-Bootstrap.png){ width="100%" loading="lazy" }

    |:---|:---|:---|
    | L | L | SPI NOR Flash |
    | L | H | SPI NAND Flash |
    | H | X | SD NAND Flash |

    !!! note "SiFli原資料の型番表記に関する注記"
        SiFliの原資料では、この節に「SF32LB52AUx6」および「SF32LB52D/F/HUx6」という末尾表記が使われていますが、同じ資料の冒頭にあるB/D/E/G/Jの型番表記と一致しません。本ガイドでは、同一パッケージ内に搭載されたメモリーの種類（FlashまたはPSRAM）に基づいて区別しています。不明な場合は、正確なチップ型番とデータシートを確認してください。

!!! important "重複するブート設定を確認する"
    アプリケーションノートではSD NANDをH/Xとしていますが、別のSF32LB52x回路図設計ガイドではH/Lです。また、外部レギュレーター給電版のアプリケーションノートはeMMCをH/Hとしています。通常、XはHighでもLowでもよいことを意味するため、外部レギュレーター給電版の設定は重複しており、資料にその違いの説明はありません。これらの表だけから最終的なストラップレベルを判断せず、対象バリアントとROMの動作をSiFliに確認してください。リファレンス回路のプルアップ抵抗は7.5 kΩで、図5.6-1では3.3 VのVDD33_VOUT1、図5.6-2では3.3 VのVDDIOAに接続されています。

##### 5.6.1.3. ブートストレージの電源制御 { #5613-boot-storage-power-control }

優先度の高いOpenSiFliのアプリケーションノートと回路図設計ガイドは、ブートストレージの電源スイッチ制御に`PA21`（Highでオン、Lowでオフ）を指定しているため、`PA21`を資料に基づく設計基準としてください。一方、SiFli Wikiからリンクされるチェックリストのワークブックは、バッテリー駆動版の外付けFlashのスイッチ制御に`PA11`を指定しています。このワークブックだけを根拠に`PA11`へ置き換えないでください。`PA11`が別の基板上イネーブルかピン割り当ての相違かは明記されていないため、リリース前に対象のネットとバリアントをSiFliに確認してください。

=== "SF32LB520/3/5/7（バッテリー駆動版）"

    - Flashを同一パッケージ内に搭載したSF32LB520Ux6では、VDD18_VOUTをVDD33_VOUT1から給電し、内蔵VDD18_VOUT LDOを無効にします。
    - PSRAMを同一パッケージ内に搭載したSF32LB523/5/7Ux6では内蔵LDOを使用します。VDD18_VOUTには外部から給電することもできます。
    - 外部NOR FlashはVDD33_VOUT1から給電し、追加の電源スイッチは不要です。
    - 外部SPI NANDまたはSD NANDはVDD33_VOUT1から給電し、電源スイッチを追加します。
    - リファレンスデザインではPA13とPA17にプルアップ抵抗のフットプリントを設けています。ストレージの種類に応じて実装し、7.5 kΩを推奨します。

=== "52B/D/E/G/J（外部レギュレーター給電版）"

    - Flashを同一パッケージ内に搭載したモデル（SF32LB52BU36）では、VDD_SIPに電源スイッチを追加します。
    - PSRAMを同一パッケージ内に搭載したモデル（SF32LB52DUB6/EUB6/GUC6/JUD6）では、PVDD = 3.3 VかつVDD_SIPに内蔵LDOを使用する場合、VDD_SIPの電源スイッチは任意です。PVDD = 1.8 Vの場合は必要です。
    - 外部ストレージの電源はVDD_SIPから独立しているため、別の電源スイッチを追加します。
    - eMMCのVCC/VCCQ電源ドメインの比較については、5.6.1.1節を参照してください。
    - アプリケーションノートは、ブート関連のストレージ電源スイッチに**PA21**を指定しています。バッテリー駆動版の外付けFlashに関する資料間の相違は、前述のとおりです。
    - MPI（Memory Peripheral Interface。SPI-NOR/SPI-NANDを接続するインターフェース）経由で接続した32 MB以上のNOR Flashは、MCUの再起動時またはHibernate移行時に4バイトモードを解除できるよう、PA21で電源を切り替えられる必要があります。そうしないとROMがFlashを認識できません。16 MB以下のNOR Flashは常時給電できます。
    - リファレンスデザインではPA13とPA17にプルアップ抵抗のフットプリントを設けています。ストレージの種類に応じて実装し、7.5 kΩを推奨します。

**ストレージ設計でよくある問題**

- ブートストラップ抵抗がない、または選択したブートメディアに合わない抵抗を実装する。
- 資料で確認済みのブートストレージ電源スイッチ制御を未接続のままにする。
- すべてのバリアントでeMMCが使えると誤認する。
- 4バイトモードが原因で再起動後にROMが認識できなくなる可能性がある大容量NOR Flashを、常時給電にする。

**ストレージ設計チェックリスト**

- [ ] PCBレイアウトの前にブートメディアを選定し、記録している。
- [ ] `PA13`/`PA17`のブートストラップ設定がブート表と一致している。
- [ ] 資料で確認済みのバリアント別ピンが、必要なすべてのブートストレージ電源スイッチを制御しており、PA11/PA21の相違をSiFliとの確認で解消している。
- [ ] 外部レギュレーター給電版ではeMMCのVCC/VCCQ構成のトレードオフを確認している。
- [ ] 立ち上げ計画に、ブートモードの設定、ストレージ電源のタイミング、ID読み出し、ファームウェアダウンロードを含めている。

#### 5.6.2. センサー { #562-sensors }

**要点**

- センサーは通常I2CまたはSPIで接続します。未使用のセンサーは電源を切ってスタンバイ電流を抑えます。ウェイクアップに必要なセンサーは、必要な動作モードを維持してください。
- ウェイクアップに使用するセンサー割り込みは、ピン配置を確定する前に割り当てる必要があります。

**設計目標**

低消費電力モードでは未使用センサーを確実に停止できるようにしながら、センサー電源、割り込み、バス配線の信頼性を確保します。

SF32LB52xには、心拍、加速度、地磁気などのセンサーを接続できます。センサー電源の切り替えには、Iqの低いロードスイッチを選択してください。

**センサー設計チェックリスト**

- [ ] センサーバス、割り込み、リセット、電源イネーブルの各ピンを割り当てている。
- [ ] センサー用ロードスイッチの静止電流（Iq）とシャットダウン電流が、スタンバイ電流の目標を満たしている。
- [ ] プルアップ抵抗を適切なセンサーI/O電圧レールに接続している。
- [ ] 立ち上げ計画に、バススキャン、割り込みウェイクアップ、センサー電源のオン/オフを含めている。

#### 5.6.3. UARTおよびI2Cのピン割り当て { #563-uart-and-i2c-pin-assignment }

**要点**

- UARTおよびI2C機能は任意のPAピンに割り当てられます。
- ただし、ピンの選定ではブート、ウェイクアップ、デバッグ、量産テスト、基板配線の制約を考慮してください。

**設計目標**

柔軟なピン割り当てを活用して配線を簡素化しつつ、ブートストラップ、ウェイクアップ、デバッグアクセス、量産用治具に必要なピンを確保します。

SF32LB52xでは、UARTおよびI2C機能を任意のPAピンに割り当てられます。

**UART/I2C設計チェックリスト**

- [ ] すべてのI2Cバスで、プルアップ、電圧ドメイン、バス容量が適切である。
- [ ] ログ出力、ダウンロード、外部モジュールに必要なUARTピンへアクセスできる。
- [ ] ピン多重化設定が、ブートストラップ、ウェイクアップ、ディスプレイ、ストレージ、デバッグ機能と競合しない。

#### 5.6.4. GPTIMのピン割り当て { #564-gptim-pin-assignment }

**要点**

- GPTIM機能は任意のPAピンに割り当てられます。
- タイマー機能はPWM出力、入力キャプチャー、モーター制御、バックライト制御、製品固有のタイミング制御に使用します。

**設計目標**

設計後半でPWM、キャプチャー、タイミング機能を配線しにくいピンやウェイクアップと競合するピンに割り当てざるを得ない状況を避けるため、タイマー機能の割り当ては早期に検討します。

SF32LB52xでは、GPTIM機能を任意のPAピンに割り当てられます。

**GPTIM設計チェックリスト**

- [ ] PWM、キャプチャー、制御ループに必要なタイマーチャネルをピン配置表に記載している。
- [ ] GPTIMピンがバックライト、モーター、デバッグ、ストレージの要件と競合しない。
- [ ] 立ち上げ計画に、PWM周波数、デューティ範囲、ピン極性の確認を含めている。

### 5.7. 製造 { #57-manufacturing }

#### 5.7.1. デバッグおよびダウンロードインターフェース { #571-debug-and-download-interface }

**要点**

- 電源投入後、`PA18`および`PA19`はデフォルトでDBG_UARTとなり、SWDと多重化されています。
- すべての試作基板および量産基板で、デバッグ/ダウンロード用ピンに物理的にアクセスできるようにします。

**設計目標**

筐体や量産用治具の仕様確定後も、ファームウェアのダウンロード、デバッグログ、ステップ実行デバッグ、障害復旧のためのアクセスを確保します。

SF32LB52xは、ダウンロードおよびデバッグ用のDBG_UARTインターフェースに対応します。3.3 VのUART-USB変換ドングルを介してPCに接続します。SWDとDBG_UARTはPA18およびPA19で多重化されており、電源投入後のデフォルト設定はDBG_UARTです。DBG_UARTではログ出力に加え、ステップ実行デバッグも可能です。

DBG_UARTによるステップ実行デバッグとログ出力の詳細は、SFtoolおよびImpellerのマニュアルを参照してください。

<div align="center"><em>表5.7-1: デバッグポートの接続</em></div>

<div align="center" markdown>

| デバッグ信号 | ピン | 説明 |
|:---|:---|:---|
| DBG_UART_RXD | PA18 | デバッグUART受信 |
| DBG_UART_TXD | PA19 | デバッグUART送信 |

</div>

**デバッグ設計チェックリスト**

- [ ] `PA18`/`PA19`、グラウンド、必要な電源基準をテストパッドまたはコネクターに引き出している。
- [ ] 筐体、バッテリー、ディスプレイの組み立て後もデバッグにアクセスできる。
- [ ] UART信号の電圧レベルは3.3 Vで、選定したアダプターまたは治具に適合している。
- [ ] アプリケーションファームウェアを起動できない基板の復旧手順を文書化している。

#### 5.7.2. 量産書き込みと水晶校正 { #572-production-flashing-and-crystal-calibration }

**要点**

- 量産プログラミングと水晶校正には、安定した電源、DBG_UARTへのアクセス、PA01、必要な電源/グラウンドのテストポイントが必要です。
- 基板外形や筐体設計を確定する前に、治具からのアクセス方法を設計してください。

**設計目標**

手作業でのはんだ付けや製品の分解を行わずに、すべての量産基板をプログラム、校正、復旧できるようにします。

SiFliは、量産時のファームウェア書き込みと水晶校正に使用するオフラインダウンローダーを提供しています。ハードウェア設計では、少なくともPVDD/VBAT、GND、AVDD33、DBG_UART_RXD、DBG_UART_TXD、PA01のテストポイントを確保してください。書き込みと校正の詳細については、開発パッケージに含まれる「Offline Downloader User Guide」を参照してください。

**量産設計チェックリスト**

- [ ] PVDD/VBAT、GND、AVDD33、DBG_UART_RXD、DBG_UART_TXD、PA01のテストポイントを確保している。
- [ ] 機構部品の組み立て後も、想定する治具からテストパッドにアクセスできる。
- [ ] 水晶校正の手順と合否基準を製造部門と定義している。
- [ ] プログラミング、校正、機能テストの記録を基板リビジョンとひも付けられる。
