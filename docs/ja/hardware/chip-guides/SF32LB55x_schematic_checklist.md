# SF32LB55xハードウェア設計ガイド — 回路図チェックリスト { #sf32lb55x-hardware-design-guide-schematic-checklist }

## 5.8. 回路図チェックリスト { #58-schematic-checklist }

以下の各表は、回路図の機能ブロックごとに確認項目をまとめたものです。「対象」列がある場合は、該当するバリアントにのみ適用してください。

赤字と黄色の背景は、原資料のレビュー上の強調を保持したものです。各強調の理由は原資料に記載されていないため、追加の確認目印として扱ってください。「必須／任意」の区分が変わるわけではありません。
