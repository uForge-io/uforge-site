### 5.1. 最小システム設計 { #51-minimum-system-design }

#### 5.1.1. 最小システム設計の手順 { #511-minimum-system-design-sequence }

立ち上げ時の不具合は、最小システム、電源ファミリー、ブートモード、ストレージのプルアップ、水晶振動子の選定、BUCK部品、ダウンロード経路の不足に起因することが多くあります。製品の周辺機能にピンを割り当てる前に、次の項目を確定してください。

1. パッケージと電源ファミリーに合った最小システム回路図を選びます。
2. `PA00` / `PA01`のブートおよびデバッグ動作を設定し、復旧用アクセスを確保します。
3. ブートメディアを選び、必要なプルアップを`PA13` / `PA15` / `PA17`に設定します。
4. 電源ツリー、充電／OVP経路、BUCKインダクター／コンデンサー、各レールの初期状態を定め、5.2節で詳細を確認します。
5. 48 MHzおよび32.768 kHzの水晶振動子を選び、5.3節で校正計画を確認します。
6. DBG-UART、SWD、ブートモード、電源、GND、治具接続用のテストポイントを確保します。

#### 5.1.3. ブートストレージとストラップ設定 { #513-boot-storage-and-strap-configuration }

回路図を確定する前にブートメディアを選定してください。パッケージ内蔵メモリーがすでにMPIチャネルを使用している場合があります。また、外付けメディアごとにプルアップと電源制御の要件が異なります。

<div align="center"><em>表 5.1-1: 外付けブートメディアの選択</em></div>

<div align="center" markdown>

| `Bootstrap[1]` (`PA13`) | `Bootstrap[0]` (`PA17`) | 外付けブートメディア |
|:------------------------|:------------------------|:--------------------|
| L | L | SPI NOR Flash |
| L | H | SPI NAND Flash |
| H | L | SD NAND Flash |
| H | H | eMMC |

</div>

<div align="center"><em>表 5.1-2: 外付けブートメディアのプルアップ要件</em></div>

<div align="center" markdown>

| ブートメディア | プルアップ要件 |
|:-----------|:--------------------|
| SPI NOR Flash | `PA13` / `PA17`に外付けプルアップは不要です。 |
| SPI NAND Flash | `PA17`に7.5 kohmのプルアップが必要です。`PA13`にプルアップは不要です。 |
| SD NAND Flash | `PA13`と`PA15`に7.5 kohmのプルアップが必要です。`PA17`にプルアップは不要です。 |
| eMMC | `PA13`、`PA15`、`PA17`のすべてに7.5 kohmのプルアップが必要です。 |

</div>

![図 5.1-7: ブートストラップピンの推奨回路](../../sf32-products/chips/assets/57x/SF32LB57x-A-Bootstrap.png){ width="100%" loading="lazy" }

<div align="center"><em>図 5.1-7: ブートストラップピンの推奨回路</em></div>

ブートメディアの電源は、メディアの種類と電源ファミリーに応じて設計してください。バッテリー駆動バリアントでは、外付けNOR Flashは`VDD33_VOUT1`から給電し、外付けSPI NAND Flashには`VDD33_VOUT1`の後段にロードスイッチを設け、外付けSD NAND FlashとeMMCには外付けLDOを使用します。3.3 V電源バリアントでは、すべての外付けブートメディアに外付けLDOを使用します。SiFliは外付けブートメディア用電源スイッチのイネーブルに`PA21`を推奨しており、高レベルで電源オン、低レベルでオフになります。バッテリー駆動バリアントで`PA21`が引き出されていない場合、原資料ではデフォルトでプルアップされるGPIOを代わりに使用できます。ブート中にメディアの電源レールが利用可能であることを確認してください。パッケージ内蔵ストレージがすでにMPI3を使用している場合、外付けMPI3の用途はSD NANDまたはeMMCに限られます。このチャネルに外付けSPI NOR／SPI NANDを接続しないでください。

#### 5.1.4. デバッグおよびダウンロード経路 { #514-debug-and-download-access }

製品のIOを割り当てる前に、デバッグと復旧のためのアクセス経路を確保してください。標準のDBG-UART、ブートストラップ、SWD経路にアクセスできないと、初回基板の不具合からの復旧が難しくなります。

<div align="center"><em>表 5.1-3: デバッグおよびダウンロード用テストポイントの推奨</em></div>

<div align="center" markdown>

| テストポイント | 推奨 | 用途 |
|:-----------|:---------------|:--------|
| 電源入力 | `VBAT`または3.3 V。必要に応じて`VSYS` / `VDD33_VOUT1`も用意 | 治具への給電、電流測定、低消費電力検証 |
| GND | 複数のGNDテストポイント | ダウンロード、デバッグ、校正、電流測定のリターン経路 |
| DBG-UART | `PA18` / `PA19`（それぞれ`DBG_UART_RXD` / `DBG_UART_TXD`） | 標準のダウンロード、ログ出力、量産書き込み |
| SWD | `PA43` / `PA44`、または型番で指定されたSWDIO/SWCLKピン | デバッグと故障解析 |
| ブートモード | `PA00`、または型番で指定されたブートモード選択ピン | ダウンロード／復旧モードへの移行 |
| SWD切り替え | `PA01`または対応する設定ピン | SWDピン位置を切り替える必要がある場合に使用 |
| 電源キー／ウェイクアップ | `PA34`または対応するキー入力ピン | 治具からの電源投入、リセット、ウェイクアップ試験 |

</div>

<div align="center"><em>表 5.1-4: 標準デバッグポートの接続</em></div>

<div align="center" markdown>

| デバッグ信号 | ピン | ネット名 |
|:-------------|:----|:---------|
| `DBG_UART_RXD` | `PA18` | `USART1_RXD` |
| `DBG_UART_TXD` | `PA19` | `USART1_TXD` |
| `SWD_CLK` | `PA43` | `SWCLK` |
| `SWD_DIO` | `PA44` | `SWDIO` |

</div>

!!! warning
    量産用テストポイントには`DBG_UART_RXD`と`DBG_UART_TXD`の両方を含めてください。RXDを誤って二重に割り当てないよう注意してください。

`PA18`/`PA19`はデフォルトのDBG-UARTピン、`PA43`/`PA44`はデフォルトのSWDピンです。SWDは`PA18`/`PA19`に切り替えることもできます。ダウンロードインターフェースはDBG-UART、SWD、標準UART、USBの4種類です。通常起動で使用できるのはDBG-UARTとSWDのみで、BOOTモードでは4種類すべてを有効にできます。BOOTモードとSWDピンの切り替えは、`PA00`、BOOTレジスター、`PA01`、ホスト側のBOOTスイッチに依存します。量産書き込みや復旧を設計する際は、原資料の全モード表を確認し、単一のピン状態だけからダウンロード方式を推定しないでください。

### 5.2. 電源システム { #52-power-system }

#### 5.2.1. 電源ツリーの計画 { #521-power-tree-planning }

回路図を作成する前に電源ツリーを描き、各レールに電源元、既定状態、最大負荷、スリープ時の状態、制御GPIOを記載してください。

<div align="center"><em>表 5.2-1: 電源レール計画のクイックリファレンス</em></div>

<div align="center" markdown>

| レールの分類 | 計画時の確認事項 |
|:--------------|:---------------|
| 常時オンのレール | RTC、ウェイクアップ、必須の検出回路、Bluetooth保持回路だけに限定します。静止電流を項目ごとに算出してください。 |
| 切り替え可能な周辺機器用レール | ディスプレイ、バックライト、センサー、モーター、外付けストレージ、カメラにはロードスイッチまたは切り替え可能なLDOを優先します。 |
| アナログ／RF／オーディオ用レール | 個別にフィルタリングし、電流ループを短く保ち、大電流領域や高速デジタル領域から分離します。 |

| プルアップ用レール | I2C、キー、センサー割り込みなどのプルアップ電源を、各周辺機器の電源制御方針と合わせて設計します。 |

</div>

#### 5.2.2. バッテリー駆動バリアント { #522-battery-powered-variants }

バッテリー駆動バリアントでは、通常`VBUS`、`VBAT`、`VCC`、`VSYS`、`BUCK_LX`、`BUCK_FB`、内部LDO出力、オーディオ電源ピン、RF電源ピンを使用します。

主な要件:

- `VBUS`を許容入力範囲内に保ち、OVP保護を追加します。
- `VBAT`をバッテリーに接続し、バッテリー電圧の検出に使用します。
- `VCC`をシステムの主入力として扱います。十分な配線幅を確保し、デカップリングコンデンサーをチップの近くに配置します。
- `VSYS`は指定された内部負荷、`AVDD_BRF`、GPIOのプルアップ回路に限って使用し、外付け周辺機器には給電しないでください。
- `VDD33_VOUT1`、`VDD33_VOUT2`などの内部レギュレーター出力は、明示的に許可された負荷に限って使用します。SiFliの原資料には不一致があります。低消費電力の説明と図では外付けセンサーを`VDD33_VOUT1`に接続していますが、同じガイドの電源チェックリストでは、この出力をパッケージ内蔵／外付けNOR/NAND Flashと`AVDD33_AUD`に限定し、他の周辺機器への給電を禁止しています。SiFliがこの不一致を明確にするまでは、センサーを`VDD33_VOUT1`に接続しないでください。
- `AVDD_BRF`と`AVDD33_AUD`は、推奨される電源レールから供給し、ローカルでフィルタリングします。

#### 5.2.3. 3.3 V電源バリアント { #523-33-v-supply-variants }

3.3 V電源バリアントでは通常、`PVDD`、`AVDD33`、`AVDD_BRF`、`AVDD33_AUD`、`VDDIOA`などの電源ドメインに外部3.3 Vレールを使用します。

主な要件:

- 重要な3.3 V電源ドメインにはスター配線を使用します。
- アナログ、RF、オーディオの電源は、大電流または高速デジタルの経路から分離して個別にフィルタリングします。
- バッテリー検出に`VBATS`を使用する場合は、入力範囲とフィルタリングを確認します。
- 3.3 V電源バリアントでは、すべての外付けブートメディアに外付けLDOから給電します。イネーブル信号には`PA21`を推奨します。
- 内部リファレンスと内部LDO出力ピンは、必要な外付けコンデンサーだけに接続してください。外部電源から電圧を印加しないでください。

#### 5.2.4. 電源コンデンサーと用途のクイックリファレンス { #524-power-capacitor-and-usage-quick-reference }

この表は回路図の事前レビューに使用します。最終的な値は、データシートとリファレンスデザインで必ず確認してください。

<div align="center"><em>表 5.2-2: 電源コンデンサーと用途のクイックリファレンス</em></div>

<div align="center" markdown>

| レール／ピン | 一般的な外付けコンデンサー | 主な用途 | 設計上の注意 |
|:-----------|:---------------------------|:---------|:-------------|
| `VBUS` | >= 10 uF | USB／充電器入力 | バッテリー駆動バリアントのみ。OVP／ESD／EOS保護を追加します。 |
| `VBAT` | >= 4.7 uF | バッテリー接続とバッテリー電圧検出 | バッテリー経路は短く幅広くし、敏感な信号線と並走させないでください。 |
| `VCC` / `PVDD` | >= 10 uF | PMU／システムの主入力 | デカップリングをチップの近くに配置し、電流に応じた配線幅を確保します。 |
| `VSYS` | 約2.2 uF | 内部電源または指定されたアナログ／RF関連電源 | 汎用周辺機器用の電源にしないでください。総負荷と容量を管理します。 |

| `VDD18_VOUT` | 選択した最小システム回路図に従う | 内部／パッケージ内蔵PSRAM関連の1.8 V電源 | 外付け1.8 V周辺機器の電源には使用しないでください。 |
| `VDD_VOUT1` / `VDD_VOUT2` | 各4.7 uF / 6.3 V | 内部LDO出力 | 内部電源専用です。外付け周辺機器に給電しないでください。 |
| `VDD_RET` / `VDD_RTC` | `VDD_RET`: 0.47 uF / 6.3 V、`VDD_RTC`: 1 uF / 6.3 V | 保持用およびRTC用内部電源 | コンデンサーをピンの近くに配置します。 |
| `AVDD_BRF` | 約4.7 uF | RFアナログ電源 | チップの近くに配置し、複数のビアで短く接地します。 |
| `AVDD33_AUD` | 約2.2 uF | オーディオアナログ電源 | DC/DC、RF、USB、SDIO、ディスプレイクロックから離します。 |
| `MIC_BIAS` | 1 uF / 6.3 V | マイクバイアス | マイクバイアス専用です。 |
| `AUD_VREF` / `GPADC_VREF` | `AUD_VREF`: 1 uF、`GPADC_VREF`: 4.7 uF | 内部リファレンス | コンデンサーのみ接続し、外部から電圧を印加しないでください。 |

</div>

#### 5.2.5. BUCKインダクターとフィードバック { #525-buck-inductor-and-feedback }

BUCKインダクターの推奨パラメーター:

<div align="center"><em>表 5.2-3: BUCKインダクターの推奨パラメーター</em></div>

<div align="center" markdown>

| パラメーター | 推奨値 |
|:----------|:------------------|
| インダクタンス | 4.7 uH ±20% |
| DCR | <= 0.4 ohm |
| 飽和電流 | >= 450 mA |

</div>

PCB設計要件:

- インダクター、出力コンデンサー、フィードバックコンデンサーをチップの近くに配置します。
- `BUCK_LX`の電流ループは短く幅広くします。この領域に銅箔ベタや敏感な信号線を配置しないでください。
- `BUCK_FB`の配線には十分な幅を持たせます。0.25 mm以上を推奨します。
- インダクター付近に連続した基準GNDを設け、水晶振動子、RF、オーディオ、GPADCの配線へのノイズ結合を避けます。
- GPS、心拍検出、ECG、アナログマイクなどの敏感な回路がある場合は、BUCK_LX付近にEMI調整用のオプション部品ランドを確保します。最終値はシステムのEMC検証で決定してください。

#### 5.2.6. 充電とOVP { #526-charging-and-ovp }

バッテリー製品では、外付け充電器または内蔵充電ブロックを使用できます。

<div align="center"><em>表 5.2-4: 充電方式の比較</em></div>

<div align="center" markdown>

| 方式 | 電源経路 | 設計上の注意点 |
|:-------|:------------|:-------------|
| PPMなしの外付け充電器 | バッテリーからチップの`VBAT`と`VCC`へ直接給電します。 | `VBAT`上のGPADCチャネルでバッテリー電圧を測定します（サンプリング精度±30 mV）。 |
| PPM付きの外付け充電器 | 充電器の`VSYS`からチップの`VCC`へ給電し、充電器の`VBAT`をバッテリーとチップの`VBAT`の両方に接続します。 | `VBAT`上のGPADCチャネルでバッテリー電圧を測定します（サンプリング精度±30 mV）。 |
| 内蔵充電器 | チップ内蔵の充電管理ブロックを使用します。 | バッテリー残量低下でシステムが停止した場合、システムが起動して充電画面を表示するには、まずバッテリー電圧が起動電圧に達する必要があります。SiFliのチェックリストでは、バッテリーが約3.6 Vに達した後、ソフトウェアでディスプレイを点灯することを前提としています。 |

</div>

OVPに関する指針:

- `VBUS`は許容入力範囲を決して超えないようにしてください。
- OVLO調整式OVPでは、SiFliの参考部品AW32905FCRを使用できます。アプリケーション説明の設定範囲は5.2～5.5 V、チェックリストの範囲は5.15～5.55 Vです。SiFliから明確な説明があるまでは、両者の共通範囲である5.2～5.5 Vを設計目標にします。部品と分圧抵抗の誤差を考慮して`V_IN_OVLO = ((R1 + R2) / R2) × V_OVLO_TH`を計算し、`V_OVLO_TH`の誤差を3%以内、R1/R2の許容差を1%とします。
- 出力安定化型OVPでは、SiFliの参考部品SGM4064YDE8GまたはLP5305AQVFを使用できます。アプリケーション説明の出力範囲は4.5～5.4 V、チェックリストの範囲は4.7～5.4 Vです。確認が取れるまでは、狭い方の4.7～5.4 Vを採用し、負荷能力を0.5 A以上、過電流保護しきい値を0.7 A以上とします。
- 充電器入力は、チップに到達する前にTVS／OVP保護回路を通します。

!!! warning "入力電圧範囲に関する資料の不一致"
    電源ピン表とチェックリストでは`VBUS`入力範囲を4.6～5.5 Vとしていますが、OVP選定の説明では4.5～5.5 Vと記載されています。SiFliから明確な説明があるまでは、最低動作入力電圧を4.6 Vとして設計してください。

#### 5.2.7. 低消費電力の電源設計 { #527-low-power-supply-strategy }

低消費電力動作を回路図の段階から考慮してください。

推奨事項:

- ディスプレイ、バックライト、センサー、モーター、外付けストレージにはロードスイッチまたは切り替え可能なLDOを使用します。
- ENがアクティブHighの電源管理部品を選定します。出力を既定でオフにする場合は、ENをGNDへ1 MΩ～5.1 MΩでプルダウンします。抵抗値は製品の低消費電力目標に応じて選定してください。
- MOSFET電源スイッチには、原資料で推奨されるPMOS＋NMOS構成を使用します。制御端子はHighでオン、Lowでオフとし、1 MΩのプルダウン抵抗でGNDに固定します。
- スリープ時のリークを防ぐため、I2Cのプルアップは対応する周辺機器と同じ電源レールから給電します。
- 常時オン回路には、静止電流（Iq）とシャットダウン電流が小さい部品を選びます。
- `VSYS`または常時オンのLDOをGPIOのプルアップ電源に使用する場合は、そのリーク電流をスリープ時の電流予算に含めます。

#### 5.2.12. ウェイクアップ設計 { #5212-wake-design }

- ウェイクアップ機能が必要なキー、タッチ割り込み、センサー割り込みは、ウェイクアップ対応GPIOに接続します。
- 外部ハードウェアのウェイクアップ信号は、可能な限り`PA33`～`PA42`の範囲で計画し、回路図にウェイクアップ用途を明記します。
- StandbyおよびHibernate時のIO保持、High-Z、プルアップ、プルダウン、周辺機器電源の状態を確認します。
- USB接続によるウェイクアップには、適切なIO電圧のウェイクアップ対応GPIOに接続したVBUS分圧回路が必要です。
- Bluetooth、RTC、外部ウェイクアップの動作は、ファームウェアの低消費電力方針と合わせて確認してください。

#### 5.2.13. 低消費電力の検証 { #5213-low-power-validation }

EVTでは、少なくとも次の状態を測定してください。

<div align="center"><em>表 5.2-9: 低消費電力検証の状態と目標</em></div>

<div align="center" markdown>

| 状態 | 測定目標 |
|:------|:-----------------|
| Shutdown／出荷モード | 長期保管中のシステムの電源オフ時の漏れ電流を確認し、周辺機器からの逆給電がないかを点検します。 |
