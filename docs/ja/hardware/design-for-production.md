# 量産に向けた設計 { #design-for-production }

チップまたはモジュールを選定した後、回路図、PCBレイアウト、BOM、製造資料をリリースする前に、この設計フローを利用してください。初回の立ち上げや製品の適合性確認で生じるリスクを抑えるため、製品別のハードウェア設計ガイド、チェックリスト、モジュールのインターフェース定義、適合性確認済み部品、EDAライブラリをまとめています。

## 推奨する量産設計の順序 { #recommended-production-sequence }

この流れは一度きりの引き継ぎではなく、繰り返し行うレビューの手順です。試作基板を製作する前にシンボルとフットプリントを確認し、設計レビューと量産を想定したハードウェアの検証を終えてから、量産用CADデータと製造資料をリリースします。基板、ファームウェア、BOMを変更した場合は、影響する項目を再確認してください。

<div align="center"><em>表: 量産設計の順序</em></div>

<div align="center" markdown style="max-width: 100%; overflow-x: auto;">

| 段階 | 参照する資料 | 保管する証跡 |
|:-----|:-------------|:-------------|
| アーキテクチャ | 製品紹介とインターフェース要件 | 選定部品、パッケージ、メモリー、ディスプレイ、オーディオ、ストレージ、電源に関する前提条件。 |
| 回路図とレイアウト | チップまたはモジュールのハードウェア設計ガイド | 電源、クロック、リセット、RF、ストレージ、ディスプレイ、インターフェースの実装レビュー結果。 |
| BOM | 承認ベンダーリスト (AVL) と各部品のデータシート | 各重要部品について、適合性を確認済み、または個別に検証した代替部品の記録。 |
| 設計レビュー | ハードウェア設計チェックリスト | 該当する各項目と例外に対する判断・対応の記録。 |
| 立ち上げ | 開発ボード資料、SDKサンプル、実測試験 | 起動、書き込み、周辺機能、無線、消費電力、復旧に関する再現可能な結果。 |
| 量産用CADリリース | 公式EDAライブラリとパッケージ図 | シンボル、フットプリント、ピン配置、ランドパターン、製造データの検証結果。 |

</div>

## 製品に合った資料を使う { #use-the-right-reference-for-the-chosen-product }

ハードウェアの実装では、次の資料を参照してください。

- **[ハードウェア設計ガイド](index.md#find-a-guide)**には、チップごとの回路図、レイアウト、電源、インターフェース、立ち上げに関する指針と、モジュール用キャリア基板の実装ガイドがあります。該当するチェックリストも使用してください。モジュールが製品アーキテクチャに適合するか確認するには、先にモジュール紹介を参照します。
- **[M2モジュール](m2-modules/interface-standards-overview.md)**には、μForgeのM2命名規則と、ピン単位のインターフェース定義案があります。インターフェース定義は提案段階のため、量産設計に採用する前に検証してください。
- **[CADと部品](cad-components/components-and-cad-libraries.md)**には、SiFliの [AVL](cad-components/sifli-approved-vendor-list.md) と[公式EDAライブラリ](cad-components/eda-tool-libraries.md)があります。いずれも、対象部品、パッケージ図、選定した設計ガイドに基づく最終確認の代わりにはなりません。

## 量産向け資料だけでは検証にならない { #a-production-reference-is-not-a-substitute-for-validation }

設計ガイドや適合性確認済み部品の一覧はリスクを減らしますが、完成品の検証を代替するものではありません。最終PCBリビジョン、ファームウェア、筐体、バッテリー、ディスプレイ、ストレージ、RF特性、使用環境、製造試験フローを検証してください。ガイドやチェックリストから外れる場合は、記録されていない例外として残さず、明確な技術判断として記録します。
