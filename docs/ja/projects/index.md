# プロジェクト概要 { #projects-overview }

プロジェクトは、実際のアプリケーションをベースにしたリファレンスです。コピーして改変し、SF32を活用した製品の可能性を探るために利用できます。機能を個別にすべて実演するのではなく、実際に作って使える製品を想定し、SF32の機能を組み合わせた具体的な例を示します。

## プロジェクトの目的 { #what-projects-are-for }

各プロジェクトには、次の要素が求められます。

- **用途が明確であること。** 抽象的な機能デモではなく、身近な製品の動作やユースケースから始めます。
- **一連の流れを追えること。** 選定したハードウェア、ソフトウェアの基準構成、依存関係、統合のマイルストーン、検証証跡、応用の道筋をつなぎ、開発工程の大部分を体験できるようにします。
- **複製して使えること。** まず実用的な基準構成を再現し、その後、自分のハードウェア、操作モデル、製品要件に合わせて変更できるようにします。
- **作る楽しさがあること。** SF32で実現できることが目に見え、試してみたくなるプロジェクトを目指します。有用であることと、作る楽しさは両立できます。

関連する[開発を始める](../getting-started/index.md)の基準構成を確認してから、プロジェクトに取り組んでください。[リファレンスデザイン](../hardware/reference-designs/reference-designs.md)では、再利用可能な基準構成と検証手順を紹介しています。現在のConnected Wearableはワークフローであり、公開済みのボード一式ではありません。具体的で適用可能な基準構成がある場合、プロジェクトはそこへリンクしてください。ない場合は、計画段階の手順を検証済みの設計であるかのように示すのではなく、独自の基準構成を明記して検証してください。
