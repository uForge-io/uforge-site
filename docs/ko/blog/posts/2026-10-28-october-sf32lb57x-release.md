# 10월: SF32LB57x를 소개합니다 [2026-10-28] { #october-sf32lb57x-2026-10-28 }

이번 달 μForge.io에 SF32LB57x 제품군을 추가했습니다. SF32LB52x와 SF32LB56x를 강화한 제품군으로, CPU 연산 성능과 그래픽 기능이 크게 향상되었으면서도 매우 경쟁력 있는 비용 구조를 유지합니다.

### 더 높은 CPU 연산 성능 { #more-cpu-power }

SF32LB52x와 SF32LB56x는 각각 240 MHz Cortex-M33 애플리케이션 코어 하나와 저전력 코어 하나를 조합합니다. SF32LB57x는 240 MHz Cortex-M33 STAR-MC1 고성능 코어 두 개와 전용 블루투스 컨트롤러 역할을 하는 24 MHz 저전력 코어를 사용합니다. 두 고성능 코어의 합산 성능은 1968 CoreMark / 740 DMIPS로, SF32LB56x 애플리케이션 코어(984 CoreMark / 370 DMIPS)의 약 두 배입니다. 이 여유 덕분에 UI 렌더링, 애플리케이션 로직, 오디오·멀티미디어 처리를 하나의 코어에서 경쟁시키지 않고 서로 다른 코어에서 실행할 수 있으며, 블루투스와 센서 작업은 저전력 경로에 그대로 남습니다.

### 더 강력한 그래픽 기능 { #more-graphics-capability }

그래픽은 SF32LB52x의 ePicasso 2.0 Lite, SF32LB56x의 ePicasso 2.0에서 ePicasso 3.0과 eZip 3.0 하드웨어 압축 해제로 향상되었습니다. ePicasso 3.0은 실시간 회전, 확대·축소, 투영, 미러링, 알파 블렌딩을 가속하고, eZip 3.0은 eZip, JPEG, MJPEG 자산을 CPU 부담이 큰 디코딩 없이 해제합니다. 코어 외에도 DCMI 카메라 입력, 일부 부품에서 최대 48 MB의 패키지 내 PSRAM과 32 MB의 패키지 내 NOR 플래시, 오디오 ADC 2개, CAN 인터페이스 2개, 타이밍에 민감한 주변장치 작업을 분담하는 병렬 작업 처리기 PTM을 갖추고 있습니다.

### 경쟁력 있는 비용 구조 { #competitive-cost-structure }

이러한 성능 향상이 SF32LB57x를 다른 비용 구간으로 옮기지는 않습니다. 저희는 제공하는 연산 성능과 그래픽 기능에 비해 매우 경쟁력 있는 비용 구조를 유지한다고 봅니다. 또한 소형 QFN68(7 × 7 mm), QFN80(8 × 8 mm), BGA112(5.4 × 4.4 mm) 패키지는 보드 크기와 복잡도를 억제하는 데 도움이 됩니다. 더 풍부한 스마트워치 인터페이스, 카메라를 갖춘 휴대용 기기, 디스플레이 중심의 소형 단말처럼 SF32LB52x나 SF32LB56x로는 부족해진 제품에 플래그십급 플랫폼으로 옮기지 않고도 쓸 수 있는 자연스러운 선택지입니다.
