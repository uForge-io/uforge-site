# 부품 및 CAD 라이브러리 { #components-and-cad-libraries }

선정한 SF32 디바이스나 모듈의 제품 아키텍처를 정한 뒤 BOM과 PCB 설계를 구체화할 때 이 페이지를 참고하십시오. 아래 두 리소스는 용도가 다릅니다. **승인 업체 목록(AVL)**은 SiFli가 인증한 부품 후보를 고르는 데 도움이 되고, **EDA 툴 라이브러리**는 선택한 하드웨어를 구현할 때 참고할 심볼, 풋프린트, 레퍼런스 프로젝트 자료를 제공합니다.

두 리소스 모두 디바이스별 하드웨어 설계 가이드, 패키지 도면, 양산 의도 보드에서의 최종 검증을 대체하지 않습니다.

## BOM에서 CAD까지의 검토 순서 { #bom-to-cad-review-sequence }

1. **구현 기준 구성을 확정합니다.** 정확한 칩 또는 모듈, 패키지, 메모리 구성, 디스플레이 인터페이스, 전원 아키텍처를 선택합니다. 주변 부품을 고르기 전에 해당 하드웨어 설계 가이드를 읽으십시오.
2. **AVL에서 핵심 부품 후보를 좁힙니다.** 부품 번호만 확인하지 말고 명시된 전기적 요구 사항도 대조하십시오. 특히 크리스털의 부하 커패시턴스와 ESR, BUCK 인덕터의 전류 한계, 플래시 전압과 타이밍 모드, 온도 범위, 펌웨어 호환성에 주의하십시오.
3. **공식 라이브러리로 회로도를 작성합니다.** 관련 EDA 라이브러리와 레퍼런스 디자인을 시작점으로 사용합니다. 각 심볼, 풋프린트, 핀 번호, 랜드 패턴, 금지 구역 규칙을 선택한 부품의 최신 데이터시트 및 패키지 도면과 독립적으로 비교하십시오.
4. **전체 BOM과 레이아웃을 함께 검토합니다.** 인증된 부품이 실제 전원 레일의 전압과 전류, 인터페이스 속도, 조립 공정, 인클로저 제약에 여전히 부합하는지 확인하십시오. 전원, RF, 클럭, 메모리, 디스플레이, 디버그 접근은 디바이스 또는 모듈 설계 가이드의 요구 사항에 맞춰 검토하십시오.
5. **양산용 하드웨어를 검증합니다.** 부팅, 펌웨어 기록, 주변 장치, 무선, 복구 동작을 시험하고 최종 보드 리비전에서 소비 전력을 측정하십시오. 승인된 대체 부품과 가이드 또는 AVL에서 의도적으로 벗어난 사항을 모두 기록하십시오.

## 실무상의 한계 { #practical-boundaries }

- AVL은 인증 시점의 스냅샷입니다. 양산 BOM을 릴리스하기 전에 목록의 리비전과 부품 공급 가능 여부를 다시 확인하십시오.
- EDA 라이브러리는 설계의 출발점이 되는 자료일 뿐입니다. 라이브러리를 사용했다고 해서 완성된 레이아웃의 제조 가능성이나 전기적 정확성이 입증되는 것은 아닙니다.
- AVL에 없는 부품은 관련 요구 사항에 맞춰 인증하고, 양산에 사용하기 전에 대상 하드웨어에서 검증하십시오.
- 모듈 기반 제품은 모듈 설계 가이드부터 검토하십시오. 캐리어 보드의 BOM과 레이아웃에도 같은 검토 원칙을 적용해야 합니다.

전체 설계 검토 경로는 [양산 설계](../design-for-production.md)에서 이어서 확인하고, 칩, 모듈 또는 보드 기준 구성을 아직 선택하지 않았다면 [SF32 제품 선택기](../../sf32-products/product-selector.md)로 돌아가십시오.
