# SF32LB57x 하드웨어 설계 가이드 — 클럭, RF 및 사용자 인터페이스 { #sf32lb57x-hardware-design-guide-clock-rf-user-interfaces }

!!! note "SF32LB57x 하드웨어 설계 가이드의 일부"
    이 페이지는 회로 설계 가이드라인의 5.3~5.5절인 클럭 생성, RF, 사용자 인터페이스를 다룹니다. [최소 시스템 및 전원](SF32LB57x_schematic_system_power.md)으로 돌아가거나, [스토리지 및 양산](SF32LB57x_schematic_storage_mfg.md)으로 이어서 진행하십시오.

### 5.3. 클럭 생성 { #53-clock-generation }

클럭 생성은 48 MHz 메인 크리스털, 32.768 kHz RTC 크리스털, 그리고 RF, Bluetooth, RTC 정확도, 저전력 동작에 영향을 주는 캘리브레이션 조건을 다룹니다. 회로도 검토와 PCB 배치 중에는 크리스털 선정과 레이아웃 제약을 계속 염두에 두십시오.

#### 5.3.1. 48 MHz 메인 크리스털 { #531-48-mhz-main-crystal }

권장 파라미터:

<div align="center"><em>표 5.3-1: 48 MHz 메인 크리스털 권장 파라미터</em></div>

<div align="center" markdown>

| 파라미터 | 권장 사항 |
|:----------|:---------------|
| 부하 커패시턴스 CL | 7 pF~12 pF, 약 8.8 pF 권장 |
| 주파수 허용 오차 | <= ±10 ppm |
| ESR | <= 30 ohm, 약 22 ohm 권장 |

</div>

원본 가이드에 따르면 `CL`과 ESR이 작을수록 크리스털 전력이 감소합니다. 48 MHz 크리스털 옆에 병렬 매칭 커패시터 풋프린트를 확보해 두십시오. `CL`이 12 pF 미만인 크리스털에서는 이 커패시터를 실장하지 않아도 된다고 원본에 나와 있습니다.

레이아웃 요구 사항:

- 크리스털은 칩 핀 가까이에, 가능하면 실드 캔 영역 안에 배치하십시오.
- PA, 충전기, PMU, DC/DC, 배터리, 고속 디지털 트레이스에서 멀리 떨어뜨리십시오.
- 가능하면 최상층에서 라우팅하며, 트레이스 폭은 0.1 mm, 길이는 3 mm~10 mm로 하십시오. 원본 레이아웃 그림과 같이 `48M_XI`와 `48M_XO` 트레이스 사이는 0.15 mm 이상 띄우십시오.
- 최상층 크리스털 금지 구역은 레퍼런스 디자인과 일관되게 유지하고, 크리스털 아래로 신호를 라우팅하지 않습니다. 인접 층의 그라운드 동박에 대해 원본의 지침이 서로 충돌하므로 아래 참고를 확인하십시오.
- 3D 그라운드 실드를 사용하되, 발진 트레이스에 그라운드를 너무 가까이 두지 않도록 하십시오.

지정된 48 MHz 크리스털 부하 커패시턴스 범위는 7 pF~12 pF이며 약 8.8 pF을 권장합니다. 선택한 크리스털을 제품 하드웨어의 발진 회로에서 검증하고 주파수 오차를 확인하십시오. 양산 브링업(초기 구동 및 검증)에 크리스털 주파수 캘리브레이션을 포함하고, 기본 소프트웨어 설정이 모든 크리스털에 적합하다고 가정하지 마십시오.

#### 5.3.2. 32.768 kHz RTC 크리스털 { #532-32768-khz-rtc-crystal }

권장 파라미터:

<div align="center"><em>표 5.3-2: 32.768 kHz RTC 크리스털 권장 파라미터</em></div>

<div align="center" markdown>

| 파라미터 | 권장 사항 |
|:----------|:---------------|
| 부하 커패시턴스 CL | 7 pF 또는 11.5 pF(칩 기본값은 11.5 pF이며, 7 pF은 레지스터 변경이 필요). 최저 전력을 위해서는 7 pF을 권장 |
| 주파수 허용 오차 | <= ±20 ppm |
| ESR | <= 80 kohm, 약 38 kohm 권장 |

</div>

원본 가이드에 따르면 `CL`과 ESR이 낮을수록 크리스털 전력이 감소합니다. 32.768 kHz 크리스털은 부하 커패시턴스로 7 pF 또는 11.5 pF을 사용할 수 있으며, 원본에 따르면 어느 쪽도 외부 매칭 커패시터가 필요하지 않습니다. 다른 부하 커패시턴스 값을 사용할 때는 회로를 측정하여 필요한 매칭 커패시턴스를 결정하십시오.

레이아웃 요구 사항:

- 크리스털은 칩 가까이에 배치하고 트레이스를 짧게 유지하십시오.
- 트레이스 폭은 0.1 mm, 길이는 10 mm 이하로 유지하십시오. 원본 레이아웃 그림과 같이 `32K_XI`와 `32K_XO` 트레이스 사이는 0.15 mm 이상 유지하고, 3D 그라운드 실드를 추가하십시오.
- 최상층 크리스털 금지 구역은 레퍼런스 디자인과 일관되게 유지하고, 크리스털 아래로 신호를 라우팅하지 않습니다. 인접 층의 그라운드 동박에 대해 원본의 지침이 서로 충돌하므로 아래 참고를 확인하십시오.
- 크리스털 영역을 전원, RF, USB, SDIO, 디스플레이 클럭, 충전 노이즈에서 멀리 떨어뜨리십시오.

<div align="center"><em>표 5.3-3: 권장 크리스털 파트</em></div>

<div align="center" markdown>

| 크리스털 | 파트 넘버 | 제조사 | 주요 파라미터 |
|:--------|:------------|:-------|:---------------|
| 48 MHz | E1SB48E001G00E | Hosonic | F0 = 48.000000 MHz, ΔF/F0 = -6~+8 ppm, CL = 8.8 pF, ESR <= 22 ohm, TOPR -30~85 °C, 2016 패키지. |
| 32.768 kHz | ETST00327000LE | Hosonic | F0 = 32.768 kHz, ΔF/F0 = -20~+20 ppm, CL = 7 pF, ESR <= 70 kohm, TOPR -40~85 °C, 3215 패키지. |
| 48 MHz | SX20Y048000B31T-8.8 | TKD | F0 = 48.000000 MHz, ΔF/F0 = -10~+10 ppm, CL = 8.8 pF, ESR <= 40 ohm, TOPR -20~75 °C, 2016 패키지. ESR이 높으면 정적 소비 전력이 약간 증가합니다. |
| 32.768 kHz | SF32K32768D71T01 | TKD | F0 = 32.768 kHz, ΔF/F0 = -20~+20 ppm, CL = 7 pF, ESR <= 70 kohm, TOPR -40~85 °C, 3215 패키지. |
| 32.768 kHz | SF32WK32768D71T005 | TKD | F0 = 32.768 kHz, ΔF/F0 = -20~+20 ppm, CL = 7 pF, ESR <= 70 kohm, TOPR -40~85 °C, 3215 패키지. |
| 48 MHz | CN4048M000885C822000 | JWT | F0 = 48.000000 MHz, ΔF/F0 = -8~+8 ppm, CL = 8.8 pF, ESR <= 22 ohm, TOPR -30~85 °C, 2016 패키지. |
| 32.768 kHz | DH2032K76807T2719002 | JWT | F0 = 32.768 kHz, ΔF/F0 = -20~+20 ppm, CL = 7 pF, ESR <= 70 kohm, TOPR -40~85 °C, 3215 패키지. |

</div>

32.768 kHz 크리스털의 `CL`은 레지스터 설정과 일치해야 합니다. 7 pF은 `PMUC->LXT_CR->CAP_SEL = 0`, 11.5 pF은 `PMUC->LXT_CR->CAP_SEL = 1`로 설정합니다. 권장 크리스털 목록은 대부분 7 pF이지만 일부 펌웨어 기본값은 다른 부하 커패시턴스 옵션을 대상으로 할 수 있으므로, EVT 이전에 펌웨어에서 이 설정을 확인하십시오.

!!! warning "원본의 상충하는 크리스털 구리 지침"
    원본 가이드는 크리스털 아래 동박에 대해 일관성이 없습니다. 클럭 참고에서는 최소한 두 번째 층의 그라운드 동박을 제거하라고 하고, 클럭 라우팅 설명에서는 인접 층에 금지 구역을 지정하며, 크리스털 단면 그림에서는 트레이스 아래 L2에 그라운드 동박을 표시하고, 스택업 절에서는 연속된 L2 그라운드 플레인을 요구합니다. 이 서술들만으로 하나의 규칙을 추정하지 마십시오. PCB를 릴리스하기 전에 최신 승인된 SF32LB57x 레퍼런스 디자인을 기준으로 레이아웃을 확정하십시오.

#### 5.3.3. 저전력 클럭 출력 { #533-low-power-clock-outputs }

Sleep, DeepSleep, Standby, Hibernate 모드에서 `PA24`~`PA27` 핀은 RC10K 클럭 또는 32.768 kHz 클럭을 출력할 수 있습니다.

Sleep, DeepSleep, Standby 모드에서 `PA24`~`PA27` 핀은 LPTIM2가 생성하는 최대 16 kHz의 PWM 클럭도 출력할 수 있습니다.

### 5.4. RF { #54-rf }

#### 5.4.1. RF 회로도 { #541-rf-schematic }

주요 RF 회로도 요구 사항:

- 스퓨리어스 필터링과 안테나 튜닝을 위해 안테나 경로에 π 매칭 회로 풋프린트를 확보해 두십시오.
- 참조 회로도는 NC 션트 커패시터 위치와 15 pF/50 V 직렬 커패시터를 보여 줍니다. 원본 설명은 이미 임피던스 매칭이 된 안테나에는 추가 매칭 부품이 필요하지 않다고도 합니다. 어느 위치에 실장할지는 안테나 설계와 RF 측정으로 확인하고, 그림에 표시된 실장 구성을 일반적인 것으로 간주하지 마십시오.
- 매칭 회로는 안테나 쪽이 아니라 칩 RF 핀 가까이에 배치하십시오.
- `AVDD_BRF` 필터 커패시터를 칩 가까이에 배치하고, 그 그라운드를 인근 비아를 통해 메인 그라운드에 직접 연결하십시오.
- 안테나, 매칭 회로, RF ESD, 커넥터를 하나의 신호 체인으로 계획하십시오.

#### 5.4.2. RF PCB { #542-rf-pcb }

PCB 요구 사항:

- RF 트레이스는 싱글 엔디드 50 ohm으로 라우팅합니다.
- 비아와 층 전환을 최소화하여 최상층 라우팅을 우선합니다.
- 예각과 직각 코너를 피합니다.
- 양쪽에 그라운드 동박과 비아 펜스를 추가합니다.
- RF 트레이스 아래에 연속된 그라운드 레퍼런스를 유지합니다.
- RF를 DC/DC, 크리스털, USB, SDIO, 디스플레이 클럭, 충전기 대전류 경로 및 기타 노이즈가 많은 영역에서 멀리 떨어뜨립니다.

#### 5.4.3. RF 브링업과 캘리브레이션 { #543-rf-bring-up-and-calibration }

RF 성능은 측정으로 검증하십시오. 회로도 연결이 올바른 것은 출발점일 뿐입니다.

권장 RF 브링업 항목:

- 48 MHz 크리스털 주파수 오차와 기동 안정성을 확인합니다.
- 전도 시험으로 송신 전력, 주파수 오차, 수신 감도, 변조 품질을 점검합니다.
- 최종 케이스, 배터리, 실드 캔, 안테나 배치 상태에서 π 매칭 회로를 튜닝합니다.
- 디스플레이가 켜져 있을 때, 충전 중일 때, USB/SDIO/디스플레이 리프레시가 동작 중일 때, 모터가 동작 중일 때, 오디오가 동작 중일 때 RF 성능을 검증합니다.
- 생산 지그가 크리스털 캘리브레이션, 기본 RF 시험, 펌웨어 플래싱을 지원하는지 확인합니다.

!!! note
    안테나 매칭은 최종 제품 구조에 가까운 하드웨어에서 완료해야 합니다. 베어 보드에서의 매칭 결과는 대개 최종 제품의 RF 성능을 대변하지 못합니다.

### 5.5. 사용자 인터페이스 { #55-user-interfaces }

#### 5.5.1. 디스플레이, 터치, 백라이트 { #551-display-touch-and-backlight }

패널 타이밍, 전원 시퀀싱, FPC 라우팅, 터치 웨이크업, ESD, 백라이트 노이즈는 보드 브링업 중에 서로 영향을 주는 경우가 많으므로, 디스플레이, 터치, 백라이트를 하나의 인터페이스 그룹으로 검토하십시오.

#### 5.5.2. 디스플레이 인터페이스 선택 { #552-display-interface-selection }

SF32LB57x LCDC는 정확한 디바이스에 따라 여러 디스플레이 인터페이스 유형을 지원합니다.

<div align="center"><em>표 5.5-1: 디스플레이 인터페이스 선택 가이드</em></div>

<div align="center" markdown>

| 인터페이스 | 사용 사례 | 하드웨어 참고 사항 |
|:----------|:---------|:---------------|
| SPI / QSPI | 소형 TFT/AMOLED 및 웨어러블 디스플레이 | 핀 수가 적고 대역폭이 제한적이며 부분 리프레시에 적합합니다. |
| 8080 MCU | 병렬 디스플레이 패널 | 시리얼 인터페이스보다 대역폭이 높지만 더 많은 핀을 사용합니다. |
| RGB / DPI | 중·고해상도 패널 | 연속적인 픽셀 스트림이며 대역폭과 타이밍 요구 사항이 엄격합니다. |
| MIPI DSI | 고밀도 AMOLED | 핀 수가 적으면서 대역폭이 높지만 초기화와 신호 무결성이 더 복잡합니다. |
| EPD | 전자 종이 | 리프레시 속도가 낮고 VCOM, PMIC, 파형 계획이 필요합니다. |
| JDI | Memory-in-Pixel 저전력 디스플레이 | Always-on 및 야외 시인성이 필요한 제품에 적합합니다. |

</div>

일반적인 디스플레이 참고 사항과 예:

- 디스플레이 컨트롤러는 3-line SPI, 4-line SPI, Dual data SPI, Quad data SPI, 16-bit RGB, 16-bit MCU 8080, 16-bit EPD, 시리얼/병렬 JDI를 지원합니다.
- 지원되는 컬러 심도에는 RGB888, RGB666, RGB565, RGB111이 있으며, 최대 해상도는 1024 x 1024에 이를 수 있습니다. 선택한 디바이스에서 지원하는 정확한 모드를 확인하십시오.
- 고해상도 프로젝트는 인터페이스 대역폭, 디스플레이 RAM, PSRAM 대역폭, 리프레시 전략을 초기에 검토하는 것이 좋습니다.
- 프로젝트에 커스텀 핀 배치가 필요하지 않다면, 선택한 패널 인터페이스에 대해 SDK에서 지원하는 IO 그룹 또는 레퍼런스 디자인의 IO 그룹에서 시작하십시오. 매트릭스 라우팅은 유연하지만, 소프트웨어가 지원하는 IO 그룹을 사용하면 드라이버 및 브링업 위험이 줄어듭니다.
- 패널 초기화, 전원 시퀀스, 인터페이스 모드는 패널 제조사 데이터시트를 따라야 합니다.

<div align="center"><em>표 5.5-2: 디스플레이 IO 시작점</em></div>

<div align="center" markdown>

| 디스플레이 인터페이스 | 권장 시작점 |
|:------------------|:---------------------------|
| SPI / QSPI | 핀 멀티플렉싱 표의 전용 `LCDC1_SPI_*` 핀을 우선 사용합니다. 매트릭스 매핑된 LCDC SPI 신호를 사용하는 경우 디스플레이 클럭을 50 MHz 이하로 유지하고 구동 세기를 확인합니다. |
| RGB / DPI | 30 MHz를 넘는 신호에는 매트릭스 매핑된 LCDC 신호에 `PA22`~`PA50`을 사용하며, `PA52`~`PA54`는 `B1`~`B6`에만 사용할 수 있습니다. 속도가 더 낮은 설계는 타이밍을 검토한 후 매트릭스 매핑을 사용할 수 있습니다. |
| 8080 MCU | 고속 설계에는 RGB/DPI와 동일한 고속 핀 그룹 규칙을 사용하며, 패널에 맞춰 버스 폭, 타이밍, 구동 세기를 확인합니다. |
| EPD | EPD 버스가 30 MHz를 넘는 경우 RGB/DPI와 동일한 고속 핀 그룹 규칙을 사용하며, VCOM과 PMIC 제어 핀도 검토합니다. |
| JDI | LCDC JDI 신호 매핑 표를 따르며, 가능하면 SDK에서 지원하는 패널 구성을 우선 사용합니다. |
| MIPI DSI | 선택한 파트와 레퍼런스 디자인의 고정된 DSI 신호 배정을 사용하며, 레인 라우팅과 패널 초기화를 소프트웨어 팀과 함께 검증합니다. |

#### 5.5.3. 디스플레이 및 터치 가이드라인 { #553-display-and-touch-guidelines }

- 디스플레이와 백라이트 전원은 독립적으로 제어하며, 제품에서 달리 요구하지 않는 한 전원 투입 시 기본적으로 꺼 둡니다.
- 고속 디스플레이 클럭에는 EMI 튜닝을 위해 직렬 저항과 선택 사항인 NC 션트 커패시터 풋프린트를 확보해 둡니다.
- FPC, 디스플레이 커넥터, 터치 트레이스를 RF 안테나 영역에서 멀리 떨어뜨립니다.
- 터치 웨이크업이 필요하면 터치 INT를 웨이크업이 가능한 GPIO에 연결합니다.
- 디스플레이, 터치 IC, MCU의 IO 전압 도메인을 일치시킵니다.
- 디스플레이와 터치 인터페이스가 외부에 노출되는 경우 ESD 보호를 추가합니다.
- SPI/QSPI 디스플레이 신호에는 전용 핀 그룹을 우선 사용합니다. RGB, 8080, EPD 및 기타 고속 병렬 인터페이스에는 고속 출력에 적합한 핀 그룹을 선택하고 레이아웃에서 타이밍 일관성을 유지합니다.
- SPI/QSPI가 매트릭스 라우팅을 사용하는 경우 클럭을 50 MHz 이하로 제한하고 GPIO 구동 세기를 `DS1 = 0, DS0 = 1`로 설정합니다.
- 30 MHz를 넘는 RGB, MCU8080, EPD 신호에는 `PA22`~`PA50`의 매트릭스 라우팅을 우선 사용하며, `PA52`~`PA54`는 `B1`~`B6`만 전달할 수 있습니다.

#### 5.5.4. 디스플레이 브링업 순서 { #554-display-bring-up-sequence }

한꺼번에 변수가 너무 많아지지 않도록 디스플레이를 단계별로 브링업합니다.

1. 디스플레이 전원, 리셋, 백라이트/인에이블, 패널 ID 읽기를 검증합니다.
2. 안정적으로 동작하는 가장 낮은 인터페이스 속도에서 단색을 표시하고, RGB 순서, 컬러 심도, 스캔 방향을 확인합니다.
3. 부분 리프레시 윈도우, TE 신호, 프레임 동기화 또는 명령/비디오 모드 동작을 검증합니다.
4. 인터페이스 속도를 점진적으로 높인 후 LVGL, ePicasso, DMA, 백라이트 디밍을 추가합니다.
5. 마지막으로 슬립, 웨이크업, 화면 꺼짐, 화면 켜짐, 충전기 연결/분리, Bluetooth 연결 상태에서의 동작을 검증합니다.

화면 노이즈(snow), 티어링, 잘못된 색상, 간헐적인 리프레시 실패가 발생하면 패널 초기화, 인터페이스 타이밍, 픽셀 포맷, 리프레시 윈도우, 캐시 일관성, FPC 신호 무결성을 먼저 점검하십시오.

#### 5.5.5. 오디오 { #555-audio }

오디오는 노이즈에 민감한 하나의 서브시스템으로 검토하십시오. 마이크 바이어스, 오디오 레퍼런스, 아날로그 입력, DAC 출력, 디지털 오디오 클럭, 외부 PA 제어, 케이스 음향을 함께 점검해야 합니다.

SF32LB57x는 싱글 엔디드 또는 차동 입력을 지원하는 아날로그 ADC 입력 2개, 스피커나 헤드폰을 구동하려면 외부 PA가 필요한 차동 아날로그 DAC 출력 1개, 그리고 디지털 마이크를 총 4개까지 지원하는 PDM 마이크 인터페이스 2개를 제공합니다.

#### 5.5.6. 아날로그 오디오 입력 { #556-analog-audio-input }

가이드라인:

- MIC_BIAS, AUD_VREF, AVDD33_AUD 디커플링 커패시터를 칩 가까이에 배치합니다.
- 아날로그 마이크 입력에는 DC 차단 커패시터를 추가하며, 2.2 uF 이상을 권장합니다.
- 아날로그 입력 부품은 칩 핀 가까이에 배치합니다.
- ADCP 및 기타 아날로그 트레이스는 짧게 유지하고 실드하며 노이즈원에서 멀리 떨어뜨립니다.
- 멀티플렉싱된 GPIO를 아날로그 입력으로 사용할 때는 필요에 따라 해당 핀을 하이 임피던스로 설정합니다.

#### 5.5.7. 아날로그 오디오 출력 { #557-analog-audio-output }

가이드라인:

- DACP/DACN은 차동 쌍으로 라우팅합니다.
- 쌍은 짧게 유지하고 길이를 맞추며, RF, DC/DC, USB, SDIO, 디스플레이 클럭에서 멀리 떨어뜨립니다.
- 출력 RC 매칭 회로는 칩 가까이에 배치합니다.
- 기생 커패시턴스를 오디오 요구 사항 이내로 유지합니다.
- 오디오 전원 및 레퍼런스 경로는 깨끗하고 짧게 유지합니다.

그림 5.5-3의 권장 회로를 따르십시오. 점선 박스 안의 차동 저역 통과 필터는 고주파 간섭을 억제하고 오디오 출력 신호 대 잡음비를 개선하기 위해 칩 핀 가까이에 배치해야 합니다.

#### 5.5.8. 디지털 오디오 { #558-digital-audio }

I2S와 PDM의 경우:

- 주변 장치의 IO 전압을 일치시킵니다.
- 클럭 트레이스 길이, 크로스토크, 레퍼런스 그라운드 연속성을 점검합니다.
- 마이크, 코덱, PA, MCU의 전원 시퀀싱을 검토합니다.
- 슬립 중에 디지털 오디오 주변 장치가 안전한 상태로 들어가도록 합니다.

#### 5.5.9. 오디오 검증 { #559-audio-validation }

오디오 문제는 하드웨어, 케이스, 소프트웨어 게인, 전원 노이즈가 동시에 관여하는 경우가 많습니다. 다음을 검증하십시오.

- 유휴 노이즈, 녹음 노이즈, 재생 노이즈, 충전 중 노이즈.
- 디스플레이 리프레시, Bluetooth 송신, 모터 진동, USB 연결, SDIO 동작 중의 크로스토크.
- 마이크 바이어스 전압, DC 차단 커패시터의 극성/용량, 입력 커먼 모드 범위.
- DACP/DACN 차동 출력 레벨, 부하 매칭, 외부 PA 입력 범위.
- PDM/I2S 클럭 주파수, 채널 매핑, 샘플링 레이트 설정.

#### 5.5.10. 카메라 { #5510-camera }

카메라 인터페이스는 최대 16-bit DVP, 2-data-line SPI, 4-data-line QSPI를 지원합니다.

가이드라인:

- 인터페이스 폭, 클럭, 동기 신호, 데이터 라인, 핀 멀티플렉싱을 확인합니다.
- 카메라 전원, 리셋, PWDN, 클럭을 MCU가 제어할 수 있게 합니다.
- 카메라 데이터와 클럭 트레이스는 길이 그룹으로 묶고 RF 및 아날로그 신호에서 멀리 떨어뜨립니다.
- 고속 카메라 라우팅에는 연속된 레퍼런스 그라운드를 제공합니다.
- 필요한 경우 카메라 커넥터 또는 FPC에 ESD 보호를 추가합니다.

권장 카메라 브링업 순서:

- 카메라 전원, 리셋, PWDN, MCLK, I2C/SPI 제어 경로를 먼저 확인합니다.
- 센서 ID를 읽고 초기화 표와 출력 포맷을 검증합니다.
- 저해상도, 저프레임 레이트 모드로 PCLK, VSYNC, HSYNC/HREF, 데이터 라인 매핑을 검증합니다.
- 기본 경로가 안정된 후에만 해상도와 프레임 레이트를 높이고, 그다음 디스플레이 리프레시, 스토리지 쓰기, Bluetooth 연결과 함께 시험합니다.

#### 5.5.11. 버튼과 모터 { #5511-buttons-and-motor }

- 전원/리셋 키는 반드시 `PA34`를 액티브 하이로 사용해야 합니다. 이 핀은 기본적으로 로우로 풀다운되어 있다가 누르면 하이가 됩니다. `PA34`는 10초 길게 누르면 하드웨어 리셋을 지원하며, 10 kohm 풀다운 저항은 메인 보드에 배치해야 합니다.
- 저항 분압 방식 GPADC 키 설계에서는 분압 전압으로 키를 구분하고, 샘플링 정확도를 높이기 위해 핀 가까이에 그라운드로 연결하는 0.1 uF 필터 커패시터를 배치합니다.
- 참조 래더 회로는 1.1 kohm, 2.8 kohm, 5.1 kohm 키 저항과 함께 10 kohm 풀다운 및 100 nF 필터 커패시터를 보여 줍니다. 이 값들은 참조 회로의 값으로 사용하고, 선택한 전원과 저항 허용 오차에 맞게 ADC 임계값을 검증하십시오.
- 외부 키에는 ESD 보호를 추가하십시오.
