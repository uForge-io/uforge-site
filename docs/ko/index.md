# 차세대 임베디드 디바이스를<br>만들어 보십시오 { #build-the-next-generationof-embedded-devices }

***μForge.io***는 혁신적인 반도체 솔루션을 위한 오픈소스 개발 플랫폼으로, SiFli의 SF32 초저전력 마이크로컨트롤러 제품군에서 시작합니다. 실리콘과 모듈에서 개발 보드, SDK, 문서, 양산용 레퍼런스 디자인까지 전체 스택을 한곳에 모아, 개발자가 연결성과 지능, 에너지 효율을 갖춘 임베디드 제품을 아이디어에서 양산까지 더 빠르고 수월하게 개발할 수 있도록 지원합니다.

## ***SF32***를 선택하는 이유 { #why-choose-sf32 .uf-center-heading }

<div class="grid cards uf-why-grid" markdown>

- :fontawesome-solid-microchip:{ .uf-icon-blue } **고성능**

    코어 수와 기능은 디바이스마다 다릅니다. 제품군은 싱글 코어부터 트라이 코어 설계까지 이어지며, 여러 제품군에서 Cortex-M33 / STAR-MC1 프로세서를 사용합니다. 캐시, FPU, MPU 지원 여부는 개별 칩과 SoC 구현에 따라 다르므로 부품별 문서를 확인하십시오. 일부 디바이스는 패키지 내장 PSRAM을 최대 64 MB까지 제공합니다.

- :fontawesome-brands-bluetooth:{ .uf-icon-blue } **Bluetooth 연결성**

    모드와 기능은 제품군과 부품에 따라 다릅니다. 디바이스에 따라 Bluetooth Classic 및 LE, LE Audio, 장거리 PHY를 지원합니다. 정확한 기능은 칩 페이지에서 확인하십시오.

- :fontawesome-solid-cube:{ .uf-icon-purple } **그래픽 가속**

    2D / 2.5D GPU, LCD 컨트롤러, LVGL 지원으로 풍부하고 부드러운 그래픽 인터페이스를 구현할 수 있습니다. 제품군 전체에서 지원하는 인터페이스는 MIPI, RGB, QSPI, 8080, JDI, EPD이며, 해상도는 최대 1280 × 720입니다.

- :fontawesome-solid-volume-high:{ .uf-icon-pink } **오디오 서브시스템**

    오디오 기능은 제품군과 부품에 따라 다릅니다. 지원 디바이스는 아날로그 오디오, I²S, PDM, 하드웨어 보조 디지털 오디오 처리를 제공합니다.

- :fontawesome-solid-brain:{ .uf-icon-amber } **AI 가속**

    일부 SF32 디바이스는 TinyML 및 기타 엣지 추론 워크로드를 위한 신경망 가속 기능을 내장합니다.

- :fontawesome-solid-leaf:{ .uf-icon-green } **초저전력**

    배터리 전원 및 상시 동작(always-on) 디바이스에 최적화된 고급 전원 관리 아키텍처입니다.
