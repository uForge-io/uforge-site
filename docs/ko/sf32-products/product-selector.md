# SF32 제품 선택기 { #sf32-product-selector }

회로도를 확정하기 전에 SF32 칩과 모듈 후보를 추리십시오. 나중에 변경하면 재설계 비용이 커지는 전원 구성, 패키지, 디스플레이, 오디오, 메모리, GPIO, 연결성, 소프트웨어 검증 경로부터 정한 다음 남은 후보를 비교하십시오.

초기 후보를 추릴 때는 대화형 선택기를 사용하십시오. 이 선택기에는 칩과 모듈만 표시됩니다. 통합 수준, PSRAM 및 GPIO 용량, 패키지, 주 전원, 디스플레이 인터페이스와 목표 해상도, SDIO 수, 오디오 인터페이스 수, 특수 하드웨어 기능을 기준으로 후보를 걸러낼 수 있습니다. 각 결과에서 해당 제품 소개 페이지로 이동할 수 있습니다. 개발 보드는 선택기에서 고르는 부품이 아니라 별도의 검증 플랫폼입니다.

## 제품 선택기 { #product-selector }

!!! info "용어와 오디오 인터페이스 개수"
    약어와 인터페이스 정의는 [용어집](../about/glossary.md)을 참고하십시오. PDM 인터페이스 하나로 디지털 마이크를 최대 2개까지 연결할 수 있으므로, PDM 인터페이스 수와 마이크 수는 같지 않습니다. 실제로 사용할 수 있는 마이크 입력 수와 핀 라우팅은 부품마다 다르므로, 해당 부품의 문서를 확인하십시오.

선택한 필터는 모두 동시에 적용됩니다. 따라서 검색 결과는 활성화된 조건을 전부 충족해야 합니다. 통합 수준, 패키지, 전원, 디스플레이는 한 번에 하나만 선택할 수 있습니다. PSRAM과 GPIO 값은 애플리케이션에 필요한 용량과 핀 수이므로, 후보 부품은 해당 값 이상을 제공해야 합니다. 여기서 "필요한 최대값"은 부품의 상한이 아니라 애플리케이션이 요구하는 최대값을 뜻합니다. 목표 해상도, SDIO 수, 각 오디오 인터페이스 수도 최소 요구량으로 적용됩니다. 기능 체크박스를 선택하면 SDIO 기반 외부 Wi-Fi, DCMI 카메라 인터페이스, AI/ML 가속기, FreeIO, PTM 등 해당 기능을 지원하는 부품만 남습니다. SDIO 수 필터와 외부 Wi-Fi 체크박스는 서로 별개입니다.

결과 표에는 정확한 부품 번호와 패키지, 메모리 용량, 최대 GPIO 수, 전원 및 I/O 전압, 디스플레이 기능, 오디오 인터페이스 수(DAC/ADC/PDM/I2S), 디지털 주변 장치 인터페이스 및 채널 수(UART/I2C/SPI/CAN/GPADC), USB 속도, 제품 카탈로그에 기록된 기능이 표시됩니다. `n/a`는 카탈로그에 해당 항목을 판단할 만한 상세 정보가 없다는 뜻입니다. 값이 0이거나 부품이 해당 기능을 지원하지 않는다는 의미는 아닙니다. 기능 열의 대시는 카탈로그에 해당 기능이 표시되지 않았다는 뜻이므로, 실제 지원 여부는 대상 부품의 문서에서 확인하십시오. 디스플레이 인터페이스 목록은 후보 선별용이며, 전체 핀 멀티플렉싱 목록은 아닙니다.

## 선택 기준 { #selection-factors }

선택기를 자동 추천 도구로 보지 말고, 필수 조건에 맞는 후보를 걸러내는 도구로 사용하십시오. 뒤늦게 발견하면 보드나 회로도를 다시 설계해야 하는 제약 조건부터 확인하고, 나머지 요소를 차례로 비교해 후보를 좁히십시오.

### 통합 수준 { #integration-level }

일정, RF 설계 범위, 보드 설계 책임이 이미 정해져 있다면 세부 사양보다 먼저 통합 수준을 선택하십시오. 칩을 선택하면 설계 자유도가 가장 크지만, 전원 설계부터 RF와 클럭, PCB 레이아웃, 양산 준비까지 직접 책임져야 합니다. 모듈은 모듈 자체의 설계와 통합 부담을 줄여 주지만, 캐리어 보드는 여전히 직접 설계해야 합니다. 개발 보드는 펌웨어와 주변 장치 동작, 시스템 설계 가정을 가장 빠르게 검증할 수 있는 수단입니다. 다만 개발 보드가 곧 양산에 적합한 하드웨어인 것은 아닙니다.

### 전원 공급과 패키지 { #power-supply-and-package }

전원 구성과 패키지는 초기에 결정하십시오. 선택기는 리튬 이온 배터리를 직접 연결하는 전원 레일(3.2~4.7 V), 문서에 해당 구성이 명시된 경우 외부 레귤레이터로 공급하는 3.3 V 전원, 주 전원이 약 1.8 V까지 내려가도 동작하는 부품을 구분합니다. 일부 사양의 최저 동작 전압은 1.71 V입니다. 이 필터는 주 전원 구성을 나타내며 GPIO의 I/O 전압을 뜻하지 않습니다. I/O 전압은 결과에 공칭값으로 별도 표시되며, 보장된 동작 한계와는 다를 수 있습니다. 정확한 부품의 전기적 사양을 확인하십시오. 패키지는 보드 면적, 핀 인출 라우팅의 난이도, 열 전달 경로, 실제 사용할 수 있는 핀 수를 좌우하므로 이 또한 초기에 정해야 합니다. 패키지 필터는 넓은 범주로 나뉘므로, 결과에서 정확한 패키지 명칭을 확인하십시오. 최대 GPIO 수가 더 많은 패키지를 선택해도 전원, 클럭, 디버그, 디스플레이, 메모리, 필수 주변 장치에 핀을 할당하고 나면 부족할 수 있습니다.

### 메모리와 GPIO 여유 { #memory-and-gpio-headroom }

PSRAM과 GPIO 필터에는 필요한 최소 용량과 핀 수를 입력한 다음, 후보 제품의 메모리 구성과 핀 할당을 확인하십시오. PSRAM 용량은 그래픽 버퍼, 오디오 버퍼, ML 모델, 애플리케이션 작업 공간을 얼마나 확보할 수 있는지에 영향을 줍니다. 다만 총용량만으로 연속된 단일 메모리 공간이 보장되지는 않습니다. GPIO 여유를 계산할 때는 첫 프로토타입의 인터페이스뿐 아니라 생산 테스트, 디버그, 인터럽트, 향후 센서, 보드 제어 신호에 필요한 핀도 포함해야 합니다.

### 디스플레이와 그래픽 { #display-and-graphics }

패널이 요구하는 디스플레이 인터페이스로 후보를 거른 다음, 목표 해상도로 대략적인 지원 범위를 가늠하십시오. 가로 × 세로 프리셋은 총 픽셀 수를 기준으로 하므로 정확한 화면비나 패널 타이밍까지 검증하지는 않습니다. 표시된 해상도는 카탈로그에서 후보를 초기 단계에 거르는 기준일 뿐, 지원이 보장되는 패널 모드나 모든 SKU의 공식 최대 해상도가 아닙니다. 정확한 부품과 패널 요구 사항은 SiFli 문서에서 확인하십시오. 선택기에서 RGB로 표시하는 병렬 디스플레이 인터페이스의 정식 명칭은 DPI(Display Pixel Interface)입니다. 나열된 인터페이스가 전체 핀 멀티플렉싱을 보여 주는 것은 아닙니다. 정확한 인터페이스 모드, 메모리 예산, 핀 라우팅, 패널 전원 시퀀스, 소프트웨어 드라이버 경로는 대상 부품의 문서에서 확인하십시오.

### 오디오 인터페이스 { #audio-interfaces }

선택기에는 오디오 DAC, ADC, PDM 인터페이스, I2S 인터페이스별로 필요한 최소 개수를 설정하는 필터가 있습니다. 각 필터는 인터페이스 수의 하한을 나타낼 뿐, 특정 오디오 기능 조합을 통째로 보장하지는 않습니다. 다른 주변 장치와 리소스를 공유하는지, 보드 수준의 아날로그 설계가 적절한지도 확인하십시오.

### 연결성과 특수 하드웨어 { #connectivity-and-specialist-hardware }

Wi-Fi, 카메라, AI 가속기, FreeIO, PTM 필터는 해당 기능이 제품 요구 사항일 때만 적용하십시오. 외부 Wi-Fi 체크박스는 문서화된 SDIO 기반 연결 경로를 나타내며, 내장 Wi-Fi를 의미하지 않습니다. 별도의 SDIO 수 필터는 문서에 명시된 SDIO 인터페이스 수를 확인합니다. 외부 Wi-Fi에는 보드 수준의 전원과 라우팅, 소프트웨어 지원도 필요합니다. 카메라와 AI 요구 사항은 인터페이스부터 메모리 대역폭, 처리 부하, 소프트웨어 스택까지 전체 경로를 함께 검토해야 합니다. FreeIO와 PTM은 신호를 유연하게 할당하거나 주변 장치 작업을 결정적으로 처리해야 할 때 유용합니다. 다만 이런 기능이 더 기본적인 전원, 메모리, 패키지 제약보다 우선되어서는 안 됩니다.

### 검증 근거 { #validation-evidence }

후보를 확정하기 전에 결과에서 제품 소개 페이지로 이동해 정확한 부품 번호, 패키지, 전기적 한계, 레퍼런스 디자인, 설계 가이드와 체크리스트의 제공 여부를 확인하십시오. 가능하면 대상 부품과 하드웨어 구성이 가장 비슷한 지원 개발 보드에서 계획한 펌웨어 흐름을 검증하십시오. 선택기는 후보를 추리는 도구이며, 실제 설계의 기준은 대상 부품에 관한 SiFli 문서입니다.

## 통합 수준 선택 { #choose-an-integration-level }

대화형 카탈로그에는 칩과 모듈만 표시됩니다. 개발 보드는 소프트웨어와 시스템 설계 가정을 검증하는 별도 경로로 아래에 안내합니다.

<div align="center"><em>하드웨어 시작점</em></div>

<div align="center" markdown>

| 시작점 | 선택하는 경우 | 다음 단계 |
|:---------------|:---------------|:----------|
| 칩 | 맞춤형 PCB를 설계하고 인터페이스와 전원 설계를 직접 제어해야 할 때 선택합니다. | 제품군을 선택한 다음, 회로도 작업 전에 해당 양산 설계 가이드를 검토하십시오. |
| 모듈 | 맞춤형 캐리어 보드는 설계하되 RF와 모듈 통합 부담은 줄이고 싶을 때 선택합니다. | 모듈 소개, 인터페이스 정의, 모듈 설계 가이드를 확인하십시오. |
| 개발 보드 | 소프트웨어, 주변 장치 또는 제품 아이디어를 빠르게 검증해야 할 때 선택합니다. | 목표 제품과 가장 가까운 보드에서 검증된 예제를 실행하십시오. 보드 회로도는 참고 자료로 활용하되, 양산 설계로 그대로 간주하지 마십시오. |

</div>

## 후보 확정 { #confirm-the-shortlist }

1. **정확한 부품을 확인합니다.** [SF32 제품군 개요](family/SF32_family.md), 검색 결과의 제품 소개, [명명 규칙](family/SF32_namingrule.md)을 참고해 주문 가능한 부품 번호, 패키지, 전원 토폴로지, 메모리 구성, 인터페이스 할당, 레퍼런스 하드웨어를 확인하십시오. 대표 기능 하나만 보고 부품을 선택하지 마십시오. 필요한 디스플레이, 오디오, 스토리지, 센서, Bluetooth, 저전력 기능을 선택한 패키지와 보드 설계에서 함께 사용할 수 있는지 확인해야 합니다.
2. **소프트웨어 경로를 검증합니다.** 하드웨어를 확정하기 전에, 목표 하드웨어와 가장 가까운 지원 보드에서 [시작하기 개요](../getting-started/index.md), [튜토리얼 개요](../getting-started/tutorials/overview.md), [개발 개요](../develop/index.md)를 따라 개발 흐름을 확인하십시오.
3. **양산 제약 조건을 확인합니다.** 회로도, 레이아웃, BOM, 디스플레이 및 스토리지 구성을 확정하기 전에 [양산 설계](../hardware/design-for-production.md)를 검토하십시오.
