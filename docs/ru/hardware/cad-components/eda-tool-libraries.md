# Библиотеки EDA для SF32 { #sf32-eda-tool-libraries }

## Назначение { #purpose }

SiFli публикует библиотеки символов принципиальных схем и посадочных мест PCB для микросхем и модулей семейства SF32. Используйте их как основу для создания схем и проектирования печатных плат, а не перерисовывайте вручную символы, распиновку и контактные площадки по даташиту.

Библиотеки помогают снизить риски на этапе первичного запуска платы, но не заменяют даташит, чертёж корпуса или руководство по аппаратной разработке для конкретного устройства. Перед выпуском проекта обязательно сверьте выбранный библиотечный компонент с точным номером детали, корпусом, распиновкой, контактными площадками и рекомендациями по разводке для вашего проекта.

JLCEDA / LCEDA Pro и PADS распространяются в архивах; OrCAD — отдельный файл библиотеки `.OLB`. В списке загрузок Wiki нет таблицы поддержки для каждого компонента. Импортируйте файл в выбранный инструмент EDA и убедитесь, что нужный компонент входит в библиотеку.

В указанном репозитории KiCad доступны исходные файлы, релизы с номерами версий и таблица поддерживаемых компонентов. Это упрощает проверку состава библиотеки, но не гарантирует поддержку всех вариантов SF32.

## Сведения о библиотеке KiCad { #kicad-library-detail }

Репозиторий [OpenSiFli/kicad-libraries](https://github.com/OpenSiFli/kicad-libraries) предоставляет официальную библиотеку SiFli для KiCad с символами, посадочными местами и 3D-моделями под лицензией CC-BY-SA-4.0. При подготовке этой статьи 2026-10-05 был проверен [выпуск `1.0.0`](https://github.com/OpenSiFli/kicad-libraries/releases/tag/1.0.0). Перед новым проектом проверьте наличие более новых выпусков.

Таблица соответствует README репозитория, проверенному 2026-10-05, а не результатам проверки каждого вывода во всех загружаемых выпусках. Группы микросхем с подстановочными символами не подтверждают поддержку каждого точного кода заказа. Проверьте выбранные символ, посадочное место и корпус в файле, который вы устанавливаете.

!!! note "Как читать обозначения в README репозитория OpenSiFli"
    В README библиотеки KiCad от OpenSiFli строки микросхем приведены как `SF32LB52XUx` и `SF32LB52xUx`. В системе обозначений SiFli заглавная `X` служит подстановочным символом для буквенных вариантов с внешним питанием, а строчная `x` — для цифровых вариантов с питанием от аккумулятора. В этой статье эти обозначения раскрыты в явные группы SF32LB52B/D/E/G/J и SF32LB520/3/5/7, которые используются в других материалах μForge.

В README репозитория [OpenSiFli/kicad-libraries](https://github.com/OpenSiFli/kicad-libraries) говорится, что автоматическая установка из каталога Package and Content Manager пока не поддерживается. Для ручной установки предлагается скачать ZIP-файл выпуска и выбрать в менеджере **Install from file...**. На странице выпуска `1.0.0` также указаны распаковка ZIP в каталог библиотек KiCad или установка через менеджер с помощью `metadata.json`. Следуйте инструкциям к используемому выпуску; в README установленные библиотеки символов и посадочных мест названы `PCM_SiFli`.

## Контрольный список проверки { #review-checklist }

- [ ] Перед выпуском схемы сверьте номер детали и суффикс корпуса в библиотеке со спецификацией BOM.
- [ ] Сверьте имена и номера выводов символа с даташитом микросхемы и руководством по аппаратной разработке для конкретного устройства.
- [ ] По официальному чертежу корпуса проверьте размер и шаг площадок, границы размещения (courtyard), исполнение открытой площадки и зазоры для монтажа.
- [ ] Используйте 3D-модели только для размещения компонентов и проверки механической совместимости; не принимайте их за размеры для производства или монтажа.
- [ ] Для JLCEDA / LCEDA Pro, PADS и OrCAD проверяйте поддержку каждого компонента после импорта: в списке загрузок Wiki она не указана для каждого компонента.
- [ ] Перед новым проектом проверьте наличие обновлений библиотек. Сохраните проверенную версию архива или пакета вместе с проектом. SiFli может обновлять файлы по мере проверки новых микросхем и модулей. Обновления могут добавлять или изменять компоненты, поэтому перед заменой повторно проверьте новую версию.
