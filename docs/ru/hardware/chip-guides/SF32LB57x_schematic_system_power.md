## 5. Рекомендации по проектированию схемы { #5-schematic-design-guidelines }

В этой главе описана типовая последовательность запуска платы. Сначала завершите проектирование минимальной системы: иначе первая плата может не включиться, не загрузиться с накопителя, не принять прошивку или не перейти в режим отладки. После проверки этой основы рассмотрите систему питания, формирование тактового сигнала, тракт RF, дисплей, аудио, камеру, датчики и другие функции конкретного изделия.

### 5.1. Проектирование минимальной системы { #51-minimum-system-design }

#### 5.1.1. Последовательность проектирования минимальной системы { #511-minimum-system-design-sequence }

Ошибки при первом запуске платы чаще всего связаны с минимальной системой, типом питания, режимом загрузки, подтяжками накопителя, выбором кварцев, компонентами BUCK или отсутствием доступа для загрузки прошивки. Зафиксируйте эти решения до распределения выводов между интерфейсами периферии изделия:

1. Выберите схему минимальной системы, соответствующую корпусу и типу питания.
2. Настройте режим загрузки и отладки через `PA00` / `PA01` и предусмотрите доступ для восстановления.
3. Выберите носитель загрузки и установите необходимые подтяжки на `PA13` / `PA15` / `PA17`.
4. Определите структуру дерева питания, тракт зарядки/OVP, дроссель и конденсаторы BUCK, а также состояния шин по умолчанию; затем выполните подробную проверку по разделу 5.2.
5. Выберите кварцы 48 MHz и 32,768 kHz и подтвердите план калибровки в разделе 5.3.
6. Предусмотрите контрольные точки для DBG-UART, SWD, режима загрузки, шин питания и земли, а также подключение производственной тестовой оснастки.

#### 5.1.3. Накопитель загрузки и конфигурация strap-выводов { #513-boot-storage-and-strap-configuration }

Выберите носитель загрузки до фиксации схемы. Память, интегрированная в корпус, может уже занимать канал MPI; для внешних носителей различаются требования к подтяжкам и управлению питанием.

<div align="center"><em>Таблица 5.1-1: Выбор внешнего носителя загрузки</em></div>

<div align="center" markdown>

| `Bootstrap[1]` (`PA13`) | `Bootstrap[0]` (`PA17`) | Внешний носитель загрузки |
|:------------------------|:------------------------|:--------------------|
| L | L | SPI NOR Flash |
| L | H | SPI NAND Flash |
| H | L | SD NAND Flash |
| H | H | eMMC |

</div>

<div align="center"><em>Таблица 5.1-2: Требования к подтяжкам внешних носителей загрузки</em></div>

<div align="center" markdown>

| Носитель загрузки | Требования к подтяжкам |
|:-----------|:--------------------|
| SPI NOR Flash | Внешние подтягивающие резисторы на `PA13` / `PA17` не требуются. |
| SPI NAND Flash | Для `PA17` требуется подтяжка 7,5 kΩ; для `PA13` подтяжка не нужна. |
| SD NAND Flash | Для `PA13` и `PA15` нужны подтяжки 7,5 kΩ; для `PA17` подтяжка не нужна. |
| eMMC | Для `PA13`, `PA15` и `PA17` нужны подтяжки 7,5 kΩ. |

</div>

![Рисунок 5.1-7: Рекомендуемая схема подключения выводов Bootstrap](../../sf32-products/chips/assets/57x/SF32LB57x-A-Bootstrap.png){ width="100%" loading="lazy" }

<div align="center"><em>Рисунок 5.1-7: Рекомендуемая схема подключения выводов Bootstrap</em></div>

Проектируйте питание загрузочного носителя с учётом его типа и семейства питания. В вариантах с питанием от аккумулятора внешнюю NOR Flash подключают к `VDD33_VOUT1`; для внешней SPI NAND Flash требуется ключ нагрузки после `VDD33_VOUT1`; внешние SD NAND Flash и eMMC питаются от внешнего LDO. В вариантах с питанием 3,3 V для всех внешних загрузочных носителей используют внешний LDO. SiFli рекомендует `PA21` для включения ключа питания внешнего носителя: высокий логический уровень включает питание, низкий — отключает его. Если в аккумуляторном варианте вывод `PA21` недоступен, руководство допускает использовать вместо него GPIO с подтяжкой вверх по умолчанию. Убедитесь, что питание носителя доступно во время загрузки. Если память, интегрированная в корпус, уже занимает MPI3, внешний MPI3 можно использовать только для SD NAND или eMMC; не подключайте к этому каналу внешние SPI NOR/SPI NAND.

#### 5.1.4. Доступ к отладке и загрузке прошивки { #514-debug-and-download-access }

Предусмотрите доступ к отладке и восстановлению до назначения выводов изделия. Многие сбои первой платы трудно устранить, если недоступны DBG-UART по умолчанию, конфигурационные выводы загрузки или интерфейс SWD.

<div align="center"><em>Таблица 5.1-3: Рекомендуемые контрольные точки для отладки и загрузки</em></div>

<div align="center" markdown>

| Контрольная точка | Рекомендация | Назначение |
|:-----------|:---------------|:--------|
| Вход питания | `VBAT` или 3,3 V; при необходимости также предусмотрите `VSYS` / `VDD33_VOUT1` | Питание от оснастки, измерение тока, проверка режима низкого потребления. |
| GND | Несколько контрольных точек земли | Обратный путь для загрузки, отладки, калибровки и измерения тока. |
| DBG-UART | `PA18` / `PA19`, соответствуют `DBG_UART_RXD` / `DBG_UART_TXD` | Загрузка по умолчанию, журналы и программирование на производстве. |
| SWD | `PA43` / `PA44` либо выводы SWDIO/SWCLK, определённые номером детали | Отладка и анализ неисправностей. |
| Режим загрузки | `PA00` либо вывод выбора режима загрузки, определённый номером детали | Переход в режим загрузки или восстановления. |
| Переключение SWD | `PA01` либо соответствующий конфигурационный вывод | Используется, если требуется переключить расположение выводов SWD. |
| Кнопка питания / пробуждение | `PA34` либо соответствующий вывод кнопки | Проверка включения, сброса или пробуждения с помощью оснастки. |

</div>

<div align="center"><em>Таблица 5.1-4: Подключение отладочных интерфейсов по умолчанию</em></div>

<div align="center" markdown>

| Отладочный сигнал | Вывод | Имя цепи |
|:-------------|:----|:---------|
| `DBG_UART_RXD` | `PA18` | `USART1_RXD` |
| `DBG_UART_TXD` | `PA19` | `USART1_TXD` |
| `SWD_CLK` | `PA43` | `SWCLK` |
| `SWD_DIO` | `PA44` | `SWDIO` |

</div>

!!! warning
    На производственных контрольных точках должны быть доступны и `DBG_UART_RXD`, и `DBG_UART_TXD`. Не допускайте повторного резервирования RXD.

`PA18`/`PA19` по умолчанию используются для DBG-UART, а `PA43`/`PA44` — для SWD; SWD также можно переключить на `PA18`/`PA19`. Микросхема поддерживает четыре интерфейса загрузки: DBG-UART, SWD, стандартный UART и USB. При обычной загрузке доступны только DBG-UART и SWD; режим BOOT позволяет использовать все четыре интерфейса. Режим BOOT и переключение выводов SWD зависят от `PA00`, регистра BOOT, `PA01` и переключателя BOOT на хосте. При проектировании производственной прошивки и восстановления сверьтесь с полной таблицей режимов в источнике; не определяйте интерфейс загрузки только по состоянию одного вывода.

### 5.2. Система питания { #52-power-system }

#### 5.2.1. Планирование дерева питания { #521-power-tree-planning }

До разработки схемы составьте дерево питания. Для каждой шины укажите источник, состояние по умолчанию, максимальную нагрузку, состояние в режиме сна и управляющий GPIO.

<div align="center"><em>Таблица 5.2-1: Краткий справочник по планированию шин питания</em></div>

<div align="center" markdown>

| Категория шины | Что учесть при планировании |
|:--------------|:---------------|
| Постоянно включённые шины | Оставьте только RTC, пробуждение, необходимое обнаружение событий и цепи сохранения состояния Bluetooth. Рассчитайте статический ток отдельно для каждого блока. |
| Коммутируемые шины периферии | Для дисплея, подсветки, датчиков, двигателя, внешнего накопителя и камеры предпочтительно использовать ключи нагрузки или коммутируемые LDO. |
| Аналоговые шины, RF и аудио | Фильтруйте их отдельно, делайте контуры короткими и изолируйте от цифровых областей с большими токами и высокой скоростью сигналов. |
| Шина носителя загрузки | Состояние по умолчанию должно обеспечивать загрузку, а в режиме сна необходимо исключить обратное питание и токи утечки. |
| Шины подтяжек | Проектируйте подтяжки I2C, кнопок, прерываний датчиков и других сигналов с учётом политики питания соответствующей периферии. |

</div>

#### 5.2.2. Варианты с питанием от аккумулятора { #522-battery-powered-variants }

В вариантах с питанием от аккумулятора обычно используются `VBUS`, `VBAT`, `VCC`, `VSYS`, `BUCK_LX`, `BUCK_FB`, выходы внутренних LDO, а также выводы питания аудио и RF.

Основные требования:

- Держите `VBUS` в допустимом диапазоне входного напряжения и предусмотрите защиту OVP.
- Подключите `VBAT` к аккумулятору и используйте этот вывод для измерения его напряжения.
- Считайте `VCC` основным входом питания системы. Предусмотрите достаточную ширину дорожек и разместите развязывающие конденсаторы рядом с микросхемой.
- Используйте `VSYS` только для указанных внутренних нагрузок, `AVDD_BRF` и цепей подтяжки GPIO; не питайте от него внешнюю периферию.
- Используйте `VDD33_VOUT1`, `VDD33_VOUT2` и другие выходы внутренних регуляторов только для прямо разрешённых нагрузок. В исходных материалах SiFli есть противоречие: в тексте и на схеме низкого энергопотребления к `VDD33_VOUT1` подключены внешние датчики, а список проверки питания разрешает только встроенную или внешнюю NOR/NAND Flash и `AVDD33_AUD`, запрещая другую периферию. Пока SiFli не прояснит это противоречие, не подключайте датчики к `VDD33_VOUT1`.
- Подключайте `AVDD_BRF` и `AVDD33_AUD` к рекомендованным шинам питания с локальной фильтрацией.

#### 5.2.3. Варианты с питанием 3,3 V { #523-33-v-supply-variants }

В вариантах с питанием 3,3 V внешняя шина 3,3 V обычно используется для `PVDD`, `AVDD33`, `AVDD_BRF`, `AVDD33_AUD`, `VDDIOA` и связанных доменов.

Основные требования:

- Для важных доменов 3,3 V используйте разводку по схеме «звезда».
- Фильтруйте аналоговое питание, RF и аудио отдельно от цифровых цепей с большими токами или высокой скоростью сигналов.
- Если `VBATS` используется для измерения напряжения аккумулятора, проверьте допустимый диапазон входного напряжения и фильтрацию.
- В вариантах с питанием 3,3 V подавайте питание на все внешние носители загрузки через внешний LDO; рекомендуется управлять его включением с помощью `PA21`.
- Подключайте внутренние опорные выводы и выходы внутренних LDO только к требуемым внешним конденсаторам. Не подавайте на них внешнее напряжение.

| `VDD33_VOUT2` | Около 2,2 µF | Дисплей, двигатель или указанные коммутируемые нагрузки | Состояние по умолчанию и пусковой ток должны соответствовать настройкам прошивки. |

#### 5.2.6. Зарядка и OVP { #526-charging-and-ovp }

В устройствах с аккумулятором можно использовать внешнее зарядное устройство или встроенный блок зарядки.

<div align="center"><em>Таблица 5.2-4: Сравнение вариантов зарядки</em></div>

<div align="center" markdown>

| Вариант | Путь питания | Примечания |
|:-------|:---------|:------|
| Внешнее зарядное устройство без PPM | Аккумулятор напрямую питает выводы микросхемы `VBAT` и `VCC`. | Канал GPADC микросхемы на `VBAT` измеряет напряжение аккумулятора с точностью выборки ±30 mV. |
| Внешнее зарядное устройство с PPM | Выход `VSYS` зарядного устройства питает `VCC` микросхемы; его `VBAT` подключён к аккумулятору и выводу `VBAT` микросхемы. | Канал GPADC микросхемы на `VBAT` измеряет напряжение аккумулятора с точностью выборки ±30 mV. |
| Встроенное зарядное устройство | Используется встроенный блок управления зарядкой микросхемы. | Если система отключилась из-за низкого заряда аккумулятора, перед запуском системы и отображением экрана зарядки напряжение аккумулятора должно достичь уровня загрузки. Согласно списку проверки источника, программное обеспечение включает дисплей, когда напряжение аккумулятора достигает примерно 3,6 V. |

</div>

Рекомендации по OVP:

- Напряжение `VBUS` не должно превышать допустимый диапазон входа.
- Для OVP с регулируемым OVLO SiFli приводит AW32905FCR в качестве примера. В описании применения указан диапазон 5,2–5,5 V, а в контрольном списке — 5,15–5,55 V. До уточнения со стороны SiFli используйте пересечение этих диапазонов: 5,2–5,5 V. Учтите допуски устройства и делителя в формуле `V_IN_OVLO = ((R1 + R2) / R2) × V_OVLO_TH`; ошибка `V_OVLO_TH` должна быть не более 3 %, а резисторы R1/R2 должны иметь допуск 1 %.
- Для OVP со стабилизированным выходом SiFli приводит SGM4064YDE8G и LP5305AQVF. В описании применения указан диапазон 4,5–5,4 V, а в контрольном списке — 4,7–5,4 V. До уточнения со стороны SiFli используйте более узкий диапазон 4,7–5,4 V, нагрузочную способность не менее 0,5 A и порог защиты от перегрузки по току не менее 0,7 A.
- Подключайте вход зарядного устройства к микросхеме через защиту TVS/OVP.

!!! warning "Расхождение в диапазоне VBUS"
    В таблице выводов питания и контрольном списке указан диапазон входа `VBUS` 4,6–5,5 V, а в описании выбора OVP — 4,5–5,5 V. До уточнения со стороны SiFli используйте 4,6 V как минимальное рабочее напряжение.

#### 5.2.7. Стратегия питания с низким энергопотреблением { #527-low-power-supply-strategy }

Режим низкого энергопотребления необходимо учитывать уже при проектировании схемы.

Рекомендации:

- Используйте ключи нагрузки или коммутируемые LDO для дисплея, подсветки, датчиков, двигателя и внешнего накопителя.
- Выбирайте микросхемы управления питанием с активным высоким уровнем на входе EN. Если выход должен быть выключен по умолчанию, подтяните EN к земле резистором 1–5,1 MΩ; номинал выбирайте с учётом целевого энергопотребления изделия.
- Для MOSFET-ключа питания используйте рекомендованную в источнике топологию PMOS + NMOS: высокий уровень на входе управления включает питание, низкий — выключает. Зафиксируйте этот вход подтяжкой 1 MΩ к земле.
- Питайте подтяжки I2C от той же шины, что и соответствующую периферию, чтобы избежать утечек в режиме сна.
- Для постоянно включённых цепей выбирайте компоненты с низким Iq и малым током в выключенном состоянии.
- Если `VSYS` или постоянно включённый LDO используется как шина подтяжки GPIO, учтите ток утечки в бюджете тока в режиме сна.

| Требуется немедленное включение экрана | Если дисплей должен включаться сразу после подключения зарядного устройства, используйте внешнее зарядное устройство с управлением силовым трактом PPM. |
| Параметры аккумулятора | Зарядка через `VBAT` поддерживает аккумуляторы с номинальным напряжением 4,2–4,45 V; ток предварительной зарядки составляет около 40 mA, максимальный ток зарядки — 1C, но не более 400 mA. |

</div>

#### 5.2.12. Проектирование пробуждения { #5212-wake-design }

- Подключайте кнопки, сигналы прерывания сенсорного экрана и датчиков, от которых требуется пробуждение, к GPIO с поддержкой пробуждения.
- По возможности назначайте внешние сигналы аппаратного пробуждения на выводы `PA33`–`PA42` и указывайте их функцию на схеме.
- Проверьте удержание уровня IO, режим High-Z, подтяжки вверх/вниз и состояние питания периферии в режимах Standby и Hibernate.
- Для пробуждения при подключении USB подключите делитель напряжения VBUS к GPIO с поддержкой пробуждения и подходящим уровнем IO.
- Согласуйте пробуждение по Bluetooth, RTC и внешним сигналам с политикой низкого энергопотребления прошивки.
