### 6.18.4. Тактирование { #6184-clock }

<div align="center"><em>Таблица 6.18.4-1. Проверка тактирования</em></div>

<div align="center" markdown>

| № | Проверяемый пункт | Категория |
|:---|:---|:---|
| 1 | Кварцевый резонатор установлен рядом с микросхемой | Обязательно |
| 2 | Вокруг кварцевого резонатора предусмотрено экранирование землёй GND | Обязательно |
| 3 | Под кварцевым резонатором не должно быть меди. На четырёхслойной плате зона без меди должна охватывать как минимум слои 1 (верхний), 2 и 3 | Обязательно |
| 4 | Расстояние от дорожки кварцевого резонатора до защитной медной заливки GND превышает трёхкратную ширину дорожки | Обязательно |

</div>

!!! warning "Уточните у SiFli количество слоёв в зоне запрета вокруг резонатора"
    В рабочей книге для четырёхслойной PCB указана зона без меди на слоях 1, 2 и 3. В [руководстве по разводке PCB](SF32LB58x_pcb_layout.md#65-clock-interface-routing) указаны поверхностный слой и соседний слой под областью каждого резонатора. Источники расходятся в том, должен ли включаться слой 3; не делайте вывод о требовании без подтверждения SiFli.

### 6.18.8. Высокоскоростные сигналы { #6188-high-speed-signals }

<div align="center"><em>Таблица 6.18.8-1. Проверка высокоскоростных сигналов</em></div>

<div align="center" markdown>

| № | Проверяемый пункт | Категория |
|:---|:---|:---|
| 1 | Дифференциальные сигналы DSI соответствуют требованию к дифференциальному импедансу 100 Ω | Обязательно |
| 2 | Длина дифференциальных пар данных DSI согласована с длиной дифференциальной пары тактового сигнала с отклонением не более 200 mil | Обязательно |
| 3 | Сигналы DSI следует по возможности прокладывать на одном слое | Обязательно |

</div>

!!! warning "В источниках расходятся ограничения согласования длины пар DSI"
    В этой рабочей книге требуется согласовать каждую пару данных DSI с тактовой парой с отклонением не более 200 mil (5,08 mm). В [руководстве по разводке PCB](SF32LB58x_pcb_layout.md#610-dsi-interface-routing) разница длины между парами ограничена значением не более 2 mm, а внутри пары — не более 0,5 mm. Ограничения между парами противоречат друг другу; до окончательной разводки подтвердите у SiFli, какое из них применимо.
