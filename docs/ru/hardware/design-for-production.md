# Разработка для серийного производства { #design-for-production }

Используйте этот порядок действий после выбора чипа или модуля и до выпуска схемы, разводки PCB, BOM или комплекта производственной документации. Здесь собраны практические материалы для снижения рисков при первом запуске и квалификации изделия: руководства по проектированию аппаратной части конкретных устройств, контрольные списки, определения интерфейсов модулей, утверждённые компоненты и библиотеки EDA.

## Рекомендуемая последовательность подготовки к производству { #recommended-production-sequence }

Рассматривайте этот порядок как повторяющийся цикл проверок, а не разовую передачу проекта. Проверьте условные обозначения и посадочные места до изготовления прототипа; выпускайте CAD-файлы и производственную документацию для серии только после проверки проекта и испытаний аппаратуры, предназначенной для серийного выпуска. При изменении платы, прошивки или BOM повторите затронутые проверки.

## Используйте подходящие материалы для выбранного изделия { #use-the-right-reference-for-the-chosen-product }

Для реализации проекта используйте следующие материалы:

- **[Руководства по проектированию аппаратной части](index.md#find-a-guide)** содержат рекомендации для конкретных чипов по схемотехнике, разводке, питанию, интерфейсам и первоначальному запуску, а для модулей — рекомендации по интеграции на плату-носитель. Если для изделия есть соответствующий контрольный список, используйте и его. Для модуля сначала изучите его описание, чтобы убедиться, что он подходит к архитектуре продукта.
- **[Модули M2](m2-modules/interface-standards-overview.md)** содержат правила обозначения M2 от μForge и проект определения интерфейса на уровне контактов. Это определение пока является предложением; проверьте его до принятия обязательств по серийному выпуску.
- **[CAD и компоненты](cad-components/components-and-cad-libraries.md)** содержат [AVL от SiFli](cad-components/sifli-approved-vendor-list.md) и [официальные библиотеки EDA](cad-components/eda-tool-libraries.md). Ни AVL, ни библиотеки не заменяют окончательную проверку конкретной модели, чертежа корпуса и выбранного руководства по проектированию.

## Материалы для серийного производства не заменяют проверку изделия { #a-production-reference-is-not-a-substitute-for-validation }

Руководства по проектированию и списки квалифицированных компонентов снижают риски, но сами по себе не подтверждают, что конечное изделие прошло проверку. Проверьте финальную ревизию PCB, образ прошивки, корпус устройства, аккумулятор, дисплей, накопитель, поведение RF, условия эксплуатации и процесс производственных испытаний. Любые отступления от руководства или контрольного списка фиксируйте как обоснованные инженерные решения, а не как незадокументированные исключения.
