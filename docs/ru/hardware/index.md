# Аппаратная часть { #hardware }

После выбора устройства SF32 и проверки базовой конфигурации на отладочной плате используйте этот раздел, чтобы разработать собственную плату на базе микросхемы или плату-носитель модуля и подготовить проект к производству. Если есть подходящий референсный дизайн, возьмите его за основу. Затем следуйте руководству для выбранного устройства и соберите результаты проверок и проектную документацию для оценки готовности проекта к производству.

## Следуйте этапам разработки аппаратуры { #follow-the-hardware-path }

1. **Повторно используйте подходящее референсное решение.** Перед адаптацией воспроизведите указанную в нём конфигурацию аппаратуры и ПО. Если подходящего решения нет, начните с руководства для выбранного устройства.
2. **Разработайте и проверьте проект.** До создания принципиальной схемы изучите соответствующее руководство, а при проверке схемы и разводки платы используйте контрольный список. До фиксации аппаратной конфигурации проверьте целевое ПО и периферийные функции на наиболее подходящей [отладочной плате](../sf32-products/index.md). Испытания на отладочной плате не заменяют проверку питания, функций выводов и RF на окончательной плате.
3. **Используйте материалы по M2, если плата-носитель должна следовать предложению M2.** Примените [правила наименования M2](m2-modules/M2%20Interface%20Naming%20Rules.md) и проверьте [описание интерфейса](m2-modules/M2-interface-definition.md) для точного варианта модуля, прежде чем окончательно определять интерфейс; назначение выводов пока представлено в предварительной версии.
4. **Проверьте CAD-материалы и выбор компонентов.** В разделе [CAD и компоненты](cad-components/components-and-cad-libraries.md) сверьте для точного номера изделия условное графическое обозначение, посадочное место, чертёж корпуса, AVL и допущения по критически важным компонентам.
5. **Завершите проверку готовности к производству.** Переходите к разделу [Разработка для серийного производства](design-for-production.md), подготовив подтверждения по проекту, согласованные отступления от требований, оставшиеся риски и допущения по производственным испытаниям.

## Следующие шаги разработки { #stay-connected-to-the-platform-path }

Если вы ещё не выбрали микросхему, модуль или отладочную плату, вернитесь к разделу [Продукты SF32](../sf32-products/index.md). В разделе [Начало работы](../getting-started/index.md) описана базовая последовательность: настройка инструментальной цепочки, прошивка платы и просмотр журналов через последовательный порт. Раздел [Разработка](../develop/index.md) содержит рекомендации по реализации ПО, которую также необходимо проверять вместе с аппаратурой.
