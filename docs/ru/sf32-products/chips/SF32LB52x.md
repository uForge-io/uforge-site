# SF32LB52x { #sf32lb52x }

## Обзор { #overview }

SF32LB52x — экономичное семейство MCU от SiFli для умных носимых устройств начального уровня, компактных графических HMI, периферийных устройств Bluetooth и других AIoT-изделий с ограниченным местом на плате. При этом таким устройствам нужны встроенные функции работы с дисплеем, аудио, памятью и беспроводной связью.

В основе платформы — прикладное ядро Arm Cortex-M33 STAR-MC1[^1] с частотой 240 MHz и отдельное маломощное ядро контроллера Bluetooth с частотой 24 MHz. Такое разделение позволяет оставить ресурсоёмкий интерфейс и прикладное ПО на основном ядре, а задачи Bluetooth и постоянно работающие процессы выполнять отдельно.

При планировании изделия основные варианты, перечисленные в руководстве SiFli по моделям микросхем, удобно разделить на две группы по типу питания:

- **SF32LB520/3/5/7**: варианты с питанием от литий-ионного аккумулятора и встроенной цепью зарядки
- **52B/D/E/G/J**: варианты с внешним питанием; 52B/E/G/J рассчитаны на стандартные системы 3,3 V, а **52D** — на специальные линии питания 1,8 V для устройств с особо низким энергопотреблением

Эти группы нельзя напрямую заменять друг другом на плате. Варианты с питанием от аккумулятора и внешним питанием имеют разную распиновку. Кроме того, 52D с питанием 1,8 V электрически отличается от группы 52B/E/G/J на 3,3 V, даже если расположение выводов корпуса кажется похожим.

[^1]: STAR-MC1 — конфигурируемый процессорный IP-блок Armv8-M Mainline для встроенных систем от Arm China. Для совместимых устройств SF32 компания SiFli описывает его как прикладной процессор Arm Cortex-M33 STAR-MC1. Программная модель класса Cortex-M33 упрощает повторное использование существующих прошивок, middleware, портов RTOS и инструментов для Cortex-M33, но для каждого устройства по-прежнему требуется обычная специализированная интеграция. Конфигурации CU, SP и SE различаются главным образом кэшем, TCM, XIPU и поддержкой TrustZone; пользовательские инструкции Arm/CDE и интерфейс сопроцессора являются опциональными возможностями, которые нужно проверять для конкретного компонента SF32. В зависимости от контекста в документации SiFli используются обозначения ***Arm Cortex-M33 STAR-MC1*** или ***Arm Cortex-M33***.

## Применение { #applications }

**SF32LB52x подходит для** устройств, в которых Bluetooth, низкая стоимость, высокая степень интеграции и длительная автономная работа имеют первостепенное значение. Примеры изделий:

- умные часы и фитнес-браслеты начального уровня
- Bluetooth-модули и беспроводные адаптеры
- Bluetooth-аудиоаксессуары
- умные датчики и носимые устройства
- электронные ценники и умные бейджи
- портативные принтеры этикеток
- дисплеи для электровелосипедов и электросамокатов
- простые HMI-устройства на базе LVGL

## Характеристики { #features-and-specs }

### Вычислительные возможности и память { #compute-and-memory }

- Прикладное ядро Arm Cortex-M33 STAR-MC1 с частотой до 240 MHz, DSP и MPU
- Отдельное ядро контроллера Bluetooth Arm Cortex-M33 STAR-MC1 с частотой 24 MHz
- Кэш инструкций 32 KB и кэш данных 16 KB
- SRAM для приложения объёмом 512 KB и SRAM для контроллера Bluetooth объёмом 64 KB
- Встроенная в корпус память зависит от варианта: от 1 MB QSPI-NOR до 16 MB OPI-PSRAM

### Графика и аудио { #graphics-and-audio }

- Графический ускоритель 2D/2.5D ePicasso 2.0
- Аппаратный декодер eZip 2.0 для сжатия графики без потерь
- Отдельный LCD-контроллер с поддержкой SPI/DSPI/QSPI, включая SPI для электронной бумаги, а также 8-битного интерфейса 8080
- 1 аудио-АЦП (ADC) с разрядностью 24 бит и SNR 99 dB
- 1 аудио-ЦАП (DAC) с разрядностью 24 бит и SNR 109 dB

### Беспроводная связь { #wireless-connectivity }

- Двухрежимный Bluetooth 5.3 (Bluetooth Classic и BLE)
- Максимальная мощность передачи:
    - 19 dBm для BLE/BR
    - 13 dBm для BT/EDR2 и BT/EDR3
- Чувствительность: -100 dBm при BLE/1 Mbps
- Отдельное ядро контроллера Bluetooth Arm Cortex-M33 STAR-MC1 с SRAM 64 KB и частотой 24 MHz
- В описании продукта указан ток в режиме сна 2 µA; ток покоя всей системы зависит от режима работы и утечек на плате

### Безопасность { #security }

- Аппаратные ускорители AES/HASH/CRC
- TRNG
- PSA Certified Level 1

### Периферия и ввод-вывод { #peripherals-and-ios }

- 3 UART
- 4 I2C
- 2 SPI
- 1 USB 2.0 FS
- 1 I2S
- 1 интерфейс PDM (поддерживает подключение до двух цифровых микрофонов)
- 1 SD3.0/SDIO3.0/eMMC
- 1 универсальный 12-битный ADC
- Датчик температуры
- RTC и таймеры watchdog
- 44 или 45 GPIO в зависимости от семейства вариантов

### Питание { #power-supply }

- **Группа с питанием от аккумулятора: SF32LB520/3/5/7** — прямое питание от одноэлементного аккумулятора Li-ion/Li-Po; предназначена для устройств со встроенной архитектурой питания и зарядки.

- **Группа с внешним питанием 3,3 V: 52B/E/G/J** — рассчитана на системы со стабилизированным внешним питанием; варианты внутри группы совместимы по выводам.

- **Группа с внешним питанием 1,8 V: SF32LB52D** — рассчитана на специальные устройства с особо низким энергопотреблением при 1,8 V; электрически не взаимозаменяема с вариантами на 3,3 V.

Группы с питанием от аккумулятора и внешним питанием построены на разных конфигурациях кристалла и **не совместимы по выводам между собой**.

## Варианты семейства { #family-variants }


Для основных вариантов из руководства SiFli по моделям микросхем ориентируйтесь на такое разделение:

- **SF32LB520/3/5/7**: группа с питанием от литий-ионного аккумулятора; варианты совместимы по распиновке внутри группы
- **52B/E/G/J**: стандартная группа с внешним питанием 3,3 V; варианты совместимы по распиновке внутри группы
- **SF32LB52D**: специальный вариант с внешним питанием 1,8 V для устройств с особо низким энергопотреблением

При переходе между вариантами с разным объёмом памяти ближайшее соответствие по конфигурации такое:

- 520 ↔ 52B
- 523 ↔ 52E; 52D — аналог с питанием 1,8 V
- 525 ↔ 52G
- 527 ↔ 52J

## Путь интеграции { #integration-path }

Двигайтесь по этому плану, чтобы превратить предварительный выбор SF32LB52x в проверенное решение:

1. **Проверьте программную поддержку.** Начните с [руководства по началу работы с SiFli SDK](../../getting-started/sifli/getting-started-sifli-sdk.md), затем используйте [процесс разработки с SiFli SDK](../../develop/platforms/sifli-sdk/overview.md) и [примеры](../../develop/examples/index.md), чтобы проверить работу необходимых периферийных устройств и Bluetooth.
2. **Выберите способ интеграции.** Если готовый RF-модуль подходит изделию, рассмотрите [SF32LB52-MOD-1](../modules/SF32LB52-MOD-1.md); в противном случае выберите наиболее близкую [отладочную плату SF32LB52](../devkits/SF32LB52-DevKit-LCD.md) для ранней проверки прошивки и периферии.
3. **Спроектируйте и проверьте аппаратную часть.** До выпуска схемы или разводки используйте [руководство по проектированию аппаратной части](../../hardware/chip-guides/SF32LB52x_hardware_design_guide.md) и его чек-листы для [схемы](../../hardware/chip-guides/SF32LB52x_schematic_checklist.md) и [разводки PCB](../../hardware/chip-guides/SF32LB52x_pcb_layout_checklist.md). Убедитесь, что выбрана нужная группа питания: 520/3/5/7, 52B/E/G/J или 52D.
4. **Сверьтесь с первичными источниками.** Сопоставьте подходящий [даташит](#development-resources) и руководство SiFli по проектированию аппаратной части для [520/3/5/7][Hardware Design Guide (520/3/5/7)] либо для [52B/D/E/G/J][Hardware Design Guide (52B/D/E/G/J)] с точным заказным номером и корпусом компонента.

## Часто задаваемые вопросы { #frequently-asked-questions }

**Каковы основные характеристики SF32LB52x?**
SF32LB52x сочетает прикладной CPU (Cortex-M33 @240 MHz) и энергоэффективное ядро (Cortex-M33 @24/48 MHz, выделенный Bluetooth-контроллер), 576 KB внутренней SRAM и двухрежимный Bluetooth (классический + BLE). Графика: ePicasso 2.0 Lite. Корпус: QFN68 (7 × 7 mm). USB 2.0 FS. Значения даны для семейства; проверяйте даташит конкретной модели.

**Какие интерфейсы дисплея поддерживает SF32LB52x?**
SPI / DSPI / QSPI / 8080 / EPD / JDI. Набор зависит от модели и корпуса.

**Сколько памяти в корпусе у SF32LB52x?**
До 16 MB PSRAM и до 4 MB NOR Flash в корпусе, в зависимости от модели.

**Какое напряжение питания нужно SF32LB52x?**
3.2–4.7 V (520/3/5/7), 2.97–3.63 V (52B/E/G/J), 1.8 V (52D), в зависимости от варианта. Точный диапазон уточняйте в даташите.

**С чего начать аппаратную разработку на SF32LB52x?**
Начните с [руководства по аппаратному проектированию SF32LB52x](../../hardware/chip-guides/SF32LB52x_hardware_design_guide.md): схема, питание, тактирование/RF и разводка PCB, а перед выпуском платы используйте контрольные списки схемы и разводки.

## Связанные изделия { #related-products }

### Модуль { #module }

[SF32LB52-MOD-1](../modules/SF32LB52-MOD-1.md) объединяет микросхему SF32LB525UC6, которая в стандартной конфигурации содержит 8 MB OPI-PSRAM в том же корпусе, с RF-согласующей цепью. Размер модуля — 27,9 × 18,0 × 3,1 mm. Он подходит проектам, которым нужны возможности SF32LB52 без самостоятельной разработки и проверки RF-тракта на уровне микросхемы.

### Отладочные платы { #development-kits }

- [SF32LB52-DevKit-LCD](../devkits/SF32LB52-DevKit-LCD.md) — основная плата для первоначального запуска дисплейных решений в экосистеме модулей SF32LB52; поддерживает QSPI и подключение LCD по MCU/8080.
- [SF32LB52-DevKit-Core-3p3](../devkits/SF32LB52-DevKit-Core-3p3.md) — компактная плата с внешним питанием для быстрой проверки прошивки, GPIO и энергопотребления вариантов класса 52B/52J.
- [SF32LB52-DevKit-Nano](../devkits/SF32LB52-DevKit-Nano.md) — самая компактная отладочная плата серии 52, подходящая для разработки устройств с ограниченным пространством.
- [SF32LB52-DevKit-ULP](../devkits/SF32LB52-DevKit-ULP.md) — плата, ориентированная на низкое энергопотребление, для оценки устройств с питанием от аккумулятора и экспериментов с компактными изделиями.

Типичные изделия на базе SF32LB52 — умные часы и фитнес-браслеты начального уровня, Bluetooth-аксессуары, компактные графические панели управления, электронные ценники, умные бейджи, портативные принтеры этикеток, а также дисплеи для электровелосипедов и электросамокатов, где важна низкая стоимость.
