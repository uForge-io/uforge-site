# Планирование изделия { #plan-a-product }

Это руководство помогает превратить идею изделия на базе SF32 в план разработки, готовый к проверке и подготовке к серийному выпуску. Если микросхема, модуль, отладочная плата, программный стек и подход к производству ещё не выбраны, проходите этапы по порядку.

## Не пропускайте цикл проверки на плате { #do-not-skip-the-board-validation-loop }

Одного сравнения семейств и успешной сборки ПО недостаточно, чтобы выбрать компонент для серийного изделия. Прежде чем зафиксировать аппаратную конфигурацию, проверьте её на наиболее близкой доступной плате и запишите название платы, версию SDK, использованный пример, результаты измерений и отличия от целевого изделия. Если в готовом изделии будут другой дисплей, накопитель, схема питания от аккумулятора, антенна или плата-носитель модуля, проверяйте каждый такой элемент отдельно.

После проверки базовой конфигурации оборудования и ПО выберите наиболее близкий к вашему проекту [референсный проект](../../hardware/reference-designs/reference-designs.md) и проследите весь путь на конкретном примере.

## Контрольный список передачи проекта { #handoff-checklist }

- [ ] Выбранный чип или модуль соответствует требованиям изделия к интерфейсам, памяти, корпусу, питанию и энергопотреблению.
- [ ] Есть поддерживаемая отладочная плата либо конкретный план проверки собственного оборудования.
- [ ] Команда проекта согласовала программный путь и уровень его зрелости.
- [ ] Требования к восстановлению, OTA/DFU, журналированию и заводскому программированию определены до фиксации разделов и BOM.
- [ ] Определены подходящие руководство по проектированию аппаратной части, контрольный список, AVL и библиотека EDA.
