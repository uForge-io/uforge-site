## Что входит в этот раздел { #what-this-section-covers }

Начните с [обзора семейства SF32](family/SF32_family.md), чтобы понять, какие семейства доступны и чем различаются их основные возможности. Когда вы сузите выбор до нескольких семейств и корпусов, [правила обозначения](family/SF32_namingrule.md) помогут расшифровать полный заказной номер нужного устройства.

Используйте инструмент [«Подбор компонентов SF32»](product-selector.md), если на выбор влияют архитектура питания, корпус микросхемы, дисплей, аудио, память, GPIO, беспроводная связь или специализированные аппаратные функции. Селектор помогает составить предварительный список вариантов; точное обозначение, корпус, электрические пределы и разводку платы всё равно необходимо проверить по соответствующей документации SiFli.

После выбора направления изучите [референсные проекты](../hardware/reference-designs/reference-designs.md) и [этапы подготовки к серийному производству](../hardware/design-for-production.md). Эти материалы связывают выбор устройства с проверенными аппаратными решениями, рекомендациями по проектированию, библиотеками CAD, составом BOM, контрольными списками ревью и результатами первоначальной проверки оборудования.

## Перейти сразу к нужному оборудованию { #browse-hardware-directly }

Уже знаете, какое оборудование вам нужно? Откройте подходящий каталог:

- [Чипы](family/SF32_family.md) — сведения о семействах устройств и выборе конкретного варианта.
- [Модули](modules/SF32LB52-MOD-1.md) — проектирование платы-носителя для модуля со встроенным радиотрактом и основными аппаратными компонентами.
- [Отладочные платы](devkits/SF32LB52-DevKit-LCD.md) — поддерживаемое оборудование для проверки ПО и периферии.

Аппаратная документация охватывает физическую часть изделия. Сведения о настройке SDK, примерах, средствах разработки и программных платформах приведены в разделе [Разработка](../develop/index.md).
