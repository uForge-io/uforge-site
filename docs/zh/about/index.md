# 关于 μForge.io { #about-forgeio }

评估一款新微控制器时，工程师不应该需要东拼西凑：这里查一份数据手册，那里翻一页 wiki，再到论坛里找一条帖子。**μForge.io 存在的目的，就是消除这种割裂。**

我们集中整理思澈科技（SiFli）的 SF32 系列超低功耗微控制器资料。这些芯片面向可穿戴设备、智能显示终端等电池供电的互联产品，具备蓝牙（Bluetooth）连接和图形处理能力，也面向 AIoT 应用。器件与模组选型、开发板、SDK 工作流、硬件设计指南和量产检查清单等内容，都按真实的产品开发流程串联起来，形成一条连贯、相互关联的资料路径，帮助你从选型、验证、设计导入一路推进到量产。对于有对应源资料的技术内容，我们会对照思澈科技（SiFli）官方文档进行核验；仍需核实的页面会明确标注。

我们选择 SF32，主要有两个原因。首先，整个系列提供多种核心配置，并集成图形加速和硬件解压缩，具体组合因系列而异。其次，它的 SDK、硬件指南和源代码都真正开放，但相关生态的知名度仍不及 ESP32、STM32。这种开放程度与生态知名度之间的落差，正是本站希望弥补的空白。

我们的目标很直接：帮助工程师更快、更有把握地做出硬件和固件决策，减少反复查找和核对基础信息的时间，把更多精力投入产品开发。
