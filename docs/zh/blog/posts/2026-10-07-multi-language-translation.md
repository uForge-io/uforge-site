# 多语言翻译，一轮一轮迭代而成 [2026-10-07] { #multi-language-translation-2026-10-07 }

嵌入式工程师习惯用自己最熟悉的语言阅读文档，因此 μForge.io 现已在英文原文之外，提供中文、日文、西班牙文、德文、法文、葡萄牙文和俄文翻译。

### 借助 LLM 工具，反复迭代完成 { #built-with-llm-tools }

没有 LLM 工具，这件事很难做成，在此表示感谢。但它并不是一次跑完的，而是经过了很多轮迭代，原因有两个。第一是使用额度有限：较长的翻译任务常常没做完就触达上限，只能等待重置或换个工具继续。ChatGPT 提供的多次免费额度重置帮了大忙，在此致谢。第二是这种翻译方式本身又慢又低效：技术页面篇幅长，包含大量表格、代码、引脚名称和交叉链接，每一轮产出都需要检查、修正，再重新运行。

### 让翻译保持一致 { #keeping-translations-consistent }

为了让迭代逐步收敛，我们维护了一份术语表，规定哪些词必须保持原文（料号、单位、协议名称），哪些词使用认可的译法；同时还有一份 QA 检查清单，涵盖技术内容完整性、链接与锚点正确性，以及 Markdown 和代码的安全性。各语言版本与英文原文保持相同的页面结构，构建均以严格模式检查，因此链接失效或页面缺失会直接报错，而不会悄悄上线。

### 一点提醒和一个请求 { #caveat-and-request }

这些是机器辅助翻译，英文页面仍是基准。由于这些语言都不是我们的母语，部分页面读起来可能不够自然。当某个技术细节会影响你的设计时，请对照英文页面和思澈科技（SiFli）官方文档确认。如果你发现误译、别扭的术语，或认为某个页面还可以改进，欢迎[联系我们](../../about/contact.md)；这些反馈会直接补充进术语表，避免同样的错误再次出现。

### 接下来 { #next }

我们会继续打磨术语，尽可能请母语读者审阅，并在英文页面更新时同步更新翻译。
