# 模组接口标准 { #module-interface-standards }

本分组介绍 μForge 模组接口的命名约定与引脚分配草案。确定载板连接器、引脚映射或对外声明兼容性前，应先了解这两类文档的用途：命名规则用于统一接口名称；引脚定义草案用于规划设计，但必须结合所选模组和产品验证。

## 命名约定不等于电气兼容 { #what-is-stable-and-what-must-be-verified }

模组说明、原理图、BOM 注释和产品文档应统一使用命名规则。这些名称描述的是目标接口配置，并不代表电气或机械规范已经定稿。接口名称相同，或连接器外形匹配，都不能证明模组与载板可以互换使用。

引脚定义草案不保证每款 μForge 模组或 SF32 封装都支持其中列出的所有信号、接口，以及这些功能的同时使用。冻结设计前，应依据所选模组、芯片和封装的准确型号及对应硬件设计指南，核对以下事项：

- 连接器机械图、防呆键位、触点编号和装配约束；
- 电源轨、电压域、电流承载能力和供电时序；
- 接口可用性、引脚复用以及不可同时使用的功能；
- 信号完整性、阻抗、长度匹配、ESD 和 RF 禁布要求；
- 调试、启动、恢复和量产测试所需的访问通路；
- 载板对显示、摄像头、音频、存储和无线配套器件的需求。

## 载板设计确认流程 { #carrier-board-decision-path }

1. 选定模组并阅读其介绍和硬件设计指南。
2. 使用 [M2 接口命名规则](M2%20Interface%20Naming%20Rules.md)明确目标接口配置方案。
3. 使用 [M2 接口定义](M2-interface-definition.md)识别候选信号和复用冲突。
4. 根据具体模组文档及适用的思澈科技（SiFli）原始文档，逐一确认使用的连接器触点。
5. 开始 PCB 布局前，在原理图评审记录中注明文档版本、模组与载板的硬件版本、已确认的例外及待解决事项。

开展载板整体评审时，请继续阅读[面向量产的设计](../design-for-production.md)。具体模组的实现要求，参见**硬件设计指南**分组中对应的模组指南。
