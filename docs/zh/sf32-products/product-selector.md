# SF32 产品选型工具 { #sf32-product-selector }

在确定原理图之前，先筛选 SF32 芯片和模组。优先明确后期变更代价较高的约束——供电架构、封装、显示、音频、内存、GPIO、连接能力和软件验证路径——再比较剩余候选项。

使用下方的交互式工具进行初筛。目录只收录芯片和模组，可按集成层级、PSRAM 和 GPIO 容量、封装、主电源、显示接口与目标分辨率、SDIO 数量、音频接口数量及专用硬件能力筛选；每个结果均链接到对应的产品介绍页。开发板不属于筛选目录，而是用于验证软件功能和系统设计假设的独立平台。

## 产品选型工具 { #product-selector }

!!! info "术语与音频接口数量"
    缩写和接口术语可参阅[术语表](../about/glossary.md)。一个 PDM 接口最多可连接两只数字麦克风，因此 PDM 接口数量不等于麦克风数量。实际可用的麦克风输入数量和引脚连接方式取决于具体器件，应查阅对应器件文档。

所有已启用的筛选条件按“与”组合，结果必须满足每一项条件。集成层级、封装、供电和显示接口为单选项。PSRAM 和 GPIO 筛选值表示应用的最低需求，候选器件必须达到或超过该值。此处的“最大需求”指应用所需的最大容量或数量，并非器件能力上限。目标分辨率、SDIO 数量以及各类音频接口数量也按最低门槛筛选。功能复选框则表示必须具备相应能力（通过 SDIO 外接 Wi-Fi、DCMI 摄像头接口、AI/ML 加速器、FreeIO 或 PTM）。SDIO 数量筛选项与外接 Wi-Fi 复选框含义不同。

结果表会列出确切料号和封装、内存容量、最大 GPIO 数量、电源与 I/O 电压、显示能力、音频接口数量（DAC/ADC/PDM/I2S）、数字外设接口/通道数量（UART/I2C/SPI/CAN/GPADC）、USB 速率及目录中标记的功能。数量或数值显示为 `n/a`，表示目录未记录该粒度的明确信息，不代表数值为零，也不能据此判断器件不支持该功能。功能项中的短横线表示目录记录未标记该能力，应查阅目标器件的文档确认。显示接口列表用于选型参考，并非完整的引脚复用清单。

## 选型因素 { #selection-factors }

应将选型工具视为按硬性条件筛选候选器件的工具，而不是自动推荐器。先处理那些一旦发现过晚就会迫使你重新设计电路板或原理图的约束，再根据其余因素区分可行候选项。

### 集成层级 { #integration-level }

如果项目进度、RF 设计工作量或板级设计责任已经明确，应先确定集成层级，再比较详细规格。芯片提供最大的设计自主权，但电源、RF、时钟、布局和量产准备都由你负责；模组可减少模组级硬件设计和集成工作，但你仍需设计载板。开发板则是验证固件、外设行为和系统设计假设的最快途径，但并不等同于适合量产的硬件。

### 供电与封装 { #power-supply-and-package }

应尽早确定供电方式和封装。选型工具区分锂离子电池直供（3.2–4.7 V）、文档明确支持外部稳压 3.3 V 供电的器件，以及主电源支持降至约 1.8 V 的器件（部分规格将下限标为 1.71 V）。这些筛选描述的是主电源方案，不是 GPIO I/O 电压；结果表会单独列出 I/O 电压，所示为标称电平，并非保证的工作范围。具体限制应以目标器件的电气规格为准。封装同样属于结构性约束：它决定 PCB 占用面积、扇出布线难度、散热路径和可用引脚预算。封装筛选使用的是粗略类别，应在结果中核对确切封装型号。即使某封装标称 GPIO 数量更高，在预留电源、时钟、调试、显示、存储和必需外设引脚后，也未必满足需求。

### 内存与 GPIO 余量 { #memory-and-gpio-headroom }

将 PSRAM 和 GPIO 筛选项视为最低门槛，再检查所选档位的内存组织和引脚分配。PSRAM 容量会影响图形缓冲、音频缓冲、ML 模型和应用工作空间，但总容量并不能保证有一整块连续可用的内存空间。GPIO 余量除了首版原型使用的接口外，还应预留量产测试、调试、中断、后续传感器和板级控制信号。

### 显示与图形 { #display-and-graphics }

先按显示屏实际需要的接口筛选，再用目标分辨率选项进行初步容量检查。选项中的宽×高是总像素数门槛，并不用于核对具体宽高比或屏时序。结果表中的分辨率数值仅供目录初筛，不保证特定面板模式，也不一定代表每个料号的实际最高分辨率；请结合目标器件文档核实。选型工具采用板级常用简称 RGB 标注并行显示接口；该接口的正式名称为 DPI（Display Pixel Interface，显示像素接口）。显示接口列表并非完整的引脚复用清单。应以目标器件文档为准，确认具体接口模式、内存预算、引脚布线、面板上电时序和软件驱动路径。

### 音频接口 { #audio-interfaces }

选型工具分别提供音频 DAC、ADC、PDM 接口和 I2S 接口的最低数量筛选项。每项都是下限条件，并非将四类接口捆绑成固定的音频配置。筛选后还应检查资源复用关系和板级模拟电路设计。

### 连接能力与专用硬件 { #connectivity-and-specialist-hardware }

仅当相关能力确实属于产品需求时，才应用 Wi-Fi、摄像头、AI 加速器、FreeIO 和 PTM 筛选项。外接 Wi-Fi 复选框表示文档记录了基于 SDIO 的连接路径，并不表示芯片内置 Wi-Fi；独立的 SDIO 数量筛选项用于检查目录中有记录的 SDIO 接口数量。外接 Wi-Fi 还需要合适的板级供电、布线和软件支持。摄像头和 AI 需求需要端到端评估接口能力、内存带宽、处理负载及软件栈是否匹配。若灵活的信号分配或确定性的外设任务处理是设计核心，FreeIO 和 PTM 会很有价值；但它们不应凌驾于供电、内存和封装等基础约束之上。

### 验证依据 { #validation-evidence }

在最终确定之前，请通过结果链接进入产品介绍页，并核对确切料号、封装、电气限制、参考设计以及是否提供设计指南或检查清单。条件允许时，尽量在受支持且硬件配置与目标器件最接近的开发板上验证预期的固件流程。选型工具只用于建立候选清单；目标器件的思澈科技（SiFli）文档才是设计依据。

## 核实候选清单 { #confirm-the-shortlist }

1. **检查确切器件。** 使用 [SF32 系列概览](family/SF32_family.md)、结果对应的产品介绍和[命名规则](family/SF32_namingrule.md)，核对可订购料号、封装、供电拓扑、内存组织、接口分配和参考硬件。不要只依据单一亮点功能选择器件；应确认所选封装和板级设计能够同时满足显示、音频、存储、传感器、蓝牙（Bluetooth）和低功耗需求。
2. **验证软件路径。** 在最终确定硬件前，先在当前可用的开发板中选择硬件配置最接近目标设计的一块，并使用[入门指南](../getting-started/index.md)、[教程](../getting-started/tutorials/overview.md)和[开发](../develop/index.md)中的内容验证软件路径。
3. **检查量产约束。** 在冻结原理图、布局、BOM、显示和存储选择前，进入[面向量产的设计](../hardware/design-for-production.md)。
