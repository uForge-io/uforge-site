# Mehrsprachige Übersetzung, Iteration für Iteration [2026-10-07] { #multi-language-translation-2026-10-07 }

Embedded-Entwickler lesen Dokumentation in der Sprache, in der sie denken. Deshalb gibt es μForge.io jetzt zusätzlich zum englischen Original in Chinesisch, Japanisch, Spanisch, Deutsch, Französisch, Portugiesisch und Russisch.

### Mit LLM-Werkzeugen erstellt, in vielen Iterationen { #built-with-llm-tools }

Ohne LLM-Werkzeuge wäre das nicht praktikabel gewesen, und dafür sind wir dankbar. Es war allerdings kein einzelner Durchlauf, sondern es brauchte viele Iterationen – aus zwei Gründen. Erstens das begrenzte Nutzungskontingent: Ein langer Übersetzungsauftrag stieß oft an sein Limit, bevor die Seiten fertig waren, und musste auf einen Reset warten oder anderswo fortgesetzt werden. Die mehrfachen kostenlosen Resets von ChatGPT haben dabei enorm geholfen – vielen Dank dafür. Zweitens ist das Übersetzen auf diese Weise langsam und ineffizient: Technische Seiten sind lang und voller Tabellen, Code, Pin-Namen und Querverweise, sodass jeder Durchlauf ein Ergebnis lieferte, das geprüft, korrigiert und erneut ausgeführt werden musste.

### Einheitlichkeit sichern { #keeping-translations-consistent }

Damit die Iterationen konvergieren, pflegen wir ein Glossar mit Begriffen, die unübersetzt bleiben müssen (Bauteilnummern, Einheiten, Protokollnamen) oder eine freigegebene Übersetzung erhalten, sowie eine QA-Checkliste für technische Vollständigkeit, korrekte Links und Anker und die Unversehrtheit von Markdown und Code. Jede Sprache behält die Seitenstruktur des englischen Originals, und die Builds werden im strikten Modus geprüft – ein defekter Link oder eine fehlende Seite fällt so sofort auf, statt unbemerkt veröffentlicht zu werden.

### Ein Hinweis und eine Bitte { #caveat-and-request }

Es handelt sich um maschinell unterstützte Übersetzungen; die englischen Seiten bleiben die Referenz. Da keine dieser Sprachen unsere Muttersprache ist, lesen sich manche Seiten für Muttersprachler möglicherweise nicht natürlich. Wenn ein technisches Detail für Ihr Design wichtig ist, prüfen Sie es anhand der englischen Seite und der offiziellen SiFli-Dokumentation. Falls Ihnen eine Fehlübersetzung oder ein holpriger Begriff auffällt oder Sie eine Seite für verbesserungswürdig halten, [sagen Sie uns Bescheid](../../about/contact.md); Ihr Feedback fließt direkt ins Glossar, damit der Fehler nicht wiederkehrt.

### Wie es weitergeht { #next }

Wir verfeinern die Terminologie, holen wo möglich Reviews von Muttersprachlern ein und halten die Übersetzungen synchron, wenn sich die englischen Seiten ändern.
