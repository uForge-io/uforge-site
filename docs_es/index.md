# Cree la próxima generación<br>de dispositivos embebidos { #build-the-next-generationof-embedded-devices }

***μForge.io*** es una plataforma de desarrollo de código abierto para soluciones innovadoras de semiconductores. Su oferta comienza con la familia SF32 de SiFli, compuesta por microcontroladores de consumo ultrabajo. Reúne en un solo lugar los recursos de toda la cadena: chips, módulos y placas de desarrollo, además de SDK, documentación y diseños de referencia preparados para producción. Así, los desarrolladores pueden llevar productos embebidos conectados, inteligentes y energéticamente eficientes desde la idea hasta la producción, con más rapidez y menos fricción.

## ¿Por qué elegir ***SF32***? { #why-choose-sf32 .uf-center-heading }

<div class="grid cards uf-why-grid" markdown>

- :fontawesome-solid-microchip:{ .uf-icon-blue } **Alto rendimiento**

    El número de núcleos y las funciones varían según el dispositivo. La familia abarca diseños de uno a tres núcleos, y varias series usan procesadores Cortex-M33 / STAR-MC1. La disponibilidad de caché, FPU y MPU depende del chip y de la implementación SoC concretos; consulte la documentación de la referencia elegida. Algunos dispositivos ofrecen hasta 64 MB de PSRAM en el encapsulado.

- :fontawesome-brands-bluetooth:{ .uf-icon-blue } **Conectividad Bluetooth**

    Los modos y funciones varían según la familia y el modelo. Según el dispositivo, la compatibilidad puede incluir Bluetooth Classic y LE, LE Audio y PHY de largo alcance. Consulte la página del chip para conocer las capacidades exactas.

- :fontawesome-solid-cube:{ .uf-icon-purple } **Aceleración gráfica**

    La GPU 2D / 2.5D, los controladores LCD y la compatibilidad con LVGL permiten crear interfaces gráficas fluidas y completas. En el conjunto de la familia se admiten interfaces MIPI, RGB, QSPI, 8080, JDI y EPD, con resoluciones de hasta 1280 × 720.

- :fontawesome-solid-volume-high:{ .uf-icon-pink } **Subsistema de audio**

    Las capacidades de audio varían según la familia y el modelo. Los dispositivos compatibles ofrecen audio analógico, I²S, PDM y procesamiento digital de audio asistido por hardware.

- :fontawesome-solid-brain:{ .uf-icon-amber } **Aceleración de IA**

    Algunos dispositivos SF32 integran aceleración de redes neuronales para TinyML y otras cargas de inferencia en el borde.

- :fontawesome-solid-leaf:{ .uf-icon-green } **Consumo ultrabajo**

    Arquitectura avanzada de gestión de energía, optimizada para dispositivos alimentados por batería y de funcionamiento permanente.

</div>
