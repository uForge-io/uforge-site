# 多言語翻訳を、一歩ずつ反復して [2026-10-07] { #multi-language-translation-2026-10-07 }

組み込みエンジニアは、普段使い慣れた言語でドキュメントを読みたいものです。そこでμForge.ioは、英語の原文に加えて、中国語、日本語、スペイン語、ドイツ語、フランス語、ポルトガル語、ロシア語の翻訳を用意しました。

### LLMツールを使い、何度も反復して完成 { #built-with-llm-tools }

LLMツールがなければ、これは現実的ではありませんでした。心から感謝しています。ただし、一度で終わったわけではなく、何度も反復を重ねました。理由は二つあります。一つ目は、利用プランの上限です。長い翻訳作業は、ページが終わる前に上限に達することが多く、リセットを待つか、別の方法で続ける必要がありました。ChatGPTの無料枠が何度もリセットされたことは大きな助けになりました。ありがとうございます。二つ目は、この方法での翻訳自体が遅く非効率なことです。技術ページは長く、表、コード、ピン名、相互リンクが多いため、1回ごとに出力の確認、修正、再実行が必要でした。

### 翻訳の一貫性を保つ { #keeping-translations-consistent }

反復が収束するよう、原文のまま残す用語（部品番号、単位、プロトコル名）や承認済みの訳語を定めた用語集と、技術内容の網羅性、リンクとアンカーの正しさ、Markdownとコードが壊れていないことを確認するQAチェックリストを運用しています。各言語は英語原文と同じページ構成を保ち、ビルドは厳格モードで検証するため、リンク切れやページ欠落は黙って公開されず、エラーとして検出されます。

### ご注意とお願い { #caveat-and-request }

これらは機械支援による翻訳であり、基準となるのは英語ページです。これらの言語は私たちの母語ではないため、母語話者の方には不自然に読める箇所があるかもしれません。設計上重要な技術的詳細は、英語ページとSiFli公式ドキュメントで確認してください。誤訳や不自然な用語を見つけた場合や、改善できると感じたページがある場合は、[お問い合わせください](../../about/contact.md)。いただいたフィードバックは用語集に反映し、同じ誤りが再発しないようにします。
