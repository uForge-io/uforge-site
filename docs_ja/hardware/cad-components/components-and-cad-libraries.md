# 部品とCADライブラリ { #components-and-cad-libraries }

選定したSF32デバイスまたはモジュールのアーキテクチャを決定し、BOMとPCB設計を管理しながら進める段階で、このページを利用してください。以下の2つの資料は目的が異なります。**承認ベンダーリスト（AVL）**はSiFliが適合性を確認した部品の選定に役立ち、**EDAツールライブラリ**は選定したハードウェアを正しく実装するためのシンボル、フットプリント、リファレンスプロジェクトデータを提供します。

どちらの資料も、デバイス固有のハードウェア設計ガイド、パッケージ図、量産を想定した基板での最終検証に代わるものではありません。

## BOMからCADまでのレビュー手順 { #bom-to-cad-review-sequence }

1. **実装の基準構成を確定する。** 正確なチップまたはモジュール、パッケージ、メモリー構成、ディスプレイインターフェース、電源アーキテクチャを選びます。周辺部品を選定する前に、該当するハードウェア設計ガイドを確認してください。
2. **AVLから重要部品の候補を絞る。** 部品番号が一致するかだけでなく、記載された電気的要件を確認します。特に水晶振動子の負荷容量とESR、降圧コンバーター用インダクターの電流定格、Flashの電圧とタイミングモード、温度範囲、ファームウェアとの互換性に注意してください。
3. **公式ライブラリを使って回路図を作成する。** 該当するEDAライブラリとリファレンス設計を出発点として利用します。シンボル、フットプリント、ピン番号、ランドパターン、キープアウト規則は、選定部品の最新データシートとパッケージ図に照らして個別に確認してください。
4. **BOMとレイアウトを合わせてレビューする。** 適合性を確認した部品が、実際の電源電圧／電流、インターフェース速度、実装工程、筐体の制約に適合することを確認します。電源、RF、クロック、メモリー、ディスプレイ、デバッグアクセスについて、デバイスまたはモジュール設計ガイドの要件を適用してください。
5. **量産を想定したハードウェアを検証する。** 最終基板リビジョンで、起動、書き込み、周辺機能、無線、復旧の動作を試験し、消費電力を測定します。承認した代替部品と、設計ガイドまたはAVLから意図的に外した項目をすべて記録してください。

## 実務上の適用範囲 { #practical-boundaries }

- AVLは適合性確認時点の情報です。量産BOMを確定する前に、リストのリビジョンと部品の入手可能性を再確認してください。
- EDAライブラリは設計の出発点となるデータであり、完成したレイアウトが製造可能、または電気的に正しいことを証明するものではありません。
- AVLに記載されていない部品は、関連する要件に照らして適合性を確認し、量産使用の前に対象ハードウェアで検証してください。
- モジュールを使う製品では、まずモジュール設計ガイドを確認します。キャリア基板のBOMとレイアウトにも、同じレビュー手順が必要です。

設計レビュー全体の流れは[量産に向けた設計](../design-for-production.md)を参照してください。チップ、モジュール、ボードの基準構成をまだ選んでいない場合は、[SF32製品選定ツール](../../sf32-products/product-selector.md)に戻ります。
