# SF32 承認ベンダーリスト { #sf32-approved-vendor-list }

## このリストの目的 { #what-this-list-is-for }

**承認ベンダーリスト（AVL）**は、SF32設計向けにSiFliが実施した部品の適格性評価を記録したものです。V0.3には水晶振動子、降圧用インダクター、NOR／NAND Flash、SD-NAND、LCDドライバー1種類を掲載し、タッチコントローラーのシートに記載はありません。候補部品や代替供給元の検討に活用し、実際のPCB、ファームウェア、筐体、量産工程、供給体制で検証してください。掲載だけで製品としての検証を終えたことにはなりません。

このページはSiFli公式AVLスプレッドシート **`SIFLI-MCU-AVL-认证表`、V0.3（2026-01-21）**に基づいています。新たな部品の評価・登録に伴いAVLは更新されるため、本ページは日付の明記されたV0.3のスナップショットであり、リアルタイムのデータベースではありません。今回確認したのはV0.3の記載内容のみです。後続版でも各部品が引き続き掲載・承認されているかは確認していません。BOMを確定する前に最新の原表を確認してください。

!!! note "このリストの使い方"
    原表には水晶振動子と降圧用インダクターの共通要件があり、その他の表は主に個別部品のデータを記録しています。要件に沿って候補を絞り込めますが、掲載部品が共通要件のすべての限界値を満たすとは限りません。原表の不整合は以下に示します。Flashのダウンロードツール対応など、全行が空欄の列は省略しており、対応確認済みを意味しません。詳細表の「—」は通常、V0.3の原表にその項目の値が記載されていないことを示します。ただし、NOR FlashのDTRクロック欄では、原表の「非対応」を表します。詳しくはNOR Flashの注記を参照してください。

部品番号だけで決めて次へ進むのではなく、次の3段階でBOM候補を評価してください。

1. **要件に照らして候補を絞る。** 容量、電源レール、パッケージに加え、部品種別ごとの要件（水晶振動子の負荷容量、インダクターのDCR／Isat、FlashのSDR／DTRクロック）を回路図と電力予算に照らして確認します。
2. **データシートの代表値だけではわからない制約を確認する。** 動作・保管環境に対する温度範囲、ファームウェアが想定する正確なManufacturer／JEDEC ID、OTA、ファイルシステム、ダウンロードツールの対応が同じシリーズの別部品ではなく、採用する部品そのもので検証されているかを確認します。
3. **量産採用を決める前に実機で検証する。** 自社基板で待機時／動作時電流を測定し、最終PCBと筐体で水晶振動子のRF校正を再確認します。また、単一ベンダーの部品はすべて、セカンドソース候補を少なくとも1つ特定してください。

!!! tip "RF校正欄の意味"
    **CBANK_SEL**はSiFliの評価データに記録されたトリム設定です。**TX Ch39 Freq Offset**は、元の試験名と3つの温度点での結果をそのまま示しています。元の表にはBluetoothのモードや試験周波数が記載されていないため、BLEのアドバタイジングチャネル39や特定の中間帯チャネルを意味すると判断しないでください。結果の比較や自分の基板へのトリム設定の適用前に、試験条件と校正手順を確認してください。また、TKDの3製品ではESR上限が40 Ωと記載され、一般要件の30 Ωを超えています。この差異も確認が必要です。

## NOR Flash { #nor-flash }

V0.3には、4 Mb～256 MbのNOR Flash部品44種類を容量別に掲載しています。表のクロック値はメモリ側の仕様であり、すべてのSF32や基板でその動作速度を保証するものではありません。対象設計の読み出しコマンド、コントローラーの制約、タイミング、ドライバーの識別処理を確認してください。原表の「Manufacture ID」という16進数の値にはデバイス識別フィールドも含まれるため、メーカーの1バイトだけでなく、想定する応答全体を比較します。動作時と待機時の消費電力は、動作条件が明記された電流値で算出してください。

## SPI-NAND Flash { #spi-nand-flash }

V0.3には、512 Mbおよび1 GbのSPI-NAND部品18種類を掲載しています。対応するドライバーとソフトウェア構成を用いれば、ファイルやデータの保存に利用できます。FatFS、FlashDB、LittleFSなどが例ですが、選定部品との互換性は別途検証が必要です。NANDのページアクセス、ECC、不良ブロック管理は、NORの直接XIPアクセスとは異なります。原表では全掲載部品の **Golden Block** が `block0` ですが、保証条件や、それを前提とするファームウェア処理は記載されていません。デバイスとSDKの文書で確認してください。

## 設計レビュー用チェックリスト { #design-review-checklist }

回路図またはBOMを確定する前に、選定した各AVL部品を実際の製品設計と照合してください。

- [ ] 正確な部品番号、パッケージ、温度グレード、発注型番末尾がAVL掲載行と一致しているか、明示的な技術承認の経路がある。
- [ ] 電圧範囲が基板で使用するSF32のIO、Flash、ディスプレイ、または電源コンバーターの各レールに合っている。
- [ ] パッケージ、ランドパターン、高さ、実装条件がPCBライブラリと製造工程に適合している。
- [ ] 該当する場合、JEDEC／メーカーIDまたは同等の実行時判定によって、ファームウェアが部品を正しく識別できる。
- [ ] 起動、ダウンロード、OTA、ファイルシステム、ディスプレイ、タッチドライバーの動作を、採用する正確な部品で検証している。
- [ ] 低消費電力時の電流を実機で測定しており、AVLや部品データシートの値をそのまま転記していない。
- [ ] 最終PCB、アンテナ、筐体で水晶振動子の周波数オフセット、CBANK_SELの動作、RF校正を確認している。
- [ ] 製品の想定電圧・温度範囲でFlashの消去／書き込み／読み出し時間を試験している。
- [ ] 水晶振動子、インダクター、Flash、ディスプレイパネルなど、リスクの高いBOM項目ごとにセカンドソース候補を1つ以上特定している。

このチェックリストは「部品がAVLに載っている」ことより厳しい基準を設けています。AVLは候補を絞り込むためのものです。製品リリースには、基板レベルでの検証結果が必要です。

## 調達用チェックリスト { #sourcing-checklist }

- [ ] 部品番号と改訂末尾を、ダウンロードできる最新版のAVLと照合する。新たな部品が適格性評価を受けると、スプレッドシートのスナップショット（このページを含む）は古くなる。
- [ ] Flash部品では、立ち上げコードが想定するManufacturer／JEDEC IDが、シリーズ名だけでなく、実際に発注する部品と一致していることを確認する。同じシリーズ名でも返すIDバイトが異なる製品がある。
- [ ] NAND、SD-NAND、ファイルシステム用の部品では、起動／ダウンロードツール対応、OTA更新フロー、実機でのファイルシステム（FatFS／FlashDB／LittleFS）の動作を確認する。立ち上げ時に読み出せただけでは、OTA対応が検証済みとは限らない。
- [ ] 水晶振動子のCBANK_SELと、表に記載されたTX Ch39の周波数オフセットを実際の製品基板で検証する。原表には基板レイアウトや測定構成の詳細がないため、比較前に試験モードと条件を確認する。
- [ ] 待機、ディープパワーダウン、読み出し時の電流を製品基板で測定する。AVLでは全値の出典や動作条件が明らかではないため、データシートと測定条件を確認する。
- [ ] 電気仕様だけでなく、パッケージとフットプリントがPCBライブラリおよび実装能力に合っていることを確認する。
- [ ] 未掲載部品は、BOMに採用する前に部品種別の要件行に照らして適格性を評価し、評価データをSiFliに共有することも検討する。
- [ ] 単一供給元の部品には代替候補を確保する。V0.3にはLCDドライバー1種類が掲載され、タッチコントローラーの掲載はない。現時点の供給と対応状況は別途確認し、このスナップショットを最新状況とみなさない。
