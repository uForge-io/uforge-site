# SF32LB52x ハードウェア設計ガイド { #sf32lb52x-hardware-design-guide }

## 1. はじめに { #1-introduction }

本書は、超低消費電力 AIoT マイクロコントローラー SF32LB52x ファミリーを採用する製品向けに、設計上の推奨事項と出典に基づく参考情報をまとめたハードウェア設計ガイドです。バッテリー駆動のウェアラブル機器や小型組み込みシステムを開発するハードウェアエンジニア、PCB 設計者、製品開発者を対象としています。

電源設計、クロック回路、RF レイアウト、ディスプレイ／ストレージインターフェース、オーディオ回路、PCB レイアウト、製造上の考慮事項まで、ハードウェア開発プロセス全体を扱います。本書の指針は、開発リスクの低減、システムの信頼性向上、製品開発期間の短縮に役立ちます。

本書は、組み込みハードウェア設計と回路図作成の基礎知識を前提としています。詳細な電気仕様、周辺機能の動作、ソフトウェア開発については、SF32LB52x のデータシート、リファレンスマニュアル、SDK ドキュメントを参照してください。これらの公式資料が最終的な根拠となります。

SiFli の元のハードウェアアプリケーションノート 2 件（バッテリー駆動の SF32LB520/3/5/7 向けと、外部レギュレーターで給電する 52B/D/E/G/J 向け）を、1 つの設計ワークフローに統合しています。元資料の表現に揺れがある場合は、正確な発注型番、電源ドメインの明確な動作説明、リリースレビュー時の分かりやすさを優先します。

## 3. デバイス概要 { #3-device-overview }

SF32LB52x ファミリーは、デュアルコア STAR-MC1 プロセッサー、Bluetooth 接続、グラフィックスアクセラレーター、オーディオ機能、ディスプレイインターフェース、ストレージコントローラー、電源管理を小型の QFN68 パッケージに統合しています。BOM コスト、バッテリー駆動時間、PCB 面積のすべてが重要となる製品に適しています。

### 3.1. 特長 { #31-features }

本ファミリーには次の機能が統合されています。

- Arm Cortex-M33 互換で、FPU と MPU を備えたデュアルコア Arm China STAR-MC1 プロセッサー
- デュアルモード Bluetooth 5.3 無線機能
- ePicasso 2.0 2D/2.5D グラフィックスアクセラレーター
- SPI、QSPI、8080、JDI、8 ビット EPD インターフェースに対応するディスプレイコントローラー
- USB 2.0 Full-Speed デバイス
- 対応バリアントで利用できる SDIO/eMMC ストレージインターフェース
- アナログ／デジタルオーディオインターフェース
- PMU、DC/DC コンバーター、LDO レギュレーターを内蔵
- 最大 44/45 本の GPIO を備える QFN68 パッケージ

### 3.2. バリアント { #32-variants }

SF32LB52x ファミリーは、電源アーキテクチャに応じて、バッテリー駆動デバイスと外部レギュレーター給電デバイスの 2 つの設計グループに分かれます。

=== "SF32LB520/3/5/7 (バッテリー駆動)"

    このグループは、チップ内に**充電管理モジュールと PMU**を搭載しています。単セルのリチウムイオンバッテリーに直接接続できるほか、外付け充電方式にも対応します。

    <div align="center"><em>表 3.2-1: 型番対応表 (バッテリー駆動バリアント)</em></div>

    <div align="center" markdown>

    | 型番 | 同一パッケージ内メモリー | 電源 | 設計上の注意 |
    |:---|:---|:---|:---|
    | SF32LB520U36 | 1 MB QSPI-NOR Flash | リチウムイオンバッテリー、3.2～4.7 V、充電式 | デフォルトでは同一パッケージ内の Flash から起動。`VDD18_VOUT` には外部 3.3 V 電源が必要 |
    | SF32LB523UB6 | 4 MB OPI-PSRAM | リチウムイオンバッテリー、3.2～4.7 V、充電式 | 外部ストレージから起動する必要あり |
    | SF32LB525UC6 | 8 MB OPI-PSRAM | リチウムイオンバッテリー、3.2～4.7 V、充電式 | 外部ストレージから起動する必要あり |
    | SF32LB527UD6 | 16 MB OPI-PSRAM | リチウムイオンバッテリー、3.2～4.7 V、充電式 | 外部ストレージから起動する必要あり |

    </div>

=== "52B/D/E/G/J (外部レギュレーター給電)"

    このグループにはチップ内蔵の**PMU**がありますが、充電回路は含まれません。安定化された外部電源から給電します。

    <div align="center" markdown>

    |:---|:---|:---|:---|

    | SF32LB52BU56 | 4 MB QSPI-NOR Flash | 2.97～3.63 V、充電不可 | `VDD_SIP` には外部 3.3 V 電源が必要 |
    | SF32LB52DUB6 | 4 MB OPI-PSRAM | 1.71～1.98 V、充電不可 | `VDD_SIP` には外部 1.8 V 電源が必要 |
    | SF32LB52EUB6 | 4 MB OPI-PSRAM | 2.97～3.63 V、充電不可 | `VDD_SIP` は内蔵 LDO から給電可能 |
    | SF32LB52GUC6 | 8 MB OPI-PSRAM | 2.97～3.63 V、充電不可 | `VDD_SIP` は内蔵 LDO から給電可能 |
    | SF32LB52JUD6 | 16 MB OPI-PSRAM | 2.97～3.63 V、充電不可 | `VDD_SIP` は内蔵 LDO から給電可能 |

    </div>

### 3.3. パッケージ { #33-packages }

どちらの設計グループも同じ QFN68 パッケージを使用します。

<div align="center"><em>表 3.3-1: パッケージ情報</em></div>

<div align="center" markdown>

| パッケージ名 | 寸法 | ピンピッチ |
|:---|:---|:---|
| QFN68L | 7 mm x 7 mm x 0.85 mm | 0.35 mm |

</div>

2 つの設計グループでは、利用できる周辺リソースが一部異なります。バッテリー駆動グループは GPIO が 44 本、外部レギュレーター給電グループは 45 本です。バッテリー駆動デバイスでは充電用にピンが割り当てられているため、本数に差があります。

- GPIO 44/45 本
- UART x 3
- I2C x 4
- GPTIM x 2
- SPI x 2
- I2S オーディオインターフェース x 1
- SDIO ストレージインターフェース x 1
- PDM オーディオインターフェース x 1
- 差動アナログオーディオ出力 x 1
- シングルエンドのアナログオーディオ入力 x 1
- 1/2/4 データライン SPI ディスプレイインターフェース、シリアル JDI ディスプレイインターフェース
- GRAM の有無を問わずディスプレイに対応
- UART ダウンロードとソフトウェアデバッグに対応

### 3.4. 用途 { #34-applications }

長いバッテリー駆動時間と小型フォームファクターが重視される、携帯型の組み込みシステムに適しています。用途の例を以下に示します。

- エントリーモデルのスマートウォッチ、フィットネスバンド
- Bluetooth モジュール、ワイヤレスアダプター
- Bluetooth オーディオアクセサリー
- スマートセンサー、ウェアラブル機器
- 電子棚札、スマートバッジ
- 電子書籍リーダー
- 携帯型ラベルプリンター
- 電動自転車／電動スクーターのディスプレイ
- ネットワーク接続型のヒューマンマシンインターフェース (HMI) 機器
- 携帯型の産業機器、医療機器
- その他のバッテリー駆動 AIoT デバイス

### 4.2. ハードウェア設計フロー { #42-hardware-design-flow }

通常、ハードウェア設計の決定事項が固まる順に本書を読み進めてください。以下のフローでは、回路図や PCB の詳細設計に入る前に、初期のアーキテクチャ選択を明確にします。

<div align="center"><em>表 4.2-1: ハードウェア設計フロー</em></div>

<div align="center" markdown>

| 手順 | 設計上の決定事項 | 主な参照セクション |
|:---|:---|:---|
| 1 | 正確な発注型番と電源バリアントを選択する | デバイス概要、バリアント選択 |
| 2 | パッケージ、GPIO 数、専用機能ピンを確認する | パッケージ、回路図設計指針 |
| 3 | 最小システムを確定する: 電源ツリー、ブートストレージ、ブートストラップピン、デバッグアクセス、クロック、ウェイクアップ方針 | 最小システム設計、ストレージ、デバッグ、クロック生成 |
| 4 | RF トポロジー、ディスプレイ、オーディオ、センサー、その他の製品インターフェースを選定する | クロック生成、RF、ユーザーインターフェース、ストレージと接続性 |
| 5 | PCB 積層、ファンアウト、インピーダンス、ノイズに敏感な信号の配線を確認する | PCB レイアウト指針 |
| 6 | 元資料の回路図、PCB レイアウト、機構図、電源図と照合する | 付録 A～E |
| 7 | 立ち上げ、デバッグ、キャリブレーション、量産テスト用のアクセスを確保する | デバッグ、製造、設計レビュー用チェックリスト |

</div>

**設計判断フロー**

- USB 経由で充電できる単セルバッテリー動作が必要ですか？`SF32LB520/3/5/7` から検討してください。
- 外部安定化電源または eMMC ブートが必要ですか？`52B/D/E/G/J` から検討してください。
- 8 ビットパラレル EPD が必要ですか？SiFli が対象設計でバッテリー駆動経路を使えると確認しない限り、外部レギュレーター給電の設計経路を選んでください。
- 待機電流をできるだけ小さくする必要がありますか？PCB 配置の前に、ストレージ電源のスイッチング、センサーのロードスイッチ、ディスプレイ電源の分離を決めてください。

### 4.3. 本書の使い方 { #43-how-to-use-this-guide }

回路図設計を始める前に、正確な発注型番を確認してください。SF32LB52x ファミリーは、バッテリー駆動の `SF32LB520/3/5/7` グループと、外部レギュレーター給電の `52B/D/E/G/J` グループに分かれます。第 3.2 節でグループを選び、第 5.1 節と第 5.2 節で最小システムと電源システムを確認してください。第 5.6.1 節と第 5.7.1 節でブートストレージとデバッグアクセスを確認し、第 5 節と第 6 節で回路図および PCB の指針をレビューします。付録 A～E は元資料の参考図との照合に使い、第 7 節をリリース前のチェックリストとして利用してください。

既存の SF32LB52x 回路図を流用する場合は、まず電源ピン、SIP メモリー電源、ブートストレージ電源レール、DBG_UART/SWD ピン、水晶振動子の負荷、RF 整合回路のフットプリント、量産テストポイントを確認してください。これらは、立ち上げ時に見落とされやすいリスクの主な要因です。

### 4.4. レビュー証跡一式 { #44-review-evidence-pack }

ハードウェアをリリースする前に、回路図 PDF、PCB 積層情報、インピーダンスレポート、部品 AVL 照合結果、DRC レポート、RF、水晶振動子、USB、SDIO/eMMC、オーディオ、電源、ブートストレージのレイアウトを示すスクリーンショットを収集してください。後のファームウェア、RF、量産上の問題をレビュー済みのハードウェア基準構成に遡って確認できるよう、基板リビジョンと一緒に証跡を保管します。


## 5. チェックリストの使い方 { #using-the-checklists }

本書には 2 段階のチェックリストがあります。第 5.1.1.5 節、第 5.5.3 節、第 7 節に埋め込まれた簡易チェックリストは、リスクの高い項目を素早くセルフチェックするためのものです。[回路図チェックリスト](SF32LB52x_schematic_checklist.md)（第 5.8 節）と[PCB レイアウトチェックリスト](SF32LB52x_pcb_layout_checklist.md)（第 6.15 節）には、ハードウェア設計ガイドとともに[SiFli の Wiki][SiFli チップハードウェア設計ガイド一覧 (Wiki)]で公開された [*SF32LB52 回路図・PCB チェックリスト*][SiFli SF32LB52 回路図・PCB チェックリスト (XLSX)]（V1.0、2026-01-21）の全項目を掲載しています。対象は、バッテリー駆動の SF32LB520/3/5/7 と外部電源駆動の 52B/D/E/G/J の両バリアントです。

両チェックリストの各項目には、適用される SF32LB52x バリアントと、「必須（Required：リリース前に合格が必要）」または「任意（Optional：該当機能を使用する場合に推奨）」の区分が記載されています。特に絞り込みがない場合、「全バリアント（All variants）」は SF32LB520/3/5/7 と 52B/D/E/G/J の両方を指します。色付き文字および<span class="flag-red flag-yellow">黄色の背景</span>は、元のスプレッドシートで強調されていた箇所です。強調理由は元資料に記載されていないため、同じ表の他の項目に代わるものではなく、追加のレビュー注意表示として扱ってください。チェックリストはスプレッドシートのレイアウトを維持していますが、元の記述が不完全、一貫しない、または短すぎる場合は、設計ガイド、データシート、リファレンスマニュアル、SiFli の型番ガイドと併せて確認してください。

[回路図チェックリスト](SF32LB52x_schematic_checklist.md)は PCB レイアウトを始める前の回路図レビュー時に、[PCB レイアウトチェックリスト](SF32LB52x_pcb_layout_checklist.md)は Gerber リリース前のレイアウトレビュー時に使用してください。通常、それぞれ設計エンジニアが確認した後、設計凍結または製造リリースの前に独立したレビュアーがもう一度確認します。

チェックリストは読むだけでなく、承認記録として使うと効果的です。

1. まず対象シリコンの正確なバリアントを確認してください。特に 520/3/5/7 と 52B/D/E/G/J のどちらでも設計できる場合は注意が必要です。
2. 表を読むだけでなく、レビュー時に各項目を合格 / 不合格 / 該当なし (pass / fail / not applicable) で記録してください。
3. ブートメディア、ディスプレイの種類、電源スイッチの動作に関する項目は、実際の回路図と設計ガイドの該当するサブシステムの節を照合してください。
4. 元資料の表現が曖昧な場合は、リリース前に正確な型番と設計上の前提をレビュー記録に残してください。
