# SF32LB52x ハードウェア設計ガイド — PCB レイアウトチェックリスト { #sf32lb52x-hardware-design-guide-pcb-layout-checklist }

!!! note "SF32LB52x ハードウェア設計ガイドの一部"
    このページでは、第 6.15 節の PCB レイアウトチェックリストを示します。[PCB レイアウト指針](SF32LB52x_pcb_layout.md)に戻ってください。

## 6.15. PCB レイアウトチェックリスト { #615-pcb-layout-checklist }

元の PCB チェックリストには「適用対象」列がありません。選択した型番と回路に該当する端子、電源ライン、機能がある場合に各項目を適用し、ない場合は「該当なし」とします。元の「必須／任意」区分は維持しますが、「任意」はデバイス仕様で必要な部品を省略してよいという意味ではありません。

!!! note "元資料における水晶振動子周辺の銅箔処理"
    チェックリストのクロック項目 3 は、銅箔禁止領域を設ける層を明確にしていません。電池駆動バリアント向けアプリケーションノート内でも記述が一致せず、クロック節は水晶振動子直下の L2 GND の除去を指示する一方、PCB 配線節はトップ層と隣接層のプレーン欠落や銅箔の切り欠きを禁止し、配線モデルでは L2 GND が連続しています。別の PCB レイアウトガイドも切り欠きを禁止しています。リリース前に、選択した基板スタックアップでの処理方法を SiFli に確認し、チェックリストの文面から推測しないでください。

!!! note "配線幅の確認"
    元の表では VCC ≥12 mil、BUCK 配線 ≥10 mil、RF ≥10 mil と規定しています。第 6 節には VCC と BUCK のより厳しい指針があり、RF は >10 mil を推奨しています。RF の 50 Ω 要件を含め、両方の適用条件を満たしてください。チェックリストの最小値で詳細なレイアウト指針を置き換えることはできません。
