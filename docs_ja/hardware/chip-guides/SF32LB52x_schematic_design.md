### 5.1. 最小システム設計 { #51-minimum-system-design }

最小システム設計は、SF32LB52x基板の回路図を承認する際の最初の確認段階です。製品固有の周辺回路を追加する前に、デバイスの正確なバリアントとパッケージ、電源ツリー、ブートメディア、ブートストラップ抵抗、ストレージの電源制御、デバッグ／ダウンロード経路、クロック源、ウェイクアップ動作を確定します。ディスプレイやセンサーの配線変更は後から対応できることが多い一方、ストレージのブートストラップ設定の誤り、デバッグ経路の欠落、不安定な電源レール、電源状態の想定違いは、基板が正常に動作しない原因になります。

回路図の初回レビューでは、次の順に確認してください。

1. 3.2節と3.3節を参照し、デバイスの型番とパッケージを確定します。
2. 適切な電源経路を選びます。充電式バッテリー製品には`SF32LB520/3/5/7`、外部レギュレーターで給電する製品には`52B/D/E/G/J`を選択します。
3. 5.2節に従って電源設計を確定します。`VBUS`/`VBAT`/`VCC`または`PVDD`/`VDDIOA`/`VDD_SIP`、BUCK、内蔵LDOのデカップリング、RF／オーディオ電源、低消費電力用ロードスイッチを含めます。
4. ブートメディアを選び、5.6.1節のブート表に合わせて`PA13`/`PA17`のブートストラップ抵抗オプションを実装します。
5. ブートストレージ電源スイッチの制御ピンは、資料間の相違を確認してから確定します。アプリケーションノートと回路図ガイドは`PA21`を指定していますが、公式チェックリストは電池駆動バリアントの外付けFlashに`PA11`を指定しています。
6. 筐体と量産治具の仕様を確定する前に、DBG_UART/SWD用として`PA18`/`PA19`、GND、適切な電源基準点を確保します。
7. 5.3.1節に従って48 MHzと32.768 kHzの水晶振動子を選定し、回路図レビューで配置制約を確認できるようにします。
8. ファームウェアの低消費電力方針を確定する前に、ウェイクアップピン、電源キーの動作、充電イベント、ストレージ／センサーの停止状態を割り当てます。

この確認段階を終えた時点で、オプションの製品周辺回路に依存せずに電源投入、選択したメディアからのブート、復旧経路の確保、クロック校正、想定する低消費電力状態への移行ができる回路図になっている必要があります。

### 5.2. 電源システム { #52-power-system }

電源システム設計では、最小システムの信頼性を左右する電源レール、ロードスイッチ、充電経路、OVP、内蔵LDOの使用方法、ウェイクアップ動作、低消費電力状態を定義します。後続のディスプレイ、ストレージ、RF、オーディオ、センサーの設計は電源レールの前提に依存するため、PCB配置を始める前にこの節を完了してください。

#### 5.2.1. 電源 { #521-power-supply }

**要点**

- バッテリー駆動機器では`SF32LB520/3/5/7`向けの電源構成を使い、`VBUS`、`VBAT`、`VCC`、充電、OVPを設計します。
- 外部レギュレーター給電の機器では`52B/D/E/G/J`向けの構成を使い、`PVDD`と`VDDIOA`を外部から供給します。`VDD_SIP`はチップ型番に合わせて設定し、外部電源または内蔵LDOから給電できます。内蔵充電経路はありません。
- PCB配置前に、BUCKインダクター、内蔵LDOのデカップリング、RF／オーディオ電源、スタンバイ時のロードスイッチを確定します。

**設計目標**

選択したバリアントに適合する安定した電源ツリーを設計し、漏れ電流を抑えます。内蔵LDO出力の過負荷を避け、RF／オーディオ電源のノイズを抑え、未使用の負荷やブートストレージを低消費電力モードで電源オフにできる構成にします。

##### 5.2.1.2. BUCKインダクターの選定 { #5212-buck-inductor-selection }

どちらの設計グループでも同じインダクター仕様を使用します。

!!! important "電源インダクターの主な仕様"
    L（インダクタンス）= 4.7 uH ± 20%、DCR（直流抵抗）≤ 0.4 Ω、Isat（飽和電流）≥ 450 mA。

##### 5.2.1.3. バッテリーと充電の制御 { #5213-battery-and-charging-control }

=== "SF32LB520/3/5/7（バッテリー駆動）"

    充電回路には、外付け充電管理ICを使う方法と、チップ内蔵の充電管理モジュールを使う方法があります。

    **外付け充電管理IC**

    外付け充電ICには、電源パス管理（Power-Path Management、PPM）機能の有無による2種類があります。PPMなしの場合、バッテリーがVBATピンとVCCピンに直接電力を供給します。PPMありの場合、充電ICのVSYSがVCCに電力を供給し、充電ICのVBATはバッテリーとチップのVBATピンの両方に接続します。どちらの方式でもVBATピンを介してバッテリー電圧を測定します。VBATにはGPADCチャネルが内蔵されており、サンプリング精度は±30 mV以内です。

    ![図 5.2-1: 外付け充電回路（PPMなし）](../../sf32-products/chips/assets/52xA/sf32lb52x-CHG-NPPM.png){ width="100%" loading="lazy" }

    <div align="center"><em>図 5.2-1：外付け充電回路（PPMなし）</em></div>

    ![図 5.2-2: 外付け充電回路（PPMあり）](../../sf32-products/chips/assets/52xA/sf32lb52x-CHG-PPM.png){ width="100%" loading="lazy" }

    <div align="center"><em>図 5.2-2：外付け充電回路（PPMあり）</em></div>

    PPM対応の構成では、充電ICのVSYS既定出力電圧を4.7 V以下にしてください。VSYSはSF32LB52xのVCCピンに直接接続され、VCCの最大入力電圧が4.7 Vであるためです。

    **チップ内蔵の充電管理モジュール**

    内蔵充電モジュールを使用する場合、バッテリー残量が少なくデバイスの電源がオフの状態で充電器を接続しても、バッテリー電圧が電源投入しきい値に達するまではシステムが起動せず、充電画面も表示されません。

    ![図 5.2-3: 内蔵充電管理回路](../../sf32-products/chips/assets/52xA/sf32lb52x-CHG-INNER.png){ width="100%" loading="lazy" }

    <div align="center"><em>図 5.2-3：内蔵充電管理回路</em></div>

    **OVP ICの選定（内蔵充電管理モジュールを使用する場合）**

    VBUS入力範囲は4.5～5.5 Vです。次のいずれかのOVP ICを選択してください。

    - OVLO調整可能なOVP IC（例：AW32905FCR）：OVLOを5.2～5.5 Vに設定します（VOVLO_THの許容差は3%以下、抵抗の許容差は1%以下）。
    - 安定化出力を持つOVP IC（例：SGM4064YDE8GまたはLP5305AQVF）：レギュレーター出力が4.5～5.4 Vの範囲内であることを確認します。

    !!! important "VBUS の値は資料によって異なる"
        OpenSiFli の電池駆動バリアント向けアプリケーションノートには、VBUS の記載に不一致があります。OVP の選定説明ではチップの VBUS 範囲を 4.5～5.5 V とする一方、電源表と内蔵充電器の注意事項では 4.6～5.5 V とし、最大充電電流時に VBUS ピンを 4.6 V 以上に保つよう求めています。Electrical Specification-A3 の一般範囲は 4.5～5.5 V、充電回路図の表示は 4.3～5.5 V です。内蔵充電器を使う場合は、SiFli が適用下限を明確にするまで、最大負荷時にピン電圧を 4.6 V 以上に保ってください。充電回路図の4.3 Vの表示を承認済みの下限と見なさないでください。

        同じアプリケーションノートでは、OVLO調整型OVPデバイスの`VIN_OVLO`を5.2～5.5 Vに設定し、`VOVLO_TH`の許容差を3%以下、R1/R2の許容差を1%以下としています。レギュレーター出力型OVPデバイスについては、LDO出力を4.5～5.4 Vとしています。これらは各OVP方式に固有の設定値であり、チップのVBUS動作範囲と相互に置き換えられるものではありません。部品公差を考慮し、承認済みの設計をSiFliに確認してください。

    !!! important "内蔵充電管理モジュールの注意事項"
        - VBUS入力範囲：4.6～5.5 V
        - VCC入力範囲：3.2～4.7 V
        - デフォルトのトリクル充電電流：56 mA、定電流充電への移行電圧：3.0 V
        - デフォルトの定電流充電電流：65 mA、設定範囲：5～560 mA
        - デフォルトの満充電電圧：4.2 V、最大4.45 Vまで設定可能
        - 再充電電圧：満充電電圧 - 0.15 V
        - 充電器のVBUSには少なくとも350 mAの供給能力が必要です。最大充電電流時にVBUSピン電圧が4.6 Vを下回らないようにしてください。
        - ワイヤレス充電では、ワイヤレス充電器の電源供給能力が定電流充電電流を上回ることを確認してください。

    !!! important "内蔵LDOの注意事項"
        - VDD33_VOUT1およびVDD33_VOUT2の出力経路に接続する総容量は9.6 uF以下にしてください。
        - AVDD33_AUDにはVSYSではなくVDD33_VOUT1から給電してください。
        - LCDには内蔵LDOから給電せず、外付けLDOを使用してください。

=== "52B/D/E/G/J（外部レギュレーター給電）"

    !!! info "該当なし"
        外部レギュレーター給電バリアントは安定化された外部電源から直接給電され、**充電管理回路を内蔵していません**。この節は該当しません。バッテリー駆動と充電が必要な製品には、SF32LB520/3/5/7シリーズを使用してください。

##### 5.2.1.4. スタンバイ電力の低減 { #5214-reducing-standby-power }

=== "SF32LB520/3/5/7（バッテリー駆動）"

    推奨する電源構成では、**VDD33_VOUT2**から振動モーターへ、**VDD33_VOUT1**から外付けFlashとセンサーへ給電し、LCDには外付けLDOを使用します。

    ![図 5.2-7: SF32LB52xシステム電源構成図](../../sf32-products/chips/assets/52xA/sf32lb52x-PWR-diagram.png){ width="100%" loading="lazy" }

    <div align="center"><em>図 5.2-7：SF32LB52xシステム電源構成図</em></div>

    電源スイッチを制御するGPIOのハードウェア上の初期状態を適切に設定し、MΩオーダーのプルアップ／プルダウン抵抗を追加して、ロードスイッチがデフォルトでオフになるようにします。LDOとロードスイッチには静止電流（Iq）とシャットダウン電流（Istb）が小さい製品を選び、常時オンの電源デバイスでは特にIqに注意してください。

=== "52B/D/E/G/J（外部レギュレーター給電）"

    各機能ブロックの動的な電源管理にはロードスイッチを使用します。常時オンのモジュールや電源経路には、静止電流の小さい製品を選んでください。

    電源スイッチを制御するGPIOのハードウェア上の初期状態を適切に設定し、MΩオーダーのプルアップ／プルダウン抵抗を追加して、ロードスイッチがデフォルトでオフになるようにします。LDOとロードスイッチには静止電流（Iq）とシャットダウン電流（Istb）が小さい製品を選び、常時オンの電源デバイスでは特にIqに注意してください。

##### 5.2.1.5. 電源設計チェックリスト { #5215-power-design-checklist }

- [ ] チップ型番に合った電源バリアント（バッテリー駆動／外部レギュレーター給電）を選択した
- [ ] BUCKインダクターが4.7 uH ±20%、DCR ≤0.4 Ω、Isat ≥450 mAを満たす
- [ ] 内蔵LDOのデカップリングコンデンサーをすべて要件どおりに配置した
- [ ] LCD電源を分離し、内蔵LDOから直接給電していない
- [ ] オーディオおよびRF電源を適切にフィルタリングした
- [ ] バッテリー駆動バリアントでは充電経路とOVPデバイスの電圧範囲を確認した。外部レギュレーター給電バリアントではチップ型番に合わせてVDD_SIP/VDDIOAを設定した

**電源設計でよくある間違い**

- LCDに外付けLDOではなく内蔵LDOから直接給電する。
- 1つの回路図でバッテリー駆動と外部レギュレーター給電の前提を混在させる。
- ストレージのリーク電流が懸念されるバリアントで、Hibernate中も`VDD_SIP`を給電したままにする。
- 最悪条件でのVBUS電流と電圧範囲を確認せずに充電器やOVPデバイスを選ぶ。

**電源の立ち上げ確認**

- ファームウェアで周辺回路を有効にする前に、`VCC`/`PVDD`、BUCK出力、RF／オーディオ電源、ストレージ電源を測定します。
- バッテリー駆動設計では、充電器の接続、トリクル充電、定電流充電、再充電の動作を確認します。
- ディスプレイ、センサー、ストレージ、モーターのロードスイッチをオフにして、スタンバイ電流とHibernate電流を測定します。

#### 5.2.2. 動作モードとウェイクアップ要因 { #522-operating-modes-and-wake-sources }

**要点**

- ActiveとSleepは割り込みにすばやく応答できます。DeepSleepとStandbyでは、消費電流が下がる代わりに復帰時間が長くなります。
- Hibernateは最も低消費電力の状態ですが、SRAMは保持されず、一部の外部電源をオフにする必要があります。
- ウェイクアップ対応GPIOの選択は、ボタン、タッチ割り込み、充電イベント、センサーによるウェイクアップに影響します。

**設計目標**

リーク電流経路やウェイクアップイベントの取りこぼしを発生させず、製品が意図した低消費電力状態に移行できるよう、ウェイクアップ要因と外部電源スイッチの初期状態を選定します。

!!! note "ファミリー共通の設計"
    製品固有の電源ツリーで外部ウェイクアップ要因を意図的に無効化しない限り、動作モードとウェイクアップ要因の動作はSF32LB52xファミリー共通です。

### 5.3. クロック生成 { #53-clock-generation }

#### 5.3.1. 水晶振動子の選定 { #531-crystal-selection }

**要点**

- メインクロックには48 MHz、RTCには32.768 kHzの水晶振動子を使用します。
- 起動時および静的な消費電流を抑えるため、AVL掲載品のうちCLとESRが低い部品を優先します。
- 水晶振動子の配線は短くし、シールドを設け、発熱源やRF、充電器、PMU、DC/DCのノイズ源から離します。

**設計目標**

発振器の消費電流、周波数ドリフト、RF干渉、立ち上げ時のリスクを抑えながら、安定した低ジッターのクロック源を実現します。

チップには、48 MHzのメイン水晶振動子と32.768 kHzのRTC用水晶振動子の2つの外部クロック源が必要です。要件は両方のバリアントで共通です。

!!! important "水晶振動子の仕様要件"
    <div align="center"><em>表 5.3-1：水晶振動子の仕様要件</em></div>

    <div align="center" markdown>

    | 水晶振動子 | 要件 | 備考 |
    |:---|:---|:---|

    | 32.768 kHz | CL ≤ 12.5 pF（7 pF推奨）、ΔF/F0 ≤ ±20 ppm、ESR ≤ 80 kΩ（38 kΩ推奨） | CLとESRが小さいほど消費電力を抑えられます。CL < 12.5 pFの場合、通常は負荷容量調整用コンデンサーは不要です。 |

    </div>

!!! note "補足"
    TKD SX20Y048000B31T-8.8はESRがやや高く、その分、静的消費電力が少し増加します。また、SiFliの回路図アプリケーションノートでは、寄生負荷容量を低減するため、48 MHz水晶振動子の下にある第2層のGND銅箔を少なくとも除去するよう推奨しています。一方、PCBレイアウトガイドでは、水晶領域下の隣接層にプレーンの欠損や銅箔の切り欠きを設けないよう指示しています。両者は矛盾しているため、[クロックインターフェースの配線](SF32LB52x_pcb_layout.md#65-clock-interface-routing)を参照し、レイアウト確定前にSiFliへ意図する層処理を確認してください。

!!! important "元資料の水晶振動子 ESR の例外"
    元資料には TKD SX20Y048000B31T-8.8 が ESR ≤ 40 Ω で掲載されていますが、48 MHz 水晶振動子の一般要件は ESR ≤ 30 Ω です。この型番の適合性確認が必要であり、任意の 40 Ω 部品を使用できるという意味ではありません。リリース前に、正確な型番が現行 AVL に掲載されていることを確認し、起動、周波数校正、発振器電流を検証してください。

!!! important "32.768 kHz 水晶振動子の推奨値が資料内で異なる"
    元資料の32.768 kHzパラメーター表はCL = 7 pF、ESR = 38 kΩを推奨していますが、本文ではCL ≤ 9 pF、ESR ≤ 40 kΩを推奨しています。両方の記述が元資料にあるため、リリース前に目標値と選定した水晶振動子のAVL掲載状況をSiFliに確認してください。

部品の適合性確認に関する最新の詳細情報は、継続的に更新される[SiFli承認ベンダーリスト（AVL）][SiFli承認ベンダーリスト (Approved Vendor List, AVL)]を参照してください。

**クロック設計でよくある間違い**

- 周波数とパッケージだけで水晶振動子を選び、CL、ESR、許容差、動作温度範囲を確認しない。
- PA、充電器、PMU、RFマッチング回路など、発熱源やノイズ源の近くに水晶振動子を配置する。
- 水晶振動子のキープアウト領域の下に銅箔や高速配線を残す。
- 32 kHzの配線を、間隔やGNDシールドを設けずに長く並走させる。

**クロックのチェックリスト**

- [ ] 48 MHzおよび32.768 kHzの水晶振動子がAVL／データシートの要件を満たしている。
- [ ] 水晶振動子の負荷容量とESRが発振器の制限値内であることを確認した。
- [ ] PCBレビューでキープアウト、配線長、配線幅、間隔、GNDシールドを確認した。
- [ ] 立ち上げ計画に48 MHz、32 kHzの測定とBluetooth周波数校正の動作確認を含めた。
