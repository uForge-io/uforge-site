# SF32LB55x ハードウェア設計ガイド — PCB レイアウト指針 { #sf32lb55x-hardware-design-guide-pcb-layout-guidelines }

## 6. PCB レイアウト指針 { #6-pcb-layout-guidelines }

### 6.1. フットプリントと基板積層 { #61-footprint-and-stack-up }

選択した QFN または BGA パッケージの図面、ランドパターン要件、実装能力に合わせてください。BGA パッケージでは、ボールのファンアウト、ビア構成、ソルダーマスクのルール、製造限界を早い段階で確認する必要があります。

#### 6.1.1. 基板積層と製造工程の参考 { #611-stack-up-and-fabrication }

SiFli は QFN68L と BGA145 に従来の PTH 工程と 4 層基板を推奨しています。BGA169 では、ブラインド／埋め込みビアを使う 1 段 HDI が推奨されています。資料に示された 4 層および 6 層の積層例は、完成基板厚 0.7 mm ±10% です。これらは参考構成であり、一般的な制限値ではありません。選択したパッケージ図面を確認し、完成厚と製造能力を基板メーカーに確認してください。

#### 6.1.2. ランドパターン寸法 { #612-land-pattern-dimensions }

- BGA145/BGA169：ボール径 0.25 mm、ピッチ 0.5 mm。参考ランドパターンでは、ソルダーマスク開口 0.33 mm、メタルマスク開口 0.25 mm です。
- QFN68L：周辺パッドは 0.2 × 0.55 mm、ピッチ 0.35 mm。参考値はソルダーマスク開口 0.3 × 0.65 mm、メタルマスク開口 0.2 × 0.55 mm です。露出パッドは公称 5.49 mm 角、範囲は 5.39～5.59 mm です。

フットプリントを確定する前に、パッケージ図面と実装メーカーのメタルマスク／ソルダーマスク規則を確認してください。

### 6.2. 一般的な PCB ルール { #62-general-pcb-rules }

- BUCK のループは短く幅広にし、リターン電流がスイッチングループに近接するようにします。
- RF、水晶振動子、GPADC、オーディオの各領域を、スイッチング電源、ディスプレイクロック、モーター、充電回路から離します。
- 高速メモリとディスプレイのインターフェースは、連続したリファレンス GND 上に配線します。
- ESD 保護素子はコネクターの近くに配置し、信号が最初に保護素子を通るように配線します。
- 電源、ブート、デバッグ、RF、量産キャリブレーションに十分なテストポイントを設けます。

#### 6.2.2. 電源とグラウンドのレイアウト { #622-power-and-ground-layout }

- DC-DC のインダクターとコンデンサーは各ピンの近くに配置します。BUCK_VSW は短く幅広にし、ループ面積を小さくします。出力コンデンサーの GND は複数のビアでプレーンに接続し、BUCK_VOUT のフィードバック配線幅は 0.25 mm を超える必要があります。インダクター下の表層銅や無関係な配線を避け、隣接層は連続した GND プレーンにします。
- PVDD_PMU1（ピン 67）のコンデンサーはピンの近くに配置し、配線幅を 0.3 mm 以上にします。LDO/IO コンデンサーも対応するピンの近くに配置します。配線幅は負荷電流に合わせ、リップルや安定性が重要な電源は短く幅広に配線します。
- QFN の露出パッドは複数のビアでメイングラウンドに直接接続します。特に RF と PMU 周辺で確実に接続してください。BGA145 と BGA169 の RF グラウンドボールは C12、C13、D12、E13 です。[BGA145 のボールマップ](https://github.com/OpenSiFli/SiFli-Wiki/blob/main/source/zh_CN/hardware/assets/55x/SF32LB55x-BGA145-Ballmap.svg)、[BGA169 デバイス 1 のボールマップ](https://github.com/OpenSiFli/SiFli-Wiki/blob/main/source/zh_CN/hardware/assets/55x/SF32LB55x-BGA169-1-Ballmap.svg)、[BGA169 デバイス 2 のボールマップ](https://github.com/OpenSiFli/SiFli-Wiki/blob/main/source/zh_CN/hardware/assets/55x/SF32LB55x-BGA169-2-Ballmap.svg)に従ってメイングラウンドへ接続してください。D2 と B3 が PMU グラウンドボールとなるのは BGA169 のみです。BGA145 では D2 は PA79、B3 は BUCK2_VOUT です。異なるグラウンドボールを表層銅で相互接続しないでください。

**原図との照合:** 原文の説明では、RF グラウンドボールの一覧で E13 が重複しています。一方、[RF グラウンド図](https://github.com/OpenSiFli/SiFli-Wiki/blob/main/source/zh_CN/hardware/assets/55x/SF32LB55x-RF-VSS-PCB.png)では AVSS_TRF が C13、AVSS_RRF が E13、AVSS_BB が C12、AVSS_VCO が D12 です。上記の座標は図のラベルに基づいています。配線前に対象パッケージのボールマップでも確認してください。

#### 6.2.3. EMI、ESD、保護 { #623-emi-esd-and-protection }

可能であれば、クロックやノイズの大きい電源配線を内層に配置します。ESD 保護素子はコネクター近くに置き、信号が基板に入る前に保護素子を通るようにし、分岐スタブを作らないでください。GND への経路は短く幅広にし、ビアでプレーンへ直接接続します。USB 充電のテストポイントは TVS のコネクター側に置きます。バッテリー入力の TVS はコネクターと基板負荷の間に置き、チップまでの経路が最初に TVS を通るようにして、GND 接続を短くします。

### 6.3. インターフェース配線 { #63-interface-routing }

クロック配線は短くし、シールドするとともに、高速デジタル信号から分離します。RF は 50 Ω の伝送路として設計し、マッチング回路を小さくまとめます。ストレージとディスプレイの配線は、速度に応じた長さ制御を行い、バスごとにまとめて配線します。オーディオと GPADC の信号はシールドし、スイッチング電流から遠ざけます。

#### 6.3.1. 水晶振動子の配置と配線 { #631-crystal-placement-and-routing }

- 各水晶振動子はシールド領域内に配置し、基板端から 1 mm 超、PA、充電器、PMU などの発熱源から 5 mm 超離します。水晶振動子の周囲に 0.25 mm 以上のクリアランスを確保します。
- 48 MHz 水晶振動子の配線はトップ層とし、長さを 3～10 mm、幅を 0.1 mm とします。48M_XI と 48M_XO の間隔は 0.15 mm 以上とし、[元の配線モデル](https://github.com/OpenSiFli/SiFli-Wiki/blob/main/source/zh_CN/hardware/assets/55x/SF32LB55x-48M-M-PCB.png)に従って、三次元的に GND でシールドします。VBAT、DC-DC、高速信号から離してください。元の説明文では、水晶振動子領域の下のトップ層と隣接層を銅箔禁止とし、無関係な配線をその領域に通さないよう求めています。
- 32.768 kHz 水晶振動子の配線はトップ層とし、長さを 10 mm 以下、幅を 0.1 mm とします。XI と XO の間隔を 0.15 mm 以上確保し、三次元的に GND でシールドします。元の説明文では、水晶振動子領域の下のトップ層と隣接層を銅箔禁止とし、無関係な配線をその領域に通さないよう求めています。

#### 6.3.2. RF と高速インターフェース { #632-rf-and-high-speed-interfaces }

RF マッチング回路はアンテナ側ではなくチップの近くに配置します。AVDD_BRF のコンデンサーをピンの近くに置き、その GND をメイングラウンドへ直接接続します。RF 配線はトップ層で層変更せず、インピーダンスを 50 Ω に制御します。元の説明文では幅 10 mil 超が推奨されていますが、元のチェックリストでは幅 10 mil 以上が必須項目です。この推奨値と必須の下限を区別し、最終的な配線幅は選択した基板スタックアップに基づく 50 Ω 設計で決めてください。両側を三次元的に GND シールドし、ステッチングビアを配置して、鋭角を避けます。DC-DC、VBAT、クロック、高速 I2C/SPI/SDIO/I2S/UART は RF 領域から離してください。

MIPI_DSI は差動インピーダンス 100 Ω で配線し、データ差動ペアをクロックペアに対して長さ整合します。OPI PSRAM および LCDC SPI/QSPI バスも長さを整合します。可能な場合はクロックと I2C 配線を GND でガードし、無関係な信号との長い並走を避けます。

#### 6.3.3. アナログ信号の配線 { #633-analog-routing }

GPADC 配線を三次元的に GND シールドし、ノイズの多いバッテリー電圧／温度検出経路から離します。必要な整定時間に照らして、分圧抵抗のインピーダンスと漏れ電流も確認してください。
