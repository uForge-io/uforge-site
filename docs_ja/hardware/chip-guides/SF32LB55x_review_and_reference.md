# SF32LB55xハードウェア設計ガイド — 設計レビュー用チェックリストと参考資料 { #sf32lb55x-hardware-design-guide-design-review-checklist-and-references }

## 7. 設計レビュー用チェックリスト { #7-design-review-checklist }

- [ ] 正確なパッケージ、ピン配置、ランドパターン、PCB製造プロセスを確認した。
- [ ] PMUと補助電源レールが、データシートに記載された電圧／電流の規定を満たしている。
- [ ] 必要なデカップリングコンデンサを各ピンの近くに配置している。
- [ ] POR/BOR／リセットのタイミングとブートモードを検証した。
- [ ] 48 MHzと32.768 kHzの水晶振動子が、CL、ppm、ESR、配置、配線の要件を満たしている。
- [ ] RFマッチング、アンテナ、グラウンドのキープアウト領域をレビューした。
- [ ] 外部メモリーとディスプレイのピン配置が、選択したパッケージに合っている。
- [ ] ウェイクアップ、GPADC、センサー、オーディオ、タッチ、バックライト、モーター回路が低消費電力要件を満たしている。
- [ ] デバッグ、ダウンロード、量産書き込み、RF試験、水晶校正のためのアクセスを確保している。

## 9. 付録 { #9-appendices }

### 9.1. 付録A. 代表的なSF32LB55x製品 { #appendix-a-a-typical-sf32lb55x-product }

一般的なSF32LB55x製品には、MCU、電源ツリー、水晶振動子、RFマッチング回路とアンテナ、外部メモリー、ディスプレイとタッチコントローラー、センサー、GPADC入力、振動モーター、オプションのBluetoothオーディオ、デバッグ用と量産試験用の接続手段が含まれます。バッテリー駆動製品では、低消費電力時のリーク電流を確認し、試験治具の接続方法も計画してください。

### 9.2. 設計に関するQ&A { #91-design-qa }

1. **Mode = 1で起動すると、一部GPIOの初期状態が仕様書と異なるのはなぜですか。** ダウンロードモードでは、外部FlashのQSPI2/QSPI3に関連するGPIOの状態が変わります。
2. **プログラム書き込み中に実装モーターが予期せず振動するのはなぜですか。** 電源制御またはPWM信号が意図せず有効になることがあります。Highで起動するモーターでは、デフォルトがプルアップ（PU）のGPIOが電源を有効にする場合があります。PWMにはデフォルトがプルダウン（PD）のGPIO17またはGPIO39を推奨します。
3. **電池のはんだ付けでチップが停止することがあるのはなぜですか。どう防げますか。** はんだごての接地不良によってサージが発生する場合があります。電池インターフェースにサージ／ESD保護を追加し、はんだごてを確実に接地してください。
4. **HibernateでウェイクボタンからMCUを起動できないのはなぜですか。** Hibernate状態からMCUを復帰させられるのはLCPU側のGPIO43～GPIO48の6本のみで、HCPU側のGPIO0～GPIO3は使用できません。
5. **低消費電力デバッグ中にGセンサーや心拍センサーの消費電力が高い、または動作異常になるのはなぜですか。** センサーのファームウェアはLCPUで動作するため、I2C、SPI、制御、割り込み信号はすべてLCPU側のインターフェースを使用する必要があります。HCPU側に割り当てると、消費電力増加や誤動作につながることがあります。
6. **すべての信号をLCPU側に接続してもセンサーの消費電力が高いのはなぜですか。** センサー電源を切るだけでは、I2Cや割り込み信号のプルアップ電源が残っている場合は不十分です。これらのインターフェースのプルアップ電源もオフにしてください。
7. **GPIO26とGPIO27の両方を出力制御に使うと、スリープ電流が増えるのはなぜですか。** スリープ中は両GPIOを同じレベルにするか、少なくとも一方をプルアップ／プルダウンなしのハイインピーダンスにしてください。
8. **SS6600がHibernate中に高電流になる場合はどうしますか。** HCPU GPIO0～GPIO3とLCPU GPIO43～GPIO48の計10本のウェイク入力を、安定したHighまたはLowに保ちます。10本すべてをプルアップする場合は、常時給電の3.3 Vを使用してください。
9. **低消費電力時の消費電流が高い場合、電源部品の静止電流が原因ですか。** はい。静止電流（Iq）の大きいBUCK、LDO、ロードスイッチは消費電力を増やすため、SiFliはIqが1 µA未満の部品を推奨しています。
10. **ESD試験で画面にノイズが出るのを防ぐにはどうしますか。** タッチパネルのVDD、SCL、SDA、RESET、INT、およびLCDの電源とRESET信号にESD保護素子を追加してください。
11. **常時表示機能の異常を防ぐにはどうしますか。** 常時表示は主にTFTより低消費電力のAMOLEDパネルで使います。LCD_EN、LCD_RSTなどの制御にはPB GPIOを推奨します。PA GPIOでHigh有効の信号を制御する場合は、デフォルトPUのGPIOを使う必要があります。デフォルトPDのPA GPIOを使うと、復帰後に10 msを超えて画面が異常に消えることがあります。
12. **スリープ中も外部Bluetoothオーディオに給電する場合、復帰後の電源制御異常を防ぐにはどうしますか。** 電源スイッチはLCPU GPIOで制御してください。Low有効の場合は、デフォルトPDのLCPU GPIOを選びます。
13. **電池の過放電後に充電できなくなるのを防ぐにはどうしますか。** 電池電圧が低すぎる場合、充電器接続時に充電器入力からシステムへ給電できる電源パス管理が必要です。これがない場合、充電ICのトリクル充電電流は40 mA以上必要です。
14. **充電器を接続しても充電が始まらないのはなぜですか。** 充電器接続検出信号を、ウェイク対応のLCPU GPIO43～GPIO48のいずれかに接続してください。他のGPIOでは充電処理を正しく開始できない場合があります。
15. **MODE Highのダウンロードモードで電流が増えるのを防ぐにはどうしますか。** オーディオPAなど、Highで有効になる高消費電力の周辺機器は、デフォルトPDのGPIOで制御してください。デフォルトPUは使用しないでください。ダウンロードモードで周辺機器が誤って有効になり、書き込みに影響することがあります。
16. **MODE Highで書き込みに失敗するのはなぜですか。GPIO46のセンサー割り込みはどうしますか。** ダウンロードモードではGPIO46がUART3_RXになるため、書き込みを妨げる場合があります。センサー割り込みをGPIO43、GPIO44、GPIO47、GPIO48のいずれかへ移してください。LCPUウェイク入力が不足する場合は、基板外のボタンを0 Ω抵抗経由でGPIO45またはGPIO46に接続できます。
17. **Gセンサーと心拍アルゴリズムでメモリーが不足する場合はどうしますか。** LCPUに割り当てたメモリーが十分か確認し、不足する場合はQSPI4に外付けNOR Flashを追加してください。
