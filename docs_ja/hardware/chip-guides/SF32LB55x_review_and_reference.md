# SF32LB55x ハードウェア設計ガイド — 設計レビュー用チェックリストと参考資料 { #sf32lb55x-hardware-design-guide-design-review-checklist-and-references }

## 7. 設計レビュー用チェックリスト { #7-design-review-checklist }

- [ ] 正確なパッケージ、ピン配置、ランドパターン、PCB 製造プロセスを確認した。
- [ ] PMU と補助電源レールが、データシートに記載された電圧／電流の規定を満たしている。
- [ ] 必要なデカップリングコンデンサを各ピンの近くに配置した。
- [ ] POR/BOR／リセットのタイミングとブートモードを検証した。
- [ ] 48 MHz と 32.768 kHz の水晶振動子が、CL、ppm、ESR、配置、配線の要件を満たしている。
- [ ] RF マッチング、アンテナ、グランドのキープアウト領域をレビューした。
- [ ] 外部メモリーとディスプレイのピン配置が、選択したパッケージに合っている。
- [ ] ウェイクアップ、GPADC、センサー、オーディオ、タッチ、バックライト、モーター回路が低消費電力要件を満たしている。
- [ ] デバッグ、ダウンロード、量産書き込み、RF 試験、水晶校正のためのアクセスを確保した。

## 9. 付録 { #9-appendices }

### 9.1. 付録 A. 代表的な SF32LB55x 製品 { #appendix-a-a-typical-sf32lb55x-product }

一般的な SF32LB55x 製品には、MCU、電源ツリー、水晶振動子、RF マッチング回路とアンテナ、外部メモリー、ディスプレイとタッチコントローラー、センサー、GPADC 入力、振動モーター、オプションの Bluetooth オーディオ、デバッグ用と量産試験用の接続手段が含まれます。バッテリー駆動製品では、低消費電力時のリーク電流を確認し、試験治具の接続方法も計画してください。

### 9.2. 設計に関する Q&A { #91-design-qa }

1. **Mode = 1 で起動すると、一部 GPIO の初期状態が仕様書と異なるのはなぜですか。** ダウンロードモードでは、外部 Flash の QSPI2/QSPI3 に関連する GPIO の状態が変わります。
2. **プログラム書き込み中に実装モーターが予期せず振動するのはなぜですか。** 電源制御または PWM 信号が意図せず有効になることがあります。High で起動するモーターでは、デフォルトがプルアップ（PU）の GPIO が電源を有効にする場合があります。PWM にはデフォルトがプルダウン（PD）の GPIO17 または GPIO39 を推奨します。
3. **電池のはんだ付けでチップが停止することがあるのはなぜですか。どう防げますか。** はんだごての接地不良によってサージが発生する場合があります。電池インターフェースにサージ／ESD 保護を追加し、はんだごてを確実に接地してください。
4. **Hibernate でウェイクボタンから MCU を起動できないのはなぜですか。** Hibernate 状態から MCU を復帰させられるのは LCPU 側の GPIO43～GPIO48 の 6 本のみで、HCPU 側の GPIO0～GPIO3 は使用できません。
5. **低消費電力デバッグ中に G センサーや心拍センサーの消費電力が高い、または動作異常になるのはなぜですか。** センサーのファームウェアは LCPU で動作するため、I2C、SPI、制御、割り込み信号はすべて LCPU 側のインターフェースを使用する必要があります。HCPU 側に割り当てると、消費電力増加や誤動作につながることがあります。
6. **すべての信号を LCPU 側に接続してもセンサーの消費電力が高いのはなぜですか。** センサー電源を切るだけでは、I2C や割り込み信号のプルアップ電源が残っている場合は不十分です。これらのインターフェースのプルアップ電源もオフにしてください。
7. **GPIO26 と GPIO27 の両方を出力制御に使うと、スリープ電流が増えるのはなぜですか。** スリープ中は両 GPIO を同じレベルにするか、少なくとも一方をプルアップ／プルダウンなしのハイインピーダンスにしてください。
8. **SS6600 が Hibernate 中に高電流になる場合はどうしますか。** HCPU GPIO0～GPIO3 と LCPU GPIO43～GPIO48 の計 10 本のウェイク入力を、安定した High または Low に保ちます。10 本すべてをプルアップする場合は、常時給電の 3.3 V を使用してください。
9. **低消費電力時の消費電流が高い場合、電源部品の静止電流が原因ですか。** はい。静止電流（Iq）の大きい BUCK、LDO、ロードスイッチは消費電力を増やすため、SiFli は Iq が 1 µA 未満の部品を推奨しています。
10. **ESD 試験で画面にノイズが出るのを防ぐにはどうしますか。** タッチパネルの VDD、SCL、SDA、RESET、INT、および LCD の電源と RESET 信号に ESD 保護素子を追加してください。
11. **常時表示機能の異常を防ぐにはどうしますか。** 常時表示は主に TFT より低消費電力の AMOLED パネルで使います。LCD_EN、LCD_RST などの制御には PB GPIO を推奨します。PA GPIO で High 有効の信号を制御する場合は、デフォルト PU の GPIO を使う必要があります。デフォルト PD の PA GPIO を使うと、復帰後に 10 ms を超えて画面が異常に消えることがあります。
12. **スリープ中も外部 Bluetooth オーディオに給電する場合、復帰後の電源制御異常を防ぐにはどうしますか。** 電源スイッチは LCPU GPIO で制御してください。Low 有効の場合は、デフォルト PD の LCPU GPIO を選びます。
13. **電池の過放電後に充電できなくなるのを防ぐにはどうしますか。** 電池電圧が低すぎる場合、充電器接続時に充電器入力からシステムへ給電できる電源パス管理が必要です。これがない場合、充電 IC のトリクル充電電流は 40 mA 以上必要です。
14. **充電器を接続しても充電が始まらないのはなぜですか。** 充電器接続検出信号を、ウェイク対応の LCPU GPIO43～GPIO48 のいずれかに接続してください。他の GPIO では充電処理を正しく開始できない場合があります。
15. **MODE High のダウンロードモードで電流が増えるのを防ぐにはどうしますか。** オーディオ PA など、High で有効になる高消費電力の周辺回路は、デフォルト PD の GPIO で制御してください。デフォルト PU は使用しないでください。ダウンロードモードで周辺回路が誤って有効になり、書き込みに影響することがあります。
16. **MODE High で書き込みに失敗するのはなぜですか。GPIO46 のセンサー割り込みはどうしますか。** ダウンロードモードでは GPIO46 が UART3_RX になるため、書き込みを妨げる場合があります。センサー割り込みを GPIO43、GPIO44、GPIO47、GPIO48 のいずれかへ移してください。LCPU ウェイク入力が不足する場合は、基板外のボタンを 0 Ω 抵抗経由で GPIO45 または GPIO46 に接続できます。
17. **G センサーと心拍アルゴリズムでメモリーが不足する場合はどうしますか。** LCPU に割り当てたメモリーが十分か確認し、不足する場合は QSPI4 に外付け NOR Flash を追加してください。
