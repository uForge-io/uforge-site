# SF32LB56x ハードウェア設計ガイド — PCB レイアウトガイドライン { #sf32lb56x-hardware-design-guide-pcb-layout-guidelines }

!!! note "SF32LB56x ハードウェア設計ガイドの一部"
    PCB レイアウトガイドラインの第 6 節です。[回路図設計ガイドライン](SF32LB56x_schematic_design.md)に戻るか、[設計レビューのチェックリストと参考資料](SF32LB56x_review_and_reference.md)に進んでください。

## 6. PCB レイアウトガイドライン { #6-pcb-layout-guidelines }

### 6.1. フットプリントと基板積層 { #61-footprint-and-stack-up }

U 版は 68 ピン QFN68L（7 × 7 × 0.75 mm、ピンピッチ 0.35 mm）です。QFN は PTH に対応し、SiFli は 4 層 PTH を推奨しています。すべてのピンを表層からファンアウトします。V 版は 175 ボール WBBGA（6.5 × 6.1 × 0.94 mm、ボールピッチ 0.4 mm、ボール径 0.25 mm）です。PTH は使用できず、HDI が必要です。外側 2 列のボールは表層から、その他のボールは内層からファンアウトします。レイアウト確定前に、選択した積層、ソルダーマスク、ファンアウト方式に基板メーカーが対応できることを確認してください。

### 6.2. 重要信号の配線 { #62-critical-routing }

#### 6.2.1. クロック配線 { #621-clock-routing }

水晶振動子はシールド内に配置し、基板端から 1 mm 超、発熱する PA、充電器、PMU からできれば 5 mm 以上離します。水晶回路から 0.25 mm 以内には金属や部品を置かないでください。48 MHz 水晶は可能なら表層に配線し、長さを 3～10 mm、幅を 0.075 mm として立体的に GND で囲みます。VBAT、DC-DC、高速信号から離してください。32.768 kHz 水晶も表層に配線し、長さを 10 mm 以下、幅を 0.075 mm、32K_XI と 32K_XO の間隔を 0.15 mm 以上にします。両方の水晶の直下は表層および隣接層をクリアし、他の配線を通さないでください。

#### 6.2.2. RF 配線 { #622-rf-routing }

RF は 50 Ω の単端制御インピーダンスとし、線幅は 10 mil 超を推奨します。可能な限り表層に配線し、ビアと鋭角を避けてください。整合回路はアンテナ側ではなくチップ側に配置します。AVDD_BRF のフィルタコンデンサはチップ端子の近くに置き、GND をビア経由で主 GND に直結します。RF 配線の両側に連続した GND シールドとステッチングビアを設け、高 di/dt 電源、高速クロック、I2C、SPI、SDIO、I2S、UART の信号を RF 領域内および直下に配置しないでください。U 版の AVSS_RF1/2/3 と V 版の AVSS_RRF、AVSS_TRF、AVSS_TRF2、AVSS_BB は主 GND に確実に接続します。

#### 6.2.3. 電源と GND { #623-power-and-ground }

BUCK インダクタとフィルタコンデンサをチップ端子の近くに配置します。BUCK_LX は短く太く配線し、BUCK_FB の幅は 0.25 mm 以上にします。インダクタ直下の表層には銅箔を設けず、隣接層は連続した GND とし、インダクタ領域に他の配線を通さないでください。BUCK 出力コンデンサの GND は複数のビアで主 GND に接続します。PVDD コンデンサは端子の近くに配置し、PVDD を短く太く配線します。PVSS はビアで主 GND に接続します。LDO と I/O 電源のデカップリングコンデンサは各端子の近くに配置し、負荷電流に応じて配線幅を決めます。

!!! warning "PVDD 配線幅の資料間不一致"
    SF32LB56xU/V のハードウェアアプリケーションガイドは PVDD 配線幅を 0.5 mm 以上としていますが、対応する PCB チェックリストでは 8 mil と記載されています。値が一致しないため、レイアウトを確定する前に SiFli または PCB 設計責任者に適用要件を確認してください。

#### 6.2.4. オーディオとアナログ信号 { #624-audio-and-analog-signals }

AVDD33_ANA と AVDD33_AUD は個別のスター配線とし、GND ガードを設け、大電流ノイズ源から離します。AVDD33_AUD、MIC_BIAS、AUD_VREF のフィルタコンデンサは各端子の近くに置き、GND を主 GND に直接接続します。ADCP/ADCN は短くガードした差動ペアとし、関連部品をチップ近くに配置します。DACP/DACN は差動ペアとして配線し、寄生容量を 10 pF 未満、配線長を 2 cm 未満に抑え、強いノイズ源から離します。GPADC 配線に GND ガードを設け、電池電圧や温度検出回路などのノイズ源を避けます。

#### 6.2.5. USB と SDIO { #625-usb-and-sdio }

USB D+/D−（PA17/PA18）は 90 Ω 差動ペアとして GND ガードを設けます。ESD 素子はコネクター近くに置き、信号をチップに入る前に通過させます。保護素子より手前で信号を分岐しないでください。素子の GND は短く太い配線とビアで主 GND に接続します。U 版は SDIO を 1 系統、V 版は SDIO1/SDIO2 の 2 系統備えます。SDIO 信号は一群として配線し、全長を 50 mm 以下、グループ内の長さ差を 6 mm 以下にします。クロックを GND でシールドし、DATA と CMD にも GND ガードを設けます。

#### 6.2.6. EMI、ESD、テストポイント { #626-emi-esd-and-test-points }

シールド外の表層に、クロックや電源などノイズの多い信号を長距離配線しないでください。可能なら内層を使用します。TVS/ESD 素子は対応するコネクターの近くに配置し、信号を保護素子に通してからチップへ接続します。保護素子の GND パッドは短く太い配線とビアで主 GND に接続します。USB 充電ケーブルのテストポイントは TVS の上流に、バッテリーコネクターの TVS はバッテリープラットフォームの上流に配置し、外部配線がチップに達する前に TVS を通るようにします。チップ直下の GND ネットは十分に接続し、ブラインド／埋め込みビアで主 GND に接続します。
