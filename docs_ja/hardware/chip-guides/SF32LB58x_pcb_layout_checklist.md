### 6.18.4. クロック { #6184-clock }

<div align="center"><em>表 6.18.4-1: クロックのチェックリスト</em></div>

<div align="center" markdown>

| 番号 | チェック項目 | 区分 |
|:---|:---|:---|
| 1 | 水晶振動子をチップの近くに配置する | 必須 |
| 2 | 水晶振動子の周囲にGNDシールドを設ける | 必須 |
| 3 | 水晶振動子の下には銅箔を設けない。4層基板では、少なくとも第 1 層（最上層）、第 2 層、第 3 層に銅箔禁止領域を設ける | 必須 |
| 4 | 水晶振動子の配線とGNDガード銅箔との間隔を、配線幅の3倍より大きくする | 必須 |

</div>

!!! warning "水晶振動子のキープアウト層をSiFliに確認してください"
    チェックリストのワークブックは、4層基板では第 1、第 2、第 3 層を銅箔キープアウトとしています。[PCBレイアウト指針](SF32LB58x_pcb_layout.md#65-clock-interface-routing)は水晶振動子領域の最上層とその下の隣接層を指定しています。第 3 層を含めるかどうかで資料間に差があります。SiFliの確認なしに最終要件を推測しないでください。

### 6.18.7. オーディオ { #6187-audio }

<div align="center"><em>表 6.18.7-1: オーディオのチェックリスト</em></div>

<div align="center" markdown>

| 番号 | チェック項目 | 区分 |
|:---|:---|:---|
| 1 | AU_ADC1PとAU_ADC1Nの並走配線にGNDガードを設ける | 必須 |
| 2 | AU_ADC2PとAU_ADC2Nの並走配線にGNDガードを設ける | 必須 |
| 3 | AU_DAC1PとAU_DAC1Nの並走配線にGNDガードを設ける | 必須 |
| 4 | AU_DAC2PとAU_DAC2Nの並走配線にGNDガードを設ける | 必須 |

!!! warning "DAC配線長の上限が資料間で一致しません"
    このワークブックはDAC配線長を2 cm未満（20 mm）としていますが、[PCBレイアウト指針](SF32LB58x_pcb_layout.md#67-audio-interface-routing)は2 mm未満としています。上限は10倍異なります。SiFliの確認なしに一方の値を選ばないでください。

### 6.18.8. 高速信号 { #6188-high-speed-signals }

<div align="center"><em>表 6.18.8-1: 高速信号のチェックリスト</em></div>

<div align="center" markdown>

| 番号 | チェック項目 | 区分 |
|:---|:---|:---|
| 1 | DSI差動信号が100 Ωの差動インピーダンス要件を満たしている | 必須 |
| 2 | DSIデータ差動ペアとクロック差動ペアの配線長差を200 mil以内にする | 必須 |
| 3 | DSI信号をできるだけ同じ層に配線する | 必須 |

</div>

!!! warning "DSI差動ペア間の上限が資料間で一致しません"
    このワークブックはDSIデータ差動ペアとクロック差動ペアの長さ差を200 mil（5.08 mm）以内としています。[PCBレイアウト指針](SF32LB58x_pcb_layout.md#610-dsi-interface-routing)はペア間のスキューを ≤2 mm、ペア内を ≤0.5 mmとしています。ペア間の上限が一致しないため、レイアウト確定前にSiFliへ適用値を確認してください。
