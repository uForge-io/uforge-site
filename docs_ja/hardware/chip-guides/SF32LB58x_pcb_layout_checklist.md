### 6.18.4. クロック { #6184-clock }

<div align="center"><em>表 6.18.4-1: クロックのチェックリスト</em></div>

<div align="center" markdown>

| 番号 | チェック項目 | 区分 |
|:---|:---|:---|
| 1 | 水晶振動子をチップの近くに配置する | 必須 |
| 2 | 水晶振動子の周囲に GND シールドを設ける | 必須 |
| 3 | 水晶振動子の下には銅箔を設けない。4 層基板では、少なくとも第 1 層（最上層）、第 2 層、第 3 層に銅箔禁止領域を設ける | 必須 |
| 4 | 水晶振動子の配線と GND ガード銅箔との間隔を、配線幅の 3 倍より大きくする | 必須 |

</div>

!!! warning "水晶振動子のキープアウト層を SiFli に確認してください"
    チェックリストのワークブックは、4 層基板では第 1、第 2、第 3 層を銅箔キープアウトとしています。[PCB レイアウト指針](SF32LB58x_pcb_layout.md#65-clock-interface-routing)は水晶振動子領域の最上層とその下の隣接層を指定しています。第 3 層を含めるかどうかで資料間に差があります。SiFli の確認なしに最終要件を推測しないでください。

### 6.18.6. RF { #6186-rf }

<div align="center"><em>表 6.18.6-1: RF のチェックリスト</em></div>

### 6.18.7. オーディオ { #6187-audio }

<div align="center"><em>表 6.18.7-1: オーディオのチェックリスト</em></div>

<div align="center" markdown>

| 番号 | チェック項目 | 区分 |
|:---|:---|:---|
| 1 | AU_ADC1P と AU_ADC1N の並走配線に GND ガードを設ける | 必須 |
| 2 | AU_ADC2P と AU_ADC2N の並走配線に GND ガードを設ける | 必須 |
| 3 | AU_DAC1P と AU_DAC1N の並走配線に GND ガードを設ける | 必須 |
| 4 | AU_DAC2P と AU_DAC2N の並走配線に GND ガードを設ける | 必須 |
| 5 | AU_DAC1P、AU_DAC1N、AU_DAC2P、AU_DAC2N の配線容量が &lt; 10 pF、配線長が &lt; 2 cm | 必須 |

</div>

!!! warning "DAC 配線長の上限が資料間で一致しません"
    このワークブックは DAC 配線長を 2 cm 未満（20 mm）としていますが、[PCB レイアウト指針](SF32LB58x_pcb_layout.md#67-audio-interface-routing)は 2 mm 未満としています。上限は 10 倍異なります。SiFli の確認なしに一方の値を選ばないでください。

### 6.18.8. 高速信号 { #6188-high-speed-signals }

<div align="center"><em>表 6.18.8-1: 高速信号のチェックリスト</em></div>

<div align="center" markdown>

| 番号 | チェック項目 | 区分 |
|:---|:---|:---|
| 1 | DSI 差動信号が 100 Ω の差動インピーダンス要件を満たしている | 必須 |
| 2 | DSI データ差動ペアとクロック差動ペアの配線長差を 200 mil 以内にする | 必須 |
| 3 | DSI 信号をできるだけ同じ層に配線する | 必須 |

</div>

!!! warning "DSI 差動ペア間の上限が資料間で一致しません"
    このワークブックは DSI データ差動ペアとクロック差動ペアの長さ差を 200 mil（5.08 mm）以内としています。[PCB レイアウト指針](SF32LB58x_pcb_layout.md#610-dsi-interface-routing)はペア間のスキューを ≤2 mm、ペア内を ≤0.5 mm としています。ペア間の上限が一致しないため、レイアウト確定前に SiFli へ適用値を確認してください。
