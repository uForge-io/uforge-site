# μForge M2 インターフェース命名規則 { #forge-m2-interface-naming-rules }

## 基本仕様 { #base-specification }

この文書は、μForge モジュールインターフェース構想で使用する名称を定めます。命名規則を示すものであり、正式に公開された電気・機械仕様ではありません。

この命名規則では、**M2** はこの体系を採用するモジュールに必須の共通基本インターフェースを表します。既存のすべての μForge または SiFli モジュールが M2 を実装しているという意味ではありません。M2 のピン配置、電気要件、機械要件は現在策定中であり、この文書では規定していません。

M2 を M.2 E-key 互換と表記する前に、正式公開する M2 定義で機械的インターフェース、ピン配置、電気的制限、必須／任意信号、キャリア基板要件、適合規則を規定する必要があります。現在の [M2 インターフェース定義](M2-interface-definition.md)は草案です。M2 という名称だけでは、M.2 との電気的互換性も、異なるモジュールとキャリア基板を組み合わせて使用できることも保証されません。

## 拡張仕様 { #extension-specifications }

任意の機能は **M2xY** 拡張仕様に分類します。名称は機能カテゴリを示すもので、特定のモジュールがそのカテゴリの全機能を実装することを保証するものではありません。

**命名形式:**

> **M2xY**

各要素の意味:

- **M2** = 基本インターフェース仕様
- **x** = 拡張を表す区切り文字
- **Y** = 拡張カテゴリ

## 拡張カテゴリ { #extension-categories }

<div align="center"><em>M2 拡張カテゴリ</em></div>

<div align="center" markdown>

| 仕様 | 説明 |
|:-----|:-----|
| **M2xM** | マルチメディア：将来的な対応を想定する RGB ディスプレイ、DVP カメラ、デジタルマイク、高度なオーディオ機能。 |
| **M2xA** | アナログ: 将来の高精度アナログ I/O およびデータ収集機能。 |
| **M2xN** | ネットワーク: 将来の Ethernet、CAN、産業用ネットワーク機能。 |
| **M2xH** | 高速: 将来の広帯域インターフェース。 |
| **M2xP** | 電源: 将来の電源管理機能および大電流 I/O 機能。 |

</div>

これらの説明は各カテゴリの想定範囲を示すもので、確定した電気要件ではありません。手元にある提案用ワークブックには M2 と M2xM のコンタクトマップが含まれています。インターフェース定義の記事には M2xN と M2xA の概要もありますが、それらを照合できる元のコンタクトマップ資料は確認できていないため、未検証として扱ってください。M2xH と M2xP は名称のみが予約されており、コンタクトの割り当てはありません。

## モジュールの仕様表記 { #module-declaration }

この命名規則を採用するモジュールは、基本インターフェースとして **M2** を記載し、実装した拡張仕様を 1 つ以上記載できます。モジュールの資料には、実際のコネクター、任意機能、同時に使用できないモードも明記する必要があります。

以下は表記例であり、発売済みモジュールの構成一覧ではありません。

- **M2**
- **M2 + M2xM**
- **M2 + M2xA**
- **M2 + M2xM + M2xN**

## 設計原則 { #design-principles }

- **M2** は、体系の発展に伴っても安定性と後方互換性を維持することを目指します。互換性は、該当する仕様の版と実際の実装に照らして検証する必要があります。
- 各 **M2xY** 拡張は固有の機能範囲を持ちます。名称が別でも、全機能を同時に使用できるとは限らず、ピン割り当てが互いに独立しているとも限りません。
- 拡張仕様は基本インターフェースを補完し、変更または置き換えるものではありません。
- モジュールは、実装している M2xY 仕様を列挙して対応機能を示します。

コネクターの選定や互換性の判断には、[モジュールインターフェース規格](interface-standards-overview.md)の検証手順を使用してください。
