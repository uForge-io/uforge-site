# モジュールインターフェース規格 { #module-interface-standards }

このセクションでは、μForge モジュールのインターフェースを記述するための規約を紹介します。キャリア基板のコネクター、ピン配置、互換性の表明を確定する前に確認してください。ここから参照できる資料は 2 種類です。命名規則は共通の用語を定め、ピン単位の定義案は計画に役立ちますが、選定したモジュールと製品に合わせて検証が必要です。

## 命名規則と電気的互換性の違い { #what-is-stable-and-what-must-be-verified }

モジュールの説明、回路図、BOMの注記、製品資料では、命名規則を一貫して使用してください。名称は想定するインターフェースプロファイルを示すもので、電気・機械仕様の確定を意味しません。プロファイル名やコネクター形状が一致しても、モジュールとキャリア基板の互換性が確認されたことにはなりません。

ピン単位の定義は、すべての μForge モジュールや SF32 パッケージが、割り当てられたすべての信号／インターフェース、または同時使用の組み合わせに対応することを保証するものではありません。設計を確定する前に、選定したモジュール、チップ、パッケージ、ハードウェア設計ガイドに照らして、以下を確認してください。

- コネクターの機械図面、キー形状、ピン番号、実装上の制約。
- 電源レール、電圧ドメイン、許容電流、電源シーケンス。
- インターフェースの対応状況、ピンの機能割り当て、同時に使用できない機能。
- 信号品質、インピーダンス、配線長の整合、ESD、RF キープアウト要件。
- デバッグ、起動、復旧、量産試験へのアクセス。
- キャリア基板で必要となるディスプレイ、カメラ、オーディオ、ストレージ、無線周辺機能。

## キャリア基板の判断手順 { #carrier-board-decision-path }

1. モジュールを選び、その製品紹介とハードウェア設計ガイドを読みます。
2. [M2 インターフェース命名規則](M2%20Interface%20Naming%20Rules.md)を使って、意図するプロファイルを明確にします。
3. [M2 インターフェース定義](M2-interface-definition.md)を使い、候補となる信号と共有時の競合を洗い出します。
4. 使用する各端子を、モジュール固有の資料と該当する SiFli の一次資料で確認します。
5. レイアウトを始める前に、文書の版、モジュールとキャリア基板の改版、確認済みの例外、未解決事項を回路図レビューに記録します。

キャリア基板全体のレビューについては、[量産に向けた設計](../design-for-production.md)に進んでください。モジュール固有の実装要件には、**ハードウェア設計ガイド**グループにある該当モジュールのガイドを参照します。
