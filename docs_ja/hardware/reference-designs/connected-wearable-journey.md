# コネクテッド・ウェアラブルのリファレンスデザイン { #connected-wearable-reference-design-journey }

このページは、ディスプレイ、BLE、センサー入力を備えた小型のバッテリー駆動コネクテッド製品向けの検証手順です。リリース済みの回路図やBOM、検証済みリファレンスボード一式ではありません。カスタムハードウェアの設計前に、製品に合うハードウェア／ソフトウェアの基準構成を確立し、検証するために利用してください。

1. **製品を選定し、基準構成を確立する。** [SF32ファミリー](../../sf32-products/family/SF32_family.md)と[SF32製品選定ツール](../../sf32-products/product-selector.md)で候補を絞り込みます。[SF32LB52-DevKit-LCD](../../sf32-products/devkits/SF32LB52-DevKit-LCD.md)、または必要なインターフェースとハードウェアの制約を満たす入手可能なボードでSiFli-SDKの`hello_world`を実行します。ボードのリビジョン、SDKバージョンまたはコミット、ビルド／書き込みコマンド、シリアルログを記録します。
2. **製品の機能を確認する。** [チュートリアルの概要](../../getting-started/tutorials/overview.md)に従い、入力／センサー処理、BLE、簡単なUI、必要に応じたストレージ、シリアル経由の復旧手順を検証します。
3. **システム連携を検証する。** [グラフィックス概要](../../learn/graphics/overview.md)、[Bluetooth概要](../../learn/bluetooth/overview.md)、[低消費電力の概要](../../learn/low-power/overview.md)を参照して、ディスプレイ更新、無線動作、スリープ／復帰を組み合わせて試験します。
4. **カスタムハードウェアを準備する。** [量産に向けた設計](../design-for-production.md)から選定したチップの設計ガイドとチェックリストを使います。ディスプレイ、ストレージ、バッテリー、アンテナ／RF、書き込み／試験に関する前提条件を確認します。
5. **リリース判断に必要な記録をそろえる。** ボード名とリビジョン、SDKバージョンまたはコミット、動作確認済みのファームウェアイメージ、ログ、各動作シナリオの消費電力測定値と測定条件、復旧／OTAの動作、BOMの選定、チェックリストの判断結果を保管します。

デモが動くだけでは、この検証は完了しません。ビルド、書き込み、復旧の手順を再現でき、製品の主要サブシステムが代表的なハードウェア上で連携して動作することを実測で示す必要があります。消費電力の測定値には動作シナリオ、電源電圧、測定条件を添え、ほかのエンジニアが同じ条件で比較できるようにします。
