## ***SF32*** を選ぶ理由 { #why-choose-sf32 .uf-center-heading }

<div class="grid cards uf-why-grid" markdown>

- :fontawesome-solid-microchip:{ .uf-icon-blue } **高い処理性能**

    コア数と機能はデバイスによって異なります。ファミリーにはシングルコアからトライコアまでの構成があり、複数のファミリーでCortex-M33 / STAR-MC1を採用しています。キャッシュ、FPU、MPUの搭載有無は、個々のチップとSoC実装によって異なるため、対象品番のドキュメントを確認してください。一部のデバイスでは、最大64 MBのパッケージ内PSRAMを利用できます。

- :fontawesome-brands-bluetooth:{ .uf-icon-blue } **Bluetooth接続**

    モードと機能はファミリーや品種によって異なります。デバイスによって、Bluetooth ClassicとLE、LE Audio、Long Range PHYなどに対応します。詳しい対応状況は各チップのページを確認してください。

- :fontawesome-solid-cube:{ .uf-icon-purple } **グラフィックスアクセラレーション**

    2D / 2.5D GPU、LCDコントローラー、LVGLにより、豊かで滑らかなグラフィカルインターフェースを実現します。ファミリー全体ではMIPI、RGB、QSPI、8080、JDI、EPDなどに対応し、解像度は最大1280 × 720です。

- :fontawesome-solid-volume-high:{ .uf-icon-pink } **オーディオサブシステム**

    オーディオ機能はファミリーや品種によって異なります。対応デバイスでは、アナログオーディオ、I²S、PDM、ハードウェア支援によるデジタルオーディオ処理を利用できます。

- :fontawesome-solid-brain:{ .uf-icon-amber } **AIアクセラレーション**

    一部のSF32デバイスはニューラルネットワークアクセラレーションを備え、TinyMLなどのエッジ推論に利用できます。

- :fontawesome-solid-leaf:{ .uf-icon-green } **超低消費電力**

    バッテリー駆動機器や常時稼働機器に最適化された高度な電源管理アーキテクチャ。

</div>
