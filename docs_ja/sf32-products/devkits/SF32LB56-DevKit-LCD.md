# SF32LB56-DevKit-LCD { #sf32lb56-devkit-lcd }

SF32LB56-DevKit-LCDは、SF32LB56-MOD-N16R12N1またはSF32LB56-MOD-A128R12N1を搭載できる、ディスプレイ向けの開発ボードです。いずれもSF32LB56xVシリーズデバイスを使用します。カスタムのSF32LB56xボードを設計する前に、ディスプレイインターフェース、オーディオ、リムーバブルストレージ、周辺機器ドライバーを評価できます。

## 主な用途 { #what-it-is-best-for }

- MIPI-DPI（RGB）、SPI、DSPI、QSPI、または8ビットMCU/8080インターフェースを使用するディスプレイアプリケーション。
- I2C経由のタッチスクリーン統合。
- アナログマイク入力と、オンボードのClass-Dパワーアンプによるアナログ出力を使ったオーディオ実験。
- SDIO/TFカードストレージと一般的なペリフェラルドライバー開発。
- キャリアボードを確定する前の、SF32LB56モジュールベースの製品アーキテクチャの評価。

**出典の補足（基板リビジョンを確認）：** SiFliの詳細なボードガイドでは、対象の開発ボードに`SF32LB56-MOD-A128R12N1`を搭載し、4 MB + 8 MBのパッケージ内OPI-PSRAMと1 Gb QSPI-NANDを備えると記載されています。また、これらのメモリー仕様は正式リリース前に変更される可能性があると明記されています。現行の型番ガイドにはN16R12N1とA128R12N1の両方が掲載され、どちらも4 + 8 MB OPI-PSRAMと1 MB標準QSPI-NORを搭載します。A128R12N1の128 MB QSPI-NANDは、詳細ガイドの1 Gbと容量上同等です。そのため、この型番のOPI-PSRAMと主NANDの容量に両資料間の矛盾はありません。ただし、詳細ガイドには1 MB標準NORの記載がなく、すべての個体やリビジョンに同じSKUが搭載されていることも確認できません。型番ガイドはCH343KにUSB-UARTデバッグチャネルが2系統あるとしていますが、詳細ガイドはType-Cの役割をUSB-UARTとUSB 2.0 FSとだけ説明し、UARTチャネルとコネクターの対応を示していません。特定のUARTチャネルを使う前に、該当リビジョンの回路図/BOMを確認してください。特定の基板を製品設計の基準にする前に、モジュールの表示と該当する回路図/BOMを確認してください。

**USB-UARTブリッジの型番表記が不一致です（実装部品を要確認）：** 詳細なボードガイドの機能ブロック図ではCH342K、型番ガイドではCH343Kと記載されています。実際の部品は該当リビジョンの回路図/BOMで確認してください。

**写真と本文のSKU表記が不一致（搭載モジュールを確認）：** 詳細ガイドの本文では対象ボードに`SF32LB56-MOD-A128R12N1`を搭載するとしていますが、注釈付きの正面写真には`SF32LB56-MOD-N16R12N1`と表示されています。SiFliは、写真が別のバリアントまたはリビジョンを示すのか説明していません。実機のモジュール表示と基板BOMを確認し、本文や写真だけでSKUを判断しないでください。

## 書き込みとデバッグ { #programming-and-debug }

ダウンロードモードでは、電源投入またはリセットの前にModeジャンパーを取り付けます。通常のアプリケーション起動とシリアルログ出力では、ジャンパーを外します。データ通信対応ケーブルでホストをUSB-UART Type-Cポートに接続してください。別のUSB 2.0 FS Type-CポートはネイティブUSBの評価に使用できます。基板には互換デバッガー用の4ピン、2.54 mmピッチ単列SWDヘッダーもあります。どちらのType-Cコネクターからも給電できます。給電方法はボードガイドと該当リビジョンの回路図に従ってください。

## SDKビルドターゲット { #sdk-build-targets }

SiFli-SDKでは、`scons --board=<board_name>`に次の正確なボードターゲット名を指定します。

- `sf32lb56-lcd_a128r12n1`
- `sf32lb56-lcd_n16r12n1`

これらはSDKのビルドターゲット識別子であり、基板やモジュールに印字された製品型番と一致するとは限りません。[Supported Boardsインデックス](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/supported_boards/index.html)とSDKの[`build_config_gcc.yaml`](https://github.com/OpenSiFli/SiFli-SDK/blob/main/build_config_gcc.yaml)では掲載されるターゲットが異なる場合があります。使用中のSDKリビジョンに対応した内容を確認してください。

## 最初の検証手順 { #first-validation-path }

1. 対応する24ビットMIPI-DPIディスプレイを40ピンFPCコネクターに接続し、データ通信対応USBケーブルでUSB-UARTポートを接続します。
2. [はじめに](../../getting-started/index.md) に沿って、ビルド、書き込み、シリアルログの基本動作を確認します。
3. UIフレームワークのデバッグに進む前に、単色などの基本表示を確認します。[グラフィックス概要](../../learn/graphics/overview.md) を参照してください。
4. タッチ、ストレージ、オーディオ、無線機能を1つずつ追加し、他の機能との同時動作と消費電力を確認します。
5. カスタム設計に進む前に、[SF32LB56-MOD](../modules/SF32LB56-MOD.md) と [量産に向けた設計](../../hardware/design-for-production.md) を確認してください。
