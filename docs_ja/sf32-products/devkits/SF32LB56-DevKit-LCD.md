# SF32LB56-DevKit-LCD { #sf32lb56-devkit-lcd }

SF32LB56-DevKit-LCD は、SF32LB56-MOD-N16R12N1 または SF32LB56-MOD-A128R12N1 を搭載できる、ディスプレイ向けの開発ボードです。いずれも SF32LB56xV シリーズデバイスを使用します。カスタムの SF32LB56x ボードを設計する前に、ディスプレイインターフェース、オーディオ、リムーバブルストレージ、周辺機器ドライバーを評価できます。

## 主な用途 { #what-it-is-best-for }

- MIPI-DPI（RGB）、SPI、DSPI、QSPI、または 8 ビット MCU/8080 インターフェースを使用するディスプレイアプリケーション。
- I2C 経由のタッチスクリーン統合。
- アナログマイク入力と、オンボードの Class-D パワーアンプによるアナログ出力を使ったオーディオ実験。
- SDIO/TF カードストレージと一般的なペリフェラルドライバー開発。
- キャリアボードを確定する前の、SF32LB56 モジュールベースの製品アーキテクチャの評価。

**出典の補足（基板リビジョンを確認）：** SiFli の詳細なボードガイドでは、対象の開発ボードに `SF32LB56-MOD-A128R12N1` を搭載し、4 MB + 8 MB のパッケージ内 OPI-PSRAM と 1 Gb QSPI-NAND を備えると記載されています。また、これらのメモリ仕様は正式リリース前に変更される可能性があると明記されています。現行の型番ガイドには N16R12N1 と A128R12N1 の両方が掲載され、どちらも 4 + 8 MB OPI-PSRAM と 1 MB 標準 QSPI-NOR を搭載します。A128R12N1 の 128 MB QSPI-NAND は、詳細ガイドの 1 Gb と容量上同等です。そのため、この型番の OPI-PSRAM と主 NAND の容量に両資料間の矛盾はありません。ただし、詳細ガイドには 1 MB 標準 NOR の記載がなく、すべての個体やリビジョンに同じ SKU が搭載されていることも確認できません。型番ガイドは CH343K に USB-UART デバッグチャネルが 2 系統あるとしていますが、詳細ガイドは Type-C の役割を USB-UART と USB 2.0 FS とだけ説明し、UART チャネルとコネクターの対応を示していません。特定の UART チャネルを使う前に、該当リビジョンの回路図/BOMを確認してください。特定の基板を製品設計の基準にする前に、モジュールの表示と該当する回路図/BOMを確認してください。

**USB-UART ブリッジの型番表記が不一致です（実装部品を要確認）：** 詳細なボードガイドの機能ブロック図では CH342K、型番ガイドでは CH343K と記載されています。実際の部品は該当リビジョンの回路図/BOMで確認してください。

**写真と本文のSKU表記が不一致（搭載モジュールを確認）：** 詳細ガイドの本文では対象ボードに `SF32LB56-MOD-A128R12N1` を搭載するとしていますが、注釈付きの正面写真には `SF32LB56-MOD-N16R12N1` と表示されています。SiFli は、写真が別のバリアントまたはリビジョンを示すのか説明していません。実機のモジュール表示と基板BOMを確認し、本文や写真だけでSKUを判断しないでください。

## 書き込みとデバッグ { #programming-and-debug }

ダウンロードモードでは、電源投入またはリセットの前に Mode ジャンパーを取り付けます。通常のアプリケーション起動とシリアルログ出力では、ジャンパーを外します。データ通信対応ケーブルでホストを USB-UART Type-C ポートに接続してください。別の USB 2.0 FS Type-C ポートはネイティブ USB の評価に使用できます。基板には互換デバッガー用の 4 ピン、2.54 mm ピッチ単列 SWD ヘッダーもあります。どちらの Type-C コネクターからも給電できます。給電方法はボードガイドと該当リビジョンの回路図に従ってください。

## SDK ビルドターゲット { #sdk-build-targets }

SiFli-SDK では、`scons --board=<board_name>` に次の正確なボードターゲット名を指定します。

- `sf32lb56-lcd_a128r12n1`
- `sf32lb56-lcd_n16r12n1`

これらはSDKのビルドターゲット識別子であり、基板やモジュールに印字された製品型番と一致するとは限りません。[Supported Boards インデックス](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/supported_boards/index.html)とSDKの[`build_config_gcc.yaml`](https://github.com/OpenSiFli/SiFli-SDK/blob/main/build_config_gcc.yaml)では掲載されるターゲットが異なる場合があります。使用中のSDKリビジョンに対応した内容を確認してください。

## 最初の検証手順 { #first-validation-path }

1. 対応する 24 ビット MIPI-DPI ディスプレイを 40 ピン FPC コネクターに接続し、データ通信対応 USB ケーブルで USB-UART ポートを接続します。
2. [はじめに](../../getting-started/index.md) に沿って、ビルド、書き込み、シリアルログの基本動作を確認します。
3. UI フレームワークのデバッグに進む前に、単色などの基本表示を確認します。[グラフィックス概要](../../learn/graphics/overview.md) を参照してください。
4. タッチ、ストレージ、オーディオ、無線機能を 1 つずつ追加し、他の機能との同時動作と消費電力を確認します。
5. カスタム設計に進む前に、[SF32LB56-MOD](../modules/SF32LB56-MOD.md) と [量産に向けた設計](../../hardware/design-for-production.md) を確認してください。
