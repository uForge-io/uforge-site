# SF32 ファミリー { #sf32-family }

## はじめに { #introduction }

**SF32** ファミリー、特に **SF32LB5xx** シリーズは、バッテリー駆動の AIoT 機器やウェアラブル機器向けに SiFli が開発した、高集積・超低消費電力の 32 ビットマイクロコントローラー製品群です。

**SF32** は、従来のマイクロコントローラーとアプリケーションプロセッサーの間にあるギャップを埋めることを目指しています。コンパクトな System-in-Package（SiP）に、低消費電力のセンサー処理、無線接続、グラフィックスアクセラレーション、マルチメディア処理、大容量の内蔵メモリを集約しています。スマートウォッチ、フィットネストラッカー、スマートディスプレイ、携帯型医療機器、エッジ処理機能を備えた接続型アクセサリーなどに適しています。

**LB**（Low-Power Bluetooth）シリーズは SF32 ファミリーの最初の製品群です。今後、特定の用途に向けたシリーズの追加も計画されています。

## 主な特徴 { #key-features }

1. **ヘテロジニアスなマルチコアアーキテクチャ**

    SF32LB マイクロコントローラーは、Arm Cortex-M33 STAR-MC1 ベースのヘテロジニアスなマルチコアアーキテクチャを採用しており、高性能なアプリケーション処理と超低消費電力のバックグラウンド動作をバランスさせています。デバイスによっては、Bluetooth 接続、センサー処理、常時稼働のシステム機能を担う専用の低消費電力プロセッサーとともに、1 つ以上のアプリケーションプロセッサーを搭載する構成もあります。

    !!! info "STAR-MC1 プロセッサー"
        STAR-MC1 は Arm China 製の構成可能な Armv8-M Mainline CPU IP であり、対応する SF32 デバイスでは Cortex-M33 クラスのアプリケーションプロセッサーとして使用されています。Cortex-M33 向けのファームウェア、ミドルウェア、RTOS ポート、ツールは、通常のデバイス固有の統合作業を前提に引き続き利用できます。CU、SP、SE の各構成は、主にキャッシュ、TCM、XIPU、TrustZone 対応の点で異なり、Arm Custom Instructions/CDE およびコプロセッサーインターフェースはオプション機能です。SiFli のドキュメントでは、文脈に応じて ***Arm Cortex-M33 STAR-MC1*** または ***Arm Cortex-M33*** のいずれかの表記が使われることがあります。

        構成、TCM、キャッシュ、CDE、コプロセッサー、代表的な性能測定に関するデバイス固有のガイダンスについては、[STAR-MC1 アーキテクチャ詳解](../../learn/architecture/star-mc1.md) を参照してください。


2. **超低消費電力の無線接続**

    SF32LB シリーズは、Bluetooth Low Energy（BLE）またはデュアルモード Bluetooth（BT/BLE）をチップに統合しています。

    対応する Bluetooth モードや RF 性能はデバイスごとに異なります。選定時には、対象型番のデータシートと検証済みリファレンスデザインで、対応モード、送信電力の設定、受信感度、消費電流を確認してください。ファミリー全体の位置付けだけから RF 性能を判断することはできません。

3. **ハードウェアアクセラレーションによるグラフィックス・ディスプレイエンジン**

    すべての SF32LB マイクロコントローラーは、SiFli が自社開発した 2.5D グラフィックスエンジン ePicasso と、独立したディスプレイコントローラーを統合しています。

    ハードウェアアクセラレーションにより、以下のような一般的なグラフィックス処理における CPU 負荷が大幅に軽減されます。

    * アルファブレンディング
    * 画像スケーリング
    * 回転および変形
    * レイヤー合成
    * ユーザーインターフェースの描画

    SF32LB ファミリーで採用されるディスプレイインターフェースおよび表示方式は次のとおりです。対応状況はデバイスごとに異なるため、一覧のすべてに対応すると想定せず、具体的な型番を確認してください。

    * SPI / DSPI / QSPI
    * 8080 MCU インターフェース
    * RGB / DPI
    * MIPI DSI
    * EPD
    * JDI（Memory-in-Pixel ディスプレイ向け）

    対応するディスプレイインターフェースを備えた型番では、LVGL などのグラフィックスフレームワークとハードウェアアクセラレーションを組み合わせることで、TFT、AMOLED、電子ペーパー（EPD）、Memory-in-Pixel（MiP）ディスプレイに滑らかで応答性の高いユーザーインターフェースを表示できます。

4. **エッジ AI とニューラルアクセラレーション**

    一部の SF32 デバイスは、機械学習、マルチメディア処理、センサーフュージョンのワークロード向けに専用のハードウェアアクセラレーターを統合しています。

    デバイスによって、以下の機能を備える場合があります。

    * ニューラルネットワークアクセラレーション
    * オーディオ処理
    * 音声認識
    * カメラインターフェース（DVP および SPI）
    * センサーフュージョンと生体認証アルゴリズム

    これらの機能により、消費電力とクラウドへの依存を抑えながら、デバイス上で低レイテンシの AI 推論を実行できます。

5. **高密度な System-in-Package（SiP）メモリ**

    グラフィックス処理と AI 対応アプリケーションをサポートするため、SF32 デバイスは外部メモリからの高性能な実行に最適化された命令キャッシュおよびデータキャッシュアーキテクチャを統合しています。

    パッケージ内で利用可能なメモリには以下が含まれます。

    * 最大 256 Mb の NOR Flash
    * 最大 512 Mb の PSRAM

    パッケージ内に NOR Flash または PSRAM を搭載するのは一部の型番に限られます。SiP 構成では、基板上に別途実装するメモリ部品や関連配線を減らせる場合があります。一方、メモリの種類、容量、インターフェース、消費電力、パッケージ外部から利用できるピンは型番ごとに異なります。基板を確定する前に、対象型番のデータシートとピン配置を確認してください。

**SF32LB55x の型番別情報：**オーディオインターフェース数は型番によって異なります。SF32LB551/553/555 は PDM と I²S を各 1 系統、SF32LB557VD3A6 は各 2 系統備えます。最新の[SF32LB55x データシート（V1.7.2）](https://downloads.sifli.com/user%20manual/DS5501-SF32LB55x-%E8%8A%AF%E7%89%87%E6%8A%80%E6%9C%AF%E8%A7%84%E6%A0%BC%E4%B9%A6%20V1p7p2.pdf)のパッケージ概要では、BGA169 は GPIO 119 本（HCPU 71 本 + LCPU 48 本）とされています。しかし、同じデータシートの製品系列の詳細表では、SF32LB557 は HCPU 71 本 + LCPU 42 本 = 113 本です。SiFli の現行[チップ型番ガイド](https://wiki.sifli.com/en/silicon/%E8%8A%AF%E7%89%87%E5%9E%8B%E5%8F%B7%E6%8C%87%E5%8D%97.html)も、SF32LB557VD3A6 を 71 + 42 = 113 本としています。データシート内の不一致について SiFli の説明はありません。本表では型番固有の 113 本を採用しています。ピンを割り当てる前に、対象 SKU のデータシートとピン表を確認してください。PDM インターフェース 1 系統には、最大 2 個のデジタルマイクを接続できます。インターフェース数とマイク数は同じではありません。

**SF32LB55x のSiP内蔵NORフラッシュに関する注記：**本表のシリーズ最大値8 MBには、SiFliが別途説明するSS6600A8の構成が含まれます。同モデルは4 MBのQSPI-NORを2個内蔵し、1個の8 MB OSPI-NORとして動作します。本表に記載したSF32から始まる型番のSiP内蔵NORフラッシュは最大4 MBです。選定時には具体的な型番を確認してください。

**SF32LB57x の BGA112 に関する注意：**この注意は BGA112 のみに適用されます。SF32LB57x には内部 MPI1、MPI2、MPI3 があり、型番中の MPI* の位置については [SF32 の命名規則](SF32_namingrule.md)を参照してください。次のいずれかの SiP メモリ構成では、MPI2 と MPI3 の端子をパッケージ外部から利用できず、GPIO は固定の 58 本です。(1) 内部 MPI1 と MPI2 に PSRAM を 1 個ずつ内蔵する構成、(2) 内部 MPI2 に 256 Mb の PSRAM を 1 個内蔵する構成、または (3) 内部 MPI3 に NOR Flash を 1 個内蔵する構成です。`SF32LB57GVD776` は (3) に該当し、末尾コード `776` の 2 つ目の `7` は内部デバイスが MPI3 を使用することを示すため、GPIO は 58 本です。それ以外の BGA112 構成では、追加の 6 本を MPI3 に使用するか、プルアップまたはプルダウンで設定した GP 静的出力として使用できます。ただし、自由に割り当てられる GPIO ではありません。たとえば、`SF32LB57ZVN7N6` の `58 + 6` は、使用可能な GPIO 58 本に加え、MPI3 または静的出力に使用できる端子が 6 本あることを示します。QFN68 と QFN80 はこの BGA112 の制約の対象外で、表示された GPIO 数のみを備え、MPI3/静的出力用の追加端子はありません。型番ごとの詳細は SF32LB57x 製品ページとデータシートを確認してください。

**SF32LB58x の GPIO 数に関する補足：**[DS5801 V1.8.3 データシート](https://downloads.sifli.com/user%20manual/DS5801-SF32LB58x-%E8%8A%AF%E7%89%87%E6%8A%80%E6%9C%AF%E8%A7%84%E6%A0%BC%E4%B9%A6%20V1p8p3.pdf)と SiFli のファミリー比較資料では、GPIO の合計を 154 本（HPSYS: 94、LPSYS: 60）としています。一方、別の [チップ型番ガイド](https://wiki.sifli.com/en/silicon/%E8%8A%AF%E7%89%87%E5%9E%8B%E5%8F%B7%E6%8C%87%E5%8D%97.html)では HCPU: 94、LCPU: 66 と記載されており、合計 160 本となってデータシートと一致しません。本比較表ではデータシートの合計値を採用しています。ピンを割り当てる前に、対象 SKU のパッケージ別ピン表で使用可能な端子を確認してください。

## 適切な SF32 を選ぶ { #choosing-the-right-sf32 }

SF32LB5xx ファミリーは、コスト重視の Bluetooth 製品から高度なグラフィックスや AI 機能を備えたシステムまで、バッテリー駆動の接続機器を幅広くカバーします。各製品は SDK の基盤を共有していますが、プロセッサー構成、周辺機能、メモリマップ、パッケージ、ピン配置は異なる場合があります。移植時には起動コード、ドライバー、リンカースクリプトやパーティション設定、ピン多重化、SDK 設定の変更が必要になることがあるため、対象デバイスで検証してください。

デバイスを選定する際は、以下の主要な要件を考慮してください。

* Bluetooth 接続（BLE またはデュアルモード BT/BLE）
* ディスプレイインターフェースと解像度
* オーディオおよびマルチメディア機能
* メモリ容量
* GPIO の要件
* グラフィックス性能
* AI およびセンサー処理の要件
* 消費電力の目標値

## ファミリー内のソフトウェア互換性 { #software-compatibility-across-the-family }

SF32 プラットフォームはソフトウェアと SDK の基盤を共有しています。ただし、プロセッサー構成、周辺機能、メモリマップ、パッケージ、ピン配置は製品ごとに異なる場合があります。移植時には起動コード、ドライバー、リンカースクリプトやパーティション設定、ピン多重化、SDK 設定の変更が必要になることがあるため、対象ハードウェアで検証してください。

ソフトウェアの再利用性と移植・検証に必要な工数も、性能、メモリ、ディスプレイ、接続性の要件とあわせて評価してください。同じファミリーに属するという理由だけで、ピン互換またはファームウェア無変更で動作すると想定しないでください。
