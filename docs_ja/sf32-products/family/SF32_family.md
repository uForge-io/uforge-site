# SF32ファミリー { #sf32-family }

## はじめに { #introduction }

**SF32** ファミリー、特に **SF32LB5xx** シリーズは、バッテリー駆動のAIoT機器やウェアラブル機器向けにSiFliが開発した、高集積・超低消費電力の32ビットマイクロコントローラー製品群です。

**SF32** は、従来のマイクロコントローラーとアプリケーションプロセッサーの間にあるギャップを埋めることを目指しています。コンパクトなSystem-in-Package（SiP）に、低消費電力のセンサー処理、無線接続、グラフィックスアクセラレーション、マルチメディア処理、大容量の内蔵メモリーを集約しています。スマートウォッチ、フィットネストラッカー、スマートディスプレイ、携帯型医療機器、エッジ処理機能を備えた接続型アクセサリーなどに適しています。

**LB**（Low-Power Bluetooth）シリーズはSF32ファミリーの最初の製品群です。今後、特定の用途に向けたシリーズの追加も計画されています。

## 主な特徴 { #key-features }

1. **ヘテロジニアスなマルチコアアーキテクチャ**

    SF32LBマイクロコントローラーは、Arm Cortex-M33 STAR-MC1ベースのヘテロジニアスなマルチコアアーキテクチャを採用しており、高性能なアプリケーション処理と超低消費電力のバックグラウンド動作をバランスさせています。デバイスによっては、Bluetooth接続、センサー処理、常時稼働のシステム機能を担う専用の低消費電力プロセッサーとともに、1つ以上のアプリケーションプロセッサーを搭載する構成もあります。

    !!! info "STAR-MC1プロセッサー"
        STAR-MC1はArm China製の構成可能なArmv8-M Mainline CPU IPであり、対応するSF32デバイスではCortex-M33クラスのアプリケーションプロセッサーとして使用されています。Cortex-M33向けのファームウェア、ミドルウェア、RTOSポート、ツールは、通常のデバイス固有の統合作業を前提に引き続き利用できます。CU、SP、SEの各構成は、主にキャッシュ、TCM、XIPU、TrustZone対応の点で異なり、Arm Custom Instructions/CDEおよびコプロセッサーインターフェースはオプション機能です。SiFliのドキュメントでは、文脈に応じて ***Arm Cortex-M33 STAR-MC1*** または ***Arm Cortex-M33*** のいずれかの表記が使われることがあります。

        構成、TCM、キャッシュ、CDE、コプロセッサー、代表的な性能測定に関するデバイス固有のガイダンスについては、[STAR-MC1アーキテクチャ詳解](../../learn/architecture/star-mc1.md) を参照してください。


2. **超低消費電力の無線接続**

    SF32LBシリーズは、Bluetooth Low Energy（BLE）またはデュアルモードBluetooth（BT/BLE）をチップに統合しています。

    対応するBluetoothモードやRF性能はデバイスごとに異なります。選定時には、対象型番のデータシートと検証済みリファレンスデザインで、対応モード、送信電力の設定、受信感度、消費電流を確認してください。ファミリー全体の位置付けだけからRF性能を判断することはできません。

3. **ハードウェアアクセラレーションによるグラフィックス・ディスプレイエンジン**

    すべてのSF32LBマイクロコントローラーは、SiFliが自社開発した2.5DグラフィックスエンジンePicassoと、独立したディスプレイコントローラーを統合しています。

    ハードウェアアクセラレーションにより、以下のような一般的なグラフィックス処理におけるCPU負荷が大幅に軽減されます。

    * アルファブレンディング
    * 画像スケーリング
    * 回転および変形
    * レイヤー合成
    * ユーザーインターフェースの描画

    SF32LBファミリーで採用されるディスプレイインターフェースおよび表示方式は次のとおりです。対応状況はデバイスごとに異なるため、一覧のすべてに対応すると想定せず、具体的な型番を確認してください。

    * SPI / DSPI / QSPI
    * 8080 MCUインターフェース
    * RGB / DPI
    * MIPI DSI
    * EPD
    * JDI（Memory-in-Pixelディスプレイ向け）

    対応するディスプレイインターフェースを備えた型番では、LVGLなどのグラフィックスフレームワークとハードウェアアクセラレーションを組み合わせることで、TFT、AMOLED、電子ペーパー（EPD）、Memory-in-Pixel（MiP）ディスプレイに滑らかで応答性の高いユーザーインターフェースを表示できます。

4. **エッジAIとニューラルアクセラレーション**

    一部のSF32デバイスは、機械学習、マルチメディア処理、センサーフュージョンのワークロード向けに専用のハードウェアアクセラレーターを統合しています。

    デバイスによって、以下の機能を備える場合があります。

    * ニューラルネットワークアクセラレーション
    * オーディオ処理
    * 音声認識
    * カメラインターフェース（DVPおよびSPI）
    * センサーフュージョンと生体認証アルゴリズム

    これらの機能により、消費電力とクラウドへの依存を抑えながら、デバイス上で低レイテンシのAI推論を実行できます。

5. **高密度なSystem-in-Package（SiP）メモリー**

    グラフィックス処理とAI対応アプリケーションをサポートするため、SF32デバイスは外部メモリーからの高性能な実行に最適化された命令キャッシュおよびデータキャッシュアーキテクチャを統合しています。

    パッケージ内で利用可能なメモリーには以下が含まれます。

    * 最大256 MbのNOR Flash
    * 最大512 MbのPSRAM

    パッケージ内にNOR FlashまたはPSRAMを搭載するのは一部の型番に限られます。SiP構成では、基板上に別途実装するメモリー部品や関連配線を減らせる場合があります。一方、メモリーの種類、容量、インターフェース、消費電力、パッケージ外部から利用できるピンは型番ごとに異なります。基板を確定する前に、対象型番のデータシートとピン配置を確認してください。

**SF32LB55xの型番別情報：**オーディオインターフェース数は型番によって異なります。SF32LB551/553/555はPDMとI²Sを各1系統、SF32LB557VD3A6は各2系統備えます。最新の[SF32LB55xデータシート（V1.7.2）](https://downloads.sifli.com/user%20manual/DS5501-SF32LB55x-%E8%8A%AF%E7%89%87%E6%8A%80%E6%9C%AF%E8%A7%84%E6%A0%BC%E4%B9%A6%20V1p7p2.pdf)のパッケージ概要では、BGA169はGPIO 119本（HCPU 71本 + LCPU 48本）とされています。しかし、同じデータシートの製品系列の詳細表では、SF32LB557はHCPU 71本 + LCPU 42本 = 113本です。SiFliの現行[チップ型番ガイド](https://wiki.sifli.com/en/silicon/%E8%8A%AF%E7%89%87%E5%9E%8B%E5%8F%B7%E6%8C%87%E5%8D%97.html)も、SF32LB557VD3A6を71 + 42 = 113本としています。データシート内の不一致についてSiFliの説明はありません。本表では型番固有の113本を採用しています。ピンを割り当てる前に、対象SKUのデータシートとピン表を確認してください。PDMインターフェース1系統には、最大2個のデジタルマイクを接続できます。インターフェース数とマイク数は同じではありません。

**SF32LB55xのSiP内蔵NORフラッシュに関する注記：**本表のシリーズ最大値8 MBには、SiFliが別途説明するSS6600A8の構成が含まれます。同モデルは4 MBのQSPI-NORを2個内蔵し、1個の8 MB OSPI-NORとして動作します。本表に記載したSF32から始まる型番のSiP内蔵NORフラッシュは最大4 MBです。選定時には具体的な型番を確認してください。

**SF32LB57xのBGA112に関する注意：**この注意はBGA112のみに適用されます。SF32LB57xには内部MPI1、MPI2、MPI3があり、型番中のMPI* の位置については [SF32の命名規則](SF32_namingrule.md)を参照してください。次のいずれかのSiPメモリー構成では、MPI2とMPI3の端子をパッケージ外部から利用できず、GPIOは固定の58本です。(1) 内部MPI1とMPI2にPSRAMを1個ずつ内蔵する構成、(2) 内部MPI2に256 MbのPSRAMを1個内蔵する構成、または (3) 内部MPI3にNOR Flashを1個内蔵する構成です。`SF32LB57GVD776`は (3) に該当し、末尾コード`776`の2つ目の`7`は内部デバイスがMPI3を使用することを示すため、GPIOは58本です。それ以外のBGA112構成では、追加の6本をMPI3に使用するか、プルアップまたはプルダウンで設定したGP静的出力として使用できます。ただし、自由に割り当てられるGPIOではありません。たとえば、`SF32LB57ZVN7N6`の`58 + 6`は、使用可能なGPIO 58本に加え、MPI3または静的出力に使用できる端子が6本あることを示します。QFN68とQFN80はこのBGA112の制約の対象外で、表示されたGPIO数のみを備え、MPI3/静的出力用の追加端子はありません。型番ごとの詳細は SF32LB57x製品ページとデータシートを確認してください。

**SF32LB58xのGPIO数に関する補足：**[DS5801 V1.8.3データシート](https://downloads.sifli.com/user%20manual/DS5801-SF32LB58x-%E8%8A%AF%E7%89%87%E6%8A%80%E6%9C%AF%E8%A7%84%E6%A0%BC%E4%B9%A6%20V1p8p3.pdf)とSiFliのファミリー比較資料では、GPIOの合計を154本（HPSYS: 94、LPSYS: 60）としています。一方、別の [チップ型番ガイド](https://wiki.sifli.com/en/silicon/%E8%8A%AF%E7%89%87%E5%9E%8B%E5%8F%B7%E6%8C%87%E5%8D%97.html)ではHCPU: 94、LCPU: 66と記載されており、合計160本となってデータシートと一致しません。本比較表ではデータシートの合計値を採用しています。ピンを割り当てる前に、対象SKUのパッケージ別ピン表で使用可能な端子を確認してください。

## 適切なSF32を選ぶ { #choosing-the-right-sf32 }

SF32LB5xxファミリーは、コスト重視のBluetooth製品から高度なグラフィックスやAI機能を備えたシステムまで、バッテリー駆動の接続機器を幅広くカバーします。各製品はSDKの基盤を共有していますが、プロセッサー構成、周辺機能、メモリーマップ、パッケージ、ピン配置は異なる場合があります。移植時には起動コード、ドライバー、リンカースクリプトやパーティション設定、ピン多重化、SDK設定の変更が必要になることがあるため、対象デバイスで検証してください。

デバイスを選定する際は、以下の主要な要件を考慮してください。

* Bluetooth接続（BLEまたはデュアルモードBT/BLE）
* ディスプレイインターフェースと解像度
* オーディオおよびマルチメディア機能
* メモリー容量
* GPIOの要件
* グラフィックス性能
* AIおよびセンサー処理の要件
* 消費電力の目標値

## ファミリー内のソフトウェア互換性 { #software-compatibility-across-the-family }

SF32プラットフォームはソフトウェアとSDKの基盤を共有しています。ただし、プロセッサー構成、周辺機能、メモリーマップ、パッケージ、ピン配置は製品ごとに異なる場合があります。移植時には起動コード、ドライバー、リンカースクリプトやパーティション設定、ピン多重化、SDK設定の変更が必要になることがあるため、対象ハードウェアで検証してください。

ソフトウェアの再利用性と移植・検証に必要な工数も、性能、メモリー、ディスプレイ、接続性の要件とあわせて評価してください。同じファミリーに属するという理由だけで、ピン互換またはファームウェア無変更で動作すると想定しないでください。
