# SF32命名規則 { #sf32-naming-convention }

## チップの命名 { #chip-naming }

### 型番：***SF32LB5xyZxYx6*** { #part-number-sf32lb5xyzxyx6 }

!!! note "表記に関する注意"
    * 小文字の ***x*** は数字を表します。
    * 大文字の ***Y*** または ***Z*** はアルファベット文字を表します。

### プレフィックス: *SF32LB5xy* { #prefix-sf32lb5xy }

- **SF32** — SiFli 32ビットMCUシリーズ
- **LB** — 製品ライン識別子
    - **LB**: 低消費電力Bluetooth MCUシリーズ
- **5** — プロセッサーファミリー
    - **5**: 32ビットArm Cortex-M33 STAR-MC1プロセッサー、または同等の性能を持つRISC-Vプロセッサーを搭載したデバイス
- **x** — 製品グレード
    - **8 / 7**: アプリケーションプロセッサー2基、低消費電力プロセッサー1基の構成（製品の位置付けはシリーズによって異なります）
    - **6 / 5**: ミッドレンジ（アプリケーションプロセッサー1基、低消費電力プロセッサー1基）
    - **2**: 低コスト向け（アプリケーションプロセッサー1基、専用の低消費電力Bluetoothコントローラー）
- **y** — デバイスバリアント
    - 値は通常、パッケージ内のPSRAM容量を反映します。具体的な対応関係は製品サブファミリーによって異なります。

### サフィックス: *ZxYx6* { #suffix-zxyx6 }
- **Z** — パッケージタイプ
    - **U**: QFN68
    - **V**: BGA
    - **Y**: QFN80
- **xYx** — 統合メモリー構成（QSPI-NOR FlashとPSRAM）
  *（注：エンコーディングの対応関係は、パッケージとデバイスファミリーによって異なります。）*

`ZxYx6`はファミリー共通の表記例であり、固定長の解析テンプレートではありません。メモリーコードの数と順序はデバイスファミリーおよびパッケージによって異なります。数値のFlashコードが含まれない場合や、複数のデバイスを内蔵する場合にPSRAMのアルファベットコードが繰り返される場合があります。具体的な型番は、該当ファミリーのバリアント表で確認してください。
<div align="center"><em>型番サフィックスの各フィールド</em></div>

<div align="center" markdown>

| フィールド | 種類 | 選択肢 | 説明 |
| :--- | :--- | :--- | :--- |
| **x** | 数字 | **1**～**6** | 汎用のQSPI-NOR Flash容量コード:<br>• **1**: 2 Mb<br>• **2**: 4 Mb<br>• **3**: 8 Mb<br>• **4**: 16 Mb<br>• **5**: 32 Mb<br>• **6**: 64 Mb<br>SF32LB57xでは **7** と **8** も使用します。下記のファミリー固有の対応表を参照してください。 |
| **Y** | アルファベット | **A**～**E** | 統合PSRAM容量とインターフェース:<br>• **A**: 16 Mb QPI-PSRAM<br>• **B**: 32 Mb OPI-PSRAM<br>• **C**: 64 Mb OPI-PSRAM<br>• **D**: 128 Mb OPI/HPI-PSRAM<br>• **E**: 256 Mb HPI-PSRAM |

</div>

- **6** — 動作温度グレード
    - **5**: −20 °C～+70 °C（商用グレード）
    - **6**: −40 °C～+85 °C（産業用グレード）

### SF32LB57x固有のメモリーコード { #sf32lb57x-memory-codes }

SF32LB57xハードウェア設計ガイドの[型番規則図](../../hardware/chip-guides/SF32LB57x_hardware_design_guide.md#33-packages)では、パッケージコードの後にMPI1、MPI2、MPI3の順で3つのメモリー位置コードが並び、その後に温度グレードが続きます。各MPI位置で使用されるファミリー固有コードは次のとおりです。

<div align="center"><em>表: SF32LB57xのMPI位置別メモリーコード</em></div>

<div align="center" markdown>

| コード | 対応するMPI位置でのSF32LB57xの意味 |
|:-----|:--------------------------------------|
| `N` | パッケージ内蔵メモリーなし |
| `B` | 32 Mb PSRAM |
| `C` | 64 Mb PSRAM |
| `D` | 128 Mb PSRAM |
| `E` | 256 Mb PSRAM |
| `2` | 4 Mb NOR Flash |
| `3` | 8 Mb NOR Flash |
| `4` | 16 Mb NOR Flash |
| `5` | 32 Mb NOR Flash |
| `6` | 64 Mb NOR Flash |
| `7` | 128 Mb NOR Flash |
| `8` | 256 Mb NOR Flash |

</div>

この対応表はSF32LB57x専用です。すべての組み合わせが注文可能とは限らないため、完全な型番は該当するバリアント表で確認してください。

### 型番の例 { #part-number-examples }

#### 例1: SF32LB527UD6 { #example-1-sf32lb527ud6 }
**SF32LB52シリーズ**の低コスト向けMCU構成:

* **プロセッサー構成:** アプリケーションプロセッサー1基と、専用の低消費電力Bluetoothコントローラープロセッサー1基（Arm Cortex-M33 STAR-MC1ベース）。
* **パッケージタイプ:** QFN68パッケージ（**U**）。
* **メモリー構成:** 128 Mb OPI-PSRAMを統合（**D**）。
* **動作温度:** −40 °C～+85 °C（**6**、産業用グレード）。

#### 例2: SF32LB587VEE56 { #example-2-sf32lb587vee56 }
**SF32LB58シリーズ**のフラッグシップMCU構成:

* **プロセッサー構成:** アプリケーションプロセッサー2基と低消費電力プロセッサー1基（Arm Cortex-M33 STAR-MC1ベース）。
* **パッケージタイプ:** BGA256パッケージ（**V**）。
* **メモリー構成:** 256 Mb HPI-PSRAMを2個統合（**E**）、および32 Mb QSPI-NOR Flashを1個搭載（**5**）。
* **動作温度:** −40 °C～+85 °C（**6**、産業用グレード）。

#### 例3: SF32LB57GVD776 { #example-3-sf32lb57gvd776 }

SF32LB57xのバリアント表では、この型番はBGA112とされています。3つのメモリー位置コードは`D/7/7`で、MPI1に128 Mb PSRAM、MPI2とMPI3にそれぞれ128 Mb NOR Flashを内蔵しています。末尾の`6`は産業用温度グレードです。したがって、`776`の2つ目の`7`はMPI3のNOR Flashを示します。BGA112のGPIOの意味は [SF32ファミリーの概要](SF32_family.md)を参照してください。

#### 例4: SF32LB57ZVN7N6 { #example-4-sf32lb57zvn7n6 }

SF32LB57xのバリアント表では、この型番もBGA112とされています。メモリー位置コードは`N/7/N`で、MPI1にはパッケージ内蔵メモリーがなく、MPI2に128 Mb NOR Flash、MPI3にはパッケージ内蔵メモリーがありません。末尾の`6`は産業用温度グレードです。`58 + 6`が64本の自由に割り当てられるGPIOを意味するわけではない点は、SF32ファミリーの概要で説明しています。

### 55x系列の旧形式サフィックス例外 { #legacy-55x-suffix-exceptions }

SF32LB55x系列は現行の命名規則より前に定義されたため、一部の型番では旧形式のサフィックスが使われています。次の3つの型番は、上記の`SF32LB5xyZxYx6`形式だけでは全フィールドを解読できません: `SF32LB551U4O5`、`SF32LB555V4O6`、`SF32LB555V436`。パッケージとメモリー構成は、該当する55xの型番一覧とデータシートで確認し、一般形式からフィールドを推測しないでください。一方、`SF32LB557VD3A6`は現行の命名規則に準拠しており、旧形式の例外ではありません。

## モジュールの命名 { #module-naming }

### 型番：***SF32LB5x-MOD-y-AaaaBbbbCccc*** { #part-number-sf32lb5x-mod-y-aaaabbbbcccc }

!!! note "表記に関する注意"
    * 一般的なサフィックスにおいて、`A`、`B`、`C`は3つのストレージフィールドの位置を表します。これらの文字が、すべてのモジュール名に実際に含まれるとは限りません。
    * 各フィールドの先頭の文字はストレージの種類を識別します。残りの数字はその容量または構成を識別します。
    * `-y`サブタイプフィールドは現在、SF32LB52モジュールファミリーでのみ使用されています。公開されているSF32LB56-MODおよびSF32LB58-MODの名前ではこれを使用していません。

### プレフィックス: *SF32LB5x-MOD-y* { #prefix-sf32lb5x-mod-y }

- **SF32LB5x** — モジュールMCUファミリー
    - **SF32**、**LB**、**5** は、上記のチップ命名規則と同じシリーズ、製品ライン、プロセッサーファミリーの意味を持ちます。
    - **x** は製品グレードを示します: **8 / 7** はアプリケーションプロセッサー2基と低消費電力プロセッサー1基の構成で、製品の位置付けはシリーズによって異なります。**6 / 5** はミッドレンジ、**2** は低コスト向けです。
- **MOD** — SiFliモジュール製品。
- **y** — モジュールのサブタイプ(ファミリーで定義されている場合)
    - **1**: SF32LB520/3/5/7向けのリチウムイオン電池直結動作。チップの電源電圧範囲は3.2～4.7 Vです。標準構成では、8 MB OPI-PSRAMを搭載したSF32LB525UC6を使用します。
    - **A**: SF32LB52B向けの通常の3.3 V電源での動作。リチウムイオン電池からの直接給電には対応せず、チップの電源電圧範囲は2.97～3.63 Vです。標準構成では、1 MB QSPI-NOR Flashを内蔵したSF32LB52BU36を使用します。
    - **B**: 52E/52G/52J向けの通常の3.3 V電源での動作。リチウムイオン電池からの直接給電には対応せず、チップの電源電圧範囲は2.97～3.63 Vです。標準構成では、4 MB OPI-PSRAMを内蔵したSF32LB52EUB6を使用します。

`-A`モジュールは外部NOR Flashデバイスを搭載していません。外部NOR Flash、またはWi-Fi、SD-NAND、4ビットモードのeMMCを含むSDIOペリフェラルを接続できます。

### サフィックス: *AaaaBbbbCccc* { #suffix-aaaabbbbcccc }

<div align="center"><em>モジュール型番サフィックスフィールドの定義</em></div>

<div align="center" markdown>

| フィールド | ストレージタイプコード | 容量、構成、サフィックス |
| :--- | :--- | :--- |
| `Aaaa`<br>可変Flash構成 | `N`: QSPI-NOR Flash<br>`A`: NAND Flash（インターフェースはモジュールファミリーによって異なる）<br>`D`: SD-NAND Flash<br>`E`: eMMC | `N16`: 16 MB QSPI-NOR Flash<br>`A128`: SF32LB52-MOD-1は128 MB SPI-NAND、SF32LB56-MODとSF32LB58-MODは128 MB QSPI-NAND<br>`D128`: SF32LB56-MODの128 MB SD-NAND<br>`E4`: SF32LB58-MODの4 GB eMMC |
| `Bbbb`<br>PSRAM | `R`: PSRAM | `R4`: 4 MB OPI-PSRAM<br>`R8`: 8 MB OPI-PSRAM<br>`R12`: 4 MB + 8 MB OPI-PSRAM<br>`R16`: 16 MB OPI/HPI-PSRAM<br>`R32`: 16 MB + 16 MB HPI-PSRAM<br>`R64`: 32 MB + 32 MB HPI-PSRAM |
| `Cccc`<br>標準Flash | `N`: QSPI-NOR Flash | `N1`: 1 MB QSPI-NOR Flash<br>`N4`: 4 MB QSPI-NOR Flash |

</div>

3つのサフィックスフィールドは区切り文字なしで連結されます。`Aaaa`は可変Flash構成、`Bbbb`はPSRAM、`Cccc`は標準Flashの構成を表します。ここに示すのはガイドで定義されている種別と容量の組み合わせです。任意の種別コードと容量コードを組み合わせられるわけではありません。各フィールドは、該当するモジュール構成で使われる場合にのみ型番に含まれます。

### 型番の例 { #part-number-examples_1 }

#### 例1: SF32LB52-MOD-1-N16R8 { #example-1-sf32lb52-mod-1-n16r8 }

**リチウムイオン電池から直接給電するSF32LB52モジュール構成:**

* **モジュールサブタイプ:** `-1`はリチウムイオン電池からの直接給電に対応します。チップの電源電圧範囲は3.2～4.7 Vです。
* **可変Flash構成:** `N16`は16 MB QSPI-NOR Flashを示します。
* **PSRAM:** `R8`は8 MB OPI-PSRAMを示します。

#### 例2: SF32LB58-MOD-A128R32N1 { #example-2-sf32lb58-mod-a128r32n1 }

**SF32LB58フラッグシップモジュール構成:**

* **モジュールサブタイプ:** 公開されているSF32LB58-MODの名前には`-y`サブタイプは使用されていません。
* **可変Flash構成:** このSF32LB58-MOD構成では、`A128`は128 MB QSPI-NAND Flashを示します。
* **PSRAM:** `R32`は16 MB + 16 MB HPI-PSRAMを示します。
* **標準Flash:** `N1`は1 MB QSPI-NOR Flashを示します。

この命名パターンは構成を表すものであり、すべてのコードの組み合わせがリリース済みのSKUであることを保証するものではありません。SiFliのガイドでは、SF32LB56-MODおよびSF32LB58-MODファミリーの標準MCU構成として、それぞれSF32LB566VCB36とSF32LB586VDD36が挙げられています。これら以外のモジュール構成はカスタマイズされる場合があります。入手可能性、搭載されるMCU、ピン配置、電気的仕様については、該当するモジュールのドキュメントで確認してください。
