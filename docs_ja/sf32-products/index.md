# SF32 製品 { #sf32-products }

## このセクションで扱う内容 { #what-this-section-covers }

利用可能なファミリーと主な機能差を把握するには、まず [SF32 ファミリー概要](family/SF32_family.md) をご覧ください。候補のファミリーとパッケージを絞り込んだら、[命名規則](family/SF32_namingrule.md) に沿って完全な型番を確認できます。

電源構成、パッケージ、ディスプレイ、オーディオ、メモリ、GPIO、接続機能、専用ハードウェアなどの要件から候補を選ぶ場合は、[SF32 製品セレクター](product-selector.md) をご利用ください。このツールでできるのは候補の絞り込みまでです。最終的な型番、パッケージ、電気的仕様、基板上の配線は、該当する SiFli の資料で必ず確認してください。

採用する方向が決まったら、[リファレンスデザイン](../hardware/reference-designs/reference-designs.md) と [量産に向けた設計](../hardware/design-for-production.md) に進んでください。デバイス選定から、リファレンス基板、設計ガイド、CAD ライブラリ、BOM の検討、設計レビュー用チェックリスト、初期動作確認の記録まで確認できます。

## ハードウェアから探す { #browse-hardware-directly }

必要なハードウェアの種類が決まっている場合は、該当する一覧へ直接進んでください。

- [チップ](family/SF32_family.md): デバイスファミリーと製品選定に関する情報。
- [モジュール](modules/SF32LB52-MOD-1.md): RF 部と主要回路を実装済みのモジュールを使ったキャリア基板の設計に役立ちます。
- [開発ボード](devkits/SF32LB52-DevKit-LCD.md): ソフトウェアや周辺機能の検証に利用できる対応済みハードウェアです。

ハードウェアの設計・実装についてはこのセクションをご覧ください。SDK のセットアップ、サンプル、ツールチェーン、ソフトウェアプラットフォームの対応状況については、[開発](../develop/index.md) に進んでください。
