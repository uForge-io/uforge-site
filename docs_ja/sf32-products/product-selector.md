# SF32製品選定ツール { #sf32-product-selector }

回路図の作成に着手する前に、SF32チップとモジュールの候補を絞り込みましょう。後から変更するとコストがかさむ電源アーキテクチャ、パッケージ、ディスプレイ、オーディオ、メモリー、GPIO、接続性、ソフトウェアの検証手順を先に確認し、残った候補を比較してください。

まずはインタラクティブな選定ツールを使用してください。掲載対象はチップとモジュールのみです。統合レベル、PSRAMとGPIOの容量、パッケージ、主電源、ディスプレイインターフェースと目標解像度、SDIO数、オーディオインターフェース数、専用ハードウェア機能で絞り込めます。各候補から製品紹介ページを開けます。開発ボードは選定対象ではなく、ソフトウェアやシステムの前提を検証するための別の手段です。

## 製品選定ツール { #product-selector }

!!! info "用語とオーディオインターフェース数"
    略語やインターフェース用語は[用語集](../about/glossary.md)を参照してください。1つのPDMインターフェースには、デジタルマイクを最大2つ接続できます。そのため、PDMインターフェース数はマイク数を表すものではありません。実際に使用できるマイク入力数とピンの割り当てはデバイスによって異なるため、対象部品のドキュメントで確認してください。

有効にした条件はすべて同時に適用され、結果には全条件を満たす候補だけが表示されます。統合レベル、パッケージ、電源、ディスプレイは単一選択です。PSRAM容量とGPIO数の選択値はアプリケーション側の必要量を表すため、候補部品はその値以上の能力が必要です。ここでいう「最大必要量」はアプリケーション側の最大要求を指し、部品側の上限ではありません。目標解像度、SDIO数、各オーディオインターフェース数も下限値で絞り込みます。機能チェックボックスでは、必要な機能（SDIO経由の外部Wi-Fi、DCMIカメラインターフェース、AI/MLアクセラレーター、FreeIO、PTM）を指定します。SDIO数のフィルターと外部Wi-Fiのチェックボックスは別の条件です。

<div id="uf-product-selector"></div>

<noscript>
このツールは部品テーブルの絞り込みと表示にJavaScriptを必要とします。JavaScriptが無効な場合は、代わりに [SF32ファミリー比較表](family/SF32_family.md) を利用してください。
</noscript>

結果表には、正確な型番とパッケージ、メモリー容量、最大GPIO数、電源とI/O電圧、ディスプレイ機能、オーディオインターフェース数（DAC/ADC/PDM/I2S）、デジタルペリフェラルのインターフェース／チャネル数（UART/I2C/SPI/CAN/GPADC）、USB速度、カタログ上の機能フラグが表示されます。数量や値が`n/a`の場合、カタログの粒度では明確な情報が記載されていないことを示し、ゼロや非対応を意味するものではありません。機能欄のダッシュは、その能力がカタログのレコードに記載されていないことを示します。対象部品のドキュメントで確認してください。ディスプレイインターフェース一覧は選定用であり、ピン多重化の全機能を示すものではありません。

## 選定時に確認するポイント { #selection-factors }

このツールは必須条件で候補を絞り込むためのもので、自動で最適な製品を推奨するものではありません。まず、見落とすと後から基板や回路図の再設計が必要になる条件を確認し、残りの条件で候補を比較してください。

### 統合レベル { #integration-level }

スケジュール、RF設計の担当範囲、基板の設計責任がすでに決まっている場合は、詳細な仕様を比較する前に統合レベルを選んでください。チップは設計の自由度が最も高い一方、電源、RF、クロック、レイアウトから量産対応までを自ら設計する必要があります。モジュールを使うと、モジュールレベルの設計・統合作業を減らせますが、キャリア基板は引き続き設計する必要があります。開発ボードなら、ファームウェアやペリフェラルの動作、システム設計上の前提をすばやく検証できます。ただし、そのまま量産用ハードウェアに使えるとは限りません。

### 電源とパッケージ { #power-supply-and-package }

供給方式とパッケージは早い段階で選定してください。セレクターは、Li-ionバッテリー直結（3.2～4.7 V）、外部レギュレーターによる3.3 V給電が明記された製品、主電源を約1.8 Vまで下げられる製品（仕様によっては下限が1.71 V）を区別します。これらは主電源の選択肢であり、GPIOのI/O電圧ではありません。I/O電圧は結果表に別項目で表示されますが、ここに示すのは公称レベルであり、保証される動作範囲ではありません。対象部品の電気的仕様を確認してください。パッケージの選択も設計上の重要事項であり、基板面積、ファンアウト配線の難易度、放熱経路、使用可能なピン数を左右します。パッケージフィルターは大まかな分類なので、結果表で正確なパッケージ型番を確認してください。公称GPIO最大数が大きいパッケージでも、電源、クロック、デバッグ、ディスプレイ、メモリー、必須ペリフェラル用のピンを確保した後では不足する場合があります。

### メモリーとGPIOの余裕 { #memory-and-gpio-headroom }

PSRAMとGPIOのフィルターは最低限のしきい値として使用し、選択した製品カテゴリのメモリー構成とピン割り当てを確認してください。PSRAM容量はグラフィックスバッファ、オーディオバッファリング、MLモデル、アプリケーションの作業領域に影響しますが、総容量だけでは連続した1つのメモリープールが保証されるわけではありません。GPIOの余裕には、最初のプロトタイプで使うインターフェースだけでなく、量産テスト、デバッグ、割り込み、将来のセンサー、ボード制御信号も含めて考慮してください。

### ディスプレイとグラフィックス { #display-and-graphics }

実際に使用するパネルが必要とするディスプレイインターフェースで候補を絞り込み、目標解像度は初期の容量確認に使ってください。選択肢の幅×高さは総画素数のしきい値であり、正確なアスペクト比やパネルタイミングを確認するものではありません。結果表に示す解像度は、カタログでの初期選定に使う目安であり、特定パネルの動作モードを保証するものでも、すべての型番の仕様上限を示すものでもありません。対象部品とパネルの要件をSiFliの資料で確認してください。セレクターでは、基板設計で一般的な略称RGBをパラレル表示インターフェースの表記に使っています。正式名称はDPI（Display Pixel Interface）です。表示インターフェース一覧はピン多重化の全機能を示すものではありません。対象部品のドキュメントで実際のインターフェースモードを確認し、メモリー予算、ピン配線、パネルの電源シーケンス、ソフトウェアドライバーの対応状況も併せて確認してください。

### オーディオインターフェース { #audio-interfaces }

セレクターには、オーディオDAC、ADC、PDMインターフェース、I2Sインターフェースの独立した最小数フィルターがあります。各値は下限であり、4種類を組み合わせた固定のオーディオプロファイルではありません。選定後は、他のペリフェラルとの共用やボードレベルのアナログ設計も確認してください。

### 接続性と専用ハードウェア { #connectivity-and-specialist-hardware }

Wi-Fi、カメラ、AIアクセラレーター、FreeIO、PTMのフィルターは、該当する機能が製品要件である場合にのみ適用してください。外部Wi-Fiのチェックボックスは、ドキュメントに記載されたSDIO接続経路を示すもので、内蔵Wi-Fiを意味しません。別のSDIO数フィルターでは、カタログに記載されたSDIOインターフェース数を確認します。外部Wi-Fiには、基板上の適切な電源、配線、ソフトウェアサポートも必要です。カメラとAIの要件では、インターフェース、メモリー帯域幅、処理負荷、ソフトウェアスタックを含めたシステム全体の検討が必要です。FreeIOとPTMは、柔軟な信号割り当てや決定論的なペリフェラルタスク処理が設計の中核となる場合に有用ですが、より基本的な電源、メモリー、パッケージの制約より優先されるべきではありません。

### 選定内容の検証 { #validation-evidence }

候補を決定する前に、結果のリンクから製品紹介ページへ進み、正確な型番、パッケージ、電気的な制限、リファレンスデザイン、利用可能な設計ガイドまたはチェックリストを確認してください。可能な限り、対象部品に最も近いハードウェア構成を持つサポート対象の開発ボードで、想定するファームウェアの流れを検証してください。セレクターは候補を絞り込むためのツールです。設計判断の根拠には、対象部品に関するSiFliのドキュメントを使用してください。

## 統合レベルを選ぶ { #choose-an-integration-level }

インタラクティブなカタログに掲載されているのはチップとモジュールのみです。以下の開発ボードは、ソフトウェアやシステムの前提を検証するための別の選択肢です。

<div align="center"><em>ハードウェアの出発点</em></div>

<div align="center" markdown>

| 出発点 | 選ぶべき場合 | 次のステップ |
|:---------------|:---------------|:----------|
| チップ | カスタムPCBを設計し、インターフェースや電源設計を直接制御したい場合。 | ファミリーを選び、回路図作業に着手する前に量産設計ガイドを確認してください。 |
| モジュール | RFとモジュール統合の作業を減らしつつ、カスタムキャリアボードを維持したい場合。 | モジュール紹介、インターフェース定義、モジュール設計ガイドを確認してください。 |
| 開発ボード | ソフトウェア、ペリフェラル、製品コンセプトを素早く検証する必要がある場合。 | 製品コンセプトに最も合う開発ボードから始め、検証済みのサンプルを実行し、その回路図は量産設計ではなくリファレンスとして扱ってください。 |

</div>

## 候補リストを確定する { #confirm-the-shortlist }

1. **正確な部品を確認する。** [SF32ファミリー概要](family/SF32_family.md)、結果ページの製品紹介、[命名規則](family/SF32_namingrule.md) を使って、注文可能な型番、パッケージ、電源トポロジー、メモリー構成、インターフェース割り当て、リファレンスハードウェアを確認してください。単一の特長だけを根拠に部品を選ばず、必要なディスプレイ、オーディオ、ストレージ、センサー、Bluetooth、低消費電力機能が、選択したパッケージとボード設計の中で共存できることを確認してください。
2. **ソフトウェア開発フローを検証する。** ハードウェアを最終決定する前に、利用可能なボードの中から対象に最も近い構成のものを選び、[はじめに](../getting-started/index.md)、[チュートリアル](../getting-started/tutorials/overview.md)、[開発](../develop/index.md) の内容を試してください。
3. **量産上の制約を確認する。** 回路図、レイアウト、BOM、ディスプレイやストレージの選定を確定する前に、[量産に向けた設計](../hardware/design-for-production.md) に進んでください。
