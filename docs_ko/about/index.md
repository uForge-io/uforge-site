# μForge.io 소개 { #about-forgeio }

새로운 마이크로컨트롤러를 평가하는 엔지니어가 여기저기 흩어진 데이터시트, 위키 페이지, 포럼 글을 일일이 모아 전체 그림을 맞춰야 해서는 안 됩니다. **μForge.io는 바로 그 간극을 메우기 위해 존재합니다.**

μForge.io는 SiFli의 SF32 초저전력 마이크로컨트롤러 제품군을 문서화합니다. SF32는 Bluetooth 연결과 그래픽 기능을 갖춘 AIoT 지향 실리콘으로, 웨어러블, 스마트 디스플레이 등 배터리로 동작하는 연결형 제품을 대상으로 합니다. 흩어진 참고 자료 대신 서로 연결된 하나의 일관된 경로로 정리했습니다. 칩 및 모듈 선정, 개발 보드, SDK 워크플로, 하드웨어 설계 가이드, 양산 체크리스트가 모두 이곳에 있으며, 실제 제품이 만들어지는 순서(부품 선정, 동작 검증, 설계 반영, 출시)에 맞춰 구성되어 있습니다. 기술 세부 사항은 원문 자료가 있는 경우 SiFli 공식 문서와 대조하여 확인하며, 내용 검증이 아직 필요한 페이지는 별도로 표시합니다.

SF32를 선택한 이유는 두 가지입니다. 먼저 여러 코어 구성을 아우르고 그래픽 가속과 하드웨어 압축 해제 기능을 통합하고 있으며, 구체적인 구성은 제품군마다 다릅니다. 또한 SDK, 하드웨어 가이드, 소스가 실질적으로 공개되어 있습니다. 다만 이를 둘러싼 생태계는 ESP32나 STM32만큼 널리 알려져 있지 않습니다. 이처럼 실질적인 개방성과 낮은 인지도가 함께 있다는 점이 바로 이 사이트가 메우려는 간극입니다.

목표는 단순합니다. 엔지니어가 하드웨어와 펌웨어 결정을 더 빠르고 더 확신을 갖고 내릴 수 있도록 돕는 것입니다. 기초를 다시 도출하는 데 쓰는 시간은 줄이고, 그만큼 제품을 만드는 데 더 많은 시간을 쓰게 하려는 것입니다.
