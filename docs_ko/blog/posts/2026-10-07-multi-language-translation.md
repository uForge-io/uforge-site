# 다국어 번역, 한 번에 한 단계씩 [2026-10-07] { #multi-language-translation-2026-10-07 }

임베디드 엔지니어는 자신이 생각하는 언어로 문서를 읽으므로, μForge.io는 이제 영어 원문과 함께 중국어, 일본어, 스페인어, 독일어, 프랑스어, 포르투갈어, 러시아어 번역을 제공합니다.

### LLM 도구로, 많은 반복을 거쳐 { #built-with-llm-tools }

LLM 도구가 없었다면 이 중 어느 것도 현실적으로 불가능했을 것이며, 이에 감사드립니다. 다만 한 번에 끝난 작업은 아니었습니다. 두 가지 이유로 많은 반복이 필요했습니다. 첫째는 사용량 제한이 있는 요금제입니다. 긴 번역 작업이 페이지를 다 마치기 전에 한도에 자주 걸려, 초기화를 기다리거나 다른 곳에서 이어 가야 했습니다. ChatGPT가 여러 차례 제공한 무료 초기화가 큰 도움이 되었으며, 감사드립니다. 둘째는 이런 방식의 번역이 느리고 비효율적이라는 점입니다. 기술 페이지는 길고 표, 코드, 핀 이름, 상호 링크가 가득하여, 한 번 작업할 때마다 확인하고, 고치고, 다시 실행해야 하는 결과물이 나왔습니다.

### 번역의 일관성 유지 { #keeping-translations-consistent }

반복이 수렴하도록, 번역하지 않고 그대로 두거나(부품 번호, 단위, 프로토콜 이름) 승인된 표기를 사용해야 하는 용어집과, 기술적 완전성, 링크와 앵커의 정확성, Markdown과 코드의 안전성을 다루는 QA 체크리스트를 관리합니다. 모든 언어는 영어 원문과 같은 페이지 구조를 유지하며, 빌드는 strict 모드로 검사하므로 깨진 링크나 누락된 페이지는 조용히 배포되지 않고 분명하게 실패합니다.

### 유의 사항과 부탁 { #caveat-and-request }

이 번역은 기계의 도움을 받은 것이며, 영어 페이지가 계속 기준입니다. 우리에게는 이 언어들 중 어느 것도 모국어가 아니므로, 일부 페이지는 원어민에게 자연스럽게 읽히지 않을 수 있습니다. 설계에서 기술적 세부 사항이 중요할 때는 영어 페이지와 SiFli의 공식 문서로 확인하십시오. 오역이나 어색한 용어를 발견하셨거나 페이지를 개선할 수 있다고 생각하시면 [알려 주십시오](../../about/contact.md). 그 피드백은 같은 실수가 되풀이되지 않도록 곧바로 용어집에 반영됩니다.

### 다음 계획 { #next }

용어를 계속 다듬고, 가능한 곳에서는 원어민의 검토를 받으며, 영어 페이지가 바뀌는 대로 번역도 보조를 맞추어 갱신하겠습니다.
