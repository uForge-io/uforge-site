# 다국어 번역, 한 번에 한 단계씩 [2026-10-07] { #multi-language-translation-2026-10-07 }

임베디드 엔지니어는 자신이 생각하는 언어로 문서를 읽으므로, μForge.io는 이제 영어 원문과 함께 중국어, 일본어, 스페인어, 독일어, 프랑스어, 포르투갈어, 러시아어 번역을 제공합니다.

### LLM 도구로, 많은 반복을 거쳐 { #built-with-llm-tools }

LLM 도구의 도움에 감사드립니다. 덕분에 이 작업을 현실적으로 진행할 수 있었습니다. 다만 한 번에 끝난 작업은 아니었습니다. 두 가지 이유로 여러 차례 반복해야 했습니다. 첫째는 사용량 제한이 있는 요금제입니다. 긴 번역 작업은 페이지를 다 마치기 전에 한도에 자주 걸려 초기화를 기다리거나 다른 곳에서 이어 가야 했습니다. ChatGPT의 무료 사용 한도가 여러 차례 초기화된 덕분에 작업을 이어 가는 데 큰 도움이 되었습니다. 감사드립니다. 둘째는 이런 방식의 번역이 느리고 비효율적이라는 점입니다. 기술 페이지는 길고 표, 코드, 핀 이름, 상호 링크가 많아 매번 결과물을 확인하고 수정한 뒤 다시 실행해야 했습니다.

### 번역의 일관성 유지 { #keeping-translations-consistent }

번역 품질을 일관된 수준으로 끌어올리기 위해 용어집과 QA 체크리스트를 관리합니다. 용어집에는 번역하지 않는 항목(부품 번호, 단위, 프로토콜 이름)과 승인된 번역어를 정리하고, 체크리스트에는 기술적 완전성, 링크와 앵커의 정확성, Markdown 및 코드의 안전성을 담습니다. 모든 언어의 페이지 구조는 영어 원문과 같으며, strict 모드 빌드에서 링크가 깨지거나 페이지가 누락되면 바로 오류가 발생해 배포 전에 드러납니다.

### 유의 사항과 부탁 { #caveat-and-request }

이 번역에는 LLM을 비롯한 기계 번역 도구가 사용되었으며, 기준 문서는 영어 페이지입니다. 저희에게는 이 언어들이 모두 모국어가 아니므로 일부 페이지가 원어민에게 자연스럽게 읽히지 않을 수 있습니다. 설계에 중요한 기술 세부 사항은 영어 페이지와 SiFli 공식 문서를 기준으로 확인하십시오. 오역이나 어색한 용어를 발견했거나 페이지를 개선할 의견이 있으면 [알려 주십시오](../../about/contact.md). 같은 문제가 반복되지 않도록 해당 피드백을 용어집에 반영하겠습니다.

### 다음 계획 { #next }

용어를 계속 다듬고 가능한 곳에서는 원어민의 검토를 받으며, 영문 페이지가 바뀔 때마다 번역도 함께 업데이트하겠습니다.
