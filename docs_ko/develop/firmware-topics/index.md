# 펌웨어 주제 { #firmware-topics }

이 주제들은 모든 플랫폼에 적용됩니다. 예제를 제품으로 바꾸는 펌웨어 관련 결정, 즉 부트 레이아웃, 파티션, OTA, USB, 전원 관리, 로깅, 크래시 분석을 다룹니다.

펌웨어 레이아웃, 업데이트 동작, 저전력 정책을 변경하기 전에 이 문서들을 읽으십시오. 이러한 실수는 빌드 성공을 막지는 않지만, 제품의 복구, 디버깅, 릴리스를 어렵게 만들 수 있습니다.

## 실무 규칙 { #practical-rule }

부트, OTA, 파일 시스템, 스토리지 동작을 변경하기 전에 파티션 테이블을 이해하고 복구 경로를 검증하십시오. 애플리케이션 결함은 불편을 초래하는 데 그치지만, 잘못된 부트 또는 업데이트 레이아웃은 보드 복구를 어렵게 만들 수 있습니다.

## 제품 준비 체크리스트 { #product-readiness-checklist }

- [ ] 일반 OTA 경로와 별도로, 테스트를 마친 디바이스 전체 플래시 명령이 준비되어 있습니다.
- [ ] 파티션 레이아웃이 제품 저장소에 문서화되어 있습니다.
- [ ] OTA/DFU 실패 시 동작을 테스트했습니다.
- [ ] USB를 사용하는 경우 USB 디스크립터와 VID/PID 소유권이 문서화되어 있습니다.
- [ ] 저전력 모드를 실제 하드웨어에서 측정했습니다.
- [ ] 릴리스된 바이너리에서 크래시 로그를 디코딩할 수 있습니다.
- [ ] 양산용 플래싱 절차와 개발용 플래싱 절차가 분리되어 있습니다.
