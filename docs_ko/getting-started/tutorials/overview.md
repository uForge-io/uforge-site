# 튜토리얼 개요 { #tutorials-overview }

이 시리즈는 첫 플래시 기록에 성공한 뒤 실용적인 SF32 개발 역량으로 이어지도록 구성했습니다. 엔지니어링 범위에 따라 먼저 주변 장치 하나를 검증하고, 이어서 서브시스템을 결합한 다음, 제품에 필요한 증거를 만들어 갑니다. 튜토리얼은 SiFli-SDK 예제를 출발점으로 사용하지만, 하드웨어를 검증하고, 정상 동작이 확인된 기준 구성을 유지하고, 결과를 측정하는 습관은 모든 SF32 소프트웨어 경로에 적용됩니다.

튜토리얼은 [시작하기 개요](../index.md)의 두 번째 단계입니다. 먼저 해당 페이지의 첫 실행 성공 기준을 완료하십시오. 칩, 모듈 또는 개발 보드를 고르는 중이라면 시리즈를 시작하기 전에 [SF32 제품군](../../sf32-products/family/SF32_family.md)부터 확인하십시오.

## 필요한 것 { #what-you-need }

USB 데이터 연결과 시리얼 콘솔이 동작하는 SF32 개발 보드를 사용하십시오. 예를 들어 `sf32lb52-lcd_n16r8`은 SF32LB52-DevKit-LCD_N16R8의 SiFli-SDK 보드 이름입니다. 이 시리즈는 하나의 보드가 모든 실습을 지원한다고 가정하지 않습니다. 각 예제의 Supported Platforms 목록을 확인하고, 핀, 주변 장치, 디스플레이, 오디오, 스토리지에 관한 세부 사항은 해당 회로도와 보드 파일에서 확인하십시오. SF32LB52x SDK 보드 식별자는 공식 [Supported Boards](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/supported_boards/index.html) 목록을 참조하십시오.

순서에는 이유가 있습니다. 보드, 플래시 흐름, 시리얼 콘솔, 간단한 GPIO 테스트가 정상으로 확인되기 전에는 디스플레이, BLE 서비스, 커스텀 드라이버부터 시작하지 마십시오. 이후 튜토리얼에서 문제가 생기면, 성공 기준을 여전히 재현할 수 있는 마지막 단계로 돌아가십시오.

## 각 튜토리얼 사용 방법 { #how-to-use-each-tutorial }

각 실습에는 유사한 SDK 예제, 목표, 성공 기준, 예상되는 실패 확인 사항이 제시되어 있습니다. 빈 프로젝트가 아니라 명시된 예제에서 시작하고, 한 번에 하나의 동작만 변경하며, 기능을 결합하기 전에 정상 동작하는 빌드를 보존하십시오. 재사용할 구성은 보드 리비전, SDK 버전, 보드 이름, 관찰된 결과를 기록하십시오.

튜토리얼은 의도적으로 레퍼런스 자료를 대체하지 않습니다.

- 플랫폼 워크플로, 도구, 펌웨어 주제, 통합 SDK 예제 색인은 [개발 개요](../../develop/index.md)를 참조하십시오.
- 그래픽 흐름, Bluetooth 동작, 전력 전략 같은 아키텍처 및 서브시스템 결정은 [학습 개요](../../learn/graphics/overview.md)을 참조하십시오.
- 디바이스 선택, 보드 정보, 하드웨어 설계 지침, 양산 점검은 [SF32 제품군](../../sf32-products/family/SF32_family.md)을 참조하십시오.
