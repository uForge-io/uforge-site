## 6. PCB 레이아웃 가이드라인 { #6-pcb-layout-guidelines }

### 6.1. 풋프린트와 스택업 { #61-footprint-and-stack-up }

U 변형(variant)은 크기 7 × 7 × 0.75 mm, 핀 피치 0.35 mm인 68핀 QFN68L 패키지를 사용합니다. QFN은 PTH를 지원하며, SiFli는 4층 PTH 스택업을 권장합니다. 모든 핀은 최상층에서 팬아웃하십시오. V 변형은 크기 6.5 × 6.1 × 0.94 mm, 볼 피치 0.4 mm, 볼 직경 0.25 mm인 175볼 WBBGA 패키지를 사용합니다. PTH를 지원하지 않으므로 HDI가 필요합니다. 가장 바깥쪽 두 볼 열은 최상층에서, 나머지 볼은 내층에서 팬아웃하십시오. 레이아웃을 릴리스하기 전에 PCB 공급업체가 선택한 스택업, 솔더 마스크, 팬아웃 전략을 지원하는지 확인하십시오.

### 6.2. 핵심 라우팅 { #62-critical-routing }

#### 6.2.1. 클럭 라우팅 { #621-clock-routing }

크리스털은 실드 캔 안쪽에, 보드 가장자리에서 1 mm 넘게 떨어뜨려 배치하고, 열을 내는 PA, 충전기, PMU 부품에서는 가급적 5 mm 이상 떨어뜨리십시오. 크리스털 회로와 다른 금속 및 부품 사이에는 0.25 mm 이상의 간격을 두십시오. 48 MHz 크리스털은 가능한 한 최상층에서 라우팅하고, 트레이스 길이는 3~10 mm, 폭은 0.075 mm로 유지하며 3차원 그라운드 실드를 적용하십시오. VBAT, DC-DC, 고속 신호에서 멀리 떨어뜨리십시오. 32.768 kHz 크리스털도 최상층에서 라우팅하십시오. 트레이스 길이는 10 mm 이하, 폭은 0.075 mm로 하고, 32K_XI와 32K_XO 사이 간격은 0.15 mm 이상으로 하십시오. 두 크리스털 영역 아래의 최상층과 인접 층은 비워 두고, 다른 트레이스가 그 영역을 지나가지 않도록 하십시오.

#### 6.2.2. RF 라우팅 { #622-rf-routing }

RF는 50 Ω 싱글 엔디드 임피던스 제어 트레이스로 라우팅하십시오. 가능하면 최상층에 10 mil보다 넓게 배선하고, 비아와 급격한 꺾임은 피하십시오. 매칭 회로는 안테나가 아니라 칩 가까이에 배치하십시오. AVDD_BRF 필터 커패시터도 칩 핀 가까이에 두고, 커패시터의 그라운드를 비아를 통해 메인 그라운드에 직접 연결하십시오. RF 트레이스 양쪽에는 연속적인 그라운드 실드와 스티칭 비아를 배치하십시오. di/dt가 큰 전원, 고속 클럭, I2C, SPI, SDIO, I2S, UART 신호는 RF 영역 안이나 아래로 지나가지 않게 하십시오. U 변형의 AVSS_RF1/2/3과 V 변형의 AVSS_RRF, AVSS_TRF, AVSS_TRF2, AVSS_BB는 메인 그라운드에 확실히 연결하십시오.

#### 6.2.3. 전원과 그라운드 { #623-power-and-ground }

BUCK 인덕터와 필터 커패시터는 칩 핀 가까이에 배치하십시오. BUCK_LX는 짧고 넓게 유지하고, BUCK_FB 트레이스 폭은 0.25 mm 이상이어야 합니다. 인덕터 아래 최상층에는 구리를 채우지 말고, 인접 층에는 견고한 그라운드 기준면을 유지하십시오. 다른 트레이스가 인덕터 영역을 지나가게 해서는 안 됩니다. BUCK 출력 커패시터의 그라운드는 여러 비아를 사용해 메인 그라운드 플레인에 연결하십시오. PVDD 커패시터는 해당 핀 가까이에 배치하고 PVDD는 짧고 넓게 라우팅하십시오. PVSS는 비아를 통해 메인 그라운드에 연결하십시오. LDO 및 I/O 전원 디커플링 커패시터는 각 핀 가까이에 배치하고, 전원 트레이스 폭은 부하 전류에 맞게 정하십시오.

!!! warning "PVDD 트레이스 폭 한계 불일치"
    SF32LB56xU/V 하드웨어 애플리케이션 가이드는 PVDD 트레이스의 최소 폭을 0.5mm로 규정하지만, 해당 PCB 체크리스트는 8mil로 규정합니다. 두 값이 다르므로, 레이아웃을 동결하기 전에 SiFli 또는 PCB 설계 담당자와 적용할 요구 사항을 확인하십시오.

#### 6.2.4. 오디오 및 아날로그 신호 { #624-audio-and-analog-signals }

AVDD33_ANA와 AVDD33_AUD는 각각 별도의 스타 방식 전원으로 라우팅하십시오. 트레이스에는 그라운드 가드를 적용하고 대전류 노이즈원에서 멀리 떨어뜨리십시오. AVDD33_AUD, MIC_BIAS, AUD_VREF 필터 커패시터는 각 핀 가까이에 배치하고, 커패시터 그라운드는 메인 그라운드에 직접 연결하십시오. ADCP/ADCN은 짧고 가드된 차동 쌍으로 라우팅하고 관련 부품은 칩 가까이에 두십시오. DACP/DACN은 기생 커패시턴스가 10 pF 미만이고 트레이스 길이가 2 cm 미만인 차동 쌍으로 라우팅하며, 강한 간섭원에서 멀리 떨어뜨리십시오. GPADC 트레이스에도 가드를 적용하고 배터리 전압 및 온도 감지 회로의 노이즈원에서 멀리 떨어뜨리십시오.

#### 6.2.5. USB와 SDIO { #625-usb-and-sdio }

USB D+/D−(PA17/PA18)는 그라운드 가드를 적용한 90 Ω 차동 쌍으로 라우팅하십시오. ESD 소자는 커넥터 가까이에 배치하고, 신호가 칩에 도달하기 전에 해당 소자를 통과하도록 라우팅하십시오. 보호 소자 앞에서 신호를 분기해서는 안 됩니다. ESD 소자의 그라운드는 짧고 넓은 트레이스와 비아를 사용해 메인 그라운드에 연결하십시오. U 변형에는 SDIO 인터페이스가 하나 있고, V 변형에는 SDIO1과 SDIO2가 있습니다. SDIO 신호는 그룹으로 라우팅하되, 전체 길이는 50 mm 이하, 그룹 내 길이 편차는 6 mm 이하로 유지하십시오. 클럭에는 그라운드 실드를 적용하고 DATA 및 CMD 신호에는 그라운드 가드를 적용하십시오.

#### 6.2.6. EMI, ESD, 테스트 포인트 { #626-emi-esd-and-test-points }

노이즈가 큰 클럭과 전원 신호는 실드 캔 밖의 표면층에서 길게 라우팅하는 것을 피하고, 가능한 한 내층에서 라우팅하십시오. TVS/ESD 소자는 해당 커넥터 가까이에 배치하십시오. 각 신호는 보호 소자를 거치도록 라우팅한 다음, 소자의 그라운드 패드를 짧고 넓은 트레이스와 비아로 메인 그라운드에 연결하십시오. USB 충전 케이블 테스트 포인트는 TVS보다 앞단에 두고, 배터리 커넥터 TVS는 배터리 플랫폼보다 앞단에 배치하여 외부 라인이 칩에 도달하기 전에 TVS를 거치도록 하십시오. 칩 아래의 그라운드 네트워크는 블라인드/베리드 비아로 메인 그라운드 플레인에 충분히 연결하십시오.
