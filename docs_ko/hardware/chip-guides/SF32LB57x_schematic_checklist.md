# SF32LB57x 하드웨어 설계 가이드 — 회로도 체크리스트 { #sf32lb57x-hardware-design-guide-schematic-checklist }

!!! note "SF32LB57x 하드웨어 설계 가이드의 일부"
    이 페이지는 SiFli 공식 설계 자체 점검표를 옮겨 놓은 항목별 회로도 체크리스트인 5.8절을 다룹니다. 세 개의 회로 설계 가이드라인 페이지 중 첫 번째인 [최소 시스템 및 전원](SF32LB57x_schematic_system_power.md)으로 돌아갑니다.

## 5.8. 회로도 체크리스트 { #58-schematic-checklist }

각 표는 회로도의 기능 블록 하나를 다룹니다. 적용 대상 열은 배터리 전원 변형(variant) 또는 3.3 V 전원 변형에만 해당하는 점검 항목을 구분하며, "모든 변형"으로 표시된 항목은 제품군 전체에 적용됩니다.

!!! warning "원본 자료의 불일치"
    원본 자체 점검표는 `PVDD` 하한을 2.93 V, `VBATS` 상한을 4.5 V로 제시하지만, 패키지 전원 표는 각각 2.97 V와 4.7 V를 제시합니다. 이 페이지는 자체 점검표의 값을 유지합니다. 정확한 주문 가능 파트에 대해 두 불일치를 SiFli에 확인하고, 설계 승인에는 더 넓은 범위를 사용하지 마십시오.

    참조 회로도는 또한 `VCC`를 3.2~4.7 V로, `VDD33_VOUT1`을 플래시와 센서에 전원을 공급하는 것으로 표기하는데, 이는 위의 3.45 V 하한 및 다른 주변 장치에 대한 제한과 다릅니다. 표의 제한 사항을 유지하고, 회로도 표기를 근거로 전압 범위나 허용 부하를 넓히지 마십시오.

    그 밖에 가이드 본문은 `VBUS` 입력 범위를 4.5~5.5 V, 내장 LDO OVP 출력 범위를 4.5~5.4 V로 제시하지만, 자체 점검표는 각각 4.6~5.5 V와 4.7~5.4 V를 제시합니다. 이 페이지는 자체 점검표의 값을 유지합니다. 설계를 승인하기 전에 해당 디바이스에 적용되는 한계를 확인하고 SiFli에도 문의하십시오.

    원본 자체 점검표의 25번 행은 제목이 `VDD33_VOUT2` 커패시터로 되어 있으나, 상세 점검 문구에는 `VDD33_VOUT1`이 잘못 기재되어 있습니다(24번 행에서도 다룹니다). 이 페이지는 25번 행의 제목을 따릅니다. 의도한 레일을 SiFli에 확인하십시오.

| 3 | 부팅 모드 선택 핀인 `PA00`에 풀업 저항과 그에 맞는 테스트 포인트를 확보해 둡니다 | 모든 변형 | |
| 4 | SWD 핀 위치 전환 핀인 `PA01`에 제품 설계에 따라 필요하면 풀업 저항과 테스트 포인트를 확보해 둡니다 | 모든 변형 | |

</div>
