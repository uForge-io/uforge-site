# 양산 설계 { #design-for-production }

칩 또는 모듈을 선택한 후, 회로도, PCB 레이아웃, BOM, 제조 패키지를 릴리스하기 전에 이 경로를 사용하십시오. 이 경로는 첫 브링업과 인증에서 발생하는 위험을 줄이는 데 도움이 되는 구현 레퍼런스를 한곳에 모았습니다. 디바이스별 하드웨어 설계 가이드, 체크리스트, 모듈 인터페이스 정의, 승인 부품, EDA 라이브러리가 그 대상입니다.

## 권장 양산 순서 { #recommended-production-sequence }

이 순서는 한 번에 끝나는 인계가 아니라 반복하는 검토 순서로 사용하십시오. 프로토타입을 제작하기 전에 심볼과 풋프린트를 확인하고, 양산용 CAD와 제조 패키지는 설계 검토와 양산 의도 하드웨어의 검증을 마친 후에만 릴리스하십시오. 보드, 펌웨어, BOM이 바뀔 때마다 영향을 받는 점검을 다시 수행하십시오.

## 선택한 제품에 맞는 레퍼런스 사용 { #use-the-right-reference-for-the-chosen-product }

구현 작업별 레퍼런스를 찾으려면 다음 시작점을 사용하십시오.

- **[하드웨어 설계 가이드](index.md#find-a-guide)**는 칩에 대한 디바이스별 회로도, 레이아웃, 전원, 인터페이스, 브링업 지침과 모듈에 대한 캐리어 보드 통합 지침을 제공합니다. 사용할 수 있으면 해당 체크리스트를 사용하고, 모듈이 제품 아키텍처에 맞는지 확인하려면 먼저 모듈 소개를 참조하십시오.
- **[모듈 인터페이스 표준](m2-modules/interface-standards-overview.md)**에는 μForge M2 명명 규칙과 핀 수준 인터페이스 정의 초안이 있습니다. 이 인터페이스 정의는 제안안이므로 양산을 확정하기 전에 검증하십시오.
- **[부품 및 CAD 라이브러리](cad-components/components-and-cad-libraries.md)**에는 SiFli의 [승인 업체 목록(AVL)](cad-components/sifli-approved-vendor-list.md)과 [공식 EDA 툴 라이브러리](cad-components/eda-tool-libraries.md)가 있습니다. 둘 다 해당 부품, 패키지 도면, 선택한 설계 가이드에 대한 최종 검증을 대신하지 않습니다.

## 양산 레퍼런스는 검증을 대체하지 않습니다 { #a-production-reference-is-not-a-substitute-for-validation }

설계 가이드와 인증 부품 목록은 위험을 줄이지만 완성된 제품을 보증하지는 않습니다. 최종 PCB 리비전, 펌웨어 이미지, 인클로저, 배터리, 디스플레이, 스토리지 디바이스, RF 동작, 사용 환경, 제조 테스트 흐름을 검증하십시오. 가이드나 체크리스트에서 벗어나는 사항은 문서화되지 않은 예외로 두지 말고 명시적인 엔지니어링 결정으로 기록하십시오.
