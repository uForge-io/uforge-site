# 양산 설계 { #design-for-production }

칩 또는 모듈을 선택한 뒤 회로도, PCB 레이아웃, BOM, 제조 패키지를 릴리스하기 전에 이 경로를 따르십시오. 초기 구동과 양산 적격성 검증의 위험을 줄이는 데 필요한 구현 자료를 모았습니다. 디바이스별 하드웨어 설계 가이드, 체크리스트, 모듈 인터페이스 정의, 승인 부품, EDA 라이브러리를 확인할 수 있습니다.

## 권장 양산 순서 { #recommended-production-sequence }

이 순서는 한 번만 거치는 인계 절차가 아니라 반복해서 적용하는 검토 흐름입니다. 프로토타입을 제작하기 전에 심볼과 풋프린트를 확인하고, 설계 검토와 양산용 하드웨어 검증을 마친 뒤에 양산 CAD와 제조 패키지를 릴리스하십시오. 보드, 펌웨어, BOM이 바뀌면 영향을 받는 항목을 다시 점검하십시오.

<div align="center" markdown style="max-width: 100%; overflow-x: auto;">

| 단계 | 참고 자료 | 남길 검증 기록 |

| 아키텍처 | 제품 소개와 인터페이스 요구 사항 | 선택한 부품과 패키지, 메모리, 디스플레이, 오디오, 스토리지 구성 및 전원 관련 가정. |
| 회로도와 레이아웃 | 칩 또는 모듈 하드웨어 설계 가이드 | 전원, 클럭, 리셋, RF, 스토리지, 디스플레이, 인터페이스 설계의 검토 결과. |
| BOM | 승인 업체 목록(AVL)과 부품 데이터시트 | 핵심 품목별로 인증되었거나 의도적으로 검증한 대체품. |
| 설계 검토 | 하드웨어 설계 체크리스트 | 적용되는 체크리스트 항목과 예외의 처리 결과. |
| 브링업 | 개발 보드 자료, SDK 예제, 측정 결과 | 재현 가능한 부팅, 펌웨어 기록, 주변 장치, 무선, 소비 전력, 복구 시험 결과. |
| 양산 CAD 릴리스 | 공식 EDA 라이브러리와 패키지 도면 | 검증된 심볼, 풋프린트, 핀 배치, 랜드 패턴 및 제조 출력물. |

## 선택한 제품에 맞는 레퍼런스 사용 { #use-the-right-reference-for-the-chosen-product }

구현 작업에 필요한 자료는 다음 항목에서 찾으십시오.

- **[하드웨어 설계 가이드](index.md#find-a-guide)**는 칩별 회로도, 레이아웃, 전원, 인터페이스, 초기 구동 지침과 모듈의 캐리어 보드 통합 지침을 제공합니다. 해당 체크리스트가 있으면 함께 사용하십시오. 모듈이 제품 아키텍처에 맞는지 먼저 확인하려면 모듈 소개를 읽으십시오.
- **[모듈 인터페이스 표준](m2-modules/interface-standards-overview.md)**에는 μForge M2 명명 규칙과 핀 수준 인터페이스 정의 초안이 있습니다. 이 인터페이스 정의는 제안안이므로 양산을 확정하기 전에 검증하십시오.
- **[부품 및 CAD 라이브러리](cad-components/components-and-cad-libraries.md)**에서 SiFli의 [승인 업체 목록(AVL)](cad-components/sifli-approved-vendor-list.md)과 [공식 EDA 툴 라이브러리](cad-components/eda-tool-libraries.md)를 확인할 수 있습니다. 이 자료만으로는 정확한 부품, 패키지 도면, 선택한 설계 가이드에 대한 최종 검증을 대신할 수 없습니다.

## 양산 레퍼런스는 검증을 대체하지 않습니다 { #a-production-reference-is-not-a-substitute-for-validation }

설계 가이드와 인증 부품 목록은 위험을 줄여 주지만 완제품의 정상 동작을 보증하지는 않습니다. 최종 PCB 리비전, 펌웨어 이미지, 인클로저, 배터리, 디스플레이, 저장 장치, RF 동작, 사용 환경, 제조 시험 절차를 검증하십시오. 가이드나 체크리스트와 다른 점은 기록되지 않은 예외로 남겨 두지 말고, 명시적인 엔지니어링 결정으로 문서화하십시오.
