# μForge M2 인터페이스 명명 규칙 { #forge-m2-interface-naming-rules }

## 기본 사양 { #base-specification }

이 문서는 제안된 μForge 모듈 인터페이스 체계에서 사용하는 이름을 정의합니다. 이는 명명 규칙이며, 릴리스된 전기 또는 기계 표준이 아닙니다.

이 규칙에서 **M2**는 이 체계를 채택하는 모듈에 공통으로 요구되는 기본 인터페이스를 가리킵니다. 기존의 모든 μForge 또는 SiFli 모듈이 M2를 구현한다는 뜻은 아닙니다. M2 핀 배치와 전기·기계 요구 사항은 아직 개발 중이며, 이 문서에서는 규정하지 않습니다.

M2가 M.2 E-key와 호환된다고 설명하려면 먼저 릴리스된 M2 정의에서 기계적 인터페이스, 핀 배치, 전기적 한계, 필수 및 선택 신호, 캐리어 요구 사항, 적합성 규칙을 규정해야 합니다. 현재의 [M2 인터페이스 정의](M2-interface-definition.md)는 초안입니다. M2라는 이름만으로는 M.2 전기적 호환성이나 모듈과 캐리어 보드의 상호 교환 가능성이 보장되지 않습니다.

## 확장 사양 { #extension-specifications }

선택 기능은 **M2xY** 확장 사양으로 묶습니다. 이름은 기능 범주를 나타낼 뿐이며, 특정 모듈이 해당 범주의 모든 기능을 구현한다는 뜻은 아닙니다.

**명명 형식:**

> **M2xY**

여기서

- **M2** = 기본 인터페이스 사양
- **x** = 확장 구분자
- **Y** = 확장 범주

## 확장 카테고리 { #extension-categories }

<div align="center"><em>M2 확장 카테고리</em></div>

<div align="center" markdown>

| 사양 | 설명 |
| --- | --- |
| **M2xM** | 멀티미디어: 향후 RGB 디스플레이, DVP 카메라, 디지털 마이크, 고급 오디오 기능. |
| **M2xA** | 아날로그: 향후 정밀 아날로그 I/O와 데이터 수집 기능. |
| **M2xN** | 네트워킹: 향후 Ethernet, CAN, 산업용 네트워킹 기능. |
| **M2xH** | 고속: 향후 고대역폭 인터페이스. |
| **M2xP** | 전원: 향후 전원 관리와 대전류 I/O 기능. |

</div>

이 설명은 각 범주의 의도된 범위를 나타낼 뿐, 확정된 전기적 요구 사항은 아닙니다. 확인 가능한 로컬 제안 워크북에는 M2와 M2xM의 컨택트 맵이 있습니다. 인터페이스 정의 문서에는 M2xN과 M2xA의 요약도 있지만, 이를 검증할 원본 컨택트 맵 데이터는 찾지 못했으므로 검증되지 않은 내용으로 취급하십시오. M2xH와 M2xP는 명칭만 예약되어 있으며 할당된 컨택트는 없습니다.

## 모듈 선언 { #module-declaration }

이 규칙을 채택하는 모듈은 **M2**를 기본 인터페이스로 선언하며, 구현한 확장을 하나 이상 나열할 수 있습니다. 모듈 문서에는 실제 커넥터, 선택 기능, 상호 배타적인 모드도 명시해야 합니다.

선언 예시이며, 릴리스된 모듈 구성의 목록이 아닙니다.

- **M2**
- **M2 + M2xM**
- **M2 + M2xA**
- **M2 + M2xM + M2xN**

## 설계 원칙 { #design-principles }

- **M2**는 체계가 발전하더라도 안정적으로 유지되고 하위 호환성을 보장하는 것을 목표로 합니다. 호환성은 해당 사양 리비전과 실제 구현을 기준으로 검증해야 합니다.
- 각 **M2xY** 확장에는 고유한 기능 범위가 있습니다. 이름이 구분되어 있어도 모든 기능을 동시에 사용할 수 있거나 핀 할당이 서로 독립적이라는 뜻은 아닙니다.
- 확장은 기본 인터페이스를 수정하거나 대체하지 않고 보완합니다.
- 모듈은 구현한 M2xY 사양을 나열하여 지원하는 기능을 알립니다.

커넥터를 선택하거나 호환성을 주장하기 전에 [모듈 인터페이스 표준](interface-standards-overview.md)의 검증 절차를 따르십시오.
