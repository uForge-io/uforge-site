# 커넥티드 웨어러블 레퍼런스 디자인 여정 { #connected-wearable-reference-design-journey }

이 여정은 디스플레이, BLE, 센서 입력을 갖춘 소형 배터리 구동 커넥티드 제품을 위한 검증 워크플로입니다. 릴리스된 회로도, BOM, 또는 검증된 레퍼런스 보드 패키지가 아닙니다. 커스텀 하드웨어를 설계하기 전에 자체 하드웨어/소프트웨어 기준 구성을 수립하고 테스트하는 데 사용하십시오.

1. **기준 구성 선택 및 수립.** [SF32 제품군](../../sf32-products/family/SF32_family.md)과 [SF32 제품 선택기](../../sf32-products/product-selector.md)를 사용하여 적합한 부품을 추립니다. [SF32LB52-DevKit-LCD](../../sf32-products/devkits/SF32LB52-DevKit-LCD.md) 또는 필요한 인터페이스 및 하드웨어 제약을 충족하는 다른 보드에서 SiFli-SDK `hello_world`를 실행합니다. 보드 리비전, SDK 버전 또는 커밋, 빌드/플래시 명령, 시리얼 로그를 기록합니다.
2. **제품 기능 검증.** [튜토리얼 개요](../../getting-started/tutorials/overview.md)를 따라 입력/센서 처리, BLE, 간단한 UI, 필요한 경우 스토리지, 시리얼 복구 경로를 검증합니다.
3. **시스템 간 상호작용 검증.** [그래픽](../../learn/graphics/overview.md), [Bluetooth](../../learn/bluetooth/overview.md), [저전력 설계 개요](../../learn/low-power/overview.md)를 사용하여 디스플레이 갱신, 무선 활동, sleep/wake를 함께 테스트합니다.
4. **커스텀 하드웨어 준비.** [양산 설계](../design-for-production.md)를 통해 선택한 칩의 설계 가이드와 체크리스트를 사용하고, 디스플레이, 스토리지, 배터리, 안테나/RF, 프로그래밍/테스트 가정을 확인합니다.
5. **릴리스 증빙 준비.** 보드 이름과 리비전, SDK 버전 또는 커밋, 정상 동작이 확인된 펌웨어 이미지, 로그, 측정한 전력 시나리오와 그 조건, 복구/OTA 동작, BOM 선택, 체크리스트 결정 사항을 보존합니다.

데모가 성공했다는 것만으로는 이 워크플로가 완료되지 않습니다. 빌드, 플래싱, 복구 절차를 반복할 수 있어야 하며, 대표 하드웨어에서 제품의 핵심 서브시스템이 함께 동작한다는 측정 증거가 있어야 합니다. 다른 엔지니어가 비교 결과를 재현할 수 있도록 각 전력 측정 결과와 함께 동작 시나리오, 공급 전압, 측정 조건을 기록하십시오.
