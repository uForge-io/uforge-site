# 제품 계획하기 { #plan-a-product }

이 가이드는 SF32 콘셉트를 초기 요구 사항에서 검증을 거쳐 양산 준비가 된 설계 계획으로 발전시키는 데 필요한 의사결정을 정리합니다. 칩, 모듈, 개발 보드, 소프트웨어 스택, 제조 방식이 아직 정해지지 않았다면 단계를 순서대로 따르십시오.

## 보드 검증 단계를 건너뛰지 마십시오 { #do-not-skip-the-board-validation-loop }

제품군 비교와 컴파일 성공만으로는 양산 디바이스를 선택하기에 충분하지 않습니다. 하드웨어를 확정하기 전에 가장 가까운 보드로 검증하고, 보드 이름, SDK 버전, 사용한 SDK 예제, 측정된 동작, 목표 제품과의 차이점을 기록하십시오. 최종 제품이 새로운 디스플레이, 스토리지 부품, 배터리 경로, 안테나 또는 모듈 캐리어를 사용한다면 각각을 별도의 검증 항목으로 다루십시오.

전체 사례 경로가 필요하다면, 초기 하드웨어 및 소프트웨어 기준 구성을 마련한 뒤 가장 가까운 [레퍼런스 디자인](../../hardware/reference-designs/reference-designs.md)을 선택하십시오.

## 인계 체크리스트 { #handoff-checklist }

- [ ] 선택한 부품 또는 모듈이 제품의 인터페이스, 메모리, 패키지, 전원 공급, 소비 전력 제약 조건을 충족합니다.
- [ ] 지원되는 보드 또는 의도적인 커스텀 하드웨어 검증 계획이 있습니다.
- [ ] 제품 팀이 소프트웨어 경로와 그 성숙도를 수용했습니다.
- [ ] 파티션과 BOM 결정을 확정하기 전에 복구, OTA/DFU, 로깅, 공장 프로그래밍 요구 사항이 정의되어 있습니다.
- [ ] 올바른 하드웨어 설계 가이드, 체크리스트, AVL, EDA 라이브러리를 확인했습니다.

!!! note "자동 생성 콘텐츠"
    이 페이지는 기존 원본 문서 없이 정리하여 작성되었습니다. 기술적 내용을 사용하기 전에 SiFli 공식 문서와 대조하여 확인하십시오.
