# SF32 제품

SF32 제품 섹션은 제품 아이디어에서 구현 가능한 SF32 설계까지 나아가도록 돕습니다. SF32 제품군을 이해하고, 하드웨어 선택을 내리고 검증하고, 재사용할 수 있는 기준 구성을 찾고, 양산에 필요한 설계 자료에 도달하는 데 활용하십시오.

## 이 섹션에서 다루는 내용 { #what-this-section-covers }

사용 가능한 제품군과 그 사이의 대략적인 기능 차이를 이해해야 한다면 [SF32 제품군 개요](family/SF32_family.md)부터 시작하십시오. 제품군과 패키지를 좁힌 뒤에는 [명명 규칙](family/SF32_namingrule.md)을 통해 전체 파트 넘버를 해독할 수 있습니다.

전원 아키텍처, 패키지, 디스플레이, 오디오, 메모리, GPIO, 연결성, 특수 하드웨어 같은 요구 사항이 선택을 좌우한다면 [SF32 제품 선택기](product-selector.md)를 사용하십시오. 선택기는 후보 목록을 만들어 줄 뿐이며, 정확한 파트 넘버, 패키지, 전기적 한계, 보드 수준 라우팅은 관련 SiFli 문서와 대조하여 반드시 확인해야 합니다.

방향이 정해지면 [레퍼런스 디자인](../hardware/reference-designs/reference-designs.md)과 [양산 경로](../hardware/design-for-production.md)로 이어서 진행하십시오. 이 부분에서 이 사이트는 디바이스 선택을 레퍼런스 하드웨어, 설계 지침, CAD 라이브러리, BOM 결정, 검토 체크리스트, 브링업 근거와 연결합니다.

## 하드웨어 바로 찾아보기 { #browse-hardware-directly }

필요한 하드웨어 종류를 이미 알고 있습니까? 해당 카탈로그로 바로 이동하십시오.

- [칩](family/SF32_family.md): 디바이스 제품군 및 파트 선택 정보.
- [모듈](modules/SF32LB52-MOD-1.md): 기성 RF 및 코어 하드웨어를 둘러싼 캐리어 보드 계획.
- [개발 보드](devkits/SF32LB52-DevKit-LCD.md): 소프트웨어와 주변 장치를 검증하는 데 사용하는 지원 하드웨어.

하드웨어 문서는 물리적인 제품 경로를 정의합니다. SDK 설정, 예제, 툴체인, 소프트웨어 플랫폼 지원은 [개발 개요](../develop/index.md)에서 이어서 확인하십시오.
