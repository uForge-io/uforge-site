# Глоссарий { #glossary }

Здесь собраны сокращения и термины из документации μForge.io: как общие понятия из области встраиваемых систем и беспроводной связи, так и названия SiFli, относящиеся к платформе SF32. Статьи глоссария ссылаются на страницы, где термин объясняется подробно. Эта страница — справочник для быстрого поиска, а не замена полного контекста.

## Архитектура и обработка данных { #architecture-and-processing }

* **MCU** — **Microcontroller Unit (микроконтроллер).** Интегральная схема, объединяющая ядро CPU, память и программируемые периферийные устройства ввода-вывода. Она рассчитана на выполнение специализированной прошивки с небольшими накладными расходами, а не универсальной операционной системы.
* **SoC** — **System on Chip (система на кристалле).** Интегральная схема, объединяющая необходимые электронные схемы и компоненты компьютерной системы на одном кристалле. В этой документации микросхемы SF32 относятся к MCU: они предназначены для прошивок микроконтроллерного класса, а не для полноценной среды ОС процессора приложений.
* **Arm Cortex-M33** — 32-разрядная процессорная архитектура Armv8-M Mainline, на которой построены прикладные и Bluetooth-ядра SF32. В отличие от более ранних Cortex-M3/M4, Armv8-M Mainline поддерживает опциональное расширение безопасности TrustZone, изолирующее доверенный код и данные от недоверенных на аппаратном уровне. Наличие TrustZone зависит от конкретной реализации микросхемы и не гарантируется для каждого Cortex-M33; в текущих компонентах SF32LB52x–SF32LB58x эта функция не настроена. См. также описание STAR-MC1 ниже и [страницу микросхемы SF32LB52x](../sf32-products/chips/SF32LB52x.md).
* **STAR-MC1** — конфигурируемый IP встроенного CPU Armv8-M Mainline от Arm China, применяемый в совместимых устройствах SF32 как прикладной процессор класса Cortex-M33. Конфигурации CU, SP и SE различаются поддержкой кэша, TCM, XIPU и TrustZone; набор функций в конкретном компоненте SF32 зависит от устройства. В документации SiFli в зависимости от контекста встречаются названия «Arm Cortex-M33 STAR-MC1» и «Arm Cortex-M33». См. [страницу архитектуры STAR-MC1](../learn/architecture/star-mc1.md).
* **CDE** — **Custom Datapath Extension (расширение пользовательского тракта данных).** Механизм пользовательских инструкций Arm для ускорения отдельных операций. В материалах Arm China по STAR-MC1 примером CDE служит CRC32; наличие этой функции и программной поддержки в конкретном SF32 необходимо проверять отдельно.
* **DSP** — **Digital Signal Processor / digital signal processing (цифровой сигнальный процессор / цифровая обработка сигналов).** Расширения ядра Cortex-M33 для вычислительно интенсивных задач, например обработки аудио и объединения данных датчиков.
* **MPU** — **Memory Protection Unit (блок защиты памяти).** Аппаратный механизм, ограничивающий доступный коду диапазон памяти; применяется для изоляции сбоев и защиты.
* **HAL** — **Hardware Abstraction Layer (уровень аппаратной абстракции).** Слой SDK, предоставляющий периферию через единый API независимо от конкретного варианта микросхемы.
* **Ускоритель AI/ML** — аппаратный блок для ускорения задач искусственного интеллекта и машинного обучения, например инференса компактной нейросетевой модели. Наличие зависит от устройства; проверяйте выбранный компонент в селекторе продуктов и его техническом описании.

## Беспроводная связь { #wireless-connectivity }

* **BLE** — **Bluetooth Low Energy (Bluetooth с низким энергопотреблением).** Радиорежим Bluetooth с низким энергопотреблением, на котором строится большинство носимых и IoT-устройств SF32.
* **Wi-Fi** — Технология беспроводной локальной сети. Если в документации продукта SF32 указана поддержка внешнего Wi-Fi, устройство подключается через интерфейс SDIO. До фиксации проекта проверьте конкретный компонент, разводку платы, питание и программную поддержку.
* **Двухрежимный Bluetooth** — Поддержка BLE и классического Bluetooth (BR/EDR) одним радиотрактом. Это нужно, например, если одновременно требуются потоковое аудио (Classic Bluetooth или LE Audio) и канал управления с низким энергопотреблением. Поддерживается в SF32LB52x/56x/57x/58x; SF32LB55x поддерживает только BLE.
* **GAP** — **Generic Access Profile (профиль общего доступа).** Уровень Bluetooth, определяющий роли устройств, рекламные сообщения и установление соединения; основа любого приложения BLE.
* **GATT** — **Generic Attribute Profile (профиль общих атрибутов).** Уровень Bluetooth, определяющий структуру сервисов и характеристик, а также обмен данными, предоставляемыми устройством BLE.
* **Sibles** — Фреймворк сервисов GATT в SiFli-SDK, построенный поверх стандартного уровня GAP. Большинство Bluetooth-продуктов SF32 начинают с готового примера на Sibles, а не создают базу GATT с нуля. См. [обзор Bluetooth](../learn/bluetooth/overview.md).
* **LE Audio** — Более новый стандарт аудио на базе Bluetooth Low Energy, включающий кодек LC3 и режимы широковещательной передачи аудио Auracast; он отличается от аудиопрофилей Classic Bluetooth. Поддерживается в SF32LB52x/56x/57x/58x, но не в SF32LB55x. См. [Bluetooth Audio и LE Audio](../learn/bluetooth/processor.md).
* **OTA** — **Over-The-Air (обновление прошивки по беспроводному каналу).** Обновление прошивки устройства по беспроводному соединению, обычно BLE, вместо проводного.
* **DFU** — **Device Firmware Update (обновление прошивки устройства).** Общая категория механизмов и протоколов обновления прошивки; Bluetooth OTA обычно использует механизм DFU.

## Графика и дисплеи { #graphics-and-display }

* **ePicasso** — Собственный графический ускоритель SiFli 2D/2.5D для семейства SF32. Он снимает с прикладного CPU попиксельные операции: копирование изображений, смешивание, масштабирование, поворот и композицию слоёв. См. [страницу архитектуры ePicasso](../learn/graphics/epicasso-gpu.md).
* **eZip** — Собственный формат SiFli для сжатия графики и данных общего назначения без потерь; на поддерживаемых устройствах SF32 данные декодируются аппаратно. Для графики SiFli указывает коэффициент сжатия немного выше, чем у PNG; для других данных результат зависит от исходного содержимого. Поскольку сжатые ресурсы перед декодированием передаются по шине, eZip может снизить требуемую пропускную способность внешней PSRAM и NOR Flash.
* **TurboPixel** — Формат финального кадрового буфера с потерями и фиксированным коэффициентом сжатия на поддерживаемых компонентах SF32. extDMA сжимает отрисованный битмап в TurboPixel, а контроллер дисплея декодирует его, уменьшая требования к пропускной способности и объёму PSRAM. См. [страницу сжатия кадрового буфера TurboPixel](../learn/graphics/turbopixel.md).
* **LVGL** — **Light and Versatile Graphics Library (лёгкая универсальная графическая библиотека).** Открытый фреймворк встраиваемого UI, используемый в большинстве продуктов SF32 для прикладного пользовательского интерфейса; работает поверх рендеринга с ускорением ePicasso.
* **HMI** — **Human-Machine Interface (человеко-машинный интерфейс).** Общее название категории пользовательского интерфейса устройства: экран, сенсорное управление и кнопки.
* **Интерфейс дисплея RGB / DPI** — Параллельный интерфейс, напрямую передающий цветовые компоненты пикселей на совместимую панель или контроллер дисплея. Официальное название — **DPI (Display Pixel Interface)**; «RGB-интерфейс» — распространённое сокращение в проектировании плат. Обычно используются тактовый сигнал пикселей, сигналы горизонтальной и вертикальной синхронизации и несколько параллельных линий цветовых данных. По сравнению с последовательным интерфейсом DPI требует больше GPIO и более аккуратной разводки параллельных линий. Проверьте бюджет выводов выбранного корпуса и требования панели к таймингам.
* **Интерфейс дисплея MIPI** — Интерфейс, определённый стандартами MIPI Alliance и используемый совместимыми панелями с высокой пропускной способностью.
* **EPD** — **Electronic Paper Display (дисплей на электронной бумаге).** Технология отражающего дисплея, часто применяемая в экранах с низким энергопотреблением.
* **Интерфейс дисплея JDI** — Поддержка совместимых дисплеев JDI / Sharp Memory-in-Pixel, если она указана для выбранного устройства SF32.

## Аудио { #audio }

* **ADC / DAC** — **Analog-to-Digital / Digital-to-Analog Converter (аналого-цифровой / цифро-аналоговый преобразователь).** Тракт аудиовхода и аудиовыхода в компонентах SF32 со встроенными аудиофункциями. Специализированные аудио ADC/DAC есть в SF32LB52x/56x/57x/58x; в SF32LB55x их нет.
* **PDM** — **Pulse-Density Modulation (импульсно-плотностная модуляция).** Распространённый формат интерфейса цифрового микрофона, поддерживаемый наряду с I2S в компонентах SF32 с аудиофункциями. Один интерфейс PDM — не то же самое, что один микрофон: обычно к одному интерфейсу можно подключить до двух цифровых микрофонов. Они используют общий тактовый сигнал: один микрофон передаёт данные по нарастающему фронту, другой — по спадающему, благодаря чему разделяются левый и правый каналы. При выборе и сравнении учитывайте число интерфейсов PDM, а не число микрофонов.
* **I2S** — **Inter-IC Sound.** Стандартный цифровой аудиоинтерфейс для подключения кодеков, DAC и других аудиопериферийных устройств.

## Питание и надёжность { #power-and-reliability }

* **PMU** — **Power Management Unit (модуль управления питанием).** Встроенный в микросхемы SF32 блок стабилизации напряжения с выходами BUCK/LDO. В некоторых проектах для дополнительных линий питания его дополняют внешним PMIC SiFli, например SF30147C.
* **PMIC** — **Power Management IC (микросхема управления питанием).** Специализированная внешняя микросхема, обеспечивающая дополнительные стабилизированные линии питания сверх возможностей встроенного PMU MCU.
* **LDO** — **Low-Dropout regulator (линейный стабилизатор с малым падением напряжения).** Тип линейного стабилизатора; один из выходных каскадов встроенного PMU в компонентах SF32.
* **BUCK** — Импульсная (нелинейная) топология стабилизатора напряжения, также встроенная в PMU SF32. При высоком токе она эффективнее LDO.
* **TRNG** — **True Random Number Generator (генератор истинных случайных чисел).** Аппаратный источник энтропии, использующий физический тепловой шум для генерации криптографических ключей и реализации функций безопасности.
* **PSA** — **Platform Security Architecture (архитектура безопасности платформы).** Архитектура безопасности и программа сертификации Arm. На страницах некоторых чипов SF32 указан уровень **PSA Certified Level 1**. Проверяйте наличие и уровень сертификации для конкретного артикула по его официальной документации и не переносите этот статус на все семейство.

## Накопители и память { #storage-and-memory }

* **SRAM** — **Static RAM (статическая оперативная память).** Быстрая встроенная рабочая память для кода и данных приложения.
* **PSRAM** — **Pseudo-Static RAM (псевдостатическая оперативная память).** Внешняя память большей ёмкости, часто интегрированная в модули SF32 в составе System-in-Package. Она дополняет встроенную SRAM и используется для графических буферов и крупных приложений.
* **NOR / NAND Flash** — Два типа энергонезависимой флеш-памяти для прошивки и ресурсов. NOR обеспечивает быстрый произвольный доступ и часто используется для прямого выполнения кода (XiP, Execute-in-Place). NAND/SD-NAND жертвует скоростью произвольного чтения ради более высокой плотности и подходит для массового хранения изображений, шрифтов и журналов.
* **OPI / QPI / QSPI** — **Octal/Quad Peripheral (или Serial Peripheral) Interface (восьми- или четырёхлинейный периферийный/последовательный интерфейс).** Классы интерфейсов Flash и PSRAM по числу линий и пропускной способности: Quad использует 4 линии данных, Octal — 8. От этого зависит достижимая пропускная способность памяти.
* **eMMC** — **Embedded MultiMediaCard (встроенная мультимедийная карта).** Интерфейс управляемой NAND-памяти для проектов SF32, которым нужна повышенная ёмкость накопителя.

## Периферия и интерфейсы { #peripherals-and-interfaces }

* **GPIO** — **General-Purpose Input/Output (ввод-вывод общего назначения).** Настраиваемые цифровые выводы для простых сигналов, кнопок, светодиодов и программной эмуляции интерфейсов методом bit-banging.
* **I/O** — **Input/Output (ввод-вывод).** Общее название выводов и периферийных сигналов, через которые устройство обменивается данными или сигналами управления с системой.
* **UART** — **Universal Asynchronous Receiver/Transmitter (универсальный асинхронный приёмопередатчик).** Стандартный последовательный интерфейс консоли, отладочного вывода и простой связи точка-точка.
* **SPI** — **Serial Peripheral Interface (последовательный периферийный интерфейс).** Синхронная последовательная шина для дисплеев, Flash, датчиков и другой высокоскоростной периферии.
* **I2C** — **Inter-Integrated Circuit (межмикросхемная шина).** Синхронная многоточечная последовательная шина, часто используемая для датчиков и настройки низкоскоростной периферии.
* **SDIO** — **Secure Digital Input Output (ввод-вывод Secure Digital).** Хост-интерфейс, используемый в документированных проектах SF32 для подключения внешнего устройства Wi-Fi.
* **DCMI** — **Digital Camera Module Interface (интерфейс цифрового модуля камеры).** Параллельный интерфейс для подключения совместимого датчика изображения.
* **FreeIO** — Гибкая функция SiFli для назначения GPIO, позволяющая подключать поддерживаемые сигналы к подходящим выводам в рамках документированных ограничений устройства.
* **PTM** — **Peripheral Task Machine (машина задач периферии).** Аппаратная функция SiFli для детерминированной обработки периферийных задач на поддерживаемых устройствах.
* **RTC** — **Real-Time Clock (часы реального времени).** Периферийный блок отсчёта времени, который может продолжать работу или пробуждать систему независимо от основных тактовых доменов приложения.

## Аппаратура и производство { #hardware-and-manufacturing }

* **QFN** — **Quad Flat No-lead package (квадратный плоский корпус без выводов).** Тип корпуса микросхем SF32, обозначаемый числом выводов и размером корпуса, например QFN68.
* **BGA** — **Ball Grid Array package (корпус с шариковыми выводами).** Корпус с массивом шариков припоя на нижней стороне. Он обеспечивает компактный размер и большое число выводов, но требует трассировки выводов на PCB и сборки, рассчитанных на BGA.
* **BOM** — **Bill of Materials (ведомость материалов).** Формальный постатейный перечень компонентов, пассивных элементов и механических деталей, необходимых для производства собранной печатной платы (PCBA). Использование рекомендованных SiFli компонентов и модулей помогает снизить сложность BOM.
* **EDA** — **Electronic Design Automation (автоматизация проектирования электроники).** Категория ПО для создания схем, моделирования SPICE и проектирования печатных плат. SF32-специфичные посадочные места и символы см. на странице [библиотек EDA-инструментов](../hardware/cad-components/eda-tool-libraries.md).
* **AVL** — **Approved Vendor List (список одобренных поставщиков).** Список квалифицированных компонентов второго источника SiFli (кварцевые резонаторы, стабилизаторы, Flash и др.), проверенных с учётом электрических допусков аппаратуры SF32. См. [список одобренных поставщиков](../hardware/cad-components/sifli-approved-vendor-list.md).
* **EVB** — **Evaluation Board (оценочная плата).** Референсная или отладочная плата SF32 от SiFli для запуска и проверки проекта до готовности собственной аппаратуры.
* **FAE** — **Field Application Engineer (инженер по технической поддержке на местах).** Контакт SiFli по вопросам проектирования аппаратуры, которые не раскрыты в общедоступной документации.

## Программное обеспечение и инструменты { #software-and-tools }

* **SiFli-SDK** — Основной комплект средств разработки прошивки SiFli для компонентов SF32; большинство промышленных прошивок создаётся на базе этого референсного SDK производителя.
* **SiFli CodeKit** — Расширение VS Code для разработки с SiFli-SDK. Помогает создавать и настраивать проекты, собирать и прошивать их, а также отслеживать выполнение, не прибегая напрямую к инструментам командной строки.
* **RTOS** — **Real-Time Operating System (операционная система реального времени).** Класс ОС с детерминированным планированием и небольшими накладными расходами, используемый в прошивках SF32 через RTOS-интеграцию SiFli-SDK или Zephyr.
* **sftool** — Утилита SiFli командной строки для прошивки и восстановления плат SF32, включая восстановление плат, которые перестали загружаться.
