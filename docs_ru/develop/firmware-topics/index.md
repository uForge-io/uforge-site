# Темы разработки прошивки { #firmware-topics }

Эти темы применимы на разных платформах и охватывают решения по прошивке, которые помогают превратить примеры в готовый продукт: структура загрузки, разделы, OTA, USB, управление энергопотреблением, журналирование и анализ сбоев.

Прочитайте эти материалы до изменения структуры прошивки, поведения обновлений или политики энергосбережения. Такие ошибки не всегда мешают успешной сборке, но могут затруднить восстановление, отладку и выпуск продукта.

## Практическое правило { #practical-rule }

Перед изменением загрузки, OTA, файловой системы или работы с хранилищем изучите таблицу разделов и проверьте способ восстановления. Сбой приложения создает неудобства; ошибка в структуре загрузки или обновления может серьезно затруднить восстановление платы.

## Проверка готовности продукта { #product-readiness-checklist }

- [ ] Есть проверенная команда для полной прошивки устройства вне штатного OTA-процесса.
- [ ] Разметка разделов задокументирована в репозитории продукта.
- [ ] Проверено поведение при сбоях OTA/DFU.
- [ ] Если используется USB, задокументированы USB-дескрипторы и сведения о владельце VID/PID.
- [ ] Режимы энергосбережения измерены на реальном оборудовании.
- [ ] Журналы сбоев можно декодировать по бинарному файлу выпущенной версии.
- [ ] Процедуры прошивки на производстве и при разработке разделены.
