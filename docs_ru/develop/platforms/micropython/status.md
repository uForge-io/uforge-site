# Статус MicroPython { #micropython-status }

В проверенной документации SiFli и репозиториях OpenSiFli не удалось найти официальный порт MicroPython для SF32, образ прошивки или инструкцию по прошивке для конкретной платы.

Проверялись [открытые репозитории OpenSiFli на GitHub](https://github.com/OpenSiFli/) и [портал документации SiFli](https://docs.sifli.com/).

Это не доказывает, что частных или созданных сообществом экспериментов не существует. Однако до появления общедоступного образа прошивки или дерева исходного кода, на которое можно сослаться, сайт не должен представлять MicroPython как проверенный вариант разработки для SF32.

## Текущая рекомендация { #current-recommendation }

Пока не следует предлагать MicroPython конечным пользователям как поддерживаемый вариант для SF32. Оставьте эту страницу информацией о статусе и планах, пока не появится общедоступный артефакт, который разработчик сможет прошить и использовать для воспроизведения результата.

## Что должно быть в полноценном руководстве { #what-a-real-page-needs }

Прежде чем превращать эту страницу в полноценное руководство, SiFli следует опубликовать:

- Образы прошивки для разных плат и конфигураций памяти.
- Репозиторий исходного кода и инструкции по сборке.
- Команды прошивки и восстановления.
- UART-интерфейс REPL и скорость обмена в бодах.
- Ожидаемое стартовое сообщение MicroPython.
- Поддерживаемые API `machine`.
- Поведение файловой системы, безопасного режима и режима восстановления.
- Известные ограничения дисплея, Bluetooth, хранилища, USB и энергосбережения.

## Предлагаемый первый тест { #suggested-first-smoke-test }

Когда появится прошивка, первый тест следует выполнить только через последовательный интерфейс:

```python
import time

while True:
    print("Hello from SF32 MicroPython")
    time.sleep(1)
```

Проверяйте GPIO только после того, как будут документированы названия выводов.

## Минимальные критерии готовности { #minimum-acceptance-criteria }

Статусную страницу можно заменить руководством по началу работы с MicroPython, когда будут выполнены все условия:

- Опубликован общедоступный репозиторий или страница релиза.
- Есть бинарный образ для конкретной платы, как минимум для одной отладочной платы SF32.
- Документирована команда прошивки.
- Документированы порт REPL и скорость обмена в бодах.
- Есть способ восстановить прошивку SiFli-SDK.
- Опубликован список поддерживаемых API `machine`.
- Есть хотя бы один пример работы с GPIO, проверенный на реальном устройстве.

## Почему это важно { #why-this-matters }

Расплывчатая инструкция «скачайте образ MicroPython» не помогает начать работу. Разработчикам нужны точный образ, подходящая плата, инструмент прошивки, настройки REPL и способ восстановления. Без этого страница о MicroPython увеличивает нагрузку на поддержку вместо того, чтобы помогать.
