# Испытания Bluetooth с сигнализацией { #run-bluetooth-signaling-tests }

В режиме с сигнализацией между испытуемым устройством (DUT) и тестером радиосвязи устанавливается реальное Bluetooth-соединение. В SDK этот режим предназначен для проверки TX/RX на соответствие протоколу и квалификационных испытаний BQB/QDID. Он отличается от фирменных тестов без сигнализации и отдельных RF-тестов по конкретным параметрам.

## Подготовка к тесту { #test-setup }

Подготовьте DUT, тестер Bluetooth-связи (в руководстве SiFli используется CMW500), ПК с Windows, кабель USB-UART и RF-коаксиальный кабель. Обеспечьте доступ к `VBAT`, `GND`, а также сигналам TX/RX UART1 на DUT. Распиновка UART1 по умолчанию зависит от корпуса:

<div align="center" markdown>

<em>Таблица: Распиновка UART1 по умолчанию для устройств и корпусов</em>

| Устройство/корпус | UART1 TX | UART1 RX |
|---|---|---|
| SF32LB52x | PA19 | PA18 |
| SF32LB551 | PA17 | PA18 |
| SF32LB555/557 | PA34 | PA30 |
| SF32LB56xU (QFN) | PA17 | PA18 |
| SF32LB56xV (BGA) | PA34 | PA30 |
| SF32LB57x | PA19 | PA18 |
| SF32LB58x | PA32 | PA31 |

</div>

Если в проекте используется другая распиновка, руководствуйтесь фактической конфигурацией его выводов. Для испытаний BLE с сигнализацией требуется последовательное соединение управления EUT с тестером. В режиме Classic BT тестер может управлять DUT по радиоканалу после перехода устройства в тестовый режим.

Главное различие — в топологии управления: при BLE путь управления UART/HCI подключается к тестеру, а при Classic BT тестер обнаруживает DUT и подключается к нему по радиоканалу. Ниже приведены схемы из руководства SiFli для SF32LB52x; для других семейств используйте таблицу выводов целевого проекта.

!!! note "Область применимости по семействам"
    В таблице UART сведены распиновки по умолчанию для нескольких семейств и корпусов. Приведенные далее схемы подключения и снимки экрана тестера взяты из руководства SiFli для SF32LB52x. Они помогают понять путь сигнала, но не являются универсальной справкой по выводам или меню для любых корпусов.

## Перевод DUT в тестовый режим { #put-the-dut-into-test-mode }

### BLE { #ble }

1. Включите DUT и не допускайте перехода в сон при работе прошивки DFU/приложения.
2. Подключите UART1 к ПК и отправьте команду FinSH `bt_cm uart_dut` из SiFli_Trace или другой программы для работы с последовательным портом.
3. Переключите отображение терминала в шестнадцатеричный режим и проверьте ответ `04 0E 04 XX 03 0C 00`.
4. Отключите ПК и подключите тот же UART1 к порту управления EUT USB-to-RS232 на тестере.

![Ответ последовательного порта при входе в режим тестирования BLE](../../../../assets/develop/app-notes/bluetooth-signalling/figure_2-1.png){ loading="lazy" }
<div align="center"><em>Иллюстрация: пример из руководства для SF32LB52x — прежде чем переключать UART, убедитесь, что получен ответ `04 0E 04 XX 03 0C 00`.</em></div>

### Classic Bluetooth { #classic-bluetooth }

1. Включите DUT, оставив экран включенным, а процессор — в активном состоянии.
2. Подключите UART1 к ПК и отправьте `bt_cm dut`.
3. Убедитесь, что получен ответ `Write scan enable success`, затем подключите RF-коаксиальный кабель к тестеру. Перед переходом в другой тестовый режим перезагрузите DUT.

## Установление соединения с сигнализацией { #establish-the-signaling-connection }

В приложении `Bluetooth Signaling` тестера включите сигнализацию. Для BLE в разделе `EUT Control` выберите `USB-to-RS232 adapter`, скорость 1 000 000 бод и `Low Energy burst type`. Подключите UART1 DUT к тестеру, а RF-коаксиальный кабель DUT — ко входу RF тестера. Запустите `Connection Check` и дождитесь сообщения `LE comm test passed`. Для Classic BT установите `HW Interface` в `None (EUT Control off)`, найдите адрес DUT с помощью `Inquire` и выберите `Connect Test Mode`.

## Измерения TX { #run-tx-measurements }

Откройте `Bluetooth 1 Multi Eval.` и включите измерение. Выберите требуемый тип радиопосылки BLE 1M/2M или Classic BT BR/EDR, канал, тип пакета и длину полезной нагрузки. После установления соединения с сигнализацией BLE или BT используется один и тот же экран TX тестера.

## Измерение чувствительности RX { #run-rx-sensitivity-measurements }

Перед возвратом на экран сигнализации отключите TX, затем откройте `Bluetooth 1 RX Meas.`. Для Classic BT выберите BER, для BLE — PER; задайте канал и тип пакета, затем включите Rx Quality. Постепенно уменьшайте `Tx Level (CMW)` тестера. Измеренной чувствительности соответствует последнее значение, при котором индикатор BER/PER еще показывает действительный результат. Укажите, проводилось ли измерение по кабелю или в эфире, и учтите потери в кабеле.
