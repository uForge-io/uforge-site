# Практические руководства по SiFli-SDK { #sdk-application-notes }

На этой странице руководства по использованию SiFli-SDK сгруппированы по задачам разработки. Так вы быстрее найдете нужную процедуру и поймете, какие результаты проверки следует сохранить для продукта.

В статьях приведены практические рекомендации по интеграции, но они не заменяют руководство по SDK. Прежде чем применять настройки, API, примеры или процедуры испытаний, выберите целевое семейство чипов и версию SDK в официальном [руководстве по использованию SiFli-SDK](https://docs.sifli.com/projects/sdk/latest/sf32lb52x/app_note/index.html).

## Как пользоваться этими руководствами { #how-to-use-these-articles }

1. Начните со страницы, название которой соответствует текущей инженерной задаче.
2. Перед изменением примера или команды выполните указанные предварительные условия по проекту, плате, версии SDK, конфигурации и аппаратной части.
3. Сверьтесь со связанным источником SiFli-SDK: уточните точные пути, символы конфигурации, команды, API и версии инструментов.
4. Сохраните для проекта результаты проверки: плату, на которой проводились испытания, версию SDK, файлы конфигурации, тестовое оборудование и полученные результаты.

Для архитектурных решений, общих для разных платформ, обратитесь к разделу [Темы разработки прошивки](../../firmware-topics/index.md). Примеры, подтверждённые для SiFli-SDK или доступные в сообществе, собраны в разделе [Примеры](../../examples/index.md).
