# Обзор раздела «Начало работы» { #getting-started }

Для устройств SF32 доступно несколько вариантов разработки. Сейчас официальные средства для первого запуска — SiFli-SDK и CodeKit. Начиная с Zephyr v4.3.0, upstream-проект Zephyr сопровождает поддержку платы SF32LB52 DevKit LCD. OpenSiFli также предлагает бета-пакет ArduinoCore-zephyr и разрабатывает поддержку Rust для SF32LB52. Для MicroPython пока нужны официальные образы прошивки и инструкции для конкретных плат; до их появления полноценное проверенное руководство подготовить нельзя.

Сведения о рекомендуемом процессе разработки и текущем статусе каждой платформы см. в разделе [Обзор раздела «Разработка»](../develop/index.md). Используйте таблицу ниже только для выбора отправной точки: основным источником сведений о поддерживаемых платах и ограничениях служит страница соответствующей платформы.

## Что понадобится { #what-you-need }

Сначала выберите плату, поддерживаемую нужным программным путём. Подключение для прошивки и последовательной связи зависит от платы и фреймворка:

- Плата для разработки SF32, например [SF32LB52-DevKit-LCD](../sf32-products/devkits/SF32LB52-DevKit-LCD.md).
- Кабель с поддержкой передачи данных и интерфейс для прошивки/последовательной связи, указанный для этой платы и фреймворка. Для SF32LB52-DevKit-LCD в [инструкциях SiFli по подключению](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/quickstart/get-started.html) для последовательной загрузки используется USB-to-UART; не путайте его с отдельным USB-разъёмом для USB-функций.
- Компьютер под управлением Windows, macOS или Linux.
- Терминал последовательного порта, настроенный для консоли платы, чтобы просматривать загрузочные журналы и вывод примеров.

!!! tip "Используйте кабель для передачи данных"
    Кабели USB, предназначенные только для зарядки, часто становятся причиной проблем при первом запуске. Если плата включается, но последовательный порт не появляется, попробуйте заведомо исправный кабель для передачи данных и подключите его напрямую к USB-порту компьютера.

## Рекомендуемый первый запуск { #recommended-first-run }

Если вы впервые работаете с платой SF32, начните с [SiFli-SDK](sifli/getting-started-sifli-sdk.md). Это эталонный программный стек для SF32 и наиболее надёжная отправная точка, чтобы проверить плату, кабель, последовательный порт, процедуру прошивки и инструментарий.

После успешного запуска `hello_world` можно перейти к другой платформе, совместимой с конкретным оборудованием. Так у вас останется заведомо рабочая конфигурация, к которой можно вернуться, если дальнейшие эксперименты пойдут не так.

## Признаки успешного запуска { #what-success-looks-like }

После выполнения руководства по началу работы вы должны уметь:

- Собрать или запустить первый пример.
- Записать его на плату.
- Открыть консоль последовательного порта.
- Увидеть ожидаемый вывод: например, загрузочный журнал, `hello_world`, приглашение оболочки или баннер REPL.
- Зафиксировать название платы, последовательный порт и сработавшую команду прошивки.

Сохраните эти сведения в заметках проекта. Когда начнёте изменять примеры, они помогут быстрее восстановить рабочую конфигурацию.

## Перейти к руководствам { #continue-with-tutorials }

Когда вы сможете повторить критерии успешного первого запуска, переходите к [обзору практических руководств](tutorials/overview.md). Это следующий этап обучения: сначала работа с одной периферийной подсистемой, затем объединение нескольких подсистем и, наконец, проверка проекта на соответствие требованиям изделия.

## Когда переходить к разделу «Разработка» { #when-to-move-to-develop }

Раздел «Начало работы» считается пройденным, когда вы можете повторить заведомо успешный первый запуск. Раздел [«Разработка»](../develop/index.md) служит постоянным инженерным справочником по зрелости платформ, инструментам, прошивке и отладке, архитектуре прошивки и интеграции изделия. После первого запуска обратитесь к [справочнику по инструментам CodeKit](../develop/tools/codekit.md), чтобы разобраться в его роли в повседневной разработке; эта страница посвящена именно первому запуску.

## Что проверить перед выбором пути разработки { #before-choosing-a-development-path }

Прежде чем выбирать вариант разработки, убедитесь, что документация охватывает нужную плату и версию ПО. В частности, проверьте наличие:

- Публичной таблицы поддержки и уровня зрелости по платам для SiFli-SDK, CodeKit, Zephyr, Arduino и MicroPython.
- Точного идентификатора платы, используемого каждым поддерживаемым программным путем.
- Инструкций по прошивке и загрузке для Windows, macOS и Linux.
- Ожидаемого вывода последовательного порта для каждого первого примера.
- Инструкций по восстановлению после неудачной прошивки или использования недействительного образа.
- Перечня известных ограничений каждой платформы, особенно для Bluetooth, дисплея, хранилища, USB и режимов низкого энергопотребления.
- Примечаний к выпускам с указанием совместимых версий SDK, CodeKit, пакетов, образов прошивки и поддержки плат.

Не считайте, что вариант разработки, доступный для одной платы, подходит для всех плат SF32. Проверяйте конкретную плату и используемую версию ПО.
