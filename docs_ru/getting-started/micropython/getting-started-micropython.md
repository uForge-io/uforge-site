# MicroPython { #micropython }

MicroPython пока нельзя считать проверенным способом начать работу с SF32. В проверенных источниках SiFli и OpenSiFli на данный момент не описаны ни официальный образ прошивки для конкретной платы, ни процедура прошивки, ни конфигурация REPL.

Опираясь на [SiFli-SDK](../sifli/getting-started-sifli-sdk.md), получите воспроизводимую базовую конфигурацию платы, кабеля, последовательного порта и прошивки. Не используйте общие инструкции по установке MicroPython и не используйте образ, предназначенный для другого микроконтроллера или платы.

На странице [Статус MicroPython](../../develop/platforms/micropython/status.md) отслеживаются конкретные общедоступные материалы и критерии приёмки, необходимые, чтобы превратить эту страницу в практическое руководство.

!!! warning "Проверенного руководства по MicroPython пока нет"
    Для полноценного руководства по MicroPython на SF32 нужны образ прошивки, точно соответствующий плате и конфигурации памяти, команды прошивки и восстановления, порт REPL и скорость обмена (baud rate), описание работы файловой системы и достоверная матрица поддержки периферии. Пока этих материалов нет, на этой странице намеренно не приводятся инструкции по установке.

## Что нужно для проверенного руководства { #what-sifli-should-publish }

Прежде чем следовать будущему руководству по MicroPython для SF32, убедитесь, что в нём указаны совместимый образ прошивки для конкретной платы, проверенные команды прошивки и восстановления, порт REPL и скорость обмена (baud rate), поведение файловой системы и актуальная матрица поддержки периферии. Пока эти сведения не приведены на [странице статуса](../../develop/platforms/micropython/status.md), используйте описанную выше последовательность работы с SiFli-SDK для первого запуска.
