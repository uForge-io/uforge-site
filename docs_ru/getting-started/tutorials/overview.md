# Обзор практических руководств { #tutorials-overview }

Эти руководства помогут перейти от первой успешной прошивки платы к практической разработке под SF32. Материал сгруппирован по уровню инженерных задач: сначала проверьте отдельную периферию, затем объединяйте подсистемы и, наконец, соберите доказательства готовности изделия. В примерах за основу взяты образцы SiFli-SDK, но основные приёмы — проверка аппаратной части, сохранение заведомо рабочей конфигурации и измерение результата — применимы при работе с SF32 на любой программной платформе.

Практические руководства — второй этап раздела [«Начало работы»](../index.md). Сначала выполните критерии успешного первого запуска. Если вы выбираете микросхему, модуль или отладочную плату, перед началом серии изучите [семейство SF32](../../sf32-products/family/SF32_family.md).

## Что понадобится { #what-you-need }

Используйте отладочную плату SF32 с работающим USB-соединением для передачи данных и консолью последовательного порта. Например, `sf32lb52-lcd_n16r8` — это имя платы SF32LB52-DevKit-LCD_N16R8 в SiFli-SDK. В этой серии не предполагается, что одна плата поддерживает все упражнения: проверяйте список поддерживаемых платформ для каждого примера, а назначение выводов, периферию, дисплей, аудио и накопители сверяйте с соответствующей схемой и файлами платы. Точные идентификаторы плат SF32LB52x в SDK приведены в официальном [списке поддерживаемых плат](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/supported_boards/index.html).

Порядок выбран не случайно. Не начинайте с дисплея, BLE-сервиса или собственного драйвера, пока не проверены плата, прошивка, консоль последовательного порта и простой тест GPIO. Если на более позднем этапе возникнет сбой, вернитесь к последнему этапу, успешный результат которого ещё удаётся воспроизвести.

## Как работать с практическими руководствами { #how-to-use-each-tutorial }

В каждом упражнении указаны подходящий пример SDK, цель, критерий успеха и вероятные причины сбоев. Начинайте с названного примера, а не с пустого проекта; меняйте по одному аспекту поведения и сохраняйте заведомо рабочую сборку, прежде чем объединять функции. Для настроек, которые планируете использовать повторно, записывайте ревизию платы, версию SDK, имя платы и результат проверки.

Эти руководства не заменяют справочную документацию:

- Раздел [«Разработка»](../../develop/index.md) содержит инструкции по платформам и инструментам, материалы по прошивке и сводный указатель примеров SDK.
- [Учебные материалы](../../learn/graphics/overview.md) помогают принимать архитектурные решения по подсистемам, например по графическому тракту, работе Bluetooth и стратегии энергопотребления.
- В разделе [«Семейство SF32»](../../sf32-products/family/SF32_family.md) собраны сведения о выборе микросхемы, платах, проектировании аппаратной части и подготовке к серийному производству.
