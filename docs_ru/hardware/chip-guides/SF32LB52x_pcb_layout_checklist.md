# Руководство по проектированию аппаратной части SF32LB52x — чек-лист разводки PCB { #sf32lb52x-hardware-design-guide-pcb-layout-checklist }

!!! note "Часть руководства по проектированию аппаратной части SF32LB52x"
    На этой странице приведён поэлементный чек-лист разводки PCB из раздела 6.15. Вернитесь к [рекомендациям по разводке PCB](SF32LB52x_pcb_layout.md).

## 6.15. Чек-лист разводки PCB { #615-pcb-layout-checklist }

В исходном PCB-чек-листе нет столбца «Применимо к». Проверяйте каждый пункт только при наличии указанного вывода, цепи питания или функции в выбранном варианте и схеме; отсутствующие функции отмечайте как неприменимые. Сохраняйте исходные категории «Обязательно/Необязательно», но не считайте вторую категорию разрешением исключить компонент, необходимый по спецификации устройства.

!!! note "Обработка меди под кварцем в источнике"
    В пункте 3 раздела тактирования чек-листа не указано, на каких слоях требуется зона без меди. Руководство по применению батарейных вариантов противоречит само себе: в разделе тактирования рекомендуется удалить плоскость GND L2 под кварцем, тогда как раздел разводки PCB запрещает разрывы плоскостей и вырезы меди на верхнем и соседних слоях и показывает сплошную землю L2. В отдельном руководстве по разводке PCB также запрещены вырезы. До выпуска платы согласуйте с SiFli решение для выбранного стека слоев; не делайте вывод только по тексту чек-листа.

!!! note "Проверка ширины трасс"
    В исходной таблице указаны VCC ≥12 mil, трассы BUCK ≥10 mil и RF ≥10 mil. Раздел 6 содержит более строгие рекомендации для VCC и BUCK и рекомендует RF >10 mil. Соблюдайте оба набора применимых требований, включая волновое сопротивление RF 50 Ω; минимальное значение из чек-листа не заменяет подробные рекомендации по разводке.
