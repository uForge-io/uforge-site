# Руководство по проектированию аппаратуры SF32LB52x — память и производство { #sf32lb52x-hardware-design-guide-storage-manufacturing }

!!! note "Раздел руководства по проектированию аппаратуры SF32LB52x"
    На этой странице рассматриваются разделы 5.6 и 5.7 рекомендаций по проектированию схемы: память и подключение периферии, а также подготовка к производству. Перейдите к разделу [RF и пользовательские интерфейсы](SF32LB52x_schematic_rf_interfaces.md) или воспользуйтесь [контрольным списком для схемы](SF32LB52x_schematic_checklist.md) для проверки по отдельным пунктам.

### 5.6. Память и подключение периферии { #56-storage-and-connectivity }

#### 5.6.1. Память { #561-storage }

**Кратко**

- Для внешней загрузки можно использовать SPI NOR, SPI NAND и SD NAND; eMMC доступна в поддерживаемых вариантах с внешним стабилизированным питанием.
- Источник загрузки выбирается с помощью bootstrap-выводов `PA13` и `PA17`.
- В примечаниях по применению и руководстве по проектированию схем для переключения питания загрузочной памяти указан PA21, а в официальном контрольном списке для внешней флеш-памяти батарейных вариантов — `PA11`. Уточните у SiFli, какой вывод управления применим к конкретному проекту. Отдельно учитывайте: NOR Flash ёмкостью 32 MB и более, подключённая через MPI, должна отключаться и включаться сигналом PA21, чтобы после сброса или перехода в Hibernate ROM могла её распознать. Во время Hibernate VDD_SIP должен быть отключён, чтобы избежать утечки через линии ввода-вывода памяти в корпусе.

**Цель проектирования**

Выберите загрузочную память и схему управления её питанием с учётом объёма прошивки, стратегии обновления, режимов пониженного энергопотребления и надёжной загрузки из ROM после сброса или выхода из Hibernate.

##### 5.6.1.1. Описание интерфейсов памяти { #5611-storage-interface-description }

Микросхема поддерживает внешнюю память SPI NOR Flash, SPI NAND Flash и SD NAND Flash. **eMMC поддерживается только в вариантах 52B/D/E/G/J с внешним стабилизированным питанием.**

<div align="center"><em>Таблица 5.6-1: Подключение сигналов SPI NOR/NAND Flash</em></div>

<div align="center" markdown>

| Сигнал Flash | Вывод ввода-вывода | Описание |
|:---|:---|:---|
| CS# | PA12 | Выбор микросхемы, активный низкий уровень |
| SO | PA13 | Данные IO1 |
| WP# | PA14 | Данные IO2 / защита от записи |
| SI | PA15 | Данные IO0 |
| SCLK | PA16 | Последовательный тактовый сигнал |
| Hold# | PA17 | Данные IO3 / удержание |

</div>

<div align="center"><em>Таблица 5.6-2: Подключение сигналов SD NAND Flash и eMMC</em></div>

<div align="center" markdown>

| Сигнал SD NAND/eMMC | Вывод ввода-вывода | Описание |
|:---|:---|:---|
| SD2_CMD | PA15 | Команда |
| SD2_D1 | PA17 | Данные 1 |
| SD2_D0 | PA16 | Данные 0 |
| SD2_CLK | PA14 | Тактовый сигнал |
| SD2_D2 | PA12 | Данные 2 |
| SD2_D3 | PA13 | Данные 3 |

</div>

!!! note "Домены питания eMMC (только для вариантов с внешним стабилизированным питанием)"
    У eMMC два домена питания: VCC и VCCQ. Вариант 1: коммутировать оба домена одновременно. Ток в выключенном состоянии будет ниже, но выход eMMC из сна займёт больше времени, а среднее энергопотребление процессора возрастёт. Вариант 2: коммутировать только VCC, оставив VCCQ постоянно включённым. Ток в выключенном состоянии будет выше, чем в варианте 1, но eMMC быстрее выйдет из сна, а среднее энергопотребление процессора будет ниже.

!!! important "Подтяжки интерфейсов памяти"
    В примечании по применению вариантов с внешним стабилизированным питанием указано: NOR Flash не требует внешней подтяжки; SPI NAND требует подтяжку PA17 (Hold#); SD NAND — PA13 (D3) и PA15 (CMD); eMMC — PA17 (D1), PA13 (D3) и PA15 (CMD). Рекомендуется 7,5 kΩ. В примечании для батарейных вариантов указаны только посадочные места bootstrap на PA13/PA17; необходимость подтяжки PA15/CMD не уточняется. Не переносите требование PA15 для вариантов с внешним стабилизированным питанием на батарейные варианты без подтверждения; согласуйте подтягивающие резисторы для точной модели и загрузочного носителя с SiFli.

##### 5.6.1.2. Настройка загрузки { #5612-boot-configuration }

=== "SF32LB520/3/5/7 (питание от аккумулятора)"

    Микросхема может загружаться из встроенной в корпус SPI NOR Flash, внешней SPI NOR Flash, внешней SPI NAND Flash или внешней SD NAND Flash (**загрузка с eMMC не поддерживается**):

    - В SF32LB520Ux6 в корпусе установлена флеш-память, и по умолчанию загрузка выполняется с неё.
    - В SF32LB523/5/7Ux6 в корпусе установлена PSRAM, поэтому загрузка должна выполняться с внешнего накопителя.

    !!! note "Примечание об обозначениях в исходной документации SiFli"
        В этом разделе исходный документ SiFli использует суффиксы «SF32LB52AUx6» и «SF32LB52D/F/HUx6», не совпадающие с обозначениями B/D/E/G/J, приведёнными в начале того же документа. В этом руководстве различие описано по фактическому типу памяти в корпусе (Flash или PSRAM). При сомнениях проверьте точную модель микросхемы и её даташит.

!!! important "Уточните перекрывающиеся варианты загрузки"
    В примечаниях по применению для SD NAND указано H/X, а в отдельном руководстве по проектированию схемы SF32LB52x — H/L; в примечании для вариантов с внешним стабилизированным питанием для eMMC также указано H/H. Поскольку X обычно означает любой логический уровень, записи для вариантов с внешним стабилизированным питанием перекрываются, а источники не объясняют это различие. Не определяйте окончательные уровни bootstrap только по этим таблицам; уточните у SiFli точный вариант и поведение ROM. Эталонные схемы используют подтяжки 7,5 kΩ: на рисунке 5.6-1 они подключены к VDD33_VOUT1 с напряжением 3,3 V, а на рисунке 5.6-2 — к VDDIOA с напряжением 3,3 V.

##### 5.6.1.3. Управление питанием загрузочной памяти { #5613-boot-storage-power-control }

В имеющих более высокий приоритет руководствах OpenSiFli по применению и проектированию схем для управления ключом питания указан `PA21` (высокий уровень — включение, низкий — выключение); поэтому в этом руководстве `PA21` принят как подтверждённая источниками основа проектирования. В таблице контрольного списка, связанной из wiki SiFli, для внешней флеш-памяти батарейных вариантов указан `PA11`. Не заменяйте `PA21` на `PA11`, опираясь только на эту таблицу. В ней не уточняется, является ли `PA11` отдельным сигналом разрешения на плате или расхождением в назначении вывода; до выпуска платы согласуйте с SiFli точную сеть и вариант микроконтроллера.

=== "SF32LB520/3/5/7 (питание от аккумулятора)"

    - В SF32LB520Ux6 со встроенной в корпус флеш-памятью подавайте на VDD18_VOUT питание от VDD33_VOUT1 и отключите внутренний LDO VDD18_VOUT.
    - В SF32LB523/5/7Ux6 со встроенной в корпус PSRAM используйте внутренний LDO; на VDD18_VOUT также можно подать внешнее питание.
    - Внешнюю NOR Flash питайте от VDD33_VOUT1; дополнительный ключ питания не требуется.
    - Внешнюю SPI NAND или SD NAND питайте от VDD33_VOUT1 через дополнительный ключ.
    - В эталонной схеме предусмотрены посадочные места для подтягивающих резисторов на PA13 и PA17. Устанавливайте их в зависимости от типа накопителя; рекомендуемое сопротивление — 7,5 kΩ.

=== "52B/D/E/G/J (внешнее стабилизированное питание)"

    - Для модели со встроенной в корпус флеш-памятью (SF32LB52BU36) установите ключ питания на VDD_SIP.
    - Для моделей со встроенной в корпус PSRAM (SF32LB52DUB6/EUB6/GUC6/JUD6): если PVDD = 3,3 V и VDD_SIP питается от внутреннего LDO, ключ питания VDD_SIP необязателен; при PVDD = 1,8 V такой ключ необходим.
    - Питание внешнего накопителя не зависит от VDD_SIP — установите отдельный ключ питания.
    - Варианты подключения доменов питания VCC/VCCQ eMMC см. в разделе 5.6.1.1.
    - В примечании по применению для ключей питания, связанных с загрузкой, указан **PA21**; расхождение источников для внешней флеш-памяти батарейных вариантов описано выше.
    - NOR Flash объёмом 32 MB и более, подключённая через MPI (Memory Peripheral Interface — интерфейс для подключения SPI NOR/SPI NAND), должна отключаться сигналом PA21, чтобы при перезапуске MCU или переходе в Hibernate выйти из режима 4-байтовой адресации; иначе ROM не распознаёт флеш-память. NOR Flash объёмом до 16 MB может оставаться постоянно запитанной.
    - В эталонной схеме предусмотрены посадочные места для подтягивающих резисторов на PA13 и PA17. Устанавливайте их в зависимости от типа накопителя; рекомендуемое сопротивление — 7,5 kΩ.

**Типичные ошибки при проектировании памяти**

- Отсутствие bootstrap-резисторов или их установка для неподходящего источника загрузки.
- Неподключённый вывод управления ключом питания загрузочной памяти, подтверждённый источниками.
- Предположение, что eMMC поддерживается всеми вариантами.
- Постоянное питание NOR Flash большого объёма, хотя после перезапуска режим 4-байтовой адресации может помешать её распознаванию ROM.

**Контрольный список памяти**

- [ ] Источник загрузки выбран и задокументирован до начала разводки PCB.
- [ ] Варианты подтяжки bootstrap-выводов `PA13`/`PA17` соответствуют таблице загрузки.
- [ ] Все необходимые ключи питания загрузочной памяти управляются подтверждённым источниками выводом, определённым для данного варианта; расхождение PA11/PA21 согласовано с SiFli.
- [ ] Для проектов с внешним стабилизированным питанием оценены компромиссы при коммутации VCC/VCCQ eMMC.
- [ ] План первичного запуска охватывает настройку bootstrap-выводов, временные параметры питания накопителя, чтение его идентификатора и загрузку прошивки.

#### 5.6.2. Датчики { #562-sensors }

**Кратко**

- Датчики обычно подключаются по I2C или SPI. Отключайте питание неиспользуемых датчиков для снижения тока в режиме ожидания; датчики, необходимые для пробуждения, оставляйте в требуемом рабочем режиме.
- Выводы прерываний датчиков, способных будить MCU, необходимо назначить до фиксации разводки выводов.

**Цель проектирования**

Обеспечьте надёжное подключение питания, прерываний и шин датчиков, предусмотрев корректное отключение неиспользуемых датчиков в режимах пониженного энергопотребления.

К SF32LB52x можно подключать датчики сердечного ритма, акселерометры, геомагнитные датчики и другие подобные устройства. Для коммутации их питания выбирайте ключ с низким током покоя (Iq).

**Контрольный список датчиков**

- [ ] Назначены выводы шины, прерывания, сброса и включения питания каждого датчика.
- [ ] Ток покоя (Iq) и ток в выключенном состоянии ключа питания датчиков соответствуют целевому потреблению в режиме ожидания.
- [ ] Подтягивающие резисторы подключены к правильной шине напряжения ввода-вывода датчиков.
- [ ] План первичного запуска включает поиск устройств на шине, пробуждение по прерыванию и проверку циклов отключения/включения питания датчиков.

#### 5.6.3. Назначение выводов UART и I2C { #563-uart-and-i2c-pin-assignment }

**Кратко**

- Функции UART и I2C можно назначить на любые выводы PA.
- При выборе выводов всё равно нужно учитывать загрузку, пробуждение, отладку, производственные испытания и ограничения разводки платы.

**Цель проектирования**

Используйте гибкое назначение выводов для упрощения разводки, не занимая выводы, необходимые для выбора режима загрузки, пробуждения, отладки или подключения производственной оснастки.

SF32LB52x позволяет назначать функции UART и I2C на любые выводы PA.

**Контрольный список UART/I2C**

- [ ] Для каждой шины I2C правильно выбраны подтягивающие резисторы, домены напряжения и допустимая ёмкость шины.
- [ ] Выводы UART, необходимые для журналов, загрузки прошивки или внешних модулей, доступны.
- [ ] Мультиплексирование выводов не конфликтует с функциями bootstrap, пробуждения, дисплея, памяти и отладки.

#### 5.6.4. Назначение выводов GPTIM { #564-gptim-pin-assignment }

**Кратко**

- Функции GPTIM можно назначить на любые выводы PA.
- Функции таймера обеспечивают выходы PWM, захват входного сигнала, управление мотором, подсветкой и другие задачи синхронизации изделия.

**Цель проектирования**

Заранее зарезервируйте выводы таймера, чтобы на поздних этапах проекта не пришлось назначать функции PWM, захвата и синхронизации на неудобные для разводки выводы или выводы, конфликтующие с пробуждением.

SF32LB52x позволяет назначать функции GPTIM на любые выводы PA.

**Контрольный список GPTIM**

- [ ] Каналы таймера, необходимые для PWM, захвата или контуров управления, перечислены в таблице назначений выводов.
- [ ] Выводы GPTIM не конфликтуют с требованиями к подсветке, двигателю, отладке или памяти.
- [ ] План первичного запуска предусматривает проверку частоты PWM, диапазона коэффициента заполнения и полярности сигнала на выводе.

### 5.7. Подготовка к производству { #57-manufacturing }

#### 5.7.1. Интерфейс отладки и загрузки прошивки { #571-debug-and-download-interface }

**Кратко**

- После подачи питания на `PA18` и `PA19` по умолчанию включён DBG_UART; эти выводы мультиплексируются с SWD.
- На каждой опытной и серийной плате предусмотрите физический доступ к выводам отладки и загрузки прошивки.

**Цель проектирования**

Обеспечьте возможность загрузки прошивки, просмотра отладочных журналов, пошаговой отладки и восстановления после сбоя даже после того, как определены корпус устройства и производственная оснастка.

SF32LB52x поддерживает интерфейс DBG_UART для загрузки прошивки и отладки. Его можно подключить к ПК через адаптер UART–USB с уровнем сигнала 3,3 V. Интерфейсы SWD и DBG_UART мультиплексируются на выводах PA18 и PA19. После включения по умолчанию активен DBG_UART; он поддерживает пошаговую отладку и вывод журналов.

Подробности пошаговой отладки и вывода журналов через DBG_UART приведены в руководствах SFtool и Impeller.

<div align="center"><em>Таблица 5.7-1: Подключение отладочного порта</em></div>

<div align="center" markdown>

| Сигнал отладки | Вывод | Описание |
|:---|:---|:---|
| DBG_UART_RXD | PA18 | Приём данных DBG_UART |
| DBG_UART_TXD | PA19 | Передача данных DBG_UART |

</div>

**Контрольный список отладки**

- [ ] Выводы `PA18`/`PA19`, земля и необходимые опорные линии питания выведены на контактные площадки или разъём.
- [ ] Доступ для отладки сохраняется после установки корпуса, аккумулятора и дисплея.
- [ ] Уровень UART 3,3 V совместим с выбранным адаптером или производственной оснасткой.
- [ ] Описан способ восстановления платы, если она не может запустить прикладную прошивку.

#### 5.7.2. Программирование в производстве и калибровка кварца { #572-production-flashing-and-crystal-calibration }

**Кратко**

- Для программирования и калибровки кварца в производстве необходимы стабильное питание, доступ к DBG_UART, PA01 и точки контроля питания и земли.
- Доступ производственной оснастки следует предусмотреть до фиксации механического контура PCB и конструкции корпуса.

**Цель проектирования**

Обеспечьте программирование, калибровку и восстановление каждой серийной платы без ручной пайки и разборки устройства.

SiFli предоставляет автономный загрузчик для записи производственной прошивки и калибровки кварца. В проекте аппаратуры предусмотрите как минимум следующие контрольные точки: PVDD/VBAT, GND, AVDD33, DBG_UART_RXD, DBG_UART_TXD и PA01. Подробное описание программирования и калибровки см. в документе «Offline Downloader User Guide», входящем в комплект разработчика.

**Контрольный список производства**

- [ ] Предусмотрены контрольные точки PVDD/VBAT, GND, AVDD33, DBG_UART_RXD, DBG_UART_TXD и PA01.
- [ ] После механической сборки контрольные площадки доступны предусмотренной производственной оснастке.
- [ ] Совместно с производством определены порядок калибровки кварца и критерии успешного/неуспешного прохождения.
- [ ] Записи о программировании, калибровке и функциональных испытаниях можно связать с ревизией платы.
