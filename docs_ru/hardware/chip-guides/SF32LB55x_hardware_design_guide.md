# Руководство по проектированию аппаратуры SF32LB55x { #sf32lb55x-hardware-design-guide }

## 1. Введение { #1-introduction }

В этом руководстве собраны рекомендации и справочные материалы по аппаратной части изделий на базе универсального семейства микроконтроллеров SF32LB55x для AIoT. Оно предназначено для инженеров по аппаратуре, проектировщиков PCB и разработчиков продуктов: BLE-носимых устройств, устройств с несколькими датчиками и питанием от батареи, средств мониторинга здоровья и компактных систем с сетевым подключением.

Руководство охватывает весь процесс разработки аппаратуры: выбор корпуса, проектирование питания, тактовые цепи, разводку RF-тракта, внешнюю память, интерфейсы дисплея, источники пробуждения, датчики, аудио, доступ для отладки, разводку PCB, проверку и подготовку к производству. Применение этих рекомендаций помогает снизить риски при разработке схемы и разводке платы, сохранить низкое энергопотребление и учесть требования SF32LB55x к корпусу, питанию, памяти, RF и интерфейсам.

Предполагается, что читатель знаком с основами разработки встроенной аппаратуры и создания принципиальных схем. Это руководство дополняет техническое описание SF32LB55x, руководство пользователя, официальное аппаратное руководство по применению, референсные проекты и список одобренных поставщиков SiFli (AVL). Эти официальные материалы остаются первоисточниками для электрических характеристик, мультиплексирования выводов, размеров корпусов, квалификации компонентов и производственных ограничений.

В SF32LB55x используется историческая система суффиксов. Наличие интерфейсов, возможности, зависящие от корпуса, и точную конфигурацию памяти определяйте по полному заказному номеру и документации на корпус, а не только по суффиксу.

## 3. Обзор устройства { #3-device-overview }

### 3.1. Архитектура { #31-architecture }

SF32LB55x предназначен для энергоэффективных устройств AIoT, которым нужно быстро реагировать на действия пользователя и при этом потреблять мало энергии в режимах ожидания и сна. В микросхеме интегрированы энергоэффективный Bluetooth-трансивер версии 5.2, управление питанием, а также интерфейсы памяти и дисплея. При разработке аппаратуры необходимо учесть корпус, линии питания PMU, режим загрузки, две цепи кварцевых резонаторов, согласование RF-тракта, внешнюю память, выбор дисплея MIPI/SPI/MCU8080/JDI, подключение GPADC и датчиков, внешнее Bluetooth-аудио, доступ для отладки и прошивки, а также калибровку на производстве.

Подключение памяти включает несколько интерфейсов QSPI, независимый интерфейс OPI-PSRAM и поддержку SD/eMMC. Конфигурация NOR Flash и PSRAM, встроенных в корпус, зависит от точного заказного номера. Интерфейсы памяти и дисплея также зависят от корпуса. BGA145 поддерживает один канал внешней OPI-PSRAM, а BGA169 — два. Интерфейс MIPI DSI с двумя линиями данных доступен в BGA145 и BGA169, но не в QFN68L. Перед распределением выводов для внешних компонентов проверьте схему выводов и конфигурацию памяти внутри корпуса для точного заказного номера.

### 3.3. Основные аппаратные возможности { #33-major-hardware-features }

- Варианты корпусов QFN68L, BGA145 и BGA169.
- Требования к проектированию с кварцевыми резонаторами 48 MHz и 32,768 kHz.
- Энергоэффективный Bluetooth-трансивер версии 5.2, требования к согласованию RF-тракта и разводке антенны.
- Интерфейсы OPI PSRAM, QSPI NOR/NAND Flash и PSRAM, SDIO eMMC или Micro SD; встроенная память зависит от точного заказного номера.
- Варианты дисплея MIPI DSI, SPI/QSPI, MCU8080 и JDI.
- Рекомендации по кнопке пробуждения, вибромотору, прерыванию пробуждения, GPADC, датчикам и внешнему Bluetooth-аудио.
- Поддержка DBG-UART, SWD, программирования на производстве и калибровки кварцевого резонатора.

### 3.4. Типовые применения { #34-typical-applications }

К типичным областям применения относятся носимые устройства в форме браслета, интеллектуальные мобильные устройства, продукты для умного дома и другие энергоэффективные разработки AIoT.

## 4. Краткий обзор проекта { #4-design-at-a-glance }

### 4.1. Краткая инженерная сводка { #41-engineering-summary }

<div align="center"><em>Таблица 4.1-1: краткая сводка по проектированию SF32LB55x</em></div>

<div align="center" markdown>

| Параметр | Основной фокус |
|:---|:---|
| Корпус | Выберите QFN68L или BGA до назначения выводов и определения структуры слоев PCB. |
| Питание | Проверьте линии PMU, остальные выводы питания, необходимые конденсаторы, POR/BOR/reset и режим BUCK. |
| Тактирование | Используйте кварцевые резонаторы 48 MHz и 32,768 kHz, соответствующие требованиям CL, ppm и ESR. |
| RF | Разместите согласующую цепь рядом с микросхемой и минимизируйте помехи в антенном тракте с волновым сопротивлением 50 Ω. |
| Память | Планируйте энергозависимую OPI/QSPI PSRAM отдельно от загрузочного и постоянного хранилища на QSPI Flash или SDIO eMMC/Micro SD; проверьте поддержку корпусом и режимом загрузки. |
| Дисплей | Заранее выберите MIPI DSI, SPI/QSPI, MCU8080 или JDI, поскольку группы выводов и разводка различаются. |
| Производство | Предусмотрите доступ к DBG-UART, SWD, выбору режима загрузки, питанию и точкам калибровки RF/кварца. |

</div>

### 4.2. Этапы разработки аппаратуры { #42-hardware-design-flow }

1. Подтвердите корпус, стратегию работы с памятью, интерфейс дисплея и целевой уровень энергопотребления.
2. Определите схему питания, линии PMU, работу BUCK/LDO и цепь сброса.
3. Выберите кварцевые резонаторы, топологию согласования RF-тракта и ограничения по разводке антенны.
4. Назначьте выводы памяти, дисплея, пробуждения, датчиков, аудио, отладки и производственных тестов.
5. Зафиксируйте структуру слоев PCB, fanout, импеданс и ограничения для ESD, RF и высокоскоростных интерфейсов.
6. Проверьте список из раздела 7 до фиксации схемы, выпуска разводки и начала EVT.

### 4.3. Комплект материалов для проверки { #43-review-evidence-pack }

До этапа EVT сохраните версии технического описания и руководства пользователя, чертеж корпуса, PDF схемы, структуру слоев PCB, отчет по импедансу, отчеты DRC/ERC, схему питания, таблицу режимов загрузки, снимки разводки RF-тракта и кварцевых резонаторов, снимки разводки памяти и дисплея, а также план размещения контрольных точек для производства.

### 4.4. Работа с контрольными списками { #using-the-checklists }

В руководстве предусмотрены два уровня контрольных списков. Краткий список в разделе 7 содержит наиболее критичные пункты для быстрой самостоятельной проверки. [Контрольный список для схемы](SF32LB55x_schematic_checklist.md) (раздел 5.8) и раздел 6.4 [Рекомендаций по разводке PCB](SF32LB55x_pcb_layout.md) полностью, пункт за пунктом, воспроизводят *SF32LB55x Schematic & PCB Checklist* (V1.0, 2026-01-21), опубликованный вместе с материалами по проектированию аппаратуры в [разделе wiki SiFli с руководствами по проектированию микросхем][Раздел wiki SiFli с руководствами по проектированию микросхем]. Чек-лист охватывает устройства 551/555/557 и вариант SS6600A8.

Для каждого пункта указаны применимые группы вариантов и категория: обязательный (должен быть успешно пройден до выпуска) или необязательный (рекомендуется, если используется соответствующая функция). Цветной текст и текст на <span class="flag-yellow">желтом фоне</span> сохраняют выделения исходной рабочей книги. Поскольку в ней не указаны причины каждого выделения, считайте их дополнительными отметками для проверки, а не заменой остальных пунктов таблицы.

Используйте [контрольный список для схемы](SF32LB55x_schematic_checklist.md) при проверке схемы до начала разводки PCB. Список проверки разводки PCB (раздел 6.4) используйте при проверке платы до выпуска Gerber-файлов. На практике каждую проверку обычно проводят дважды: сначала инженер-разработчик, затем независимый проверяющий до фиксации проекта или передачи в производство.

Для максимальной пользы используйте список как форму регистрации результатов проверки, а не как перечень для чтения:

1. Сначала подтвердите точный артикул компонента и корпус.
2. Во время проверки отмечайте каждый пункт как пройденный, не пройденный или неприменимый, а не просто читайте таблицу.
3. Сверяйте пункты о дисплее, памяти, пробуждении и низком энергопотреблении с соответствующими разделами руководства по проектированию аппаратуры.
4. Запишите в примечаниях допущения, связанные с корпусом, в частности BGA или QFN, дисплей DSI или SPI, а также использование QSPI2/QSPI3 для памяти.
