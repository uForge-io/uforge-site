# Руководство по проектированию аппаратуры SF32LB56x { #sf32lb56x-hardware-design-guide }

## 1. Введение { #1-introduction }

В этом руководстве собраны рекомендации и справочные материалы для продуктов на базе семейства микроконтроллеров SF32LB56x, оптимизированных для графических приложений AIoT. Оно предназначено для инженеров-разработчиков аппаратуры, проектировщиков PCB и разработчиков продуктов: смарт-часов, подключенных HMI-систем, медицинских устройств и устройств для здравоохранения, промышленных портативных приборов, измерительных устройств, а также дисплеев для электровелосипедов и электросамокатов.

Руководство охватывает весь процесс разработки аппаратуры для вариантов SF32LB56xU и SF32LB56xV: выбор корпуса, питание PMIC и процессора, сброс, режим загрузки, режимы работы, кварцевые резонаторы, RF, дисплей, память, аудио, датчики, планирование выводов UART/I2C/GPTIM, разводку PCB, проверку и подготовку к производству. Соблюдение рекомендаций помогает снизить риски при разработке схемы и разводке платы, сохранить низкое энергопотребление и учитывать различия вариантов U и V на всех этапах проекта.

Предполагается, что читатель знаком с основами разработки встроенной аппаратуры, создания принципиальных схем и разводки PCB. Это руководство дополняет аппаратные рекомендации, технические описания, руководства пользователя и референсные проекты для SF32LB56xU и SF32LB56xV, а также список одобренных поставщиков SiFli (AVL). Именно эти официальные материалы являются первоисточниками для электрических характеристик, мультиплексирования выводов, размеров корпусов, квалификации компонентов и производственных ограничений.

## 3. Обзор устройства { #3-device-overview }

### 3.1. Архитектура { #31-architecture }

SF32LB56x предназначен для устройств с более развитыми дисплеями и HMI, чем узлы датчиков, использующие только BLE. В официальных аппаратных руководствах по вариантам U и V рассматриваются одни и те же инженерные вопросы: распределение питания на базе PMIC, кварцевые резонаторы 48 МГц и 32,768 кГц, проектирование RF-тракта, выбор интерфейсов дисплея и памяти, аудио, выводы PBR, датчики, планирование UART/I2C/GPTIM, отладка и программирование, а также калибровка кварца на производстве.

### 3.3. Основные аппаратные возможности { #33-major-hardware-features }

- Распределение питания с PMIC на примере SF30147C.
- Требования к кварцевым резонаторам 48 МГц и 32,768 кГц, а также рекомендуемые модели.
- Проектирование Bluetooth RF-тракта и требования к согласованию антенны.
- Дисплей SPI/QSPI и JDI для варианта U; SPI/QSPI, MCU8080, DPI и JDI для варианта V.
- Варианты внешней памяти и загрузочного хранилища, включая интерфейсы SDIO/eMMC/SD NAND.
- Кнопки, вибромотор, аудиоинтерфейс, выводы PBR, датчики, UART/I2C, GPTIM, отладка/программирование и калибровка.

### 4.2. Этапы разработки аппаратуры { #42-hardware-design-flow }

1. Выберите вариант U или V, корпус, интерфейс дисплея, вариант памяти и целевой процесс изготовления PCB.
2. Определите схему распределения питания от PMIC, питание процессора, сброс, зарядку и управление режимами низкого энергопотребления.
3. Выберите кварцевые резонаторы, согласование RF-тракта, а также схемы дисплея, памяти, аудио, датчиков, кнопок, вибромотора и PBR.
4. Зафиксируйте назначение выводов и проверьте конфликты между дисплеем, памятью, аудио, отладкой, пробуждением и производственными функциями.
5. Проверьте fanout, структуру слоев, импеданс, RF-тракт, тактовые сигналы, USB/SDIO, аудио, DC-DC-преобразователи и защиту ESD.
6. Проведите проверку по контрольному списку до фиксации схемы, выпуска разводки, этапа EVT и передачи оснастки в производство.

### 4.3. Комплект материалов для проверки { #43-review-evidence-pack }

До этапа EVT сохраните версии исходных документов для вариантов U/V, версии технического описания и руководства пользователя, PDF схемы, структуру слоев PCB, данные о возможностях процесса производства, отчеты DRC/ERC, конфигурацию PMIC, схему питания, конфигурацию загрузки и памяти, снимки разводки дисплея и размещения RF-тракта/кварцевых резонаторов, снимки аудио- и аналоговых участков, а также план программирования и калибровки на производстве.

### 4.4. Работа с контрольными списками { #using-the-checklists }

В руководстве предусмотрены два уровня контрольных списков. Краткий список в разделе 7 содержит наиболее критичные пункты для быстрой самостоятельной проверки. [Контрольный список для схемы](SF32LB56x_schematic_checklist.md) (раздел 5.8) и раздел 6.3 [Рекомендаций по разводке PCB](SF32LB56x_pcb_layout.md) полностью, пункт за пунктом, воспроизводят *SF32LB56x Schematic & PCB Checklist* (V1.0, 2026-01-21), опубликованный вместе с материалами по проектированию аппаратуры в [разделе wiki SiFli с руководствами по проектированию микросхем][Раздел wiki SiFli с руководствами по проектированию микросхем]. Чек-лист охватывает семейства SF32LB56xU и SF32LB56xV, а также вариант SS6700A.

Для каждого пункта указаны применимые группы микросхем и категория: обязательный (должен быть выполнен до выпуска) или необязательный (рекомендуется, если соответствующий функционал используется). Цветной текст и текст на <span class="flag-yellow">желтом фоне</span> сохраняют исходные акценты в рабочей книге. Поскольку в ней не указаны причины каждого выделения, считайте такие отметки дополнительными предупреждениями, а не заменой остальных пунктов таблицы.

Используйте [контрольный список для схемы](SF32LB56x_schematic_checklist.md) при проверке схемы, до начала разводки PCB. Контрольный список разводки (раздел 6.3) используйте при проверке разводки, до выпуска файлов Gerber. На практике каждую такую проверку обычно выполняют дважды: сначала инженер-разработчик, затем независимый проверяющий до фиксации проекта или передачи в производство.

Чтобы получить максимальную пользу, используйте список как форму регистрации результатов проверки, а не как перечень для чтения:

1. Сначала подтвердите точный артикул компонента и корпус.
2. Во время проверки отмечайте каждый пункт как выполненный, невыполненный или неприменимый, а не просто читайте таблицу.
3. Сверяйте пункты о дисплее, памяти, пробуждении и низком энергопотреблении с соответствующими разделами руководства по проектированию аппаратуры.
4. Запишите в примечаниях допущения, связанные с корпусом и вариантом: SF32LB56xU или SF32LB56xV, QFN или WBBGA, дисплей DSI или SPI, использование SD2/MPI3 для памяти.
