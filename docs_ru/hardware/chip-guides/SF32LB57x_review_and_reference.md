    На этой странице рассматриваются разделы 7–10: самопроверка проекта заказчика, связанные документы и справочные материалы, приложения и история версий. Вернитесь к [рекомендациям по разводке PCB](SF32LB57x_pcb_layout.md).

## 7. Самопроверка проекта заказчика { #7-customer-design-self-check }

Заполните этот контрольный список до запроса проверки принципиальной схемы или разводки PCB, а также до принятия решения о выпуске проекта на этап EVT. Ответственный со стороны заказчика должен зафиксировать результат и подтверждающие материалы по каждому пункту и, при необходимости, приложить ссылки на страницы схемы, снимки PCB, результаты измерений или замечания по итогам проверки.

### 7.1. Корпус и номер изделия { #71-package-and-part-number }

- [ ] Подтвердите заказной номер микросхемы, семейство питания, корпус и распиновку.
- [ ] Убедитесь, что символ схемы и посадочное место на PCB соответствуют даташиту.
- [ ] Проверьте контактные площадки QFN<!-- BGA-ONLY -->/BGA<!-- /BGA-ONLY -->, трафарет, открытую площадку и конструкцию переходных отверстий.

### 7.2. Питание { #72-power }

- [ ] Напряжение и нагрузка на каждом выводе питания не превышают заданных пределов; номиналы и расположение конденсаторов соответствуют даташиту.
- [ ] Дроссель BUCK, конденсаторы и трассировка цепи обратной связи соответствуют требованиям к разводке.
- [ ] Встроенные выходы LDO не используются как источники питания для периферии с высоким потреблением тока.
- [ ] Цепи питания соответствуют выбранному семейству. Проверьте применимые подключения зарядного устройства/OVP, VBUS, VBAT, VCC и/или PVDD по таблице питания для конкретного корпуса и варианта; не смешивайте топологии вариантов с питанием от аккумулятора и 3,3 V.
- [ ] Питание периферии можно отключать, а состояния по умолчанию безопасны.

### 7.3. Тактирование { #73-clocks }

- [ ] Кварцы на 48 MHz и 32,768 kHz соответствуют рекомендуемым параметрам.
- [ ] Кварцы размещены рядом с микросхемой; вокруг них определены зоны запрета (keep-out).
- [ ] Трассы кварцев удалены от источников помех: цепей питания, RF, USB, SDIO, дисплея и зарядного устройства.

### 7.4. Память и загрузка { #74-storage-and-boot }

- [ ] Если выбранное изделие содержит память в корпусе, подтверждены её конфигурация и влияние на внешние интерфейсы памяти и выводы именно для этого корпуса и варианта.
- [ ] Правильно выбраны тип внешнего носителя загрузки, подтягивающие резисторы, управление питанием и состояние по умолчанию.
- [ ] Предусмотрены конфигурация загрузки и контрольные точки для загрузки прошивки и отладки.

### 7.5. RF { #75-rf }

- [ ] Трасса подвода сигнала к антенне рассчитана на контролируемый импеданс 50 Ω.
- [ ] π-образная согласующая цепь размещена рядом с микросхемой.
- [ ] Для трассы RF предусмотрены непрерывный опорный слой земли и экранирование переходными отверстиями.
- [ ] RF изолирован от источников помех и высокоскоростных интерфейсов.

### 7.6. Дисплей и сенсорный экран { #76-display-and-touch }

- [ ] Интерфейс дисплея, разрешение и группа выводов соответствуют требованиям панели.
- [ ] Питанием дисплея, подсветки и сенсорного экрана можно управлять.
- [ ] Если требуется пробуждение по касанию, линия прерывания сенсорного экрана подключена к GPIO с поддержкой пробуждения.
- [ ] FPC и высокоскоростные трассы дисплея удалены от RF.

### 7.7. Аудио и аналоговые сигналы { #77-audio-and-analog }

- [ ] Развязка MIC_BIAS, AUD_VREF и AVDD33_AUD выполнена правильно.
- [ ] Для аналогового входа правильно реализованы блокировка постоянной составляющей и фильтрация.
- [ ] Дифференциальная трассировка DACP/DACN и согласующая цепь выполнены правильно.
- [ ] Правильно выбраны входное напряжение GPADC, делитель напряжения, фильтрация и экранирование.

### 7.8. Общие интерфейсы { #78-general-interfaces }

- [ ] Правильно выполнены соединения и согласованы уровни IO для UART, I2C, SPI, SDIO, USB и CAN.
- [ ] Питание подтягивающих резисторов I2C переключается синхронно с питанием IO соответствующего периферийного устройства, чтобы при отключении домена не возникал ток утечки.
- [ ] При необходимости предусмотрены защита USB от ESD, дифференциальная трассировка с импедансом 90 Ω и обнаружение пробуждения по VBUS.
- [ ] Для внешних сигналов пробуждения используются выводы с поддержкой этой функции.

### 7.9. Производство и надёжность { #79-production-and-reliability }

- [ ] Предусмотрены тестовые точки DBG-UART, SWD, режима загрузки, PA00, PA01, PA34, питания и земли.
- [ ] Тестовые точки соответствуют требованиям к пробникам производственной оснастки.
- [ ] Проверена стратегия защиты от ESD, EOS, OVP, переполюсовки и импульсных перенапряжений.
- [ ] Можно выполнить производственную загрузку прошивки, калибровку кварцев и RF-тестирование.

### 7.10. Критерии утверждения и выпуска проекта { #710-review-release-criteria }

Перед окончательной фиксацией проекта убедитесь, что выполнены следующие критерии:

- [ ] Все применимые пункты закрыты и подтверждены ссылками на страницы схемы, снимками PCB, результатами измерений или замечаниями по проверке; для пунктов, отмеченных как неприменимые, указано обоснование.
- [ ] Для каждого отклонения от даташита или референсного проекта указано обоснование, относящееся к конкретному проекту.
- [ ] Ответственные специалисты проверили RF, кварцы, зарядку, питание, USB, дисплей, аудио и контрольные точки для производственных испытаний.
- [ ] В бюджет тока в режиме низкого энергопотребления включены токи ожидания всех периферийных устройств, токи подтягивающих резисторов и ток покоя Iq регуляторов.
- [ ] Для запуска EVT доступны средства загрузки прошивки, получения журналов, измерения тока, сброса и управления загрузкой.

### 9.1. Приложение A. Типичное устройство на базе SF32LB57x { #appendix-a-a-typical-sf32lb57x-product }

Типовое изделие на базе SF32LB57x может включать MCU, систему питания, кварцы на 48 MHz и 32,768 kHz, согласующую RF-цепь и антенну, дисплей и сенсорный контроллер, загрузочную память, аудиовходы и аудиовыходы, датчики, необязательную камеру и необходимые интерфейсы USB/SDIO/CAN/UART/I2C/SPI. Предусмотрите также доступ к отладке и производственным испытаниям. Цепь зарядки, OVP, выбор силового ключа и токи утечки в режиме низкого энергопотребления проверяйте с учётом выбранной архитектуры питания.
