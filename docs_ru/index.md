# Создавайте встраиваемые устройства<br>нового поколения { #build-the-next-generationof-embedded-devices }

***μForge.io*** — платформа с открытым исходным кодом для разработки инновационных полупроводниковых решений. В основе — семейство микроконтроллеров SF32 компании SiFli со сверхнизким энергопотреблением. Платформа объединяет в одном месте полный набор ресурсов: от микросхем и модулей до отладочных плат, SDK, документации и референсных дизайнов, готовых к серийному производству. Всё это помогает разработчикам быстрее доводить подключённые, интеллектуальные и энергоэффективные встраиваемые продукты от идеи до производства, упрощая интеграцию.

## Почему стоит выбрать ***SF32***? { #why-choose-sf32 .uf-center-heading }

<div class="grid cards uf-why-grid" markdown>

- :fontawesome-solid-microchip:{ .uf-icon-blue } **Высокая производительность**

    Число ядер и набор функций зависят от конкретного устройства. В семействе есть одно-, двух- и трёхъядерные конфигурации; в нескольких сериях используются процессоры Cortex-M33 / STAR-MC1. Наличие кэша, FPU и MPU определяется конкретным чипом и реализацией SoC; сверяйтесь с документацией выбранной модели. В некоторых устройствах PSRAM объёмом до 64 MB размещена в составе корпуса.

- :fontawesome-brands-bluetooth:{ .uf-icon-blue } **Подключение Bluetooth**

    Режимы и функции зависят от семейства и конкретной модели. В зависимости от устройства могут поддерживаться Bluetooth Classic и LE, LE Audio и PHY дальнего действия. Точные возможности указаны на странице соответствующего чипа.

- :fontawesome-solid-cube:{ .uf-icon-purple } **Графическое ускорение**

    GPU 2D / 2.5D, контроллеры LCD и поддержка LVGL позволяют создавать насыщенные и плавные графические интерфейсы. В семействе доступны интерфейсы MIPI, RGB, QSPI, 8080, JDI и EPD; максимальное разрешение достигает 1280 × 720.

- :fontawesome-solid-volume-high:{ .uf-icon-pink } **Аудиоподсистема**

    Возможности аудио зависят от семейства и модели. Поддерживаемые устройства обеспечивают аналоговый звук, I²S, PDM и аппаратное ускорение цифровой обработки аудио.

- :fontawesome-solid-brain:{ .uf-icon-amber } **Аппаратное ускорение ИИ**

    В некоторых устройствах SF32 есть ускоритель нейронных сетей для TinyML и других задач инференса на периферии.

- :fontawesome-solid-leaf:{ .uf-icon-green } **Сверхнизкое энергопотребление**

    Современная архитектура управления питанием, оптимизированная для устройств с батарейным питанием и постоянно активных систем.
