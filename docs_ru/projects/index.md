# Обзор проектов { #projects-overview }

Проекты — это прикладные референсы, которые можно копировать и адаптировать для изучения вариантов устройств на базе SF32. Каждый проект не пытается изолированно показать все возможности чипа, а объединяет выбранные функции SF32 в решении, которое можно собрать и использовать на практике.

## Для чего нужны проекты { #what-projects-are-for }

Каждый проект должен быть:

- **Основанным на реальном применении.** В основе — понятная функция продукта или практический сценарий, а не абстрактная демонстрация возможностей.
- **Достаточно полным, чтобы пройти весь путь.** Проект связывает выбранную аппаратную платформу, программную основу, зависимости, этапы интеграции, результаты проверки и путь адаптации, помогая освоить значительную часть процесса разработки.
- **Предназначенным для копирования и адаптации.** Сначала вы воспроизводите практическую исходную конфигурацию, а затем изменяете её под собственную аппаратную платформу, модель взаимодействия и требования продукта.
- **Увлекательным в разработке.** Проект должен побуждать к экспериментам и наглядно показывать, что можно создать с помощью SF32. Практическая польза и удовольствие от разработки одинаково важны.

Переходите к проекту после выполнения соответствующего маршрута из раздела [Начало работы](../getting-started/index.md). В разделе [Референсные решения](../hardware/reference-designs/reference-designs.md) описаны повторно используемые базовые конфигурации и процессы проверки. Текущий материал Connected Wearable — это описание рабочего процесса, а не опубликованный комплект платы. Если существует конкретная подходящая базовая конфигурация, проект должен на неё ссылаться; в противном случае он должен определить и проверить собственную, не выдавая планировочный сценарий за проверенную конструкцию.

## Что должен содержать каждый проект { #what-every-project-includes }

В описании каждого проекта μForge должны быть указаны целевой результат, предполагаемые читатели, поддерживаемые версии аппаратной и программной частей, предварительные требования, исходный репозиторий, этапы сборки по контрольным точкам, критерии проверки, результаты измерений и переход к адаптации для продукта. Проект — это отправная точка инженерной работы, а не замена производственной проверке конечной аппаратуры, интеграции сервисов, безопасности, конфиденциальности и соответствия нормативным требованиям.
