# SF32LB52-DevKit-LCD { #sf32lb52-devkit-lcd }

## Обзор { #overview }

SF32LB52-DevKit-LCD — плата разработки для дисплейных приложений на базе семейства SF32LB52x. В основе платы — модуль SF32LB52x; она предназначена для быстрой разработки устройств с дисплейными интерфейсами SPI, DSPI, QSPI или MCU/8080.

На одной отладочной платформе объединены модуль MCU, разъёмы дисплея, интерфейс сенсорного экрана, аналоговый вход микрофона, аналоговый аудиовыход, USB Type-C, отладка через USB-UART, слот для TF-карты и подключение аккумулятора. Плата подходит для разработки человеко-машинных интерфейсов (HMI) смарт-часов, компактных приборных панелей, дисплейной периферии и других устройств на SF32LB52x, которым экран нужен уже на раннем этапе разработки.

## Основные особенности { #board-highlights }

- Платформа на модуле SF32LB52x, совместимая с SF32LB52-MOD-1, SF32LB52-MOD-A и SF32LB52-MOD-B
- Поддержка QSPI/SPI/DSPI LCD через 22-контактный разъём FPC
- Поддержка 8-битного MCU/8080 LCD через FPC и 40-контактный разъём расширения
- Поддержка сенсорной панели по I2C
- USB Type-C для загрузки прошивки и отладки через USB-UART, а также питания платы
- Отдельный разъём USB Type-C для сценариев USB 2.0 FS
- Встроенный MEMS-микрофон и аудиоусилитель класса D
- Слот MicroSD с интерфейсом SPI
- Разъём аккумулятора и линейное зарядное устройство ETA9640P
- 40-контактный разъём расширения для сигналов дисплея, GPIO, накопителя, аудио и питания

## Когда использовать эту плату { #when-to-use-this-board }

Выбирайте SF32LB52-DevKit-LCD, если проекту нужна готовая платформа для разработки устройств с дисплеем, а не плата только для вывода сигналов.

- Отладка LCD-панелей с интерфейсами QSPI, SPI, DSPI или MCU/8080
- Проверка интеграции сенсорной панели
- Тестирование LVGL или собственной графической оболочки на SF32LB52x
- Оценка входа микрофона и выхода на динамик
- Прототипирование хранения данных на TF-карте
- Сравнение вариантов модуля до перехода к собственной печатной плате

Для более компактной платы с металлизированными полуотверстиями по краям используйте [SF32LB52-DevKit-Nano](SF32LB52-DevKit-Nano.md). Для максимального числа выведенных контактов и прямого доступа к сигналам используйте [SF32LB52-DevKit-Core-3p3](SF32LB52-DevKit-Core-3p3.md).

В официальных источниках для Flash-памяти A128R16 используются разные обозначения: в [руководстве OpenSiFli по моделям модулей](https://github.com/OpenSiFli/SiFli-Wiki/blob/main/source/en/silicon/%E6%A8%A1%E7%BB%84%E5%9E%8B%E5%8F%B7%E6%8C%87%E5%8D%97.md) модуль указан как SPI-NAND объёмом 128 МБ, а в руководстве по моделям плат для соответствующей SKU DevKit указана QSPI-NAND объёмом 128 МБ. Источники не поясняют, связано ли различие с установленной микросхемой или с обозначением интерфейса. Прежде чем полагаться на эту конфигурацию, сверьте Flash-компонент и режим шины со схемой и BOM конкретной ревизии платы.

## Начало работы { #getting-started }

### Необходимое оборудование { #required-hardware }

- Плата SF32LB52-DevKit-LCD
- LCD-модуль, совместимый с выбранным интерфейсом
- Кабель USB 2.0 для передачи данных, Type-A—Type-C или аналогичный
- Хост-компьютер под управлением Windows, Linux или macOS

### Дополнительное оборудование { #optional-hardware }

- Динамик
- TF-карта
- Одноэлементный аккумулятор Li-ion/Li-poly, обычно ёмкостью 450–500 мА·ч
- Второй USB-кабель, если отладка через UART и проверка штатного USB-интерфейса нужны одновременно

### Базовая настройка { #basic-setup }

1. Подключите LCD-модуль к соответствующему разъёму LCD.
2. Подключите порт USB-UART Type-C к хост-компьютеру.
3. Запустите SifliTrace или утилиту SiFli для загрузки прошивки.
4. Выберите обнаруженный последовательный порт.
5. Подайте питание на плату и загрузите или запустите целевую прошивку.
6. После включения дисплея проверьте сенсорный ввод, графику, накопитель и аудио в соответствии с требованиями приложения.

Используйте USB-кабель с поддержкой передачи данных. Кабель только для зарядки подаст питание на плату, но не обеспечит последовательный интерфейс или передачу данных по USB.

## Питание { #power }

Плату SF32LB52-DevKit-LCD можно питать двумя основными способами:

- От USB Type-C, подключённого к любому из разъёмов USB
- От аккумулятора через установленный на плате разъём

Для загрузки прошивки и обычной отладки используйте порт USB-UART Type-C. Питание от аккумулятора удобно при проверке дисплея, аудио и энергопотребления без подключения кабеля.

На плате установлен линейный зарядный контроллер ETA9640P. Максимальный поддерживаемый ток зарядки — 1 А; значение тока постоянной зарядки по умолчанию — 450 мА. Используйте одноэлементный аккумулятор Li-ion или Li-poly и перед подключением проверьте полярность разъёма по маркировке на плате.

## Загрузка прошивки и отладка { #download-and-debug }

Порт USB-UART — основной интерфейс для загрузки прошивки и получения журналов.

- **Режим загрузки**: включите параметр BOOT в утилите загрузки, затем подайте питание на плату или выполните сброс.
- **Режим отладки/журналирования**: отключите параметр BOOT, затем подайте питание на плату или выполните сброс, чтобы перейти к обычному выводу журналов через последовательный порт.

На некоторых платах SF32LB52x для сброса используется сигнал RTS адаптера USB-UART. Если при первом открытии последовательного порта плата неожиданно сбрасывается, отключите управление потоком модема или аппаратное управление потоком в настройках последовательного порта на хост-компьютере.

## Интерфейс LCD и сенсорной панели { #lcd-and-touch-interface }

Плата поддерживает QSPI LCD-панели через вертикальный разъём FPC на 22 контакта с шагом 0,5 мм и откидным фиксатором. Если порядок контактов панели отличается, перед подключением используйте адаптерную плату.

Поддерживаются следующие функции LCD и сенсорного экрана:

- Сигналы LCD SPI, DSPI и QSPI
- Сигналы LCD QSPI в режиме DDR
- 8-битные сигналы LCD MCU/8080
- Сброс LCD, выбор микросхемы, тактовый сигнал, линии данных, TE и PWM подсветки
- SDA/SCL I2C сенсорной панели, сигнал прерывания и сброс

В исходной документации SiFli для этой платы указана поддержка дисплея модели `TFT-H043A28WQISTKN22_V0-3`.

Источник не объясняет это расхождение. Перед выбором или подключением шлейфа проверьте фактический разъём и схему конкретной ревизии платы; не считайте 22-контактный шлейф совместимым с разъёмом на 24 контакта.

## Совместимость модулей { #module-compatibility-notes }

- На SF32LB52-MOD-1 контакт 17 — выход 3,3 В, отключённый по умолчанию; для его использования требуется программное включение.
- На SF32LB52-MOD-A/B контакт 17 служит входом питания 3,3 В.
- На SF32LB52-MOD-1 контакт 27 — вход VBAT с напряжением от 3,2 до 4,7 В.
- На SF32LB52-MOD-A/B контакт 27 служит входом питания 3,3 В.
- На SF32LB52-MOD-1 пороги включения и выключения питания VBAT составляют 3,58 В и 3,48 В соответственно. Для испытаний без аккумулятора рекомендуется подать 3,8 В на VBAT.
- PA21 на контакте 62 модуля доступен только на SF32LB52-MOD-A/B. На SF32LB52-MOD-1 он не подключён.
- Контакты модуля 62–68 по умолчанию могут быть внутренне подключены к NOR Flash. Для внешнего использования SDIO выбирайте вариант модуля без внутренней Flash на этих контактах.

## Аудио { #audio }

На плате установлены MEMS-микрофон и аудиоусилитель мощности.

- Для проверки аналогового аудиовхода используйте встроенный микрофонный тракт.
- Для проверки аудиовыхода подключите динамик к соответствующему разъёму.
- Согласно исходной документации платы, выход для внешнего динамика рассчитан на нагрузку 4 Ом и мощность до 3 Вт.

## Хранение данных { #storage }

Разъём MicroSD подключён по SPI. Он подходит для проверки файловых систем, графических ресурсов, журналов и записи данных до перехода к собственной плате.

## Целевые конфигурации сборки SDK { #sdk-build-targets }

Для сборки с SiFli-SDK укажите `scons --board=<board_name>`, подставив вместо параметра одно из следующих точных имён целевой конфигурации платы:

- `sf32lb52-lcd_52d`
- `sf32lb52-lcd_n16r8`
- `sf32lb52-lcd_a128r16`

Это идентификаторы конфигураций сборки SDK, а не обязательно маркировка платы или модуля. В индексе [Supported Boards](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/supported_boards/index.html) и файле [`build_config_gcc.yaml`](https://github.com/OpenSiFli/SiFli-SDK/blob/main/build_config_gcc.yaml) основной ветки могут быть перечислены разные наборы целей. Проверьте сведения для используемой версии SDK.
