# SF32LB52-DevKit-Nano { #sf32lb52-devkit-nano }

## Обзор { #overview }

SF32LB52-DevKit-Nano — компактная отладочная плата на базе SF32LB52x для прототипирования и оценки встроенных систем. По краям платы расположены металлизированные полукруглые отверстия (castellated holes), поэтому её можно использовать отдельно или припаять к плате-носителю на раннем этапе разработки изделия.

Размер платы — 51 × 20,32 мм. На ней доступны основные ресурсы SF32LB52x для разработки с GPIO, UART, I2C, SPI, LCD, I2S, GPADC, PWM, USB и аналоговым аудио.

## Варианты платы { #board-variants }

<div align="center"><em>Варианты платы SF32LB52-DevKit-Nano</em></div>

<div align="center" markdown>

| Вариант | MCU | Память в корпусе | Внешняя Flash |
| :--- | :--- | :--- | :--- |
| SF32LB52-DevKit-Nano-N4 | SF32LB52BU56 | 4 МБ SPI NOR Flash | Нет |
| SF32LB52-DevKit-Nano-N16R16 | SF32LB52JUD6 | 16 МБ OPI-PSRAM | 16 МБ QSPI-NOR Flash |
| SF32LB52-DevKit-Nano-A128R16 | SF32LB52JUD6 | 16 МБ OPI-PSRAM | 128 МБ QSPI-NAND Flash |

</div>

Вариант N4 подходит для компактных систем управления, Bluetooth-устройств и простых интерфейсов. В N16R16 установлены 16 МБ OPI-PSRAM и 16 МБ QSPI-NOR, а в A128R16 — 16 МБ OPI-PSRAM и 128 МБ QSPI-NAND. Обе конфигурации подходят для приложений с крупными графическими ресурсами, внешними файловыми системами или кадровыми буферами и рабочими данными в PSRAM.

**Расхождение источников — проверьте перед выбором:** В [подробном руководстве платы Nano](https://wiki.sifli.com/en/board/sf32lb52x/SF32LB52-DevKit-Nano.html) конфигурация с 16 МБ OPI-PSRAM и 16 МБ NOR названа `R16N16 V1.0.0`. В [актуальном руководстве по моделям плат](https://wiki.sifli.com/en/board/devkit_guide.html) та же конфигурация обозначена как `N16R16`; отдельно указана `A128R16` с 16 МБ OPI-PSRAM и 128 МБ QSPI-NAND. В подробном руководстве нет описания A128R16. Для этого SKU используйте запись из руководства по моделям и не переносите на него остальные характеристики N16R16. Перед выбором прошивки или разметки хранилища сверьте маркировку платы и актуальные схему/BOM.

Источники SiFli также немного расходятся в размерах платы Nano: в подробном руководстве указано 21 × 51 мм, а в руководстве по моделям — 51 × 20,32 мм. Сторона 51 мм совпадает, короткая сторона отличается на 0,68 мм. В этой статье приведено более точное значение из руководства по моделям; перед проектированием корпуса или платы-носителя проверьте механический чертёж нужной ревизии.

## Особенности платы { #board-highlights }

- Компактная плата размером 51 × 20,32 мм
- Металлизированные полукруглые отверстия по краям для пайки к плате-носителю
- Питание через USB Type-C и загрузка/отладка через USB-UART на CH340N
- Выведены GPIO, UART, I2C, SPI, GPADC, PWM, I2S, PDM и выводы с поддержкой пробуждения
- Подключение QSPI LCD через 16-контактный FPC; обычно требуется переходной кабель с 22 на 16 контактов
- Поддержка сенсорной панели с интерфейсом I2C
- Аналоговый вход микрофона и дифференциальные аудиовыходы
- Сигналы USB 2.0 FS выведены на краевые контакты платы
- Два пользовательских светодиода
- Кнопка питания и функциональная кнопка

## Когда использовать эту плату { #when-to-use-this-board }

Выбирайте SF32LB52-DevKit-Nano, если прототип должен по размерам и способу монтажа быть близок к конечному изделию.

- Создавать компактные прототипы с Bluetooth и дисплеем
- Припаивать плату к плате-носителю
- Проверять близкое к серийному изделию назначение выводов до разработки собственной платы
- Сравнивать конфигурацию только с NOR Flash с конфигурациями, где PSRAM сочетается с QSPI-NOR или QSPI-NAND Flash
- Проверять LCD, аудио, датчики и USB в компактной конструкции

Для удобного подключения на лабораторном столе и доступа к большему числу сигналов используйте [SF32LB52-DevKit-Core-3p3](SF32LB52-DevKit-Core-3p3.md). Если нужна плата с дисплеем, зарядным устройством, картой TF, микрофоном и усилителем динамика, выберите [SF32LB52-DevKit-LCD](SF32LB52-DevKit-LCD.md).

## Питание { #power }

Плату можно питать тремя способами:

- Через USB Type-C; этот способ рекомендуется при разработке
- Подать питание 3,3 В через контакты 3,3 В и GND на металлизированных полукруглых площадках, если USB не подключён
- Подать питание 5 В через контакты 5 В и GND на металлизированных полукруглых площадках, если USB не подключён

При подключённом USB Type-C некоторые выводы 3,3 V и 5 V можно использовать как выходы питания. Перед подключением внешних цепей проверьте направление подачи питания.

На плате есть выключатель питания, управляемый сигналом RTS# микросхемы CH340N. Это позволяет инструменту управлять сбросом платы.

## Загрузка и отладка { #download-and-debug }

Используйте UART-интерфейс USB Type-C для записи прошивки и просмотра логов в последовательном интерфейсе.

- **Режим загрузки:** включите BOOT в программе загрузки, затем подайте питание на плату или сбросьте её.
- **Режим отладки/логирования:** выключите BOOT, затем подайте питание на плату или сбросьте её.
- **Сброс по RTS:** если при открытии последовательного порта плата неожиданно сбрасывается или выключается, отключите управление потоком по сигналам модема (modem flow control) или аппаратное управление потоком в настройках порта на компьютере.

## Выводы внешней Flash и SDIO { #external-flash-and-sdio-pins }

Вариант N16R16 оснащён внешней QSPI-NOR Flash объёмом 16 МБ. Группа выводов для памяти:

<div align="center"><em>Группа выводов внешней Flash и SDIO</em></div>

<div align="center" markdown>

| GPIO MCU | Общая функция Flash / SDIO |
| :--- | :--- |
| PA12 | MPI2_CS / SD1_D2 |
| PA13 | MPI2_D1 / SD1_D3 |
| PA14 | MPI2_D2 / SD1_CLK |
| PA15 | MPI2_D0 / SD1_CMD |
| PA16 | MPI2_CLK / SD1_D0 |
| PA17 | MPI2_D3 / SD1_D1 |

В зависимости от варианта эти выводы могут быть заняты установленной Flash. Перед использованием в качестве выводов расширения проверьте точную комплектацию платы.

## Подключение аудио { #audio-expansion }

На Nano выведены аналоговый вход микрофона, напряжение смещения микрофона и дифференциальный аналоговый аудиовыход. При необходимости добавьте внешнюю схему микрофона и аудиоусилитель, предусмотренные целевым изделием.

## Целевые конфигурации сборки SDK { #sdk-build-targets }

Для сборки с SiFli-SDK укажите `scons --board=<board_name>`, подставив вместо параметра одно из следующих точных имён целевой конфигурации платы:

- `sf32lb52-nano_n4`
- `sf32lb52-nano_n16r16`
- `sf32lb52-nano_a128r16`

Это идентификаторы конфигураций сборки SDK, а не обязательно маркировка платы или модуля. В индексе [Supported Boards](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/supported_boards/index.html) и файле [`build_config_gcc.yaml`](https://github.com/OpenSiFli/SiFli-SDK/blob/main/build_config_gcc.yaml) SDK могут быть перечислены разные наборы целей. Сверьте целевую конфигурацию с используемой версией SDK.
