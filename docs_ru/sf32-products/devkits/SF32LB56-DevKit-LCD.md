# SF32LB56-DevKit-LCD { #sf32lb56-devkit-lcd }

SF32LB56-DevKit-LCD — отладочная плата для дисплейных решений, доступная с модулем SF32LB56-MOD-N16R12N1 или SF32LB56-MOD-A128R12N1; оба модуля построены на микросхеме серии SF32LB56xV. Плата позволяет проверить интерфейсы дисплея, аудиотракт, съёмные накопители и драйверы периферии до разработки собственной платы на базе SF32LB56x.

## Для каких задач подходит плата { #what-it-is-best-for }

- Разработка дисплеев с интерфейсами MIPI-DPI (RGB), SPI, DSPI, QSPI или 8-разрядным MCU/8080.
- Подключение сенсорного экрана по I2C.
- Проверка аналогового входа микрофона и аналогового аудиовыхода через встроенный усилитель мощности класса D.
- Работа с картой MicroSD через SDIO и разработка драйверов периферии.
- Оценка архитектуры изделия на базе модуля SF32LB56 до проектирования платы-носителя.

**Примечание к источникам — проверьте ревизию платы:** В подробном руководстве SiFli указано, что описанная плата оснащена модулем `SF32LB56-MOD-A128R12N1`, в котором установлены 4 + 8 МБ OPI-PSRAM и 1 Гбит QSPI-NAND; там же сказано, что эти параметры памяти могут измениться до официального выпуска. В актуальном руководстве по моделям перечислены конфигурации N16R12N1 и A128R12N1; обе включают 4 + 8 МБ OPI-PSRAM и стандартную QSPI-NOR на 1 МБ. Для A128R12N1 указанные в руководстве моделей 128 МБ QSPI-NAND по ёмкости соответствуют 1 Гбит из подробного руководства. Таким образом, для A128R12N1 эти значения ёмкости совпадают. Однако подробное руководство не упоминает стандартную QSPI-NOR на 1 МБ и не устанавливает, какой SKU используется на каждой плате или ревизии. Согласно руководству по моделям, CH343K обеспечивает два USB–UART-канала отладки; подробное руководство указывает для двух разъёмов Type-C функции USB–UART и USB 2.0 FS, но не описывает распределение UART-каналов между разъёмами. Прежде чем использовать конкретный UART-канал, сверьтесь со схемой/BOM соответствующей ревизии. Перед использованием конкретной платы в качестве основы изделия сверьте маркировку модуля и соответствующую схему/BOM.

**Различается обозначение моста USB–UART — проверьте установленную микросхему:** В функциональной блок-схеме подробного руководства указан CH342K, а в руководстве по моделям — CH343K. Фактически установленную микросхему следует проверить по схеме/BOM соответствующей ревизии.

**В тексте и на фото указаны разные SKU — проверьте установленный модуль:** В тексте подробного руководства для описанной платы указан модуль `SF32LB56-MOD-A128R12N1`, тогда как на аннотированном фото платы модуль помечен как `SF32LB56-MOD-N16R12N1`. SiFli не поясняет, относится ли фото к другому варианту или ревизии. Проверьте маркировку модуля и BOM конкретного экземпляра; не определяйте SKU только по тексту или фотографии.

## Прошивка и отладка { #programming-and-debug }

Для перехода в режим загрузки установите перемычку Mode до включения или сброса платы; для обычного запуска приложения с выводом логов через последовательный порт снимите её. Подключите компьютер к разъёму Type-C с функцией USB–UART кабелем, поддерживающим передачу данных. Отдельный разъём USB 2.0 FS Type-C предназначен для проверки нативного USB. На плате также есть однорядный 4-контактный разъём SWD с шагом 2,54 мм для совместимого отладчика. Оба разъёма Type-C могут питать плату; соблюдайте предусмотренную схему питания из руководства и схемы соответствующей ревизии.

## Целевые конфигурации сборки SDK { #sdk-build-targets }

Для сборки с SiFli-SDK используйте команду `scons --board=<board_name>` с одним из следующих точных имён целевой конфигурации платы:

- `sf32lb56-lcd_a128r12n1`
- `sf32lb56-lcd_n16r12n1`

Эти имена обозначают целевые конфигурации сборки SDK и не обязательно совпадают с маркировкой платы или модуля. В индексе [Supported Boards](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/supported_boards/index.html) и файле [`build_config_gcc.yaml`](https://github.com/OpenSiFli/SiFli-SDK/blob/main/build_config_gcc.yaml) SDK могут быть перечислены разные наборы целей. Сверьте целевую конфигурацию с используемой версией SDK.

## Первичная проверка { #first-validation-path }

1. Подключите совместимый 24-разрядный дисплей MIPI-DPI к 40-контактному FPC-разъёму и соедините USB–UART-разъём с компьютером кабелем USB, поддерживающим передачу данных.
2. Выполните инструкции раздела [Начало работы](../../getting-started/index.md), чтобы проверить сборку, прошивку и вывод последовательного журнала на заведомо исправной конфигурации.
3. Сначала выведите на экран простые сплошные цветовые поля и только после этого переходите к отладке UI-фреймворка. См. раздел [Обзор графики](../../learn/graphics/overview.md).
4. Подключайте сенсорный экран, накопитель, аудиоустройство и беспроводные функции по одной подсистеме за раз, затем проверяйте их совместную работу и энергопотребление.
5. Перед разработкой собственной платы ознакомьтесь с материалами [SF32LB56-MOD](../modules/SF32LB56-MOD.md) и [Разработка для серийного производства](../../hardware/design-for-production.md).
