# SF32LB56-DevKit-LCD { #sf32lb56-devkit-lcd }

SF32LB56-DevKit-LCD — отладочная плата для дисплейных решений, доступная с модулем SF32LB56-MOD-N16R12N1 или SF32LB56-MOD-A128R12N1; оба модуля построены на микросхеме серии SF32LB56xV. Плата позволяет проверить интерфейсы дисплея, аудиотракт, съёмные накопители и драйверы периферии до разработки собственной платы на базе SF32LB56x.

## Для каких задач подходит плата { #what-it-is-best-for }

- Разработка дисплеев с интерфейсами MIPI-DPI (RGB), SPI, DSPI, QSPI или 8-разрядным MCU/8080.
- Подключение сенсорного экрана по I2C.
- Проверка аналогового входа микрофона и аналогового аудиовыхода через встроенный усилитель мощности класса D.
- Работа с картой MicroSD через SDIO и разработка драйверов периферии.
- Оценка архитектуры изделия на базе модуля SF32LB56 до проектирования платы-носителя.

**Примечание к источникам — проверьте ревизию платы:** В подробном руководстве SiFli описана плата с модулем `SF32LB56-MOD-A128R12N1`, 4 + 8 MB OPI-PSRAM и QSPI-NAND объёмом 1 Gbit; там же предупреждают, что конфигурация памяти может измениться до официального выпуска. Актуальное руководство по моделям перечисляет N16R12N1 и A128R12N1: оба варианта включают 4 + 8 MB OPI-PSRAM и стандартную QSPI-NOR объёмом 1 MB. Для A128R12N1 объём QSPI-NAND составляет 128 MB по руководству моделей и 1 Gbit по подробному руководству; эти значения эквивалентны. При этом подробное руководство не упоминает стандартную QSPI-NOR на 1 MB и не указывает, какой SKU установлен на каждой плате или ревизии. Руководство по моделям указывает два канала USB–UART для отладки на мосте CH343K, а подробное руководство описывает функции разъёмов Type-C (USB–UART и USB 2.0 FS), но не связывает конкретные UART-каналы с разъёмами. Перед использованием определённого канала сверьтесь со схемой/BOM нужной ревизии. Также проверьте маркировку модуля и соответствующую схему/BOM конкретной платы, прежде чем использовать её как основу изделия.

**Различие в обозначении моста USB–UART — проверьте установленную микросхему:** На функциональной схеме из подробного руководства мост обозначен как CH342K, а руководство по моделям указывает CH343K. Сверьте фактически установленную микросхему со схемой/BOM нужной ревизии платы.

**В тексте и на фото указаны разные SKU — проверьте установленный модуль:** В тексте подробного руководства для платы указан модуль `SF32LB56-MOD-A128R12N1`, а на аннотированном фото — `SF32LB56-MOD-N16R12N1`. SiFli не поясняет, относится ли фото к другому варианту или ревизии. Проверьте маркировку модуля и BOM конкретного экземпляра; не определяйте SKU только по тексту или фото.

## Прошивка и отладка { #programming-and-debug }

Чтобы перейти в режим загрузки, установите перемычку Mode до подачи питания или сброса платы. Для обычного запуска приложения и вывода журналов через последовательный порт снимите перемычку. Подключите компьютер кабелем с поддержкой передачи данных к разъёму Type-C с функцией USB–UART. Отдельный разъём USB 2.0 FS Type-C используйте для проверки штатного USB-интерфейса. Для совместимого отладчика предусмотрен однорядный 4-контактный разъём SWD с шагом 2,54 mm. Оба разъёма Type-C могут питать плату; схему питания выбирайте по руководству и схеме нужной ревизии.

## Целевые конфигурации сборки SDK { #sdk-build-targets }

Для сборки с SiFli-SDK используйте команду `scons --board=<board_name>` с одним из следующих точных имён целевой конфигурации платы:

- `sf32lb56-lcd_a128r12n1`
- `sf32lb56-lcd_n16r12n1`

Эти имена обозначают целевые конфигурации сборки SDK и не обязательно совпадают с маркировкой платы или модуля. В индексе [Supported Boards](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/supported_boards/index.html) и файле [`build_config_gcc.yaml`](https://github.com/OpenSiFli/SiFli-SDK/blob/main/build_config_gcc.yaml) SDK могут быть перечислены разные наборы целей. Сверьте целевую конфигурацию с используемой версией SDK.

## Первичная проверка { #first-validation-path }

1. Подключите совместимый 24-разрядный дисплей MIPI-DPI к 40-контактному разъёму FPC, а порт USB–UART — к компьютеру кабелем с поддержкой передачи данных.
2. Выполните инструкции раздела [Начало работы](../../getting-started/index.md), чтобы проверить сборку, прошивку и вывод последовательного журнала на заведомо исправной конфигурации.
3. Сначала проверьте вывод сплошных цветовых полей и лишь затем переходите к отладке UI-фреймворка. См. раздел [Обзор графики](../../learn/graphics/overview.md).
4. Подключайте сенсорный экран, накопитель, аудиоустройство и беспроводные функции по одной подсистеме за раз, затем проверяйте их совместную работу и энергопотребление.
5. Перед разработкой собственной платы ознакомьтесь с материалами [SF32LB56-MOD](../modules/SF32LB56-MOD.md) и [Разработка для серийного производства](../../hardware/design-for-production.md).
