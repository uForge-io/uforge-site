# SF32LB58-DevKit-LCD { #sf32lb58-devkit-lcd }

## Обзор { #overview }

SF32LB58-DevKit-LCD — отладочная плата на базе семейства модулей SF32LB58-MOD. Она предназначена для разработки устройств с дисплеями DSI, DPI/RGB или QSPI и позволяет на практике проверить запуск дисплеев высокого разрешения, аудио, накопителей, USB и периферии.

На плате установлены модуль SF32LB58x, несколько разъёмов дисплея, аналоговый вход микрофона, стереовыход для динамиков, слот MicroSD, два разъёма USB Type-C и разъёмы расширения GPIO для высокопроизводительного и энергоэффективного ядер. Также предусмотрены интерфейсы расширения CAN и Wi-Fi по SDIO.

До разработки собственной платы с её помощью можно проверить совместную работу дисплея, накопителя, аудио, USB и внешней периферии.

## Основные особенности платы { #board-highlights }

- В зависимости от версии платы установлен модуль SF32LB58-MOD-N16R32N1 или SF32LB58-MOD-A128R32N1
- В V1.0.1 используется SF32LB586VDD36 с двумя микросхемами HPI-PSRAM по 16 MB и корпусной QSPI-NOR объёмом 1 MB; в источниках SiFli есть расхождение по обозначению MCU для V1.0.0 (см. примечание о версиях выше)
- Дополнительная память: 16 MB QSPI-NOR или 128 MB QSPI-NAND, в зависимости от варианта модуля
- Основной кварцевый резонатор 48 MHz и кварцевый резонатор RTC 32,768 kHz
- Разъём антенны IPEX и согласующая RF-цепь модуля
- Поддержка дисплеев MIPI DSI / RGB888 через отдельные разъёмы FPC
- Два интерфейса дисплея QSPI / DSPI / SPI выведены на 40-контактные разъёмы
- Поддержка сенсорных панелей с интерфейсом I2C
- Аналоговый вход микрофона и стереовыход аудио класса D
- Два разъёма USB Type-C: один для загрузки прошивки и отладки через USB-UART, второй для USB 2.0 HS
- Слот MicroSD с интерфейсом SDIO
- Два 40-контактных разъёма для расширения GPIO высокопроизводительного и энергоэффективного ядер
- Возможность расширения интерфейсами CAN и Wi-Fi по SDIO

## Когда стоит выбрать эту плату { #when-to-use-this-board }

Выбирайте SF32LB58-DevKit-LCD, если для проекта нужна полноценная платформа для проверки современных дисплеев и периферии, а не простая плата с выведенными контактами.

- Проверка дисплейных панелей MIPI DSI, RGB888 или QSPI
- Совместная проверка сенсорного ввода, аудио, накопителя и USB
- Проверка работы интерфейса высокого разрешения на платформе SF32LB58x
- Оценка расширения CAN или Wi-Fi по SDIO
- Сравнение вариантов модуля с NOR- и NAND-памятью
- Проверка прошивки на флагманской плате до разработки собственной PCB

Для планирования интеграции модуля см. также [SF32LB58-MOD](../modules/SF32LB58-MOD.md). Архитектура семейства микросхем, возможности дисплея и памяти описаны в разделе [SF32LB58x](../chips/SF32LB58x.md).

## Начало работы { #getting-started }

### Необходимое оборудование { #required-hardware }

- Плата SF32LB58-DevKit-LCD
- Модуль ЖК-дисплея с интерфейсом MIPI DSI, RGB888 или QSPI
- Кабель USB 2.0 для передачи данных, Type-A — Type-C или аналогичный
- Компьютер под управлением Windows, Linux или macOS

### Дополнительное оборудование { #optional-hardware }

- Два динамика
- Карта TF / MicroSD
- Отладчик J-Link или совместимый SWD-отладчик
- Плата с CAN-трансивером
- Модуль Wi-Fi с интерфейсом SDIO

### Подключение и запуск { #basic-setup }

1. Подключите дисплейную панель к соответствующему разъёму LCD.
2. Подключите разъём USB-UART Type-C к компьютеру.
3. Запустите утилиту SiFli для загрузки прошивки и выберите нужный COM-порт.
4. Установите или снимите перемычку Mode, чтобы выбрать режим загрузки прошивки или обычный запуск.
5. Подайте питание на плату и загрузите прошивку либо запустите уже записанную программу.
6. После проверки дисплея по очереди проверьте сенсорный ввод, аудио, накопитель и необходимые проекту периферийные устройства.

Используйте USB-кабель с поддержкой передачи данных. Некоторые кабели Type-C предназначены только для питания и не обеспечивают передачу данных UART или USB.

## Питание { #power }

Плата SF32LB58-DevKit-LCD питается через USB Type-C.

- Питание на плату можно подать через любой из двух разъёмов USB Type-C.
- Для загрузки прошивки и вывода UART-логов используйте разъём USB-UART Type-C.
- При проверке функций встроенного USB отдельно предусмотрите подключение к разъёму USB 2.0 HS Type-C.

## Загрузка прошивки и отладка { #download-and-debug }

Основной интерфейс для загрузки прошивки и вывода логов через последовательный порт — разъём USB-UART Type-C.

- **Режим загрузки прошивки**: установите перемычку Mode, затем включите питание платы или перезапустите её.
- **Режим программной отладки и логирования**: снимите перемычку Mode, затем включите питание платы или перезапустите её.

Плата также поддерживает отладку через J-Link / SWD.

## Интерфейсы дисплея { #display-interfaces }

Плата поддерживает три основных варианта подключения дисплея:

- **MIPI DSI** через 30-контактный разъём FPC с шагом 0,5 мм
- **RGB888** через 40-контактный разъём FPC с шагом 0,5 мм и распространённой распиновкой RGB от ALIENTEK
- **QSPI / DSPI / SPI** через два 40-контактных разъёма расширения

Согласно документации SiFli, поддерживаются следующие параметры дисплеев:

- MIPI DSI: до 2 линий передачи данных, разрешение до 1280 × 800
- RGB888: разрешение до 1280 × 800
- QSPI: разрешение до 512 × 512

!!! warning "Число линий MIPI DSI"
    В распиновке 30-контактного разъёма платы указаны D0–D3, однако руководство платы и SDK документируют работу максимум с двумя линиями данных. Не следует считать, что разъём обеспечивает поддержку четырёх линий, только по их обозначениям. Перед подключением проверьте разводку для конкретной панели и ревизии платы.

## Аудио { #audio }

Плата поддерживает:

- Один тракт входа встроенного микрофона
- Два входных тракта аудио-ADC; один из них общий со встроенным микрофоном, а резисторные перемычки позволяют переключать его между встроенным микрофоном и входом 40-контактного разъёма
- Два выхода для динамиков
- Один тракт сигнала PDM, мультиплексированный с сигналами RGB; поэтому он недоступен при работе дисплейного интерфейса RGB

В [подробном руководстве по плате](https://wiki.sifli.com/en/board/sf32lb58x/SF32LB58-DevKit-LCD.html) SiFli указывает максимальную мощность аналогового стереовыхода 2,8 Вт при 4 Ω, тогда как в [руководстве по моделям плат разработки](https://wiki.sifli.com/en/board/devkit_guide.html) для двух выходов на динамики указано 3 Вт/4 Ω. Ни один источник не уточняет, относится ли мощность к одному каналу или к обоим вместе. Перед выбором динамиков проверьте точную ревизию платы, схему и условия питания и нагрузки усилителя; не считайте ни одно из значений гарантированной мощностью на канал.
