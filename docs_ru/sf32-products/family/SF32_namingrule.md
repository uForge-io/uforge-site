# Правила обозначения SF32 { #sf32-naming-convention }

## Обозначения микросхем { #chip-naming }

### Обозначение микросхемы: ***SF32LB5xyZxYx6*** { #part-number-sf32lb5xyzxyx6 }

!!! note "Примечание о синтаксисе"
    * Строчная ***x*** обозначает цифру.
    * Прописные ***Y*** и ***Z*** обозначают буквы.

### Префикс: *SF32LB5xy* { #prefix-sf32lb5xy }

- **SF32** — серия 32-разрядных микроконтроллеров SiFli
- **LB** — идентификатор линейки продуктов
    - **LB**: серия Bluetooth-микроконтроллеров с низким энергопотреблением
- **5** — семейство процессоров
    - **5**: устройства на базе 32-разрядного Arm Cortex-M33 STAR-MC1 или процессора RISC-V сопоставимой производительности
- **x** — категория изделия
    - **8 / 7**: два прикладных и один маломощный процессор; позиционирование зависит от семейства.
    - **6 / 5**: средний класс (***один*** прикладной процессор и ***один*** маломощный процессор)
    - **2**: устройства с оптимизацией по стоимости (***один*** прикладной процессор и ***отдельный*** маломощный контроллер Bluetooth)
- **y** — вариант устройства
    - Значение обычно отражает объём PSRAM, интегрированной в корпус; точное соответствие зависит от подсемейства продуктов.

### Суффикс: *ZxYx6* { #suffix-zxyx6 }

- **Z** — тип корпуса
    - **U**: QFN68
    - **V**: BGA
    - **Y**: QFN80
- **xYx** — конфигурация встроенной памяти (QSPI-NOR Flash и PSRAM)
  *(Примечание: точное соответствие кодов зависит от корпуса и семейства устройства.)*

`ZxYx6` — это обобщённая схема для семейства, а не шаблон фиксированной длины. Количество и порядок кодов памяти зависят от семейства устройства и корпуса: цифровой код Flash может отсутствовать, а буквенный код PSRAM может повторяться, если встроено несколько микросхем. Конкретное обозначение следует расшифровывать по таблице вариантов соответствующего семейства.

<div align="center"><em>Поля суффикса обозначения микросхемы</em></div>

<div align="center" markdown>

| Поле | Тип | Варианты | Описание |
| :--- | :--- | :--- | :--- |
| **x** | Числовой | **1**–**6** | Общее соответствие кодов ёмкости QSPI-NOR Flash:<br>• **1**: 2 Mb<br>• **2**: 4 Mb<br>• **3**: 8 Mb<br>• **4**: 16 Mb<br>• **5**: 32 Mb<br>• **6**: 64 Mb<br>В SF32LB57x также применяются коды **7** и **8**; см. семейную таблицу ниже. |
| **Y** | Буквенный | **A**–**E** | Ёмкость и интерфейс встроенной PSRAM:<br>• **A**: 16 Mb QPI-PSRAM<br>• **B**: 32 Mb OPI-PSRAM<br>• **C**: 64 Mb OPI-PSRAM<br>• **D**: 128 Mb OPI/HPI-PSRAM<br>• **E**: 256 Mb HPI-PSRAM |

</div>

- **6** — температурный класс эксплуатации
    - **5**: от −20 °C до +70 °C (коммерческий)
    - **6**: от −40 °C до +85 °C (промышленный)

### Коды памяти SF32LB57x { #sf32lb57x-memory-codes }

Схема обозначения из руководства по аппаратному проектированию SF32LB57x показывает три кода позиции памяти после кода корпуса: MPI1, MPI2 и MPI3, именно в таком порядке; затем указывается температурный класс. В каждой позиции MPI для SF32LB57x используются следующие коды:

<div align="center"><em>Таблица: коды памяти SF32LB57x по позициям MPI</em></div>

<div align="center" markdown>

| Код | Значение в соответствующей позиции MPI для SF32LB57x |
|:-----|:------------------------------------------------------|
| `N` | Нет памяти в общем корпусе |
| `B` | PSRAM 32 Mb |
| `C` | PSRAM 64 Mb |
| `D` | PSRAM 128 Mb |
| `E` | PSRAM 256 Mb |
| `2` | NOR Flash 4 Mb |
| `3` | NOR Flash 8 Mb |
| `4` | NOR Flash 16 Mb |
| `5` | NOR Flash 32 Mb |
| `6` | NOR Flash 64 Mb |
| `7` | NOR Flash 128 Mb |
| `8` | NOR Flash 256 Mb |

</div>

Эта таблица применима только к SF32LB57x. Каждое полное обозначение сверяйте с таблицей точных вариантов: из этой таблицы не следует, что любое сочетание кодов является SKU, доступным для заказа.

### Примеры обозначений микросхем { #part-number-examples }

#### Пример 1: SF32LB527UD6 { #example-1-sf32lb527ud6 }

**Экономичная конфигурация MCU семейства SF32LB52:**

* **Конфигурация процессоров:** один прикладной процессор и отдельный маломощный процессор-контроллер Bluetooth на базе Arm Cortex-M33 STAR-MC1.
* **Тип корпуса:** QFN68 (**U**).
* **Конфигурация памяти:** встроенная OPI-PSRAM объёмом 128 Mb (**D**).
* **Рабочая температура:** от −40 °C до +85 °C (**6**, промышленный класс).

#### Пример 2: SF32LB587VEE56 { #example-2-sf32lb587vee56 }

**Флагманская конфигурация MCU семейства SF32LB58:**

* **Конфигурация процессоров:** два прикладных процессора и один маломощный процессор на базе Arm Cortex-M33 STAR-MC1.
* **Тип корпуса:** BGA256 (**V**).
* **Конфигурация памяти:** две встроенные микросхемы HPI-PSRAM по 256 Mb каждая (**E**) и одна QSPI-NOR Flash объёмом 32 Mb (**5**).
* **Рабочая температура:** от −40 °C до +85 °C (**6**, промышленный класс).

#### Пример 3: SF32LB57GVD776 { #example-3-sf32lb57gvd776 }

В таблице вариантов SF32LB57x этот артикул указан для BGA112. Три кода позиции памяти — `D/7/7`: на MPI1 установлена PSRAM 128 Mb, на MPI2 и MPI3 — NOR Flash по 128 Mb. Последняя цифра `6` обозначает промышленный температурный класс. Следовательно, в коде `776` вторая `7` указывает на NOR Flash на MPI3. О том, что это означает для GPIO в корпусе BGA112, см. [обзор семейства SF32](SF32_family.md).

#### Пример 4: SF32LB57ZVN7N6 { #example-4-sf32lb57zvn7n6 }

В таблице вариантов SF32LB57x этот артикул указан для BGA112. Коды позиции памяти — `N/7/N`: на MPI1 нет памяти в общем корпусе, на MPI2 — NOR Flash 128 Mb, на MPI3 нет памяти в общем корпусе. Последняя цифра `6` обозначает промышленный температурный класс. В обзоре семейства поясняется, почему запись `58 + 6` не означает 64 GPIO со свободным назначением.

### Артикулы 55x с устаревшим форматом суффикса { #legacy-55x-suffix-exceptions }

Семейство SF32LB55x было сформировано до появления действующей схемы обозначений, поэтому в некоторых артикулах сохранён прежний формат суффикса. Эти три артикула нельзя полностью декодировать по приведённой выше схеме `SF32LB5xyZxYx6`: `SF32LB551U4O5`, `SF32LB555V4O6` и `SF32LB555V436`. Корпус и конфигурацию памяти проверяйте по таблице вариантов 55x и техническому описанию конкретного артикула; не выводите поля из общей схемы. `SF32LB557VD3A6`, напротив, соответствует действующей схеме и не является исключением.

## Обозначения модулей { #module-naming }

### Обозначение модуля: ***SF32LB5x-MOD-y-AaaaBbbbCccc*** { #part-number-sf32lb5x-mod-y-aaaabbbbcccc }

!!! note "Примечание о синтаксисе"
    * В общей схеме суффикса `A`, `B` и `C` обозначают позиции трёх полей памяти; эти буквы не обязательно присутствуют в каждом названии модуля.
    * Первый символ каждого используемого поля задаёт тип памяти. Последующие цифры обозначают её ёмкость или конфигурацию.
    * Поле подтипа `-y` сейчас используется только в семействе модулей SF32LB52. В опубликованных названиях SF32LB56-MOD и SF32LB58-MOD это поле не применяется.

### Префикс: *SF32LB5x-MOD-y* { #prefix-sf32lb5x-mod-y }

- **SF32LB5x** — семейство модулей на базе MCU
    - **SF32**, **LB** и **5** имеют те же значения серии, линейки продуктов и семейства процессоров, что и в обозначениях микросхем выше.
    - **x** задаёт категорию изделия: **8 / 7** — два прикладных и один маломощный процессор, при этом позиционирование зависит от семейства; **6 / 5** — средний класс, **2** — оптимизация по стоимости.
- **MOD** — модульный продукт SiFli.
- **y** — подтип модуля, если он предусмотрен для семейства
    - **1**: непосредственное питание от литий-ионного аккумулятора для устройств SF32LB520/3/5/7. Диапазон питания микросхемы — 3,2–4,7 V; стандартная конфигурация использует SF32LB525UC6 с OPI-PSRAM 8 MB.
    - **A**: обычное питание 3,3 V для семейства SF32LB52B. Непосредственное питание от литий-ионного аккумулятора не поддерживается; диапазон питания микросхемы — 2,97–3,63 V. В стандартной конфигурации используется SF32LB52BU36 со встроенной QSPI-NOR Flash объёмом 1 MB.
    - **B**: обычное питание 3,3 V для семейства 52E/52G/52J. Непосредственное питание от литий-ионного аккумулятора не поддерживается; диапазон питания микросхемы — 2,97–3,63 V. В стандартной конфигурации используется SF32LB52EUB6 со встроенной OPI-PSRAM 4 MB.

На модуле `-A` внешняя NOR Flash не установлена. К нему можно подключить внешнюю NOR Flash или периферийные устройства с интерфейсом SDIO, в том числе Wi-Fi, SD-NAND и eMMC в 4-разрядном режиме.

### Суффикс: *AaaaBbbbCccc* { #suffix-aaaabbbbcccc }

<div align="center"><em>Поля суффикса обозначения модуля</em></div>

<div align="center" markdown>

| Поле | Код типа накопителя | Ёмкость, конфигурация и суффикс |
| :--- | :--- | :--- |
| `Aaaa`<br>Вариант Flash-памяти | `N`: QSPI-NOR Flash<br>`A`: NAND Flash (интерфейс зависит от семейства модулей)<br>`D`: SD-NAND Flash<br>`E`: eMMC | `N16`: QSPI-NOR Flash 16 MB<br>`A128`: SPI-NAND 128 MB для SF32LB52-MOD-1; QSPI-NAND 128 MB для SF32LB56-MOD и SF32LB58-MOD<br>`D128`: SD-NAND 128 MB для SF32LB56-MOD<br>`E4`: eMMC 4 GB для SF32LB58-MOD |
| `Bbbb`<br>PSRAM | `R`: PSRAM | `R4`: OPI-PSRAM 4 MB<br>`R8`: OPI-PSRAM 8 MB<br>`R12`: OPI-PSRAM 4 MB + 8 MB<br>`R16`: OPI/HPI-PSRAM 16 MB<br>`R32`: HPI-PSRAM 16 MB + 16 MB<br>`R64`: HPI-PSRAM 32 MB + 32 MB |
| `Cccc`<br>Стандартная Flash | `N`: QSPI-NOR Flash | `N1`: QSPI-NOR Flash 1 MB<br>`N4`: QSPI-NOR Flash 4 MB |

</div>

Три поля суффикса записываются подряд, без разделителей. `Aaaa` обозначает вариант Flash-памяти, `Bbbb` — вариант PSRAM, а `Cccc` — вариант стандартной Flash. В руководстве определены только перечисленные сочетания типа и ёмкости; не следует считать, что любой код типа можно сочетать с любым кодом ёмкости. Поле указывается только в тех документированных конфигурациях модуля, где оно используется.

### Примеры обозначений модулей { #part-number-examples_1 }

#### Пример 1: SF32LB52-MOD-1-N16R8 { #example-1-sf32lb52-mod-1-n16r8 }

**Конфигурация модуля SF32LB52 с прямым питанием от литий-ионного аккумулятора:**

* **Подтип модуля:** `-1` поддерживает прямое питание от литий-ионного аккумулятора; диапазон напряжения питания микросхемы составляет 3,2–4,7 V.
* **Вариант Flash-памяти:** `N16` обозначает QSPI-NOR Flash объёмом 16 MB.
* **PSRAM:** `R8` обозначает OPI-PSRAM объёмом 8 MB.

#### Пример 2: SF32LB58-MOD-A128R32N1 { #example-2-sf32lb58-mod-a128r32n1 }

**Флагманская конфигурация модуля SF32LB58:**

* **Подтип модуля:** в опубликованных названиях SF32LB58-MOD подтип `-y` не используется.
* **Вариант Flash-памяти:** в этой конфигурации SF32LB58-MOD `A128` означает QSPI-NAND Flash объёмом 128 MB.
* **PSRAM:** `R32` обозначает HPI-PSRAM 16 MB + 16 MB.
* **Стандартная Flash:** `N1` обозначает QSPI-NOR Flash объёмом 1 MB.

Обозначение описывает конфигурацию, но не гарантирует, что каждому сочетанию кодов соответствует серийный SKU. В руководстве SiFli SF32LB566VCB36 и SF32LB586VDD36 указаны как стандартные конфигурации MCU для семейств SF32LB56-MOD и SF32LB58-MOD соответственно; возможны и другие конфигурации модулей, разработанные под требования заказчика. Сведения о наличии, установленном MCU, распиновке и электрических характеристиках сверяйте с документацией конкретного модуля.
