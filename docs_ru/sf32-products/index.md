# Продукты SF32 { #sf32-products }

## Что входит в этот раздел { #what-this-section-covers }

Начните с [обзора семейства SF32](family/SF32_family.md), чтобы понять, какие семейства доступны и чем различаются их основные возможности. Когда выбор семейства и корпуса сузится до нескольких вариантов, [правила обозначения](family/SF32_namingrule.md) помогут расшифровать полное обозначение нужного устройства.

Используйте инструмент [«Подбор компонентов SF32»](product-selector.md), если на выбор влияют архитектура питания, корпус микросхемы, дисплей, аудио, память, GPIO, беспроводная связь или специализированные аппаратные функции. Селектор помогает составить предварительный список вариантов; точное обозначение, корпус, электрические пределы и разводку платы всё равно необходимо проверить по соответствующей документации SiFli.

После выбора направления изучите [референсные проекты](../hardware/reference-designs/reference-designs.md) и [этапы подготовки к серийному производству](../hardware/design-for-production.md). Эти материалы связывают выбор устройства с референсным оборудованием, рекомендациями по проектированию, библиотеками CAD, решениями по BOM, контрольными списками ревью и свидетельствами успешного первоначального запуска.

## Перейти сразу к нужному оборудованию { #browse-hardware-directly }

Уже знаете, какое оборудование вам нужно? Откройте подходящий каталог:

- [Чипы](family/SF32_family.md) — сведения о семействах устройств и выборе конкретного варианта.
- [Модули](modules/SF32LB52-MOD-1.md) — проектирование платы-носителя на основе модуля, в котором уже интегрированы радиотракт и основные аппаратные узлы.
- [Отладочные платы](devkits/SF32LB52-DevKit-LCD.md) — поддерживаемое оборудование для проверки ПО и периферии.

Аппаратная документация охватывает физическую реализацию изделия. Настройку SDK, примеры, цепочки инструментов и поддержку программных платформ см. в разделе [Разработка](../develop/index.md).
