# SF32LB52-MOD-1 { #sf32lb52-mod-1 }

## Общие сведения { #overview }

SF32LB52-MOD-1 — семейство энергоэффективных Bluetooth-модулей на базе MCU-платформы SF32LB52x. В стандартном варианте N16R8 используется SF32LB525UC6. Модуль размером 27,9 × 18,0 × 3,1 mm объединяет двухъядерную платформу Arm Cortex-M33 STAR-MC1, RF-тракт, кварцевый резонатор 48 MHz и интерфейс для антенны. В зависимости от кода изделия используется печатная антенна на модуле либо внешний разъём IPEX.

В DS5203 V0.3 описана печатная антенна на модуле и отмечена возможность подключения внешней антенны через IPEX для другой модели. Однако документ не связывает варианты антенн с опубликованными SKU памяти. До завершения разводки платы-носителя уточните у SiFli конфигурацию антенны для выбранного модуля. Готовое изделие необходимо проверить по RF-характеристикам и требованиям применимой сертификации. Выведенные интерфейсы позволяют использовать функции Bluetooth, графики и аудио в компактных подключённых устройствах.

В зависимости от SKU в корпус микросхемы может быть включена OPI-PSRAM. Интерфейс модуля выводит основные функции семейства микросхем: GPIO, SPI, LCD, MPI, UART, I2C, PWM, SDIO, USB 2.0 FS и аналоговые аудиоинтерфейсы.

!!! info
    Сведения о семействе микросхем, архитектуре и наборе периферийных устройств см. на странице [SF32LB52x](../chips/SF32LB52x.md). Здесь рассматриваются интеграция на уровне модуля, питание, корпус и выбор варианта.

## Области применения { #applications }

**SF32LB52-MOD-1 подходит для изделий, которым нужны функции Bluetooth, графики и аудио, а также требуется снизить риски проектирования RF-части и разводки платы.** Например:

- Смарт-часы, фитнес-браслеты и носимые медицинские устройства
- Bluetooth-хабы для датчиков и подключённые аксессуары
- Умные замки, устройства умного дома и компактная бытовая техника
- Компактные графические HMI
- Автомобильные брелоки и носимые пульты дистанционного управления
- Подключённые устройства с дисплеем для проектов, чувствительных к стоимости

Рассмотрите SF32LB52-MOD-1, если изделию требуется одна или несколько из следующих возможностей:

- Интеграция RF на уровне модуля с вариантами печатной и внешней антенны
- Выведенные интерфейсы для функций Bluetooth, графики и аудио платформы микросхемы
- Повторное использование ПО и периферийных возможностей SF32LB52x
- Компактная интеграция модуля в носимые устройства или HMI с ограниченным пространством

## Возможности и характеристики { #features-and-specifications }

### Вычисления и память { #compute-and-memory }

- Прикладное ядро Arm Cortex-M33 STAR-MC1 (HCPU), частота до 240 MHz, производительность до 370 DMIPS / 984 EEMBC CoreMark
- Кэш инструкций: 32 KB; кэш данных: 16 KB
- 512 KB SRAM с сохранением данных
- Специализированное малопотребляющее ядро Arm Cortex-M33 STAR-MC1 (LCPU), частота до 24 MHz, с 64 KB SRAM с сохранением данных
- FPU одинарной точности и MPU на обоих ядрах
- Дополнительная встроенная в корпус OPI-PSRAM (зависит от SKU модуля)

### Беспроводная связь { #wireless-connectivity }

- Двухрежимный Bluetooth 5.3 с поддержкой BLE Audio
- Чувствительность: −100 dBm (BLE/1 Mbps), −96,3 dBm (BR), −95,5 dBm (EDR2)
- Максимальная мощность передачи: 19 dBm (BR/BLE), 13 dBm (EDR2/EDR3)
- Пиковый ток приёма BR: 2,4 mA при 3,8 V

### Графика и дисплей { #graphics-and-display }

- Графический движок ePicasso 2.0 для 2D/2.5D
- Аппаратный ускоритель декомпрессии графики без потерь eZip 2.0
- Контроллер LCD с поддержкой интерфейсов 8080, SPI, Dual-SPI и Quad-SPI
- Хорошо подходит для компактных дисплеев часов и небольших HMI-устройств

### Аудио { #audio }

- 1 × 24-битный аудио-DAC
- 1 × 24-битный аудио-ADC Sigma-Delta
- 1 интерфейс I2S
- 1 интерфейс PDM
- Аналоговый аудиовход и аудиовыход через интерфейс модуля

К одному интерфейсу PDM можно подключить до двух цифровых микрофонов, поэтому количество интерфейсов PDM не равно числу подключаемых микрофонов. Фактическая схема зависит от мультиплексирования выводов и разводки платы. Если установлен дополнительный кварц 32,768 kHz, выводы PA22/PA23 не выведены на внешние контакты; альтернативное назначение выводов PDM приведено в руководстве по аппаратной части.

### Интерфейсы хранения данных { #storage-interfaces }

- Дополнительная встроенная в корпус OPI-PSRAM (зависит от SKU модуля)
- 1 × MPI (QSPI) для внешней памяти SPI NOR или SPI NAND
- 1 интерфейс SD/SDIO с поддержкой SD3.0, SDIO3.0 и eMMC

### Безопасность { #security }

- Аппаратные ускорители AES, HASH и CRC
- Генератор истинно случайных чисел (TRNG)
- Сертификация PSA уровня 1 (PSA Certified Level 1)

### Питание, корпус и ввод-вывод { #power-package-and-io }

- Корпус модуля: 27,9 × 18,0 × 3,1 mm
- Рабочая температура: от −40 °C до +85 °C
- VSYS: 3,2–4,7 V при прямом подключении литий-ионного аккумулятора или 3,7–4,7 V от стабилизированного источника питания; рекомендуется 3,8 V.
- Напряжение I/O: 3,3 V
- VBATS: вход для измерения напряжения аккумулятора и вход ADC, диапазон 0–4,7 V. Подключайте измеряемое напряжение напрямую, без внешнего резистивного делителя.
- VDD33_VOUT2: выход встроенного в модуль LDO 3,3 V для внешней периферии. По умолчанию он отключён и включается программно. Максимальный выходной ток — 150 mA; суммарная ёмкость линии не должна превышать 7,4 µF.
- 68-контактный интерфейс модуля. Сигнальные контакты поддерживают мультиплексированные функции: GPIO, SPI, LCD, MPI, UART, I2C, PWM, SDIO, USB 2.0 FS, цифровое и аналоговое аудио.

В [руководстве SiFli по моделям модулей](https://github.com/OpenSiFli/SiFli-Wiki/blob/main/source/en/silicon/%E6%A8%A1%E7%BB%84%E5%9E%8B%E5%8F%B7%E6%8C%87%E5%8D%97.md) и руководстве по применению EPD также указан A128R16, однако в связанном здесь даташите DS5203 V0.3 приведён только N16R8. Перед выбором A128R16 уточните у SiFli его текущую доступность и конфигурацию памяти.

В официальных источниках для флеш-памяти A128R16 используются разные обозначения: в [руководстве OpenSiFli по моделям модулей](https://github.com/OpenSiFli/SiFli-Wiki/blob/main/source/en/silicon/%E6%A8%A1%E7%BB%84%E5%9E%8B%E5%8F%B7%E6%8C%87%E5%8D%97.md) указана SPI-NAND объёмом 128 MB, а в [руководстве SiFli по моделям плат](https://wiki.sifli.com/board/devkit_guide.html) для соответствующей SKU DevKit указана QSPI-NAND объёмом 128 MB. Источники не поясняют, связано ли различие с установленной микросхемой или с обозначением интерфейса. Прежде чем использовать конфигурацию платы как основу для модуля, сверьте установленный компонент флеш-памяти и режим шины со схемой/BOM конкретной ревизии платы.
