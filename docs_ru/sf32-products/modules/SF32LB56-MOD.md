# SF32LB56-MOD { #sf32lb56-mod }

## Общие сведения { #overview }

SF32LB56-MOD — семейство универсальных маломощных MCU-модулей с Bluetooth на платформе SF32LB56xV от SiFli. Стандартная конфигурация включает SF32LB566VCB36, 4 МБ + 8 МБ OPI-PSRAM в составе SiP и 1 МБ QSPI-NOR. Компактный модуль объединяет двухъядерную обработку MCU, Bluetooth 5.3 с поддержкой BLE Audio, графическое ускорение, аудиоинтерфейсы, варианты Flash в зависимости от SKU и интегрированный RF-тракт.

В модуле интегрированы RF-тракт, кварцевый резонатор и высокоскоростная память; предусмотрен вариант с печатной антенной на модуле или с внешней антенной через разъём, совместимый с IPEX. RF-характеристики готового изделия необходимо проверить, а разводку платы-носителя выполнить с учётом выбранного варианта антенны. Интерфейсы и конфигурации памяти подходят для изделий с требованиями к дисплею, аудио, датчикам и локальной обработке.

Семейство выпускается в нескольких конфигурациях памяти. Габариты всех вариантов составляют 18,0 × 32,9 × 3,1 мм; рабочий диапазон температур — от -40 до +85 °C. В [руководстве по аппаратному проектированию SF32LB56-MOD](../../hardware/chip-guides/SF32LB56-MOD_hardware_design_guide.md), основанном на DS5602 V0.3, приведены дополнительные сведения об антенне и разводке. В руководстве SiFli по моделям модулей перечислены конфигурации памяти, но не указано, какой вариант антенны соответствует каждому SKU. До завершения разводки платы-носителя уточните у SiFli вариант антенны выбранного модуля.

!!! info
    Описанные ниже вычислительные, графические и аудиовозможности относятся к платформе SF32LB56xV, установленной в модуле; доступность функций извне зависит от распиновки модуля и мультиплексирования выводов. Архитектура и полный набор периферийных устройств семейства микросхем описаны на странице [SF32LB56x](../chips/SF32LB56x.md). Здесь рассматриваются интеграция модуля, варианты памяти по SKU, линии питания и области применения.

## Области применения { #applications }

SiFli указывает для SF32LB56-MOD следующие области применения:

- Носимые устройства: смарт-часы высокого класса, смарт-браслеты, носимые медицинские устройства и фитнес-оборудование
- Промышленность: экономичные дисплейные решения, графические интерфейсы HMI, центры управления промышленными датчиками, мониторинг оборудования и измерительные приборы
- Автомобильная техника: центральные блоки управления электромобилями, автомобильные ключи и носимые устройства дистанционного управления автомобилем
- Домашняя автоматизация: малые и средние интеллектуальные бытовые приборы и умные замки
- Общие применения: хабы для датчиков с низким энергопотреблением и Bluetooth Mesh
- Примеры AIoT: распознавание голосовых команд, устройства умного дома, интеллектуальные ключи и интеллектуальные панели управления

Рассмотрите SF32LB56-MOD, если проекту требуется одна или несколько из следующих возможностей:

- Интеграция RF-тракта, варианта антенны, кварцевого резонатора и высокоскоростной памяти на уровне модуля
- Выбор конфигурации памяти среди перечисленных SKU модулей
- Интерфейсы для дисплея, аудио, датчиков и локальной обработки
- Компактные размеры для изделий с ограниченным пространством

## Возможности и характеристики { #features-and-specifications }

### Вычисления и память { #compute-and-memory }

- HCPU: Arm Cortex-M33 STAR-MC1, частота до 240 МГц, производительность до 370 DMIPS / 984 EEMBC CoreMark
- LCPU: Arm Cortex-M33 STAR-MC1, частота до 96 МГц, производительность до 148 DMIPS / 394 EEMBC CoreMark
- Система памяти HCPU: кэш инструкций 32 КБ, кэш данных 16 КБ и SRAM 800 КБ, включая 128 КБ SRAM с сохранением данных
- Система памяти LCPU: кэш инструкций 16 КБ, кэш данных 8 КБ и 160 КБ SRAM с сохранением данных
- FPU одинарной точности и MPU на обоих ядрах
- Матричный ускоритель нейронных сетей и ускорители обработки сигналов для более сложных локальных задач

### Беспроводная связь { #wireless-connectivity }

- Двухрежимный Bluetooth 5.3 с поддержкой BLE Audio
- Чувствительность: -100 дБм для BLE при 1 Мбит/с, -96,3 дБм для BR, -95,5 дБм для EDR2 и -88,5 дБм для EDR3
- Максимальная мощность передачи: 19 дБм для BR/BLE и 13 дБм для EDR2/EDR3
- Пиковый ток приёма BR: 2,2 мА при 3,3 В

### Графика и дисплей { #graphics-and-display }

- Графический движок ePicasso 2.0 для 2D/2.5D
- Аппаратная поддержка поворота, масштабирования, зеркального отражения и альфа-смешивания
- Графические задачи с разрешением до 1024 × 1024
- Декомпрессия графики без потерь с помощью eZip 2.0 и поддержка анимации eZip-A
- Поддержка LCD-интерфейсов 8080, SPI, Dual-SPI, Quad-SPI, DPI/RGB и JDI
- TurboPixel: extDMA сжимает итоговый framebuffer с потерями и фиксированным коэффициентом, а контроллер дисплея распаковывает его. Это снижает требуемые для конкретной нагрузки пропускную способность PSRAM и объём памяти кадрового буфера.

### Аудио { #audio }

- 1 аудио-ЦАП 24 бит
- 1 аудио-АЦП Sigma-Delta 24 бит
- 2 интерфейса PDM (PDM1/PDM2), каждый поддерживает левый и правый микрофонные каналы
- 1 интерфейс I2S
- Преобразование частоты дискретизации аудио и аппаратное ускорение эквалайзера (EQ)

К каждому интерфейсу PDM можно подключить до двух цифровых микрофонов, поэтому оба интерфейса вместе поддерживают до четырёх микрофонов. Число интерфейсов PDM не равно числу микрофонов. Фактическое подключение зависит от мультиплексирования выводов и разводки платы.

SiFli указывает в качестве стандартной конфигурации SF32LB566VCB36 с 4 МБ + 8 МБ OPI-PSRAM в одном корпусе и 1 МБ QSPI-NOR; эта конфигурация памяти соответствует N16R12N1. В руководстве по моделям не указан отдельный номер детали микросхемы для A128R12N1 и D128R12N1. Уточните у SiFli точный номер детали для этих SKU.

### Питание и ввод-вывод { #power-and-io }

- Рекомендуемый диапазон рабочего напряжения VDD_3V3: 2,97–3,6 В
- Рекомендуемый диапазон рабочего напряжения VDD_1V8: 1,7–1,95 В
- Рекомендуемый диапазон рабочего напряжения VDDIO: 1,7–3,6 В
- Питание VDD_3V3, VDD_1V8 и VDDIO должно включаться одновременно
- Уровень интерфейса PA00–PA11 фиксирован на 3,3 В и не зависит от VDDIO
- Интерфейс модуля с 89 выводами
- Рабочая температура: от -40 до 85°C
