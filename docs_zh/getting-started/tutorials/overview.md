# 教程概览 { #tutorials-overview }

本系列帮助你从“成功烧录一次”逐步掌握可在实际项目中复用的 SF32 开发技能。内容按工程推进方式安排：先验证单个外设，再组合多个子系统，最后建立产品开发所需的验证证据。教程以 SiFli-SDK 示例为起点，但核实硬件状态、保留已知可用的基线配置并测量实际结果，这些做法适用于所有 SF32 软件开发路径。

本系列是[入门指南](../index.md)的第二阶段。开始前，请先达到其中规定的首次运行成功标准。如果你仍在选择芯片、模块或开发板，建议先阅读[SF32 系列](../../sf32-products/family/SF32_family.md)。

## 所需准备 { #what-you-need }

请使用具备可用 USB 数据连接和串口控制台的 SF32 开发板。例如，`sf32lb52-lcd_n16r8` 是 SiFli-SDK 中 SF32LB52-DevKit-LCD_N16R8 的板级名称。本系列不假设某一块开发板支持所有练习：请查看每个示例的支持平台列表，并根据相关原理图和板级文件核对引脚、外设、显示、音频和存储信息。如需核对 SF32LB52x 的 SDK 板级标识，可参阅官方[支持的开发板列表](https://docs.sifli.com/projects/sdk/latest/en/sf32lb52x/supported_boards/index.html)。

</div>

## 推荐学习路径 { #recommended-learning-path }

<div align="center"><em>表：教程路线图</em></div>

<div align="center" markdown>

| 学习阶段 | 开始条件 | 将练习的内容 | 后续去向 |
|:-----|:---------|:-------------|:---------|
| [基础外设](beginner.md) | `hello_world`、烧录和串口输出均已正常工作。 | GPIO、FinSH、ADC、PWM、RTC，以及一个小型板级项目。 | 能够独立验证输入、输出和基础外设后，进入下一阶段。 |
| [子系统集成](intermediate.md) | 单个外设已经能够可靠工作。 | I2C 传感器、LVGL、BLE、音频、存储，以及有针对性的共存测试。 | 两个实际需要协同工作的子系统能够稳定运行后，进入下一阶段。 |
| [产品验证](advanced.md) | 已能集成中间件并诊断常规故障。 | 实测功耗、OTA 恢复、自定义显示方案、崩溃分析、多连接 BLE，以及可复用驱动。 | 将“开发”和“学习”栏目中的相关文章作为后续实现的参考资料。 |

</div>

这一顺序是有意设计的。在开发板、烧录流程、串口控制台和简单 GPIO 测试都已确认可用前，不要急于从显示屏、BLE 服务或自定义驱动开始。后续教程出现问题时，先回到最近一个仍能稳定复现成功标准的阶段。

## 如何使用每篇教程 { #how-to-use-each-tutorial }

每个练习都会说明可作为起点的 SDK 示例、目标、成功标准和常见故障检查项。请从指定示例开始，而不是从空项目开始；每次只改变一个行为，并在组合功能前保留一个已知可用的构建版本。对于预计会复用的配置，请记录开发板版本、SDK 版本、板级名称和观察结果。

教程并不替代参考资料：

- 使用[开发](../../develop/index.md)了解平台工作流、工具、固件主题和汇总后的 SDK 示例索引。
- 使用[学习](../../learn/graphics/overview.md)辅助架构和子系统决策，例如图形处理流程、蓝牙（Bluetooth）行为和功耗策略。
- 使用[SF32 系列](../../sf32-products/family/SF32_family.md)了解器件选型、开发板信息、硬件设计指南和量产检查。
