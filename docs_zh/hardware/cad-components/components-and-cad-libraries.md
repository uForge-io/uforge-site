# 元器件和 CAD 库 { #components-and-cad-libraries }

选定 SF32 芯片或模组、确定系统架构后，下一步是进入受控 BOM 管理和 PCB 设计阶段。本页介绍这一阶段需要的两类资料。它们的用途不同：**合格供应商名录（AVL）**用于筛选经思澈科技（SiFli）验证的元器件；**EDA 工具库**提供实现所选硬件时需要的原理图符号、PCB 封装和参考工程数据。

两者都不能替代器件专用的硬件设计指南、封装图或在量产版本电路板上的最终验证。

## 从 BOM 到 CAD 的评审顺序 { #bom-to-cad-review-sequence }

1. **锁定实现基线。** 选定准确的芯片或模组、封装、内存配置、显示接口和电源架构。选择配套元器件前先阅读其硬件设计指南。
2. **从 AVL 筛选关键元器件。** 检查列出的电气要求，而不只匹配料号。尤其应关注晶体负载电容与 ESR、Buck 电感电流限值、Flash 电压与时序模式、温度范围以及固件兼容性。
3. **使用官方库创建原理图。** 以相关 EDA 库和参考设计为起点。将每个原理图符号、PCB 封装、引脚编号、焊盘图和禁布要求与所选器件的最新数据手册及封装图独立对照。
4. **结合 PCB 布局评审完整 BOM。** 确认每个经过适用性验证的元器件仍符合实际电源轨电压、电流、接口速率、装配工艺和外壳结构约束。落实器件或模组硬件设计指南中关于电源、RF、时钟、内存、显示和调试访问的要求。
5. **验证量产版本硬件。** 在最终电路板版本上测试启动、烧录、外设、无线和恢复行为，并测量功耗。记录已批准的替代料，以及所有有意偏离设计指南或 AVL 的设计项。

## 实际使用边界 { #practical-boundaries }

- AVL 反映的是特定版本下的元器件适用性验证结果；发布量产 BOM 前，请再次确认清单版本和元器件供货情况。
- EDA 库提供的是设计起点，不能证明完成后的 PCB 布局满足制造要求或电气要求。
- 若元器件未列入 AVL，应按相关要求完成适用性验证，并在目标硬件上验证后再用于量产。
- 对于模组方案，应先阅读模组设计指南；载板的 BOM 和布局仍需要同样严格的评审。

完整设计评审请继续阅读[面向量产的设计](../design-for-production.md)；若芯片、模组或开发板基线尚未确定，请返回[SF32 产品选型工具](../../sf32-products/product-selector.md)。
