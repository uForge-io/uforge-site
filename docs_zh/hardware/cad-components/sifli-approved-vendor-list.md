# SF32 合格供应商名录 { #sf32-approved-vendor-list }

## 本列表的用途 { #what-this-list-is-for }

**合格供应商名录（AVL）**记录了思澈科技（SiFli）针对 SF32 设计开展的器件验证。V0.3 收录了无源晶体、Buck 电感、NOR/NAND Flash、SD-NAND 和一款 LCD 驱动器，触控控制器工作表中没有条目。可据此筛选候选器件、寻找替代供应商，并结合实际 PCB、固件、外壳、生产工艺和供应链条件完成验证。列入 AVL 不等于已经通过具体产品的验证。

本页根据思澈科技（SiFli）官方 AVL 电子表格 **`SIFLI-MCU-AVL-认证表` V0.3（2026-01-21）**整理。随着新器件通过验证，AVL 可能更新；本页仅反映截至该日期的 V0.3 版本，并非实时数据库。本次核对只确认了 V0.3 所列内容，不能据此判断任何器件在后续 AVL 版本中是否仍获认可。冻结 BOM 前，请查阅最新原始文件：

!!! note "如何使用此列表"
    原表为晶体和 Buck 电感给出了通用要求，其他表格主要记录各料号的参数。可以按这些要求筛选候选器件，但不能默认所有已列入器件都满足每项通用限值；下文会标出原始数据中的差异。原表中整列为空的字段，例如 Flash 下载工具支持，本页予以省略，不能据此认定已经验证了相应支持。详细表格中的“—”通常表示 V0.3 原表未提供该字段数值；NOR Flash 的 DTR 时钟列除外，该列用“—”表示原表标注为“不支持”，详见下文 NOR Flash 说明。

做 BOM 选型时，建议按下面三个步骤推进，而不是看到一个料号就直接定案：

1. **先按要求筛选候选料号。** 核对容量、电源电压、封装及各类器件的要求，例如晶体的负载电容、电感的 DCR/Isat、Flash 的 SDR/DTR 时钟，确认它们与原理图设计和功耗预算相符。
2. **再核对数据手册关键参数之外的约束。** 确认温度范围是否匹配产品的工作和存储环境，固件期望读取的 Manufacturer ID / JEDEC ID 是否与该器件一致，以及 OTA、文件系统或下载工具是否已针对这个准确料号完成验证，而不只是验证过同系列的其他器件。
3. **量产定型前必须完成实板验证。** 在自己的板上测量待机和工作电流，在最终 PCB 和整机外壳上重新验证晶体的 RF 校准，并为目前只有单一供应商的器件各确定至少一个备选供应商。

## NOR Flash { #nor-flash }

## SPI-NAND Flash { #spi-nand-flash }

V0.3 收录了 18 个 SPI-NAND 料号，容量为 512 Mb 和 1 Gb。配合兼容的驱动和软件栈，这些器件可用于文件或数据存储，例如 FatFS、FlashDB 和 LittleFS；具体料号是否兼容仍需验证。NAND 的页访问、ECC 和坏块管理与 NOR 的直接 XIP 访问不同。原表中所有料号的 **Golden Block** 均为 `block0`，但未说明保证条件，也未说明哪些固件流程依赖该块。应结合器件和 SDK 文档确认这些前提。

## 设计审查核对清单 { #design-review-checklist }

在冻结原理图或 BOM 之前，请结合实际产品设计，逐项审查每个选定的 AVL 器件：

- [ ] 准确料号、封装、温度等级和订货后缀与 AVL 中批准条目一致，或者已有明确的工程放行路径。
- [ ] 电压范围与板上使用的 SF32 IO 电源轨、Flash 电源轨、显示电源轨或电源转换器电压相匹配。
- [ ] 封装、焊盘、器件高度和装配限制与 PCB 库及制造工艺匹配。
- [ ] 固件能够在适用场景下通过 JEDEC / Manufacturer ID 或等效运行时探测机制正确识别该器件。
- [ ] Boot、下载、OTA、文件系统、显示或触控驱动行为已在该准确器件上完成验证。
- [ ] 低功耗电流数据来自真实硬件测量，而不是直接照抄 AVL 或器件数据手册。
- [ ] 晶体的 CBANK_SEL 行为、频偏表现和 RF 校准已在最终 PCB、天线和整机结构上完成验证。
- [ ] Flash 擦除 / 编程 / 读取时间已在产品目标电压和温度范围内测试通过。
- [ ] 对于晶体、电感、存储器和显示面板等高风险 BOM 项，至少确定了一个可行的替代来源。

这份核对清单有意采用比“器件出现在 AVL 中”更严格的标准。AVL 只能帮助缩小选型范围；产品能否发布，最终仍取决于板级验证证据。

## 选型检查清单 { #sourcing-checklist }

- [ ] 对照当前可下载的 AVL 原始电子表格，重新核对料号和修订后缀，而不要只依赖本页快照。
- [ ] 对于 Flash 器件，确认固件期望读取的 Manufacturer / JEDEC ID 与订购的准确料号一致，而不是只核对系列名。同一系列或商品名称下的器件也可能返回不同的 ID 字节。
- [ ] 对于 NAND、SD-NAND，以及用于存放文件系统的器件，在真实硬件上验证启动和下载工具支持、OTA 更新流程，以及 FatFS / FlashDB / LittleFS 的运行情况。启动调试时能成功读取，并不代表已经验证了 OTA 兼容性。
- [ ] 对于晶体，应在实际产品板上验证 CBANK_SEL 和表中所列的 TX Ch39 频偏。原表未说明参考板布局或完整测试配置，因此比较结果前应先确认测试模式和条件。
- [ ] 在实际产品板上测量待机、深掉电和读取电流。AVL 未交代每项数据的来源及完整工作条件，因此还需核对数据手册和测试条件。
- [ ] 确认封装和焊盘与 PCB 库、装配能力和工艺限制匹配，而不仅仅是电参数符合。
- [ ] 对于尚未列入 AVL 的器件，在纳入 BOM 之前，应按对应器件类别的要求完成适用性验证，并视情况与思澈科技（SiFli）共享验证结果。
- [ ] 为每个单一供应来源的器件确定替代来源。V0.3 只列出一个 LCD 驱动器，未列出触控控制器；应另行确认当前供货和支持情况，不能将此快照视为最新状态。
- [ ] 每次重大 BOM 冻结前都重新核查一次本清单——它是快照，不是实时数据库。
