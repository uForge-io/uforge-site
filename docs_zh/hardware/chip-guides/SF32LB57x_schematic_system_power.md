# SF32LB57x 硬件设计指南 — 最小系统与电源 { #sf32lb57x-hardware-design-guide-minimum-system-power }

!!! note "SF32LB57x 硬件设计指南的一部分"
    原理图设计指导现分为三页：本页（第 5.1-5.2 节：最小系统设计与电源系统）、[时钟、RF 与用户接口](SF32LB57x_schematic_clock_rf_interfaces.md)（第 5.3-5.5 节），以及[存储与制造](SF32LB57x_schematic_storage_mfg.md)（第 5.6-5.7 节）。如需选型和完整设计流程，请从 [SF32LB57x 硬件设计指南概览](SF32LB57x_hardware_design_guide.md) 开始。

## 5. 原理图设计指导 { #5-schematic-design-guidelines }

本章按常规板级启动调试顺序组织原理图设计内容。必须先完成最小系统设计，否则首版样机可能无法上电、无法从存储启动、无法下载固件或无法进入调试。最小系统确认后，再依次评审详细电源系统、时钟生成、RF 路径、显示、音频、摄像头、传感器和其他产品功能。

### 5.1. 最小系统设计 { #51-minimum-system-design }

#### 5.1.1. 最小系统设计顺序 { #511-minimum-system-design-sequence }

启动调试阶段的故障，最常追溯到最小系统、供电系列、启动模式、存储上拉、晶体选型、BUCK 器件，或缺少下载访问接口。分配产品外设前，应先固定以下内容：

1. 将最小系统原理图与封装和供电系列匹配。
2. 设定 `PA00` / `PA01` 的启动与调试行为，并预留恢复访问路径。
3. 选择启动介质，并按介质类型配置 `PA13` / `PA15` / `PA17` 上拉。
4. 定义电源树框架、充电/OVP 路径、BUCK 电感/电容和默认电源状态，并在第 5.2 节完成详细评审。
5. 选择 48 MHz 和 32.768 kHz 晶体，并在第 5.3 节确认校准方案。
6. 预留 DBG-UART、SWD、启动模式、电源、地和治具测试点。

启动介质必须在原理图冻结前确定。合封存储可能已经占用 MPI 通道，不同外部介质的上拉和电源控制要求也不同。

<div align="center"><em>表 5.1-1：外部启动介质选择</em></div>

<div align="center" markdown>

| `Bootstrap[1]` (`PA13`) | `Bootstrap[0]` (`PA17`) | 外部启动介质 |
|:------------------------|:------------------------|:-------------|
| L | L | SPI NOR Flash |
| L | H | SPI NAND Flash |
| H | L | SD NAND Flash |
| H | H | eMMC |

</div>

<div align="center"><em>表 5.1-2：外部启动介质上拉要求</em></div>

<div align="center" markdown>

| 启动介质 | 上拉要求 |
|:---------|:---------|
| SPI NOR Flash | `PA13` / `PA17` 无需外部上拉。 |
| SPI NAND Flash | `PA17` 需 7.5 kohm 上拉；`PA13` 无需上拉。 |
| SD NAND Flash | `PA13`、`PA15` 需 7.5 kohm 上拉；`PA17` 无需上拉。 |
| eMMC | `PA13`、`PA15`、`PA17` 均需 7.5 kohm 上拉。 |

</div>

<div align="center"><em>图 5.1-7：Bootstrap 管脚推荐电路</em></div>

启动存储介质的供电应按介质类型和供电系列分别设计。电池供电系列中，外接 NOR Flash 使用 `VDD33_VOUT1` 供电；外接 SPI NAND Flash 应在 `VDD33_VOUT1` 后级增加负载开关；外接 SD NAND Flash 或 eMMC 使用外部 LDO。3.3 V 供电系列的外接启动介质统一使用外部 LDO。思澈科技（SiFli）推荐使用 `PA21` 作为外部启动介质电源开关的使能脚，高电平开启、低电平关闭；若电池供电型号未引出 `PA21`，来源指南允许改用默认上拉的 GPIO。启动阶段必须保证介质电源处于可用状态。若合封存储已经占用 MPI3，外部 MPI3 仅支持 SD NAND 或 eMMC，不应再挂载外部 SPI NOR/SPI NAND。

#### 5.1.4. 调试与下载访问 { #514-debug-and-download-access }

产品 IO 分配前应预留调试和恢复访问。若默认 DBG-UART、启动配置或 SWD 路径不可访问，首版问题会很难恢复。

<div align="center"><em>表 5.1-3：调试下载测试点建议</em></div>

<div align="center" markdown>

| 测试点 | 建议 | 用途 |
|:-------|:-----|:-----|
| 电源输入 | `VBAT` 或 3.3 V、必要时预留 `VSYS` / `VDD33_VOUT1` | 夹具供电、电流测试、低功耗验证。 |
| GND | 多个地测试点 | 下载、调试、校准和电流测试回路。 |
| DBG-UART | `PA18` / `PA19`，对应 `DBG_UART_RXD` / `DBG_UART_TXD` | 默认下载、日志和产线烧录。 |
| SWD | `PA43` / `PA44` 或型号定义的 SWDIO/SWCLK | 调试和问题定位。 |
| 启动模式 | `PA00` 或型号定义的启动模式选择脚 | 进入下载/恢复模式。 |
| SWD 切换 | `PA01` 或对应配置脚 | 需要切换 SWD 位置时使用。 |
| 电源键 / 唤醒 | `PA34` 或对应按键脚 | 夹具开机、复位或唤醒测试。 |

</div>

<div align="center"><em>表 5.1-4：默认调试口连接</em></div>

<div align="center" markdown>

| 调试信号 | 管脚 | 网络名称 |
|:---------|:-----|:---------|
| `DBG_UART_RXD` | `PA18` | `USART1_RXD` |
| `DBG_UART_TXD` | `PA19` | `USART1_TXD` |
| `SWD_CLK` | `PA43` | `SWCLK` |
| `SWD_DIO` | `PA44` | `SWDIO` |

!!! warning
    量产测试点中应同时预留 `DBG_UART_RXD` 和 `DBG_UART_TXD`。不要误将 RXD 预留两次。

`PA18`/`PA19` 默认用于 DBG-UART，`PA43`/`PA44` 默认用于 SWD；SWD 也可切换到 `PA18`/`PA19`。芯片支持 DBG-UART、SWD、普通 UART 和 USB 四种下载方式：常规启动模式仅支持 DBG-UART 和 SWD，BOOT 模式可启用四种方式。BOOT 模式与 SWD 引脚切换由 `PA00`、BOOT 寄存器、`PA01` 及上位机 BOOT 开关共同决定；设计量产和恢复流程时，应按来源指南中的完整模式表核对，不能只依据单一管脚状态推断下载方式。

### 5.2. 电源系统 { #52-power-system }

#### 5.2.1. 电源树规划 { #521-power-tree-planning }

应在原理图录入前先画出电源树，并标注每一路电源的来源、默认状态、最大负载、睡眠状态和控制 GPIO。

<div align="center"><em>表 5.2-1：电源树规划速查</em></div>

<div align="center" markdown>

| 电源类别 | 规划重点 |
|:---------|:---------|
| 常供电电源 | 只保留 RTC、唤醒、必要检测和蓝牙保持所需电路，逐项计算静态电流。 |
| 可关断外设电源 | 显示、背光、传感器、马达、外部存储、摄像头等优先使用负载开关或可关断 LDO。 |
| 模拟/RF/音频电源 | 单独滤波、短回路、远离大电流和高速数字区域。 |
| 启动介质电源 | 默认状态必须支持启动，睡眠状态必须避免倒灌和漏电。 |
| 上拉电源 | I2C、按键、传感器中断等上拉电源应随对应外设电源策略一起设计。 |

</div>

#### 5.2.2. 电池供电系列 { #522-battery-powered-variants }

电池供电系列通常涉及 `VBUS`、`VBAT`、`VCC`、`VSYS`、`BUCK_LX`、`BUCK_FB`、内部 LDO 输出、音频电源和 RF 电源。

关键要求：

- `VBUS` 输入范围必须控制在芯片规格允许范围内，并配置 OVP 保护。
- `VBAT` 接电池，同时用于电池电压检测。
- `VCC` 为系统输入电源，应使用足够线宽并靠近芯片放置去耦电容。
- `VSYS` 仅用于指定内部负载、`AVDD_BRF` 和 GPIO 上拉回路；不得用作外部外设电源。
- `VDD33_VOUT1`、`VDD33_VOUT2` 等内部 LDO 输出只能用于规格明确允许的负载，不应作为通用外设电源。注意：来源指南的低功耗说明图文将外部传感器列为 `VDD33_VOUT1` 的负载，但同一指南的电源自查表规定该电源仅用于合封/外部 NOR/NAND Flash 和 `AVDD33_AUD`，并禁止驱动其他外设。该处存在来源冲突；在思澈科技（SiFli）澄清前，不要将传感器接到 `VDD33_VOUT1`。
- `AVDD_BRF`、`AVDD33_AUD` 应从推荐的电源轨取电，并就近滤波。

#### 5.2.3. 3.3 V 供电系列 { #523-33-v-supply-variants }

3.3 V 供电系列通常由外部 3.3 V 电源为 `PVDD`、`AVDD33`、`AVDD_BRF`、`AVDD33_AUD`、`VDDIOA` 等电源域供电。

关键要求：

- 重要的 3.3 V 电源域应采用星型分配。
- 模拟、RF、音频电源应与大电流或高速数字路径分开滤波。
- 使用 `VBATS` 检测电池电压时，应确认输入范围并配置合适滤波。
- 3.3 V 供电系列的所有外接启动存储介质统一由外部 LDO 供电；其使能脚推荐使用 `PA21`。
- 所有内部参考或 LDO 输出管脚只允许连接所需的外部电容，不应接外部电压。

#### 5.2.4. 电源电容与用途速查 { #524-power-capacitor-and-usage-quick-reference }

下表用于原理图初审，最终值仍以数据手册和参考设计为准。

<div align="center"><em>表 5.2-2：电源电容与用途速查</em></div>

<div align="center" markdown>

| 电源/管脚 | 典型外接电容 | 主要用途 | 设计注意事项 |
|:----------|:-------------|:---------|:-------------|
| `VBUS` | >= 10 μF | USB/充电输入 | 仅电池供电系列使用；应增加 OVP/ESD/EOS 防护。 |
| `VBAT` | >= 4.7 μF | 电池连接与电池电压检测 | 电池路径走线短粗，避免与敏感线并行。 |
| `VCC` / `PVDD` | >= 10 μF | 主 PMU/系统输入 | 去耦靠近芯片，走线满足电流能力。 |
| `VSYS` | 约 2.2 μF | 内部或指定模拟/RF 相关电源 | 不应作为通用外设供电；总负载和总电容需受控。 |
| `VDD33_VOUT1` | 2.2 μF / 6.3 V | 合封 Flash、外部 NOR/NAND Flash 和 `AVDD33_AUD` | 不应用于心率传感器或其他普通外设；软启动负载电流必须满足源端限制。 |
| `VDD33_VOUT2` | 约 2.2 μF | 显示、马达或指定可控负载 | 默认状态和上电浪涌需与软件配置匹配。 |
| `VDD18_VOUT` | 按所选最小系统原理图配置 | 内部/合封 PSRAM 相关 1.8 V 电源 | 不应用作外部 1.8 V 外设电源。 |
| `VDD_VOUT1` / `VDD_VOUT2` | 各 4.7 μF / 6.3 V | 内部 LDO 输出 | 仅供芯片内部使用，不应给外部外设供电。 |
| `VDD_RET` / `VDD_RTC` | `VDD_RET` 为 0.47 μF / 6.3 V；`VDD_RTC` 为 1 μF / 6.3 V | 保持域和 RTC 内部电源 | 电容靠近管脚放置。 |
| `AVDD_BRF` | 约 4.7 μF | RF 模拟电源 | 滤波电容靠近芯片，接地短且多过孔。 |
| `AVDD33_AUD` | 约 2.2 μF | 音频模拟电源 | 远离 DC/DC、RF、USB、SDIO 和显示时钟。 |
| `MIC_BIAS` | 1 μF / 6.3 V | 麦克风偏置 | 仅作为麦克风偏置电源使用。 |
| `AUD_VREF` / `GPADC_VREF` | `AUD_VREF` 为 1 μF；`GPADC_VREF` 为 4.7 μF | 内部参考 | 仅接电容，禁止外部驱动。 |

</div>

#### 5.2.5. BUCK 电感与反馈 { #525-buck-inductor-and-feedback }

BUCK 电感推荐参数：

<div align="center"><em>表 5.2-3：BUCK 电感推荐参数</em></div>

<div align="center" markdown>

| 参数 | 推荐值 |
|:-----|:-------|
| 电感值 | 4.7 μH ±20% |
| DCR | <= 0.4 ohm |
| 饱和电流 | >= 450 mA |

</div>

PCB 要点：

- 电感、输出电容和反馈电容应靠近芯片放置。
- `BUCK_LX` 回路短而粗，避免在该区域铺铜或布置敏感走线。
- `BUCK_FB` 反馈线宽不宜过细，建议不小于 0.25 mm。
- 电感附近应保持完整参考地，避免噪声耦合到晶体、RF、音频和 GPADC 走线。
- 若整机包含 GPS、心率、ECG、模拟麦克风等敏感模组，可在 BUCK_LX 附近为 EMI 调试器件预留可选焊盘；最终器件值应在整机 EMC 验证期间确定。

#### 5.2.6. 充电与 OVP { #526-charging-and-ovp }

电池产品可选择外部充电管理芯片或片内充电管理模块。

<div align="center"><em>表 5.2-4：充电方案对比</em></div>

<div align="center" markdown>

| 方案 | 供电路径 | 设计要点 |
|:-----|:---------|:---------|
| 外部充电芯片，无 PPM | 电池直接为芯片的 `VBAT` 和 `VCC` 供电。 | 电池电压通过芯片 `VBAT` 管脚上的 GPADC 通道检测，采样精度为 ±30 mV。 |
| 外部充电芯片，带 PPM | 充电芯片的 `VSYS` 为芯片 `VCC` 供电；充电芯片的 `VBAT` 同时连接电池和芯片 `VBAT`。 | 电池电压通过芯片 `VBAT` 管脚上的 GPADC 通道检测，采样精度为 ±30 mV。 |
| 片内充电模块 | 使用芯片内部充电管理模块。 | 若电池亏电导致系统关机，接入充电器后须先将电池充至开机电压，系统才能启动并显示充电界面；自查表以电池达到约 3.6 V 后再由软件开机亮屏为适用条件。 |

</div>

OVP 选型要求：

- `VBUS` 输入不得超过允许范围。
- 可选 OVLO 可调 OVP，思澈科技（SiFli）列出的参考型号为 AW32905FCR。应用说明给出的设置范围是 5.2 V～5.5 V，自查表给出 5.15 V～5.55 V；在思澈科技（SiFli）澄清前，按两者交集 5.2 V～5.5 V 设计。计算时须纳入器件和分压电阻误差：`V_IN_OVLO = ((R1 + R2) / R2) × V_OVLO_TH`，`V_OVLO_TH` 误差不超过 3%，R1/R2 容差为 1%。
- 可选带稳压输出 OVP，思澈科技（SiFli）列出的参考型号为 SGM4064YDE8G 和 LP5305AQVF。应用说明规定为 4.5 V～5.4 V，自查表规定为 4.7 V～5.4 V；在思澈科技（SiFli）澄清前按较窄的 4.7 V～5.4 V 范围设计，负载能力不低于 0.5 A，过流阈值不低于 0.7 A。
- 充电器输入应先经过 TVS/OVP 保护，再进入芯片。

!!! warning "来源指南中的范围差异"
    电源管脚表和自查表将 `VBUS` 输入范围列为 4.6 V～5.5 V，而 OVP 选型说明写为 4.5 V～5.5 V。思澈科技（SiFli）澄清前，按 4.6 V 作为最低工作输入电压设计。

#### 5.2.7. 低功耗电源策略 { #527-low-power-supply-strategy }

低功耗行为应在原理图阶段纳入设计。

建议：

- 显示、背光、传感器、马达、外部存储等外设使用负载开关或可关断 LDO。
- 选用 EN 高电平有效的电源管理芯片。若要求输出默认关闭，应在 EN 与地之间接入 1 MΩ～5.1 MΩ 下拉电阻；具体阻值按整机低功耗指标确定。
- MOS 管电源开关应采用来源指南推荐的 PMOS 加 NMOS 组合拓扑：控制端为高电平时开启电源，低电平时关闭电源；控制端固定通过 1 MΩ 电阻下拉至地。
- I2C 上拉电源应与对应外设使用同一电源轨，避免睡眠漏电。
- 常开器件优先选择低 Iq、低关断电流型号。
- 用 `VSYS` 或常供电 LDO 作为 GPIO 上拉电源时，应将该漏电流计入睡眠电流预算。

#### 5.2.12. 唤醒设计建议 { #5212-wake-design }

- 需要硬件唤醒的按键、触摸、传感器中断应连接到支持唤醒的 GPIO。
- 外部硬件唤醒中断建议优先在 `PA33` 到 `PA42` 范围内规划，并在原理图中标注唤醒用途。
- 应评审待机和休眠状态下的 IO 保持、高阻、上拉、下拉和外设供电状态。
- USB 接入唤醒需要将 VBUS 分压电路接到支持唤醒的 GPIO，并确保 IO 电压正确。
- 蓝牙唤醒、RTC 唤醒和外部中断唤醒应与软件低功耗策略一起评审。
