# μForge M2 接口命名规则 { #forge-m2-interface-naming-rules }

## 基础规范 { #base-specification }

本页规定 μForge 模组接口体系草案中的名称及其含义。这是一套命名约定，不是已经发布的电气或机械标准。

在这套约定中，**M2** 表示采用该体系的模组必须实现的公共基础接口。这项要求不代表现有的每款 μForge 或思澈科技（SiFli）模组都已实现 M2。M2 的引脚定义、电气要求和机械要求仍在制定中，本页不作具体规定。

在宣称 M2 兼容 M.2 E-key 之前，正式发布的 M2 定义至少应明确机械接口、引脚定义、电气限制、必需与可选信号、载板要求和符合性规则。目前的 [M2 接口定义](M2-interface-definition.md)仍是草案；仅凭 M2 名称，不能认定接口在电气上兼容 M.2，也不能认定模组与载板可互换搭配使用。

## 扩展规范 { #extension-specifications }

可选功能按 **M2xY** 扩展规范分类。名称表示功能类别，不保证某款模组实现该类别中的全部功能。

**命名格式：**

> **M2xY**

其中：

- **M2** = 基础接口规范
- **x** = 扩展分隔符
- **Y** = 扩展类别

## 扩展类别 { #extension-categories }

<div align="center"><em>M2 扩展类别</em></div>

<div align="center" markdown>

| 规范 | 说明 |
| --- | --- |
| **M2xM** | 多媒体：规划涵盖 RGB 显示、DVP 摄像头、数字麦克风和高级音频功能。 |
| **M2xA** | 模拟：规划涵盖高精度模拟 I/O 和数据采集功能。 |
| **M2xN** | 网络：规划涵盖以太网、CAN 和工业网络功能。 |
| **M2xH** | 高速：规划涵盖高带宽接口。 |
| **M2xP** | 电源：规划涵盖电源管理和大电流 I/O 功能。 |

</div>

表中说明的是各类别的规划范围，不是已经定稿的电气要求。当前可用的本地提案工作簿包含 M2 和 M2xM 触点映射。接口定义文章还列有 M2xN 和 M2xA 摘要，但目前没有这两类接口的原始触点映射资料可供核实，因此这些摘要尚未核实。M2xH 和 M2xP 仅预留了名称，尚未分配触点。

## 模组声明 { #module-declaration }

采用这套约定的模组以 **M2** 声明基础接口，并可列出已实现的一个或多个扩展。模组文档还必须说明实际采用的连接器、可选功能，以及不能同时使用的模式。

以下仅为声明格式示例，不代表已发布模组的实际配置：

- **M2**
- **M2 + M2xM**
- **M2 + M2xA**
- **M2 + M2xM + M2xN**

## 设计原则 { #design-principles }

- **M2** 的设计目标是在体系演进过程中保持稳定和向后兼容；实际兼容性仍须按对应的规范版本及具体实现验证。
- 每个 **M2xY** 扩展都有独立的功能范围。名称分开不意味着所有功能可以同时使用，也不意味着引脚分配互不影响。
- 扩展是在不修改或替换基础接口的前提下对其进行补充。
- 模组通过列出已实现的 M2xY 规范来声明其支持的能力。

选择连接器或声明兼容性前，请按[模组接口标准](interface-standards-overview.md)中的流程完成验证。
