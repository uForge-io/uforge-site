## 为什么选择 ***SF32*** { #why-choose-sf32 .uf-center-heading }

<div class="grid cards uf-why-grid" markdown>

- :fontawesome-solid-microchip:{ .uf-icon-blue } **高性能**

    各器件的核心数量与功能配置有所不同：SF32 系列涵盖单核至三核设计，多个系列采用 Cortex-M33 / STAR-MC1 处理器。缓存、FPU 和 MPU 是否提供，取决于具体芯片及 SoC 实现；请以对应型号文档为准。部分器件可提供最高 64 MB 合封 PSRAM。

- :fontawesome-brands-bluetooth:{ .uf-icon-blue } **蓝牙连接**

    不同系列和型号支持的蓝牙模式与功能有所不同。各器件支持的功能可能包括经典蓝牙和 LE、LE Audio 以及远距离 PHY。具体能力请查阅相应芯片页面。

- :fontawesome-solid-cube:{ .uf-icon-purple } **图形加速**

    2D / 2.5D GPU、LCD 控制器与 LVGL 支持流畅、丰富的图形界面。整个系列支持的接口包括 MIPI、RGB、QSPI、8080、JDI 和 EPD，分辨率最高可达 1280 × 720。

- :fontawesome-solid-volume-high:{ .uf-icon-pink } **音频子系统**

    音频能力因系列和型号而异；受支持的器件提供模拟音频、I²S、PDM 接口以及硬件辅助的数字音频处理能力。

- :fontawesome-solid-brain:{ .uf-icon-amber } **AI 加速**

    部分 SF32 器件集成神经网络加速器，可用于 TinyML 和其他边缘推理工作负载。

- :fontawesome-solid-leaf:{ .uf-icon-green } **超低功耗**

    先进的电源管理架构，专为电池供电与常开设备优化。

</div>
