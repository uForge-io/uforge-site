## 不要跳过开发板验证闭环 { #do-not-skip-the-board-validation-loop }

仅比较产品系列并成功编译一次，还不足以选定量产器件。在冻结硬件前，应先用最接近目标产品的开发板完成验证，并记录开发板名称、SDK 版本、所用示例、实测结果以及与目标产品的差异。如果最终产品使用了不同的显示屏、存储器件、电池供电路径、天线或模组载板，应分别验证这些变更。

建立初步软硬件基线后，可参考最接近的[参考设计](../../hardware/reference-designs/reference-designs.md)，结合具体实例了解完整的设计流程。

## 交接检查清单 { #handoff-checklist }

- [ ] 所选器件或模组满足产品对接口、内存、封装、供电和功耗的约束。
- [ ] 已有受支持的开发板，或已有明确的自定义硬件验证计划。
- [ ] 产品团队已接受软件路径及其成熟度。
- [ ] 在冻结分区和 BOM 决策前，已定义恢复、OTA/DFU、日志和工厂烧录需求。
- [ ] 已确认应使用的硬件设计指南、检查清单、合格供应商名录（AVL）和 EDA 库。
